## LIVE 전용 여부

**시장국면 알림은 LIVE 전용이 아니다.** `trading/notifications.py`의 공통 발행 함수와 큐에는 국면 이벤트의 PAPER/LIVE 필터가 없다. Binance 거래 사이클은 PAPER/LEARNING/LIVE 공통 단계에서 국면 확인을 호출하고, UnifiedTrader도 모드별 주문 분기 전에 국면 확인을 호출한다. 증권 분석·자동거래 역시 공통 `get_market_regime()`을 사용한다.

기관 분석 루프가 실제 실행되고, 유효한 국면 변화가 발생하며, 전체 알림·채널·국면 이벤트·기관별 허용이 켜져 있어야 한다. 최초 관찰·동일 국면·시세 부족 unknown·반복 방지 시간에는 변화 알림이 없을 수 있다. ‘PAPER에서도 가능’과 ‘PAPER로 켜두면 주기적으로 반드시 도착’은 다르다.

LIVE 전용인 것은 실계좌 손실 경고·손실 가드레일·실계좌 위험 데이터 실패 알림이다. 시장국면과 구분해야 한다. 현재 국면 메시지에는 실행 모드 자체를 넣지 않아 메시지만으로 모드를 알 수 없다.

## 감지·발송 차이와 재현

1. 코인: 기본 300초 확인, 2회 연속 확인, 최소 600초 유지. Binance는 BTC 70%·ETH 30% 가중 관찰(15분봉, 요청 10개), 공통 거래소는 BTC 15분봉(요청 20개)의 RSI·추세·거래량·30분 변화로 분류한다. 국내 현물은 BTC/KRW를 사용한다. Binance와 공통 거래소의 수치 임계값까지 동일한 것은 아니다. 거래 후보가 없거나 Binance 후보가 전부 점수 미산출이면 재선정 경로의 국면 관찰을 생략할 수 있다.
2. 증권: `get_market_regime()`은 300초 캐시 후 바뀐 결과를 즉시 알린다. 코인의 `RegimeStabilizer`와 같은 연속 확인·최소 유지 처리를 사용하지 않는다. 따라서 임계값 주변에서 알림이 더 잦을 수 있다.
3. 증권 판단 근거: 감지 함수는 지수 이력→지수 당일값→대표 종목 순으로 시도하지만 현재 4개 증권사 어댑터 클래스 모두 `get_index_history`, `get_index_price_history`, `get_index_price`를 제공하지 않는다. 현재 기본 경로는 삼성전자(005930)·POSCO홀딩스(005490)의 제공 가능한 당일 등락률 평균을 사용하는 `proxy_stock_quotes`다. 이를 한국 증시 지수 자체의 변화로 설명하면 부정확하다. 최근 사용자 메시지에도 실제 사용 근거가 포함되지 않는다.
4. 오프라인 실제 증권 감지 함수에 1.49%→1.51%→1.49%→1.51%를 301초 간격으로 공급: `volatile→bull→volatile→bull`, 변화 이벤트 3개 발생. 국면 메시지 mode 필드는 모두 부재. 코인 안정화 함수에 교대 관찰을 공급하면 2회 연속 확인을 충족하지 않아 변화 이벤트 없음. 이는 구조적 차이 재현이며 사용자 당시의 실제 시세를 재현했다는 뜻은 아니다.
5. 공통 큐에 11기관 유효 국면 전환을 각각 공급하면 11건 모두 수락한다. 외부 발송 워커는 시작하지 않았다. 따라서 ‘한국투자증권만 허용’하는 공통 하드코딩은 확인되지 않았다.

## 결론과 필요한 후속

- 사용자 착오로 종결하지 않는다. 최근 수신 기관 편중은 실제 자료에 있다.
- 자료만으로 최근 코인 국면이 바뀌지 않은 것인지, 분석 루프가 중단/생략된 것인지, 설정에 의해 제외됐는지, 전송에 실패했는지는 확정할 수 없다. 채팅 export는 도착한 메시지만 있고 보내지 못한 판단·시세·상태는 없다.
- 현행 코드에서 확인된 개선 대상은 증권의 국면 변화 안정화, 대표 종목 대용 판단 근거 표시, 모드·관찰 시각 표시, 감지/발송/억제/실패의 구분이다. 자산별 판단 기준을 무조건 같은 값으로 만들 필요는 없다.
- 기관별 마지막 유효 국면·시세 오류·실행 상태·알림 허용·최근 발송/억제 사유를 앱 안에서 함께 보여주는 진단이 필요하다. 이를 통해 사용자가 ‘알림 없음=분석 안 됨’으로 오해하지 않게 해야 한다.
- 특정 사용자의 최신 누락 원인 확정에는 같은 날짜의 런타임 로그와 비밀값을 제외한 알림/기관 실행 설정이 필요하다. API 키·Telegram 토큰을 요청할 필요는 없다. LIVE로 전환해 시험하도록 안내하지 않는다.
