## 구현

### 배포 전 후속 재감사와 수정

- 신규 판단도 기관/모드 충돌을 unknown으로 저장하던 경로를 재현했다. 신규 입력을 정규화 전에 검사하고 충돌 원문·사유를 `contract_rejections`에 보존하며 정상 학습·판단 조회에서 제외한다. 과거 DB 이관의 unknown 보존과 구분한다. 이 기능이 불충분한 역사 근거를 자동 복구한다는 뜻은 아니다.
- 증권 서비스의 공유 Recorder 기관 변경과 학습 매니저의 입력 기관 덮어쓰기를 제거했다. 관련 기존 시험 2개는 기존 덮어쓰기를 기대하고 있어, 공유 객체 불변과 호출별 기관 전달을 확인하도록 수정했다.
- 증권 자동청산 XAI의 실행 모드·종목 유형·주문 결과 연결을 보강했다. 실패/타임아웃의 success=false만으로 실제 주문 없음으로 확정하지 않는다. 주문 근거가 없으면 null을 유지한다.
- 512 MiB 진단 예산 도달 후 계속 억제되던 흐름을 보강했다. 80%부터 닫힌 날짜형 로그를 백그라운드 압축하고 공간 회수 후 캐시를 갱신하여 기록을 재개한다. 작업당 최대 8파일, 계정별 예약 간격 60초, 프로세스 내 압축 직렬화. 활성/임의 파일·심볼릭 링크는 제외한다. 압축 복원 SHA-256·원본 변경 여부·fsync 후 원본을 보관본으로 대체한다. 원본 대체 실패 시 재시도 가능하다.
- 유지관리에 보관 로그 별도 용량·압축 오류·충돌 기록 수·다음 행동을 한/영으로 표시한다. 정상 사용자가 매번 버튼을 누를 필요 없음을 안내하고 앱 매뉴얼·사용 가이드·변경 내역·빌드 지침을 동기화했다.

- 전체 Python 회귀: **3,009개 통과, 8개 환경 의존 skip, 3개 subtest 통과**, 2개 경고, 2026-09-21 후속 보강본 최종 재실행(49.82초). 저장소·학습·XAI·웹 gateway·거래소 격리·증권 PAPER·리포트·v43 복구·버전·빌드 계약 및 7개 동시 스키마 초기화 포함. 새 `test_v39144_hardening.py`는 11기관×3모드, 신규 충돌 원문 보존·학습 제외, 공유 기관 불변, 타임아웃 주문 미확정, 진단 압축 복원·활성 파일 보존·공간 회수 후 기록 재개·디스크 오류 주입·재시도·심볼릭 링크 제외를 검사한다.
- Electron 업데이트 스케줄러 Node 시험 **6개 통과**. 웹 TypeScript 검사 및 Vite production 빌드 **73 modules 통과**. 기존 1 MB대 번들 크기 경고는 남아 있으며 이 저장소 패치가 해결한 항목은 아니다.

## 남은 경계와 배포 절차

1. Windows 새 설치/기존 v43 계정 업데이트, 실제 7기관 장시간 운영, 절전·재개·백신 잠금·실제 디스크 부족·전원 차단은 미검증이다. 설치기 빌드는 사용자가 수행한다.
2. 기존 최근 JSON/저널은 최초 이관하지만 과거 `_archive_*.json/jsonl` 및 전역 중복 원본은 보존한다. 기존 전체 역사 파일을 자동 삭제·재귀속하는 작업은 아니다. 최초 이관은 추가 여유 공간이 필요하다.
3. 512 MiB는 hot 진단 파일 예산이다. 닫힌 날짜형 로그는 검증된 gzip으로 대체하며 `log_archives` 용량은 별도다. 영구 업무 원장·보관본·학습 근거까지 포함하는 전체 디스크 상한은 아니다. 활성 파일만으로 예산을 넘거나 파일 잠금/공간 부족으로 압축하지 못하면 경고와 제한이 유지된다. 파일 포맷·큐/외부 sink 때문에 엄밀한 바이트 hard cap도 아니다.
4. 모든 과거/레거시 자유 형식 로그의 모드·실주문 근거가 소급 복구되는 것은 아니다. 공통 주요 기록 경로 외 문장은 남고, 미확인 값은 unknown/null이다. XAI 근거 보존 시험이 설명 품질이나 실거래 성과 전체의 검증을 뜻하지는 않는다.
5. 거래 판단·전략 승인·PAPER/LIVE 실행·PnL 보호 정책은 바꾸지 않았다. 저장소 최적화가 미대조 PnL 복구를 대신하지 않는다.
6. `deploy/release-manifest.json`, `deploy/version.txt` 및 기존 설치 자산은 v43 증거를 그대로 보존했다. v44 산출물인 것처럼 재명명하거나 해시를 복사하지 않았다. [빌드 가이드](../docs/BUILD_GUIDE.md)에 따라 새 빌드·검증으로 재생성한다. 공개 기반 표기는 로컬 `publish_ready=true` v43 매니페스트와 동기화했으며 현재 원격 최신 릴리스를 재조회한 것은 아니다.
