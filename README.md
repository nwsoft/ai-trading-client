반복된 Tk/CustomTkinter 화면 수명주기 문제를 해소하기 위해 Python 매매·AI 엔진을 UI-neutral 런타임으로 분리하고 Web UI와 Electron 셸로 전환하고 있습니다. 화면은 DB·설정·Trader를 직접 호출하지 않고 Application Services를 거쳐야 합니다. 다만 기술 구조 변경은 사용자 화면을 새로 설계할 권한이 아니며, 기존 클라이언트의 정보·배치·동작·상태·데이터 범위를 그대로 보존해야 합니다. 현재 판정은 [Web UI 1:1 전환 실행 원장](docs/WEB_UI_1_TO_1_PARITY_EXECUTION_PLAN_v3.9.1.0.md)을 따릅니다.

- PyQt5는 Windows 키움 OpenAPI+의 `QAxWidget`/COM 연결에 필요하므로 제거하지 않습니다.
- PyQt5·pandas·루트에서 수집된 VC DLL을 모두 제거한 뒤, 빌드 아키텍처와 같은 공식 VC143 재배포 폴더의 검증된 단일 세트만 EXE 루트에 넣습니다.
- ONNX Runtime 바이너리의 PE 링커 버전보다 오래된 VC 런타임, 필수 DLL 누락, 서로 다른 릴리스 세트 혼합이면 빌드를 즉시 중단합니다.
- 빌드 완료 후 EXE 아카이브를 열어 하위 폴더 VC DLL 0개와 공식 원본 SHA-256 일치를 다시 검사합니다.
- 대시보드 import만으로 RapidOCR/ONNX 네이티브 모듈을 로드하지 않습니다. 실제 OCR 기능을 호출할 때만 초기화합니다.
- 동적 서비스·거래소 탭은 콜백 정리 후 실제 프레임까지 파괴해 CustomTkinter 메뉴·위젯 리소스가 전환 횟수만큼 남지 않게 합니다. Windows에서는 설정창/서비스 전환 전후 USER·GDI 수를 진단 로그로 남깁니다.
- Bitget·Bybit·OKX·Upbit·Bithumb 분석은 선택 거래소의 티커·캔들만 사용하며 Binance 펀딩비·OI·K라인으로 폴백하지 않습니다. Binance가 활성 범위에 없는 프로필은 Binance REST/WebSocket 런타임 자체를 만들지 않습니다.

## v3.9.0.5 Fix Patch 5 업데이트 대상 소스 (2026-08-01)

- Binance 포지션 카드는 오래된 Trader 내부 raw 클라이언트를 직접 호출하지 않고 현재 정본 `BinanceClient.get_positions_result()`를 사용합니다. 시간 오차는 서버시간 재동기화 후 한 번 재시도하며 조회 실패를 0개 포지션으로 숨기지 않습니다.

- 청산 통계는 심볼만으로 최근 행을 찾지 않고 거래소·방향·진입 주문 ID를 함께 사용합니다. 체결 성공 뒤 DB 기록 실패는 성공처럼 묵살하지 않고 오류로 기록합니다.
- 거래 통계의 `실제 체결` 건수와 체결금액은 확정 체결 원장에서, 승률·PnL은 NoahAI 청산 완료 원장에서 계산합니다.

### NoahAI의 3가지 역할

1. **금융 의사결정 보조**
   - 자산을 사고팔 때, 대출을 빌릴 때, 보험을 들 때 "올바른 선택"을 돕는 조언자
   - 거래 신호만이 아니라 "왜 그 선택을 해야 하는가"를 설명

2. **금융 이해도 향상**
   - 투자 경험이 없어도 자산을 이해할 수 있도록 돕기
   - 금융사기, 약탈적 거래, 부당한 조건으로부터 보호

3. **판단 기록 및 환류**
   - 의사결정의 근거, 결과, 교훈을 자동 기록
   - "내가 내린 결정이 맞았는가"를 나중에 검증할 수 있게 제공

### 특징

- **멀티자산 지원**: 암호화폐, 주식, ETF, 장래 글로벌 금융자산 모두 동일한 판단 인프라 사용
- **암호화폐 실증**: 암호화폐 거래를 통해 AI 판단·기록·검증 구조 검증 중
- **사용자 주도**: NoahAI는 판단과 설명을 제공할 뿐, 실행은 항상 사용자가 결정
- **생활금융 확장**: 향후 대출, 보험, 금융사기 탐지 등 일상 금융 의사결정으로 확대 예정

- **조건부 청산**: 수익률 ≥ 슬리피지+수수료 시 자동청산
- **AI 자동 TP/SL**: AI가 시장 상황에 따라 TP/SL 자동 최적화
- **레버리지 관리**: 동적 레버리지 조정
- **수수료 최적화**: 거래 비용 최소화
- **전략 커스터마이저**: 사용자 맞춤형 거래 전략 설정

### 🔐 보안 및 상태 관리
- **중복 실행 방지**: 같은 계정으로 다중 로그인 차단
- **원격 상태 체크**: 백엔드 서버와 10분마다 상태 동기화
- **자동 프로세스 관리**: 비정상 종료 시 프로세스 자동 정리
- **세션 무결성**: 다른 위치에서 로그인 시 자동 종료

### 🛡️ 트레이딩 가드레일(신규)
- 레버리지 가드레일: 거래소/전역 상한에 따라 자동 clamp (기본 상한 20)
- 마진 타입 가드레일: 기본 ISOLATED 강제, python-binance 호환(CROSS→CROSSED)
- 최소 노셔널 보정: 현재가 기반으로 최소 거래금액(기본 ≥5 USDT) 충족하도록 수량 자동 상향

### 🧰 주문 경로/성공 판정 표준화(신규)
- 주문 경로: UnifiedTradingManager 경유 표준 결과 우선, 어댑터/네이티브로 폴백
- 성공 판정: status(success/FILLED/NEW/…) 또는 id/orderId를 허용하는 범용 판정

### 🧪 Paper Trading 모드(신규)
- 설정에서 `paper_trading: true`로 켜면 실시간 시세 네트워크는 사용하되 거래소·증권사 주문 API를 호출하지 않고 주문을 시뮬레이션합니다.
- 시뮬레이션 주문은 현재가를 기준으로 처리되며 가상 포지션·손익·통계는 실계좌 포지션·실거래 통계와 분리됩니다.
- 전역 페이퍼 모드는 `실제 주문 실행 거래소` 선택보다 우선하므로, 하단 실주문 범위를 선택하지 않아도 선택된 거래소·증권사의 분석과 가상 체결이 작동합니다.
- 빠른 기능 검증이나 API 키 없이 UI/로직 검증에 유용합니다.

### 💾 거래 통계 영구 저장 시스템 (v3.8.2 신규)
- **영구 저장**: 앱 재시작 후에도 거래 통계 완전 유지
- **실시간 동기화**: 메모리와 DB 동시 업데이트로 데이터 일관성 보장
- **통합 관리**: 바이낸스와 CCXT 거래소 통계 통합 관리
- **자동 백업**: SQLite 기반 안전한 데이터 저장

### 🔄 포지션 복구 시스템 (v3.8.2 신규)
- **자동 복구**: 앱 시작 시 실제 거래소에서 포지션 자동 조회
- **대조 동기화**: 거래소 주문 ID·체결 상태와 NoahAI 원장을 대조하고 불일치는 숨기지 않음
- **안전한 재시작**: 거래 중에도 앱 재시작 가능
- **데이터 무결성**: 일치 여부와 마지막 대조 시각을 기록하고, 확인되지 않은 상태는 `대조 미확정`으로 분리

## 기술 스택

### GUI
- **React + Vite + Electron**: v3.9.1.0 목표 사용자 UI와 Windows 설치 셸
- **CustomTkinter**: v3.9.0.10 롤백 소스에만 보존하며 v3.9.1.0 bundle에는 포함하지 않음
- **PyQt5/QAxWidget**: Windows 키움 OpenAPI+ broker worker 경계에만 유지

### 백엔드
- **Python 3.8+**: 메인 프로그래밍 언어
- **SQLite**: 로컬 데이터베이스
- **WebSocket**: 실시간 데이터 통신
- **REST API**: 백엔드 서버 연동

### AI/ML
- **OpenAI GPT-4**: AI 분석 및 신호 생성
- **scikit-learn**: 머신러닝 모델
- **pandas**: 데이터 분석 및 처리
- **numpy**: 수치 계산

### 거래소 연동
- **python-binance**: 바이낸스 API 클라이언트
- **ccxt**: 통합 거래소 API 라이브러리
- **websockets**: 실시간 데이터 스트림

## 📦 설치 및 실행

### 시스템 요구사항
- **운영체제**: Windows 10+, macOS 10.14+, Ubuntu 18.04+
- **Python**: 3.8 이상
- **메모리**: 최소 4GB RAM (권장 8GB)
- **저장공간**: 최소 2GB 여유 공간
- **네트워크**: 안정적인 인터넷 연결

```bash
# 1. 저장소 클론
git clone [repository-url]
cd noahai_client

# 2. 의존성 설치
pip install -r requirements.txt

# 3. 실행
python main.py
```

2. 실행 파일을 원하는 위치에 저장
3. 더블클릭하여 실행
4. 첫 실행 시 필요한 라이브러리 자동 설치

### ✅ 빠른 스모크 테스트(선택)
- API 키 없이도 다음을 빠르게 점검할 수 있습니다.
	- 레버리지 clamp 동작
	- 최소 노셔널 보정
	- 다양한 주문 결과 포맷의 성공 판정
- 방법: `noahai_client/test_unified_system.py` 실행
- 팁: `config/settings.json` 또는 템플릿에서 `paper_trading`을 `true`로 두면 실거래 없이 전체 흐름을 검증할 수 있습니다.
