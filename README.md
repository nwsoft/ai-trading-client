# NoahAI - AI 금융 동반자 & 의사결정 인프라

## 🎯 NoahAI란?

**NoahAI는 사용자가 금융을 깊이 있게 배우지 않아도 자신의 자산·상황·위험을 이해하고 선택할 수 있도록 돕는 AI 금융 동반자입니다.**

NoahAI의 핵심은 자동매매가 아니라 **판단·설명·기록·검증·환류 구조를 갖춘 AI 금융 의사결정 인프라**입니다.

## 현재 릴리스: v3.9.0.2

- `레퍼럴` 무료회원과 서버 관리형 Binance·Bybit·OKX·Bitget 허용 정책, 사용자별 동시 실행 거래소 KPI를 추가했습니다.
- AI 커스텀은 영상·문서·Pine·텍스트를 설명 가능한 실행 규칙으로 만들고 사용자 승인·비용 반영 자동검증 뒤 운용합니다.
- SMA/EMA 20·50·200, ADX, ATR, 실제 `crossover/crossunder`, 코인 명시 청산을 지원하며 미지원 조건은 승인 전에 차단합니다.
- NoahAI 어시스턴트는 허용 설정만 최종확인 후 저장하고, 저장 재검증·사용자별 감사로그·되돌리기를 제공합니다.
- 시장 트렌드·AI 학습·AI 어시스턴트와 금융 인텔리전스·생활금융의 공통 UI를 정리하고 금융 인텔리전스에 초보자 절차·AI 사용법 질문을 추가했습니다.
- 기존 `거래 통계`와 오늘·주간·월간·실시간 AI 리포트에서 실제 체결금액을 USDT·KRW로 분리하고 검증 가능한 평균 보유시간을 확인할 수 있습니다.
- 주문·거래 시작/중지·API 키·출금 요청은 보호 작업으로 분류해 채팅에서 실행하지 않고 미실행 상태를 명확히 알립니다.
- daltrading KPI 수집·통화 분류·보유시간 코호트·DB 동시성 후속은 운영 서버에 배포됐고, Client 3.9.0.2 Windows 설치파일은 신규 빌드 전입니다.
- 검증: 전체 자동 회귀 `1,076 passed, 6 skipped`, 문서 정합성·배포 `prekey` 게이트 PASS.
- 전체 변경과 남은 외부 검증은 [릴리스 노트](RELEASE_NOTES.md)와 [업데이트 계획](docs/UPDATE_PLAN.md)을 확인하세요.

### NoahAI의 3가지 역할

1. **금융 의사결정 보조**
   - 자산을 사고팔 때, 대출을 빌릴 때, 보험을 들 때 "올바른 선택"을 돕는 조언자
   - 거래 신호만이 아니라 "왜 그 선택을 해야 하는가"를 설명

2. **금융 이해도 향상**
   - 투자 경험이 없어도 자산을 이해할 수 있도록 돕기
   - 금융사기, 약탈적 거래, 부당한 조건으로부터 보호

3. **판단 기록 및 환류**
   - 의사결정의 근거, 결과, 교훈을 자동 기록
   - "내가 내린 결정이 맞았는가"를 나중에 검증할 수 있게 제공

### 특징

- **멀티자산 지원**: 암호화폐, 주식, ETF, 장래 글로벌 금융자산 모두 동일한 판단 인프라 사용
- **암호화폐 실증**: 암호화폐 거래를 통해 AI 판단·기록·검증 구조 검증 중
- **사용자 주도**: NoahAI는 판단과 설명을 제공할 뿐, 실행은 항상 사용자가 결정
- **생활금융 확장**: 향후 대출, 보험, 금융사기 탐지 등 일상 금융 의사결정으로 확대 예정

## 🤖 AI 동반자로서 할 수 있는 것

**사용자가 물어볼 수 있는 질문들:**

- "내 자산 상태를 쉽게 설명해줄래?"
- "이 금융상품이 나에게 맞는지 비교해줘"
- "이 대출 조건이 위험한지 알려줄래?"
- "보험을 어떻게 비교해야 해?"
- "이 메시지가 금융사기인가?"
- "부모님도 이해할 수 있게 쉽게 설명해줄래?"

**AI 어시스턴트가 제공하는 것:**

- 자산·거래·제품 분석 및 설명
- 위험도 평가 및 경고
- 비교 분석 및 추천
- 금융사기 탐지 및 경고
- 실시간 모니터링 및 알림
- 의사결정 기록 및 성과 검증

## 🚀 주요 기능

### 🤖 AI 기반 금융 의사결정
- **실시간 기술적 분석**: RSI, MACD, 볼린저 밴드, 이동평균 등
- **AI 신호 생성**: SHORT/LONG/HOLD 신호 자동 생성
- **패턴 인식**: 과거 데이터 기반 패턴 학습 및 최적화
- **자동 파라미터 조정**: TP/SL/Position Size 자동 최적화
- **AI 채팅 전략**: 실시간 대화를 통한 전략 커스터마이징
- **AI 학습 시스템**: 거래 결과 기반 자동 학습 및 개선

### 📊 실시간 모니터링
- **실시간 시세**: 바이낸스 WebSocket 연동
- **포지션 관리**: 활성 포지션 실시간 추적
- **수익률 계산**: 실시간 P&L 모니터링
- **리스크 관리**: 자동 청산 조건 설정
- **AI 리포트**: 자동 생성되는 시장 분석 리포트

### 🎯 실행 연계 및 리스크 가드레일
- **조건부 청산**: 수익률 ≥ 슬리피지+수수료 시 자동청산
- **AI 자동 TP/SL**: AI가 시장 상황에 따라 TP/SL 자동 최적화
- **레버리지 관리**: 동적 레버리지 조정
- **수수료 최적화**: 거래 비용 최소화
- **전략 커스터마이저**: 사용자 맞춤형 거래 전략 설정

### 🔐 보안 및 상태 관리
- **중복 실행 방지**: 같은 계정으로 다중 로그인 차단
- **원격 상태 체크**: 백엔드 서버와 10분마다 상태 동기화
- **자동 프로세스 관리**: 비정상 종료 시 프로세스 자동 정리
- **세션 무결성**: 다른 위치에서 로그인 시 자동 종료

### 🛡️ 트레이딩 가드레일(신규)
- 레버리지 가드레일: 거래소/전역 상한에 따라 자동 clamp (기본 상한 20)
- 마진 타입 가드레일: 기본 ISOLATED 강제, python-binance 호환(CROSS→CROSSED)
- 최소 노셔널 보정: 현재가 기반으로 최소 거래금액(기본 ≥5 USDT) 충족하도록 수량 자동 상향

### 🧰 주문 경로/성공 판정 표준화(신규)
- 주문 경로: UnifiedTradingManager 경유 표준 결과 우선, 어댑터/네이티브로 폴백
- 성공 판정: status(success/FILLED/NEW/…) 또는 id/orderId를 허용하는 범용 판정

### 🧪 Paper Trading 모드(신규)
- 설정에서 `paper_trading: true`로 켜면 네트워크/실거래 없이 주문을 시뮬레이션합니다.
- 시뮬레이션 주문은 현재가를 기준으로 정상 진입 처리되며 포지션 기록/모니터링 플로우는 동일하게 작동합니다.
- 빠른 기능 검증이나 API 키 없이 UI/로직 검증에 유용합니다.

### 💾 거래 통계 영구 저장 시스템 (v3.8.2 신규)
- **영구 저장**: 앱 재시작 후에도 거래 통계 완전 유지
- **실시간 동기화**: 메모리와 DB 동시 업데이트로 데이터 일관성 보장
- **통합 관리**: 바이낸스와 CCXT 거래소 통계 통합 관리
- **자동 백업**: SQLite 기반 안전한 데이터 저장

### 🔄 포지션 복구 시스템 (v3.8.2 신규)
- **자동 복구**: 앱 시작 시 실제 거래소에서 포지션 자동 조회
- **완전 동기화**: 바이낸스와 CCXT 거래소 포지션 완전 동기화
- **안전한 재시작**: 거래 중에도 앱 재시작 가능
- **데이터 무결성**: 실제 거래소와 앱 내 포지션 100% 일치

## 📦 설치 및 실행

### 시스템 요구사항
- **운영체제**: Windows 10+, macOS 10.14+, Ubuntu 18.04+
- **Python**: 3.8 이상
- **메모리**: 최소 4GB RAM (권장 8GB)
- **저장공간**: 최소 2GB 여유 공간
- **네트워크**: 안정적인 인터넷 연결

### 빠른 설치
```bash
# 1. 저장소 클론
git clone [repository-url]
cd noahai_client

# 2. 의존성 설치
pip install -r requirements.txt

# 3. 실행
python main.py
```

### 실행 파일 사용 (권장)
1. **AITrading.exe** 다운로드
2. 실행 파일을 원하는 위치에 저장
3. 더블클릭하여 실행
4. 첫 실행 시 필요한 라이브러리 자동 설치

### ✅ 빠른 스모크 테스트(선택)
- API 키 없이도 다음을 빠르게 점검할 수 있습니다.
	- 레버리지 clamp 동작
	- 최소 노셔널 보정
	- 다양한 주문 결과 포맷의 성공 판정
- 방법: `noahai_client/test_unified_system.py` 실행
- 팁: `config/settings.json` 또는 템플릿에서 `paper_trading`을 `true`로 두면 실거래 없이 전체 흐름을 검증할 수 있습니다.
