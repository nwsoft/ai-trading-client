## 2026-08-15 12시 사용자 실화면 재감사

정오에 캡처된 실제 Web UI에서 다음 실패를 확인했다. 이전 표의 `MAC RENDER PASS` 중 소스 연결이나 일부 화면만 보고 전체 동등성으로 확대한 항목은 철회한다.

- Electron 기본 실행 아이콘 노출, 로그인 카드 하단 여백 불일치
- 실시간 로그의 내부 높이 계약 누락으로 창 전체가 로그 길이만큼 늘어남
- 코인 정보와 BINANCE가 동시에 활성화되는 탭 상태 충돌
- 코인 정보가 기존 AI 평가 화면이 아니라 차트·엔진 명령·원시 DB 표로 대체됨
- 거래소 화면이 기존 제어·잔고·포지션·통계·로그 전용 화면과 다름

현재 소스에서는 제품 아이콘 계약, 로그인 카드 높이, 고정 대시보드/내부 로그 스크롤, 기능 탭과 source 탭의 상호배타 상태, 코인 정보·거래소 전용 워크스페이스, 기존형 AI 어시스턴트와 AI 커스텀 상단 흐름을 재작업했다. 실시간 로그 안에 임의로 추가했던 `XAI 판단·체결 감사` 중복 보기는 제거하고, 판단·체결 근거는 AI 리포트의 `실행 품질`과 하단 감사 원장에서 확인하도록 원래 정보 구조에 맞췄다. 이 변경은 `SOURCE PASS`이며 빌드 후 macOS 재렌더·기존 화면 나란히 대조·Windows E2E 전에는 화면 PASS가 아니다.

2026-08-15 16시 실제 Electron 재검증에서는 저장된 로컬 로그인 정보로 대시보드에 진입하되 LIVE 명령은 실행하지 않았다. 기본 실시간 로그는 2026-08-15 최신 행, BINANCE source 로그도 최신 행으로 자동 이동했다. 주식/증권은 `AI 학습 / AI 리포트 / AI 어시스턴트 / AI 커스텀` 독립 탭과 증권 전용 로그를 사용했고, 하단 상태/업데이트/AI 실행 기록 영역도 실제 렌더에서 확인했다. 다만 BINANCE 잔고는 외부 계좌 응답이 없어 `새로고침 필요`로 표시됐으므로 실제 계좌·주문 E2E와 전체 탭 나란히 대조는 OPEN이다.

오후 추가 제보에서 주식/증권 화면이 블록체인 전역 `selected_source`, Binance 로그와 `selected_coins`를 재사용하는 서비스 경계 오류를 확인했다. 현재 소스는 블록체인/증권의 선택 소스·활성/실행 source·로그를 각각 분리하고, 증권 후보 저장소가 없을 때 암호화폐 후보를 주식으로 표시하지 않고 `stock_candidate_store_unavailable` 빈 상태로 실패 폐쇄한다. 하나로 합쳤던 증권 AI 허브는 철회하고 `AI 학습 / AI 리포트 / AI 어시스턴트 / AI 커스텀`을 기존처럼 독립 탭으로 복원했다. 이는 SOURCE/회귀 PASS이며 실제 증권사 연결 E2E를 대신하지 않는다.

## 판정 규칙

- `SOURCE`: 코드·API 계약만 확인했다. 화면 완료를 뜻하지 않는다.
- `MAC RENDER`: macOS Electron 개발 실행에서 실제 창을 열어 확인했다.
- `LEGACY COMPARE`: 같은 항목의 기존 CTk 화면/흐름과 나란히 대조했다.
- `WINDOWS E2E`: 완성 Setup 설치본으로 Windows에서 반복 검증했다.
- 한 항목이 `SOURCE`만 PASS면 전체 화면 동등성은 미완료다.

### 아직 PASS가 아닌 명시적 사용자 흐름

2026-08-16 소스/Mac 보강에서 아래 흐름은 구현하고 실제 개발 브라우저로 렌더·실패 폐쇄를 확인했다. 다만 동일 계정 레거시/EXE 나란히 비교와 Windows E2E가 없어 최종 PASS로 올리지 않는다.

- AI 모델 조회·기능 검증은 사용자 명시 클릭과 intent 헤더가 있어야만 실행되며, 키 미설정은 실패와 조치를 반환한다. 3개 설명 프리셋과 5문항 초기 설정 진입도 저장 전 확인 흐름으로 연결했다.
- 거래소·증권 연결은 공식 포털 링크, 실제 계정 snapshot 점검, 비밀값 없는 지원 요약 복사/TXT 저장 흐름을 갖췄다.
- AI 시스템 준비도는 네트워크 호출 없이 로컬 상태를 표시하고 미준비 LIVE는 `LIVE 차단`으로 표현한다.
- AI 어시스턴트는 설정 기반 브라우저 STT/TTS, 설정관리·차트분석 동작을 연결했다. 키/마이크/실계정이 필요한 성공 E2E는 아직 열려 있다.
- 매뉴얼은 11개 정본 탭, 전체 검색의 다음 탭 순환, 본문 강조, 결과 탭 수, 설정·AI 커스텀·거래소·증권 딥링크를 연결했다.

- 설정 `AI 엔진/API`: 제공사별 모델 새로고침, 실제 API 기능 검증, 절약형/균형형/정밀형 프리셋, 5문항 초기 설정, 음성 모듈/TTS의 실제 동작을 레거시와 대조해야 한다.
- 설정 `거래소 API`: 공식 발급 경로, 증권 연결 점검, 지원요약 복사·파일 저장, 오류 후보와 조치 안내를 동일한 사용자 흐름으로 복원해야 한다.
- 설정 `고급 매매 계층`·`AlphaArena`: 각 항목의 역할·기본값·적용 범위·위험 경고와 저장 후 적용 계약을 실제 현재값 기준으로 검증해야 한다.
- 매뉴얼: 레거시 클래스에 정의된 메서드 수가 아니라 `show_manual()`에서 실제 열리는 11개 탭을 정본으로 확정했다. 탭 이름과 본문 전체를 빌드 산출물로 자동 추출해 Web 전용 축약·재작성을 제거했다. 화면 크기, 처음 사용 순서, 설정 딥링크, 오류 검색, AI 질문의 현재 기능 정합은 계속 전수 대조해야 한다.
- AI 어시스턴트: 음성 입력·설정관리·차트분석·심층분석이 버튼 모양이 아니라 실제 동작까지 이어지는지 검증해야 한다.
- AI 커스텀: 멘토 8문항, 12단계 안내, 원본 근거, XAI, 전략 수정·새 버전·승인·삭제·PAPER가 같은 전략 ID/버전으로 끝까지 연결되는지 검증해야 한다.
