# v3.9.1.41 · 시장 트렌드 시각화와 근거형 XAI 관찰 후보

기준일 2026-09-19. 소스 후보 **3.9.1.41**, updater **3.9.141**. 공개 stable/latest는 **v3.9.1.40**이며 공개 자산과 manifest는 변경하지 않습니다.

## 수정 계약

같은 v41 후보에 [KPI·원격 관리 실행 계획](V39141_REMOTE_KPI_IMPLEMENTATION_PLAN.md)의 변경이 추가되었습니다. 아래 2,639건/63 modules/fingerprint는 시장 트렌드 변경 직후 기록이며 최신 전체 결과는 [통합 검증 보고](../reports/v39141-remote-kpi-verification.md)를 사용합니다.

- 코인과 주식·ETF 화면에서 `오늘 / 7일 / 30일`을 같은 기간 기준으로 비교합니다.
- 원형 그래프는 상승·중립·하락의 **표본 구성 비율**에만 사용합니다. 가격 흐름은 미니 선, 방향·변동성은 막대와 숫자로 함께 표시합니다.
- 코인은 기관 capability에 따라 KRW 현물과 USDT 선물의 공개 캔들을 구분합니다. 펀딩비와 롱·숏 비율은 제공 기관에서만 표시하며 이를 공포·탐욕지수로 바꾸어 부르지 않습니다.
- 주식 오늘은 공개 당일 시세, 7일·30일은 선택 증권사의 일봉을 순차 조회합니다. 일봉이 없거나 실패하면 오늘 값으로 대체해 장기 수익률인 것처럼 표시하지 않습니다.
- 화면은 고정 대표 표본(코인 3개, 주식 6개)의 동일가중 요약입니다. 전체 시장 지수나 개인 계좌 추천으로 표현하지 않습니다.
- 실제 공포·탐욕, 미결제약정, 청산, BTC 도미넌스와 외국인·기관 수급, 환율, 금리, 공시·뉴스가 없으면 `누락 데이터`로 명시합니다.
- `이 시장 브리핑 AI에게 묻기`와 `관찰 후보 XAI 비교`는 기관·기간·수집 시각·표본·누락 항목을 구조화된 화면 근거로 전달합니다. 로컬 답변은 지지 근거·반대 근거·무효화 조건을 포함합니다.
- 관찰 후보는 개인화 매수·매도 추천이나 주문 지시가 아닙니다. 실제 주문과 Strategy Studio 적용은 기존 승인·검증·PAPER/LIVE 경계를 그대로 따릅니다.
