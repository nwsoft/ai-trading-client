### **Phase 1 (즉시~2주)**: AI 어시스턴트 강화 🎯 **추천**

**기간**: 2026년 4월 28일~5월 10일 (1~2주)  
**목표**: 현재 프로토타입의 실질적 가치 확대 (규제 위험 제로)

**액션 항목**:

#### 1-1. 개인화 점수 계산 강화
```python
# LifeFinanceAssistant 또는 LifeFinanceWidget에 추가
사용자 입력:
  - 신용도 등급: "좋음" / "보통" / "낮음"
  - 위험도: "회피형" / "보수형" / "공격형"
  - 소득 안정성: "안정" / "변동"

점수 조정:
  - 신용도 좋음 → 대출 금리 -0.5% 시뮬레이션
  - 보험 위험도 높음 → 보장 범위 확대 추천
  - 예적금 정기성 → 적금 우선 추천
```

#### 1-2. 대화형 "AI 상담" 강화
```
사용자: "신용도가 좋으면 금리가 얼마나 낮아질까요?"
AI: "당신의 신용도(좋음)를 기반으로, 
    KB국민은행 주택담보는 기본 4.05% → 우대금리 3.75% 가능합니다."
    
사용자: "그럼 신청하려면?"
AI: "현재는 상품 비교 단계입니다. 
    실제 신청은 각 금융사 웹사이트에서 직접 진행하시면 됩니다.
    (향후 원스톱 신청 지원 예정)"
```

#### 1-3. UI 표기 개선
```
🧪 생활금융 금융상품 비교 (프로토타입/데모)
  • 현재: 더미 데이터 기반 시뮬레이션
  • 실제 금리/상품: 금융사 웹사이트 확인 필수
  • 피드백 기록: [피드백하기] 버튼 추가
```

**의존사항**: 없음  
**비용**: 개발팀 2주 (저비용)  
**효과**:
- ✅ 사용자에게 실질적 AI 상담 가치 제공
- ✅ 규제 위험 제로 (더미 명시)
- ✅ 피드백 수집 → Phase 2 의사결정 자료

**신청 링크**: [AI 상담 예시]
```
(현재 구현 예정 섹션)
```

### **Phase 2 (4~8주 후)**: 금융사 파트너십 탐색

**기간**: 2026년 5월 중순~7월 초 (4~8주)  
**목표**: 실제 금융사 데이터 연동 가능성 검토 및 협의

**액션 항목**:

#### 2-1. 전략 수립 (1개월)
- [ ] 비즈니스 정체성 명확화
  - NoahAI의 수익 모델: 투자자 기능료? vs 일반인 중개 수수료?
  - 생활금융 추가 이유: 사용자 기반 확대? vs R&D 자금? vs 둘 다?

- [ ] 파트너 대상 선정 (Tier별)
  - **Tier 1** (데이터 공유 가능성 높음): KB금융, 신한금융, 카카오뱅크
  - **Tier 2** (중간): 하나은행, 우리은행, NH농협
  - **Tier 3** (저): 핀테크 데이터 업체 (월정액 비용 있음)

#### 2-2. 파트너십 협의 (2개월)
- [ ] BD 담당자 모집 (영업 1명 + 법무 담당 1명)
- [ ] Tier 1 금융사와 MOU 협의
- [ ] 금융위 규제 샌드박스 신청 준비

#### 2-3. 규제 검토 (1개월)
- [ ] 금감원 규제 요건 문서화
  - 부정확한 상품 정보 제공 시 벌칙
  - 신용도/소득 정보 수집 기준
  - 광고법상 "추천" 표현 제한

**의존사항**: 경영진 의사결정, BD팀 구성  
**비용**: BD 투입 (예상 300만원~500만원/월)  
**효과**:
- ✅ 실제 금융사 파트너십 확보 가능성 검증
- ✅ 정부 R&D 지원 대상 확대 (BUSINESS_PROPOSAL 연계)
- ⚠️ 성공 보장 없음

**성공 기준**:
- 최소 1개 금융사 (대출 또는 보험)의 데이터 공유 합의

---

### **Phase 3 (4~8주 후)**: MVP 실제 데이터 연동

**기간**: 2026년 7월~8월 (4~8주, Phase 2와 병렬 가능)  
**목표**: 첫 금융사(1개)와의 실제 데이터 연동 및 운영

**액션 항목**:

#### 3-1. 첫 금융사 선정 및 기술 연동 (2개월)
- [ ] 파트너 선정: KB국민은행 (대출) 또는 신한은행 (전 상품)
- [ ] API 또는 크롤링 기술 검토
- [ ] 매일 갱신 파이프라인 구축

#### 3-2. UI 개선 (1개월)
- [ ] 사용자 신용도 입력 폼 추가
- [ ] 개인화 점수 실시간 반영
- [ ] 신청 링크 추가 ([금융사 바로가기] 버튼)

#### 3-3. 추적 및 피드백 (1개월)
- [ ] 사용자 선택 기록 시스템
- [ ] 만족도 설문 (선택한 상품 후 평가)
- [ ] A/B 테스트 (추천 vs 자유 선택)

#### 3-4. 규제 준수 (지속)
- [ ] 금감원 신고 (대출중개 신고)
- [ ] 개인정보보호 감시
- [ ] 월간 규제 준수 리포트

**의존사항**: Phase 2 협상 진행 중 (완료 대기 불필요, 병렬 진행 가능)  
**비용**: 개발팀 투입 (기술 검증 우선)  
**효과**:
- ✅ 실제 사용자 가치 제공 시작
- ✅ 신뢰도 향상 (실제 금융사 데이터)
- ✅ 수익 창출 경로 구체화 (중개 수수료 등)

**성공 기준**:
- 월 100+ 사용자의 실제 신청
- 사용자 만족도 4.0점 이상 (5점 만점)

### **Phase 4+ (12개월 이후)**: 확장 및 고도화

**기간**: 2027년 4월~지속  
**목표**: 다중 금융사 확대 및 심화 기능 구현

**확장 전략**:
- 보험 (현대해상, 삼성생명 등) 추가
- 예적금 (전 은행권) 확대
- 자동 분류 및 시뮬레이션 기능
