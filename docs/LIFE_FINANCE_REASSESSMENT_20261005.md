## 판단

현재 생활금융은 기초 기록·상황 안내·조건을 아는 사용자의 수동 비교에 사용할 수 있다. 상품을 모르는 사용자가 자신에게 맞는 실상품을 찾고, 차이를 이해하고, 실제 상담 결과까지 이어가는 서비스로는 부족하다. 보험·대출·예적금 모두 추가 수정이 필요하다. UI의 일관된 색상·카드·접기 구조와 사용자가 과업을 끝낼 수 있는지는 별도로 평가한다.

기존 테스트 통과는 구현한 계약의 회귀 근거다. 상품 공급 범위, 실제 AI 설명 품질, 초보자 성공률, 기관 접수 성공을 입증하지 않는다. 이 평가에서 임의의 완성도 점수나 사용자 만족도 수치를 만들지 않는다.

## UI 평가

색상·간격·컴포넌트 일관성과 비교표의 내부 스크롤은 개선됐다. 그러나 사용 흐름은 아직 긴 설명과 수동 입력에 치우쳐 있다. 매뉴얼은 정보를 찾고 읽으면 되지만, 금융상품 화면은 사용자가 모르는 항목을 찾아내고 다음 행동을 도와야 한다.

입력 요소에는 체크박스·선택창·잠금 입력이 포함되며 모두 필수라는 뜻은 아니다. 전체 높이도 위에서 아래까지의 흐름 길이이며 화면 밖 가로 넘침을 뜻하지 않는다. 수치는 합성 QA 환경의 관찰치로, 실제 사용자 이탈률 측정값이 아니다.

후속 화면의 목표 흐름:

1. ‘처음 알아보기 / 받은 견적 비교 / 기존 계약 점검 / 작성 중인 계획’ 진입을 분리한다.
2. 처음에는 목적·금액 또는 예산·사용 시점처럼 필요한 질문 3~5개 이내만 제시한다. 모름/건너뛰기를 허용한다.
3. 후보 카드에는 왜 표시했는지, 확인된 조건, 아직 모르는 조건, 다음 행동 하나를 보여준다. 탐색 자료와 개인 견적 배지를 구분한다.
4. 결과에서는 핵심 차이 3개와 월 부담/총비용/사용 가능 시점 등을 먼저 보여주고 세부 가정은 펼쳐 본다.
5. 견적이 없으면 질문 정리·저장·상담 준비로 이어진다. 견적이 있을 때만 해당 입력 폼을 연다. 이미 선택한 이름을 다시 입력하게 하지 않는다.
6. 보관함의 잠금 목적과 저장 상태를 같은 위치에서 설명한다. 재진입/탭 이동/재시작은 동의한 암호화 초안에서 복원한다. 잠금·로그아웃 시 화면에는 민감정보를 남기지 않는다.

## 사용자 관점의 완료 기준

| 과업 | 완료 기준 |
|---|---|

| 기존 보험 사용자 | 본인이 확인한 기존 보장과 새 후보를 연결하고 유지·추가·변경의 비용/미확인을 구분한다 |
| 주거/신용/대환 사용자 | 목적이 다른 후보가 추천으로 섞이지 않고 월 부담·총비용·미확인 견적을 이해한다 |
| 예금/적금/비상금 사용자 | 돈을 쓸 시점과 납입 방식에 맞춰 진행하며 비상금 선택으로 기능이 막히지 않는다 |
| AI 질문 | ‘이 두 상품의 차이’, ‘예산을 낮추면’, ‘왜 제외됐나’에 같은 화면 상태·같은 버전 근거로 답한다 |
| 자료/키/기관 장애 | 자동 재전송/확정값 생성 없이 입력을 보존하고, 재시도·로컬 준비·운영 문의 경로를 제시한다 |

출시 전 비개발자 10명 이상의 관찰 시험을 제안한다. 지정 핵심 과업에서 80% 이상이 매뉴얼·직원 도움 없이 5분 안에 ‘후보 차이 이해+저장/상담 준비’를 완료하는 것을 초기 목표로 삼는다. 실제 기관 견적 회신 시간은 이 5분 목표에 포함하지 않는다. 실패 사유·이탈 위치·필드 오류를 익명화하여 개선하고 단순 버튼 클릭 성공으로 대체하지 않는다.

AI는 보험/대출/저축·부정/다중 목적·무자료/만료·조건 변경을 포함한 고정 한국어 평가셋과 실제 지원 계정의 응답으로 검증한다. 근거 없는 보험료/금리/가입 승인 확정은 허용하지 않고, 정확도·근거 일치·보류 적절성·P50/P95·비용을 함께 기록한다. 테스트 개수나 한 모델의 이름만으로 품질을 보증하지 않는다.

기존 거래 엔진·보호 기준, 계정별 데이터 격리, 계산·암호화·동의·중복 접수 방지 회귀를 유지한다. 자료 확대와 UI 변경을 이유로 그 경계를 완화하지 않는다.

## 3.9.2.5 후속 구현 상태 보충

미체크된 F07~F08/데이터 운영/상담 항목은 코드가 없다는 뜻이 아니다. 관심 자료 재점검, 검토 피드 배포 수신·롤백·재개, 상담 담당·응답 예정·반환 견적 가져오기까지 구현했으며 실제 운영 URL/수신처 인수가 남아 있다. 분야별 최소 2개 회사 자료, 실제 공급·모델 평가·초보자 관찰·MyData와 Windows 출시는 완료로 표시하지 않는다. 세금은 요청 귀속연도와 적용 연도 미검증을 구분하며 새로운 귀속연도 법령을 검증한 것으로 표시하지 않는다.
