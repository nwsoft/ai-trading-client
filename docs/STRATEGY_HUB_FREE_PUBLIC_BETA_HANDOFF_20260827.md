# NoahAI Verified Strategy Hub ↔ daltrading 무료 공개 베타 연결

- 기준일: 2026-09-18
- 클라이언트 계약: `.noahstrategy` schema 1
- 공개 허브: `https://daltrading.net/strategies`
- 상세 서버 실행계획: `../../daltrading/docs/STRATEGY_HUB_FREE_PUBLIC_BETA_EXECUTION_PLAN_20260827.md`

> 클라이언트 최종 사용자 명칭은 `NoahAI Strategy Studio`다. 전환 기간에는 `전략 스튜디오 (기존 AI 커스텀)`으로 병행 표기할 수 있다. 전체 단계는 [Strategy Studio 마스터 플랜](NOAHAI_STRATEGY_STUDIO_MASTER_PLAN.md)을 따른다.

> 현재 상태: Strategy Studio는 제공 중이며 Strategy Hub는 무료 공개 테스트 중이다. `Marketplace`는 향후 전체 생태계 명칭으로 사용할 수 있지만, 결제·환불·분쟁·제작자 정산이 열리기 전에는 현재 유료 마켓으로 표현하지 않는다.

## 사용자 흐름

1. Strategy Studio에서 원본 분석과 XAI 검토를 완료한다.
2. 전략 버전을 저장하고 사용자가 승인한다.
3. 자동검증과 PAPER 전진검증 근거를 확인한다.
4. `패키지 내보내기`로 `.noahstrategy` 파일을 만든다.
5. Strategy Studio 상단의 `무료 전략 허브 열기`로 daltrading에 로그인한다.
6. 파일과 공개 설명·권리 근거를 제출한다.
7. 권리 자기선언과 패키지·IR 구조 검사를 통과하면 E0로 공개된다. 운영자 사전승인은 요구하지 않는다.
8. 다른 회원은 무료로 다운로드한 뒤 NoahAI의 `전략 가져오기`를 사용한다.
9. 가져온 전략은 항상 비활성 검토 버전이며 승인·검증·PAPER를 다시 거쳐야 한다.
10. 제작자는 `내 전략 제출`에서 공개 중지를 요청할 수 있으며 요청 즉시 신규 다운로드가 차단된다. 운영자는 감사 기록을 보존한 채 중지를 확정하거나 반려·재공개한다.

실제 투자 시드는 제출 조건이 아니다. 제작자는 실계좌 주문 없이 과거 재생과 PAPER 가상 체결 근거를 쌓아 E0 전략을 공유할 수 있다. 다만 PAPER는 거래소 확인 체결이 아니므로 여권에서 E3 PAPER와 E5 확인 체결을 분리한다.

## 회원 제출 위치와 자동화 경계

- 대시보드 `전략 스튜디오 → 내 프라이빗 전략 버전`에 `내 전략 제출` 버튼을 둔다.
- 각 버전 행에는 `패키지 내보내기`와 `허브에 제출`을 함께 표시한다.
- 제출은 자동화하지 않는다. 전략은 사용자 지식재산이므로 앱이 저장·승인·PAPER 상태만으로 외부 전송하지 않는다.
- 회원이 `.noahstrategy` 파일, 공개 제작자명, 적용 시장·거래소·국면, 위험 수준, 공개 설명과 권리 근거를 직접 확인해야 제출된다.
- daltrading의 제출 위치는 `https://daltrading.net/strategies/submit`, 전체 사용법은 `https://daltrading.net/strategies/guide`다.

## 저장 위치

| 단계 | 저장 위치 | 공개 여부 |
|---|---|---|
| NoahAI 프라이빗 전략 | `Documents/NoahAI/<계정>/custom_strategies` | 사용자 PC 계정 범위, 비공개 |
| 패키지 내보내기 | 운영체제가 선택한 다운로드 위치 | 사용자가 파일을 전달하기 전까지 로컬 |
| daltrading 제출 원본 | 서버 `DALTRADING_STRATEGY_PACKAGE_DIR` 아래 서버 생성 제출 ID | 공개 웹 경로 아님, 권한 제한 저장 |
| 제출·검증 메타데이터 | daltrading DB의 제출·여권·검증·신고·감사·다운로드 원장 | 공개 여권의 허용 필드와 증거 단계만 노출 |
| 다운로드 후 가져오기 | 다시 `Documents/NoahAI/<계정>/custom_strategies` | 비활성 검토 버전 |

서버 저장소는 접근 권한을 제한하지만 현재 파일 자체를 별도 암호화한다고 주장하지 않는다. 백업은 DB와 패키지 디렉터리를 같은 시점으로 묶어야 한다.

공개 중지는 파일 삭제가 아니다. 제작자 요청 즉시 공개 카탈로그와 신규 다운로드를 실패 폐쇄하고, 운영자 처리 결과와 사유를 별도 원장에 남긴다. 이미 내려받은 로컬 복사본을 원격 삭제한다고 약속하지 않는다.

## 신뢰와 백테스트 경계

- 백테스트는 과거 규칙 재생이며 미래 수익 증명이나 인증서가 아니다.
- 기간 선택, 미래 데이터 누출, 데이터 스누핑, 과최적화, 생존자 편향, 낮은 표본, 수수료·슬리피지 축소로 결과를 좋게 만들 수 있다.
- 패키지에 적힌 자기신고 승률·수익률은 랭킹 점수로 사용하지 않는다.
- 서버는 패키지 SHA-256, IR SHA-256, 금지필드, 비활성 가져오기 계약을 독립 재검사한다.
- E0 공개에는 제작자 권리 자기선언, 패키지·IR 무결성, 금지필드·비활성 가져오기 계약과 `supported` 실행 구조가 필요하다. 미사용 구간 표본 30개 이상, 워크포워드, PAPER 3체결·7일 이상, 가드레일·실행·설명·지원 품질은 상위 증거 단계 승격 기준이다.
- 랭킹은 강건성, 위험 효율, 실행 품질, PAPER·실체결 증거, 설명·운영 품질을 분리한다. 원시 승률·총수익률과 통화가 다른 PnL은 합산하지 않는다.
- 이 장치들은 허위·과장 가능성을 낮추고 근거를 추적하게 하지만 조작 불가능이나 미래 수익을 보장하지 않는다. 다운로드 사용자는 자신의 계정에서 검증과 PAPER를 다시 수행한다.

## 무료 베타 이후 수익원

1. 무료 베타: E0 즉시 공개·증거 단계·신고 기반 사후 검토·목적별 탐색·다운로드·철회·감사 안정화
2. 무료 원장 준비: 신규 다운로드를 `FREE` 취득 거래와 계정별 영구·비독점 실행 라이선스로 기록
3. 제작자 운영: 제작자 프로필, 버전 업데이트, 서버 서명, 검증 리포트
4. 유료 준비: Noah Point 충전, 상품·가격 스냅샷, 전략 버전 구매, 제작자 수익 원장, 구매 권한과 클라이언트 E2E
5. 결제수단 확장: 카드·계좌 결제를 먼저 연결하고 외부 코인 결제를 통한 Noah Point 충전을 후속 추가
6. 수익 모델: 전략 버전 영구 실행 라이선스, 독립 검증 서비스, B2B 감사 도구. 성과 기반 과금 제외
7. 금지 원칙: 광고·결제로 랭킹을 올리거나 검증되지 않은 수익률을 판매 근거로 사용하지 않음
8. 선택적 블록체인: 스키마·권리·철회 운영이 안정된 뒤 패키지 해시·버전·공개·철회 상태만 앵커링. 원문·개인정보·거래내역·API 키는 온체인 금지

현재 `strategy_download_audit`와 함께 가격 0인 제공 스냅샷, `FREE` 취득 거래와 계정별 영구·비독점 실행 라이선스를 기록한다. 패치 이전 무료 다운로드 감사도 합법적 무료 취득 시각을 보존해 1회 마이그레이션하며, 반복 다운로드는 같은 취득·라이선스를 재사용한다. 취득자는 전략 소유권 전체가 아니라 해당 전략 버전의 NoahAI 실행 라이선스를 취득한다.

회원·팀 비공개 공유는 현재 일반 사용자 무료 베타·Marketplace 완료 조건에서 제외한다. 향후 B2B·기관 수요가 확인될 때 별도 권한 서비스로 검토한다.

## 안전 경계

- 전략 파일에 API 키, 시크릿, 패스프레이즈, 계좌번호, 잔고, 개인 거래내역, 로컬 절대경로를 포함하지 않는다.
- 승인·활성 상태와 LIVE 확인값은 패키지로 전달하지 않는다.
- 다운로드 횟수나 랭킹이 수익 보장 또는 자동 실행 권한을 의미하지 않는다.
- daltrading 서버는 전략을 실행하지 않고 패키지·IR 무결성과 공개 정책만 검증한다.
- 최종 호환성·사용자 승인·PAPER·LIVE 실행 게이트의 정본은 설치된 NoahAI 클라이언트다.
- PAPER E4 전략도 제출·랭킹·다운로드와 향후 판매 대상이 될 수 있으며 LIVE E5는 별도 상위 증거다. 두 실행모드의 성과를 합산하지 않는다.
- 포인트·라이선스·코인 결제 단계는 `docs/STRATEGY_MARKETPLACE_POINTS_AND_LICENSE_PLAN.md`를 따른다.

## 배포 증거 구분

- 이 문서와 Web UI 링크 변경: NoahAI 소스 변경
- `npm test`/`npm run build`: Web UI 소스 회귀·빌드 확인
- Windows 설치본에서 외부 링크와 내려받기·재가져오기 확인: 클라이언트 배포 확인
- daltrading 실서비스 제출·승인·다운로드 확인: 서버 무료 베타 배포 확인

서로 다른 네 가지 증거를 하나의 완료 주장으로 합치지 않는다.
