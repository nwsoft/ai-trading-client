## 1. 발명의 명칭

실행 분리형 AI 의사결정 인프라 및 판단 감사 재현 방법

## 2. 기술분야

본 발명은 AI 기반 의사결정 시스템, 상태 관리 시스템, 로그 감사 시스템, 실행 분리 아키텍처, 재현 검증 기술에 관한 것이다.

본 발명은 금융을 대표 실시예로 포함하되, 의료, 교육, 커머스, 운영지원, 보안, 고객지원, 다중 에이전트 운영 등 다양한 산업의 의사결정 업무에 적용 가능한 범용 인프라 기술이다.

## 3. 배경기술

기존의 AI 시스템은 분석 또는 예측을 제공하더라도 실제로 어떤 근거로 판단했는지, 어떤 상태를 참조했는지, 어떤 실행이 그 판단에 연결되었는지, 그리고 동일 입력에서 동일 판단이 다시 나오는지를 충분히 설명하지 못하는 경우가 많다.

특히 다음 문제가 반복된다.

- 판단 근거가 기록되지 않아 사후 감사가 어렵다.
- 실행과 판단이 결합되어 블랙박스가 심해진다.
- 다중 시스템 운용 시 상태가 교차 오염된다.
- 실패 시 원인 추적과 재현이 어렵다.
- 다른 산업으로 확장할 때 동일한 구조를 반복 구축해야 한다.

NoahAI는 이러한 문제를 해결하기 위해 판단, 설명, 기록, 검증, 환류를 담당하는 인프라와 실행 계층을 구조적으로 분리하는 방식을 채택하였다.

## 4. 해결하고자 하는 과제

본 발명이 해결하고자 하는 과제는 다음과 같다.

1. AI 판단의 근거와 결과를 구조적으로 분리하여 기록하는 것.
2. 실행 신호와 판단 로그를 구분하여 책임 경계를 명확히 하는 것.
3. 동일 입력에 대한 재현성과 감사 가능성을 확보하는 것.
4. 다중 엔터티 환경에서 상태 오염을 방지하는 것.
5. 금융 외 산업에도 재사용 가능한 범용 인프라 구조를 제공하는 것.

## 5. 발명의 구성

### 5.1 전체 구조

본 발명은 다음 3계층으로 구성된다.

1. Decision Layer

   - 입력 데이터, 상태, 위험 조건을 해석하여 판단 결과를 생성한다.
   - 실행을 직접 수행하지 않는다.

2. Execution Bridge Layer

   - 판단 결과를 외부 시스템으로 전달한다.
   - 실제 실행, 집행, 상태 변경은 외부 시스템이 담당한다.

3. Audit and Replay Layer

   - 판단 근거, 대안 시나리오, 위험 점수, 실행 매핑을 저장한다.
   - 동일 입력 또는 유사 입력에 대해 재현 가능성을 제공한다.

### 5.2 판단 로그 구조

판단 로그는 최소한 다음을 포함한다.

- 입력 시각
- 입력 도메인
- 상태 스냅샷
- 판단 결과
- 대안 시나리오
- 위험 점수
- 실행 연결 ID
- 후속 결과
- 재현 검증 결과

### 5.3 상태 분리 구조

다중 엔터티 환경에서는 엔터티 식별자를 기준으로 상태 저장소를 분리하고, 서로 다른 엔터티의 상태가 혼합되지 않도록 한다.

## 6. 동작 방법

1. 시스템이 입력 데이터와 상태 데이터를 수신한다.
2. Decision Layer가 판단을 수행하고 결과를 생성한다.
3. 판단 결과와 판단 근거를 별도 로그로 저장한다.
4. Execution Bridge Layer가 외부 시스템에 실행 정보를 전달한다.
5. 외부 시스템이 실제 실행 또는 상태 변경을 수행한다.
6. 결과가 돌아오면 Audit and Replay Layer가 판단 로그와 매핑한다.
7. 동일 입력 재주입 시 재현성 또는 차이 사유를 제공한다.
8. 엔터티가 복수인 경우 각 엔터티의 상태는 격리 유지된다.

## 7. 핵심 차별점

- 판단과 실행을 분리하여 책임 구조를 명확히 한다.
- 감사와 재현을 전제로 판단 로그를 설계한다.
- 금융뿐 아니라 다른 산업에도 그대로 적용 가능한 범용 구조다.
- 다중 엔터티 운영에서 상태 오염을 막는 안정화 제어를 포함한다.
- 단순 모델 예측이 아니라 운영 가능한 인프라로 구현된다.

## 8. 효과

- 블랙박스 문제 감소
- 감사 및 재현 가능성 향상
- 운영 책임 경계 명확화
- 다중 시스템 환경에서 안정성 향상
- B2B/엔터프라이즈 확장성 향상
- 기술 모방 방어력 강화

## 9. 실시예

### 9.1 금융 실시예

암호화폐, 주식, ETF, 채권, 예적금, 보험, 대출 비교와 같이 판단-설명-기록-검증이 중요한 금융 의사결정 환경에서 적용 가능하다.

### 9.2 비금융 실시예

의료 추천, 교육 추천, 고객상담, 보안 경보, 운영 자동화, 다중 에이전트 관리에도 동일 구조를 적용할 수 있다.

## 10. 청구항 초안 방향

### 청구항 1

도메인 입력 데이터와 상태 정보를 수신하여 판단 결과를 생성하고, 실행 신호와 판단 로그를 분리 저장하는 AI 의사결정 인프라 방법.

### 청구항 2

판단 근거, 대안 시나리오, 위험 점수를 구조화 로그로 저장하고, 외부 시스템 실행 결과를 상기 로그와 매핑하는 방법.

### 청구항 3

동일 입력 재주입 시 판단 결과 일치성 또는 차이 사유를 제공하여 재현 검증을 수행하는 방법.

### 청구항 4

복수 엔터티 환경에서 엔터티 식별자를 기준으로 상태 저장소를 분리하고 상태 교차 오염을 차단하는 방법.

## 12. 정리

본 발명은 금융에 한정되지 않는 범용 AI 의사결정 인프라 특허 후보이다.
금융은 대표 실시예이며, 핵심 권리 포인트는 판단과 실행의 분리, 감사 재현, 상태 격리, 범용 확장성에 있다.

이 문서는 출원용 초안이므로, 최종 청구항과 문언은 선행기술 조사 및 변리사 검토 후 조정한다.
