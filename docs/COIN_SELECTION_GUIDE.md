# 🎯 NoahAI 코인 선택 시스템 가이드

## 📖 개요

**evaluator.py**는 NoahAI의 **코인 선택 핵심 엔진**입니다. 이 시스템은 단순한 랜덤 선택이 아닌, **5가지 차원의 과학적 평가**를 통해 최적의 거래 코인을 선별하는 고도화된 AI 시스템입니다.

## 🔍 evaluator.py란?

### **핵심 역할**
- **AI 거래의 두뇌**: 어떤 코인을 거래할지 결정하는 핵심 시스템
- **과학적 선별**: 데이터 기반의 객관적 평가 시스템
- **시장 적응**: 시장 상황에 따른 동적 조정 시스템

### **주요 특징**
- ✅ **5가지 차원 점수 계산** (기술적, 변동성, 거래량, 트렌드, 리스크)
- ✅ **거래소별 특화** (바이낸스, 업비트, 바이비트 등)
- ✅ **시장 상황별 자동 조정** (상승장/하락장/횡보장)
- ✅ **하이브리드 접근법** (캐싱 + 백업 + 하드코딩)

## 📊 5가지 평가 기준

### **1. 기술적 점수 (Technical Score)**
```
기술적 지표 분석:
├── RSI (상대강도지수): 과매수/과매도 구간 판단
├── MACD (이동평균수렴확산): 트렌드 변화 신호
├── 볼린저밴드: 변동성과 가격 위치 분석
└── 이동평균선: 지지/저항 레벨 확인
```

### **2. 변동성 점수 (Volatility Score)**
```
스캘핑 최적화:
├── 0.5% 미만: 30점 (스캘핑 부적합)
├── 0.5-2.0%: 100점 (스캘핑 최적)
├── 2.0-5.0%: 80점 (스캘핑 가능)
└── 5.0% 초과: 20점 (위험도 높음)
```

### **3. 거래량 점수 (Volume Score)**
```
유동성 보장:
├── 거래량 급증 감지
├── 평균 거래량 대비 비율 계산
└── 최대 100점까지 선형 증가
```

### **4. 트렌드 점수 (Trend Score)**
```
시장 방향성:
├── 상승 트렌드: 양수 점수
├── 하락 트렌드: 음수 점수
└── 횡보 트렌드: 중립 점수
```

### **5. 리스크 점수 (Risk Score)**
```
안정성 평가:
├── 과거 변동성 패턴 분석
├── 거래소별 리스크 특성 반영
└── 포트폴리오 분산 효과 고려
```

## 🚀 하이브리드 접근법

### **3단계 백업 시스템**

#### **1단계: 캐시된 API 데이터 (1시간 이내)**
```python
# 가장 정확한 실시간 데이터
if cache_age < 3600:
    exchange_info = load_from_cache()
```
- ✅ **장점**: 가장 정확한 실시간 데이터
- ✅ **성능**: 즉시 로딩
- ⚠️ **제한**: 1시간마다 갱신 필요

#### **2단계: 백업 심볼 파일 (API 실패 시)**
```python
# API 실패 시 자동 전환
if api_failed:
    exchange_info = load_backup_symbols()
```
- ✅ **장점**: API 장애 시에도 안정적
- ✅ **성능**: 빠른 로딩
- ⚠️ **제한**: 최신 데이터가 아닐 수 있음

#### **3단계: 하드코딩된 주요 심볼 (최종 백업)**
```python
# 최종 안전장치
backup_symbols = [
    'BTCUSDT', 'ETHUSDT', 'BNBUSDT', 'SOLUSDT', 'ADAUSDT',
    # ... 주요 30개 심볼
]
```
- ✅ **장점**: 100% 확실함
- ✅ **성능**: 즉시 사용 가능
- ⚠️ **제한**: 제한된 코인 수

## 🔧 사용법

### **기본 사용법**
```python
# evaluator 인스턴스 생성
evaluator = Evaluator(analyzer, recorder, settings)

# 코인 선택 실행
selected_coins = evaluator.select_trading_coins(
    num_alt=15,      # 알트코인 개수
    num_major=5,     # 메이저 코인 개수
    regime='auto',   # 시장 상황 (auto/up/down/sideways)
    exchange='binance'  # 거래소
)
```

### **고급 설정**
```python
# 거래소별 특화 설정
if exchange == 'binance':
    # 바이낸스 전용 최적화
    valid_coins = evaluator._analyze_candidate_coins()
elif exchange in ['upbit', 'bithumb']:
    # 국내 거래소 전용
    valid_coins = evaluator._analyze_candidate_coins_spot()
elif exchange in ['bybit', 'okx', 'bitget']:
    # CCXT 선물 거래소
    valid_coins = evaluator._analyze_candidate_coins_ccxt_futures()
```
