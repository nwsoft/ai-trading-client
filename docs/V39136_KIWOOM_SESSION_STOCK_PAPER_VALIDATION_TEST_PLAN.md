# v3.9.1.36 키움 세션·증권 PAPER·전략검증 정합 검증 계획

제품 3.9.1.36 / updater 3.9.136. 현재 공개 안정판은 v3.9.1.35이며 기존 자산은 교체하지 않습니다. 소스·자동 회귀·패키지·Windows 실계정·장시간 운용을 서로 다른 증거로 기록합니다.

## 반영 범위

- 키움 RPC timeout/EOF/응답 불일치 뒤 전용 호스트 자동 재시작을 잠그고 명시적 disconnect 후 수동 재연결만 허용합니다.
- 같은 수동 재연결 필요 오류의 반복 알림을 억제하며, 최초 오류와 `logs/kiwoom_host_events.jsonl` 진단은 보존합니다.
- 키움·신한·미래에셋·한국투자 PAPER 열린 주식/ETF 포지션을 계정별 원자적 파일로 저장·복구합니다.
- 복구 행은 PAPER·LONG·KRW·양수 수량/단가만 허용합니다. LIVE 또는 손상 행은 복구하지 않습니다.
- 주식/ETF 과거 전략검증은 선택한 증권사 일봉과 증권 PAPER 비용계약을 사용합니다. 주식 매도세와 ETF 세금 차이를 구분합니다.
- 암호화폐/증권 범위, 기관 전용 범위, 국내 현물 신규 SHORT 차단, 분봉을 일봉으로 대체하지 않는 계약을 유지합니다.
