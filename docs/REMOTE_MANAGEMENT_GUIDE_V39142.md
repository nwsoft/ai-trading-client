# v3.9.1.42 원격 자율운행 사용법

언어: PC 상단 `Language / 언어 → English (Beta)`로 핵심 표시를 바꿀 수 있습니다. 모바일 `/remote` 상단 한국어 / English 선택 또는 PC의 모바일 대시보드 링크가 선택 언어를 전달합니다. 미로그인 시 기존 한국어 로그인 화면을 거친 뒤 원격 화면은 선택 언어로 돌아옵니다. 언어 변경은 거래/권한 변경이 아닙니다.

소스 후보 v3.9.1.42 / updater 3.9.142. 공개 v41 설치 자산은 유지하며 사용자가 새 Client를 빌드·릴리스한다. daltrading 서버는 구형 v41 연결을 호환한다.

## PC에서 한 번 승인하기

1. 로그인 → 설정 → 알림·리포트 → 원격 관리 · 내 PC 상태 공유.
2. PC 이름을 정하고 상태 공유를 켠다. PC와 NoahAI는 실행 중이어야 한다.
3. `모바일에서 새 거래 일시정지 허용`, `모바일에서 자율운행 시작·재개 허용`, `포지션 수·위험 상태·손익 요약 공유`를 각각 선택한다. 기존 v41 동의는 시작/재개나 손익 공유로 자동 확대되지 않는다.
4. 시작·재개 권한을 저장하면 현재 기관·PAPER/LIVE·설정·전략 파일 내용에 대한 승인 식별자가 생성된다. 같은 설정을 재승인해도 식별자를 바꿔 이전 요청을 무효화한다. 설정이나 전략이 바뀌면 PC에서 다시 저장한다.
5. 모바일에서 같은 계정으로 daltrading 로그인 → 대시보드 → 내 PC 확인.

## 상태에 맞는 버튼

- 실행 중: **새 거래 일시정지**. 새 진입만 막고 기존 포지션 보호·청산은 유지한다. 이미 거래소에 제출한 주문은 취소하지 않아 이후 체결될 수 있다.
- 정지: **자율운행 시작**. PC에서 승인한 현재 모드·설정으로 기존 시작 경로를 호출한다.
- 일시정지: **자율운행 재개**. 필요한 경우 워커를 시작하고 위험 검사를 통과한 뒤 새 진입을 허용한다.
- 오프라인/구형 v41/미승인/설정 변경: 시작·재개 버튼 대신 안내한다. 증권 LIVE는 PC에 실제 어댑터가 준비되고 LIVE 허용 조건을 확인할 수 있어야 한다. LEARNING의 원격 시작은 이번 범위가 아니다.

시작·재개 확인창에는 PC·기관·PAPER/LIVE·승인 식별자를 표시한다. 비밀번호는 매 요청 재확인용이고 명령 DB나 PC로 전달하지 않는다. 이것은 MFA가 아닌 비밀번호 재인증이다. 위험 검사 실패·회원 확인 실패·만료·계정/권한 변경은 거부한다. 원격 요청으로 손실 한도·일일 기준·모드·전략을 바꾸지 않는다.

## 접수는 실행 완료가 아니다

PC는 약 60초마다 수신하고 웹은 약 30초마다 갱신한다. 명령 유효시간은 120초다. `PC 확인 대기 → PC 실행 확인`을 구분한다. `만료·실행 여부 미확인`은 실행하지 않았다는 보장이 아니며 PC를 확인한다. PC는 실행 전에 명령 수신 기록을 저장하므로 중간 종료 시 동일 요청을 자동 재실행하지 않는다. `결과 미확인`은 PC에서 확인한다. 폴링 원격은 긴급 청산 도구가 아니다.

## 상태 설명과 손익

접힌 `상태 설명·손익 확인`에서 마지막 위험 평가의 순실현·관리 미실현·손실률/한도·평가 시각과 관리 포지션/사용자 전략 수를 확인한다. 공유 OFF·자료 없음·미대조는 `확인 전`이지 0이 아니다. PAPER는 LIVE 계좌 손실 평가 대상이 아니므로 손익이 표시되지 않을 수 있다. 증권 LIVE 포지션 수 등 확인 경로가 없는 항목도 미확정으로 둔다.

이것은 **NoahAI 위험 평가 범위의 요약**이며 거래소 전체 계좌 일별 PnL이나 전략 성과 보고서를 대체하지 않는다. 설명은 수신 상태에 따른 규칙 기반 설명으로, 외부 AI 호출·투자 판단·자동 설정 변경이 아니다. Telegram/Discord의 위험/오류 알림에는 해당 기관 원격 페이지 링크만 넣고 명령이나 인증 토큰은 넣지 않는다.

## 연결 해제

`기기 관리 → 원격 연결 해제`는 원격 권한과 저장 상태를 제거한다. 거래를 종료하거나 일시정지를 해제하지 않는다. 재연결은 PC에서 승인한다.

## 제공하지 않는 기능

모드 전환, 설정/전략 교체, 전량 청산, PC 전원 켜기, 원격 백테스트, AlphaArena 제어는 제공하지 않는다. 전략 원격 검증은 자원 제한과 결과/여권 동기화 설계 후 별도 단계다. API 키·전략 원문·개별 포지션 내역은 업로드하지 않는다.
