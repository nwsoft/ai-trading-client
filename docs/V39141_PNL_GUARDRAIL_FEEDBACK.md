## DB 확인 후 추가 구현

- `BinanceCloseEvidence`: 직접 제출한 보호 주문에 진입 주문 ID를 영속 연결한다. 거래소 Algo 응답의 실제 주문 ID를 조회하고 해당 주문의 체결만 가져온 뒤 심볼·방향·완전 수량·단일 원장 소유권을 확인한다. 재시작·지연 수신 재시도, 30초 간격/회당 최대 2개 대상. 외부 수동 주문을 시간/수량으로 추정 연결하지 않는다. 기존 증거 없는 40건에 이 연결이 소급 생성되는 것은 아니다.
- 기본 진입 정책의 조기 반환 전에 위 재대조를 실행한다. 차단 때문에 복구 재시도도 실행되지 않는 순환을 막는다.
- Binance 미실현 손익은 성공 상태의 현재 계좌 포지션과 관리 원장 수량을 대조한다. 확인된 무포지션에서는 과거 미청산 행을 평가하지 않는다. 조회 실패·잘못된 응답·NaN·수량 불일치는 정상/0손실로 위장하지 않는다. 사용자 DB 복사본 + 모의 무포지션 응답에서 미실현 0을 확인했다. 실제 계좌 호출은 하지 않았다.
- `daily_risk_basis`: 동일 API 연결 식별 해시·기관·통화·일자의 최초 위험 기준값을 SQLite에 저장·복원한다. 재시작만으로 분모를 재설정하지 않는다. 저장 실패는 신규 진입 보류. 이는 실제 거래소 자정 계좌 자산 복원이 아니며 API 연결 변경은 다른 범위다.
- 포지션 조회 실패를 소멸/청산으로 간주하던 감시 경로를 차단한다. 가격 추정 TP/SL 결과와 실패 후 무포지션 확인 결과는 승패·순손익 통계 및 성과 학습으로 승격하지 않는다.
- 주문별 체결 조회가 확인한 실제 fill을 공통 원장에도 보존한다. 직접 청산 후 통계/RiskManager/AI 분석은 저장된 대조 완료 순손익을 사용한다. lifecycle KPI의 진입 비용 미포함 값을 순손익으로 보내지 않는다.
- Binance 요약·실제 거래 조회·일반 청산 기록의 음수 수수료 환급을 보존한다. PnL/수수료/비용 통화 누락과 비유한 값은 확정 금액으로 사용하지 않는다.
- 선택적 성과 튜닝의 Binance/통합 거래소 패턴·자동 최적화 경로는 대조 완료 순손익을 사용한다. 미대조가 있는 창 전체의 튜닝을 보류하고 확정 수익 거래만 선별하지 않는다. AI 전역 데이터 수집도 여러 기관/통화를 하나의 PnL로 합산하지 않는다. 이 필터를 LIVE 진입 가드의 콜드스타트 경로에 사용하지 않는다.

API 근거: [Binance Query Algo Order / Account Trade List](https://developers.binance.com/en/docs/catalog/core-trading-derivatives-trading-usd-s-m-futures/api/rest-api/trade). 실제 계정 호출이 아닌 공식 계약 + 모의 API 회귀다.

## 수정한 공통 결함

1. Binance 수익성 표본이 모든 모드의 거래 이력을 읽던 경로에서 PAPER/LEARNING/MOCK/DEMO를 제외했다. 미확정 LIVE·알 수 없는 모드는 삭제하거나 확정으로 간주하지 않는다. DB 조회 실패는 빈 이력/콜드스타트가 아닌 미대조 상태로 차단한다.
2. 일일 조회의 `T`/공백/시간대 offset 혼용에 따른 누락을 넓은 날짜 후보 조회 + epoch 비교로 수정했다. LIVE 별칭을 포함하고 다른 기관·PAPER는 제외한다. 레거시 불명 모드는 미확정으로 보존한다.
3. 일일 손실 가드레일이 미대조 추정 `pnl`을 사용하던 것을 `performance_evidence_ready` 및 유한한 `net_pnl` 확인으로 바꿨다. 한 건이라도 미확정이면 부분 합계를 전체 손실처럼 알리지 않고 `risk_data_unavailable`을 알린다. DB 오류도 0손실로 처리하지 않는다.
4. 미실현 평가에서도 LIVE 별칭을 처리하며 DB 오류·NaN 현재가는 정상 0손실로 처리하지 않는다. 기관별 공급자가 없을 때 다른 기관에 Binance 잔고를 재사용하지 않는다.
5. 경고에 당일 NoahAI 청산 순손익, 관리 포지션 미실현, 실행 세션 추정 기준 자산을 구분했다. 거래소 계좌 일별 총 PnL과 같다고 표시하지 않는다. 수익성 차단 로그에 미대조 건수와 체결 동기화 안내를 추가했다.

원격 UI도 내비게이션 이후 카드 배치, 긴 기기명 줄바꿈, 기존 대시보드 색상/폰트, 베타 미활성 HTML 안내를 수정했다. API의 베타·소유권·CSRF 권한은 완화하지 않았다.
