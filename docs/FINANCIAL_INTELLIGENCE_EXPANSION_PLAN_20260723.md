# NoahAI 금융 인텔리전스 대규모 확장 계획

기준일: 2026-07-23  
적용 기준: NoahAI Client v3.9.0.1  
상위 정본: `docs/UPDATE_PLAN.md`

## 1. 결론

기존 업데이트 계획은 전부 완료된 상태가 아니다.

- v3.9.0.0 AI 커스텀, 공통 가드레일, 거래 기록, 주식·ETF 기본 분석, 시장 트렌드, 자산 통합 진단은 코드와 테스트가 존재한다.
- v3.9.0.0 Windows 릴리스 자산은 생성·게시됐지만 거래소별 실제 사이클, 전수 GUI 실클릭, 이전 버전 자동업데이트 E2E 증적은 남아 있다.
- 경제 이벤트 캘린더, RSS 뉴스 수집·정규화, 뉴스 출처·중복·새로움 평가, 근거 연결 내러티브, 기업 재무제표, 가치평가, 퀀트 스크리너, 범용 백테스트, 산업·거시경제 분석, 기관 보유 분석은 2026-07-23 코드와 실행형 화면에 반영했다.
- Yahoo Finance·Binance 공개 시세는 라이브 스모크 검증을 통과했다. SEC Companyfacts·DART는 어댑터와 자동 테스트를 완료했으며 실제 자격증명을 사용한 운영 검증은 남아 있다.
- v3.9.0.1 배포 기능으로 승격했으며 대시보드 업데이트 카드와 인앱 전용 사용법을 함께 제공한다.
- 기존 문서의 기능명 또는 안내 문구만으로 구현 완료를 판단하지 않는다. 실제 데이터 수집, 계산 엔진, 화면, 사용자 동작, 저장·복기, 테스트가 연결돼야 완료다.

이번 확장은 Valley AI 화면을 복제하는 작업이 아니다. NoahAI의 강점인 실제 계좌·주문·가드레일·거래 복기와 금융 분석을 연결하는 것이 목표다.

## 2. 완료 판정 기준

각 기능은 아래 여섯 조건을 모두 충족해야 `완료`로 표시한다.

1. 데이터: 운영 또는 명시된 샘플 소스에서 입력을 수집하고 출처·수집시각을 표시한다.
2. 계산: 계산식, 결측값, 통화·시간대·분할·배당 보정 기준이 테스트된다.
3. 화면: 메뉴에서 실제 결과, 빈 상태, 오류 상태를 확인할 수 있다.
4. 연결: 보유 종목, AI 분석, 가드레일 또는 거래 복기 중 필요한 소비자와 연결된다.
5. 기록: 입력 스냅샷, 결과, 모델·규칙 버전, 사용자 동작을 재현할 수 있다.
6. 검증: 단위·통합 테스트와 실제 화면 확인 증적이 있다.

분류:

- `완료`: 여섯 조건 충족
- `부분`: 재사용 가능한 코드나 화면은 있으나 전체 흐름 미완
- `미구현`: 안내 문구, 프롬프트 또는 문서만 있거나 제품 경로가 없음
- `흡수`: 별도 기능으로 만들지 않고 기존/신규 공통 모듈에 통합

## 4. 기능별 중복 제거와 배치 결정

기존 상단 메뉴를 유지한다.

- `블록체인`
- `주식/증권`
- `자산 통합`
- `생활금융`
- `AI애널리스트`

새 공통 엔진은 한 번만 만들고 각 메뉴에서는 자산 컨텍스트만 다르게 보여준다.

| 요청 기능 | 현재 상태 | 최종 배치 | 결정 |
|---|---|---|---|
| 금융시장 현황 | 부분 | AI애널리스트 `글로벌 시장` | 교차자산 해석 허브. 주문 기능은 두지 않음 |
| 섹터 히트맵 | 미구현 | 주식/증권 `시장·섹터`; 블록체인은 자산 모드 재사용 | 자산 상관 히트맵과 분리 |
| 경제·기업·코인 캘린더 | 미구현 | AI애널리스트 `이벤트`; 보유자산 화면에 관련 일정 노출 | 일정 저장소는 공통, 화면만 재사용 |
| 실시간 속보 | 미구현 | AI애널리스트 `이벤트·속보` | 단순 긍부정 대신 영향·출처·새로움 표시 |
| 실시간 내러티브 | 미구현 | AI애널리스트 `내러티브` | 뉴스·가격·수급을 묶는 해석 계층 |
| 포트폴리오 관리 | 부분 | 자산 통합 `자산 현황` | AI애널리스트로 이동하지 않음 |
| 포트폴리오 분석 | 부분 | 자산 통합 `성과·위험 분석` | 공통 성과 엔진 사용 |
| 종목 재무분석 | 미구현 | 주식/증권 `기업 분석` | 코인에 억지 적용 금지 |
| 종목 가치평가 | 미구현 | 주식/증권 `가치평가` | 일반/전문가 보기로 단계화 |
| 퀀트 스크리너 | 미구현 | 주식/증권·블록체인 `탐색` | 공통 필터 엔진 + 자산별 필드 |
| 퀀트 백테스트 | 부분 | 주식/증권·블록체인 `전략 검증` | 하나의 공통 엔진을 자산 모드로 제공 |
| 기술지표 탐색 | 부분 | 주식/증권·블록체인 `지표 탐색` | 기존 분석기의 지표 계산 재사용 |
| 거장·기관 포트폴리오 | 미구현 | 주식/증권 `기관 동향` | 데이터 라이선스 확보 후 P3 |
| 산업 분석 | 미구현 | AI애널리스트 `산업`; 종목 화면에서 링크 | 산업 해석은 AI, 기업 수치는 증권 |
| 거시경제 분석 | 미구현 | AI애널리스트 `거시경제` | 레짐 결과만 전략·가드레일에 전달 |

### AI애널리스트에 넣지 않을 것

- 주문 버튼, 포지션 수량 변경, 브로커 연결
- 재무제표 원본 테이블과 가치평가 입력 폼
- 대규모 종목 필터 설정
- 백테스트 전략 편집기

AI애널리스트는 공통 엔진의 결과를 설명하고 여러 결과의 관계를 연결한다. 원본 계산과 실행 책임까지 소유하지 않는다.

## 5. 공통 기술 구조

### 5.1 공통 금융시장 코어

신규 패키지 제안: `trading/financial_intelligence/`

- `market_data.py`: 가격·수익률·거래량·금리·환율·원자재 정규화
- `taxonomy.py`: 자산군·국가·섹터·산업·팩터·통화 식별자
- `event_calendar.py`: 경제·실적·배당·IPO·ETF·코인 이벤트
- `news_pipeline.py`: 수집·정규화·엔터티 태깅·중복 제거·출처 관리
- `narrative_engine.py`: 뉴스·가격·수급·이벤트 연결과 변화 추적
- `fundamentals.py`: 재무제표·추정치·공시 표준화
- `valuation.py`: 상대가치·DCF·DDM·RIM과 민감도
- `screener.py`: 공통 필터 AST와 자산별 필드
- `backtest.py`: 신호·주문·체결·비용·포트폴리오 시뮬레이션
- `performance.py`: 기존 수익성 검증을 포트폴리오·전략 공통 지표로 확장
- `provenance.py`: 공급자, 수집시각, 지연, 통화, 시간대, 조정 여부 기록

### 5.2 공통 데이터 계약

모든 카드와 리포트는 최소 다음 필드를 가진다.

```text
as_of, source, source_url_or_id, asset_type, symbol,
currency, timezone, freshness, is_delayed, quality_flags,
calculation_version, model_version
```

AI 생성 결과에는 추가로 다음을 저장한다.

```text
evidence_ids, confidence, counter_evidence,
generated_at, expires_at, prompt_version
```

### 5.3 실행 연결 원칙

분석 결과는 직접 주문하지 않는다.

```text
데이터 수집
→ 계산/분석
→ AI 설명
→ 이벤트·위험 플래그
→ 기존 전략 평가
→ 기존 가드레일
→ 주문 또는 HOLD
→ 결과 복기
```

- 이벤트 중요도는 `정보`, `주의`, `제한 검토`, `사용자 정책상 차단`으로 나눈다.
- FOMC·CPI·실적 등은 기본적으로 경고만 제공한다.
- 자동 주문 제한 또는 레버리지 축소는 사용자가 승인한 정책과 테스트를 통과한 경우에만 적용한다.
- 뉴스 한 건이나 AI 내러티브만으로 매수·매도 신호를 만들지 않는다.

## 6. 기능 명세

### 6.1 글로벌 시장

- 지수, 주식, ETF, 코인, 원자재, 국채금리, 환율의 동일 시점 스냅샷
- 1일·1주·1개월·3개월·YTD 수익률
- 시가총액 가중·동일가중 전환
- 자산군·섹터·팩터 흐름
- 시장 위험도와 데이터 최신성
- 보유 자산에 영향을 주는 시장 변화 우선 표시

완료 기준:

- 서로 다른 시장의 통화·거래일·시간대가 정규화된다.
- 지연 데이터는 실시간처럼 표시되지 않는다.
- 시장 요약 문장마다 근거 지표를 열 수 있다.

### 6.2 시장·섹터 히트맵

- 시장 → 섹터 → 산업 → 종목 드릴다운
- 수익률·거래대금·변동성·모멘텀 전환
- 기간, 가중 방식, 거래소·국가 필터
- 보유 종목·AI 관찰 종목 강조
- 섹터 강도 변화와 자금 이동 추정

코인에서는 섹터 대신 L1, L2, DeFi, AI, RWA, Meme 등 명시된 분류를 사용한다. 분류 출처와 갱신일을 표시한다.

### 6.3 이벤트 캘린더와 가드레일

- 경제: FOMC, CPI, PPI, 고용, GDP, 금리
- 증권: 실적, 배당락, 공시, IPO, ETF 리밸런싱
- 코인: 락업 해제, 하드포크, 상장·상폐, 네트워크 점검
- 예상·이전·실제와 발표 시각
- 보유 종목·활성 전략과의 연관도
- 이벤트 전후 가격·거래량·슬리피지 기록

### 6.4 뉴스·내러티브

- 동일 기사·재전송 제거
- 종목·산업·국가·자산군·이벤트 태깅
- 출처 신뢰도, 새로움, 파급 범위, 가격 민감도 분리
- 사실, 주장, 추정, 시장 반응을 구분
- 내러티브 생성·확산·약화와 반대 근거 추적
- 가격 선반영과 뉴스·수급 불일치 탐지
- 현재 포지션과 AI 판단에 사용된 근거 연결

기존 문서에 이름만 있는 `news_signal_reliability.py`와 테스트를 이 단계에서 실제 구현한다.

### 6.5 기업 분석과 가치평가

기업 분석:

- 기업 개요, 표준 손익·재무상태·현금흐름표
- 성장성·수익성·안정성·효율성·주당·배당 지표
- 실적 추정치 변화와 어닝 서프라이즈
- 공시·IR·컨퍼런스콜 요약과 원문 링크
- 내부자·기관 거래는 데이터 권리 확인 후 제공

가치평가:

- 일반: PER, PBR, PSR, EV/EBITDA, 과거 밴드, 섹터·경쟁사 비교
- 전문가: DCF, Reverse DCF, DDM, RIM
- Bull·Base·Bear와 WACC·영구성장률 민감도
- 입력값, 기준일, 통화, 주식수, 순부채를 모두 공개
- 가치평가 결과는 목표가격 보장이 아니라 가정별 범위로 표시

### 6.6 스크리너와 기술지표 탐색

- 공통: 가격, 규모, 유동성, 변동성, 모멘텀, AI 관찰점수, 예상 슬리피지
- 증권: 성장성, 수익성, 재무안정성, 가치, 배당, 추정치
- 코인: 거래소, 현물·선물, 펀딩비, 미결제약정, 토큰 유통, 섹터
- 계좌 규모·최소주문·현재 위험예산 내 진입 가능 여부
- 멀티타임프레임 RSI·MACD·이동평균·볼린저·거래량
- 지표 충돌, 레짐별 적중률, 동일조건 과거 거래
- 진입하지 않은 이유와 실제 발생 거래 연결

AI 점수 하나로 정렬하지 않고 원점수 구성요소와 데이터 부족을 표시한다.

### 6.7 포트폴리오 관리·분석

- 거래소·증권사·통화 통합 원장
- 실현·미실현·수수료 전후 손익
- 자산군·전략·브로커·국가·통화·섹터 노출
- 현금·증거금·가용 주문금액·레버리지·청산 위험
- AI 관리 포지션과 수동 포지션 구분
- 수익률, 변동성, Sharpe, Sortino, MDD, 회복기간
- Profit Factor, Expectancy, 승률, 평균 손익비
- 레짐·시간대·AI 판단 유형·HOLD·취소별 성과
- 벤치마크와 현금흐름 보정 성과
- 증권사·거래소별 수수료·슬리피지·주문 성공률

### 6.8 범용 백테스트

- 신호 시각과 주문 시각 분리
- 수수료, 세금, 스프레드, 슬리피지, 펀딩비
- 최소주문, 호가단위, 부분체결, 취소, API 실패
- 레버리지, 증거금, 강제청산
- 기업행동·상장폐지·생존편향·미래정보 누수 방지
- In-sample, Out-of-sample, Walk-forward
- 레짐별 성과, 전략 용량, 혼잡 비용
- 실제 거래 로그와 시뮬레이션 괴리

현재 `시나리오 점검`과 AI 커스텀 500캔들 검증은 유지하되 범용 백테스트 완료로 간주하지 않는다.

### 6.9 산업·거시경제

산업:

- 산업 정의, 시장 규모, 성장 동력, 위험, 밸류체인
- 대표 기업과 공급자·수요자 관계
- 실적 방향, 상대가치, 뉴스·내러티브, 자금 흐름

거시:

- 성장, 물가, 고용, 유동성, 금리, 신용, 환율, 원자재, 주택, 소비, 기업활동
- 확장·둔화·침체·회복과 인플레이션 레짐
- 자산군 영향과 반대 시나리오
- 전략 파라미터 변경 근거 제시

거시 레짐은 AI의 자유 문장이 아니라 버전이 있는 규칙·모델 출력으로 저장한다.

### 6.10 기관·거장 포트폴리오

- 공시 기준일과 실제 매매일의 차이를 명확히 표시
- 신규 편입·확대·축소·청산 추정
- 여러 기관 공통 보유와 사용자 포트폴리오 중복도
- 현재 가치평가와 공시 이후 성과

실시간 매매 신호처럼 표현하면 안 되며, 데이터 비용·라이선스·지연을 확인한 뒤 P3에서 결정한다.

## 10. 릴리스 원칙

- 기능명만 있는 카드와 AI 프롬프트는 `미구현`으로 표시한다.
- 외부 데이터가 없을 때 생성형 AI가 수치·일정·재무정보를 채우지 않는다.
- 데이터 지연과 라이선스 제한을 사용자에게 숨기지 않는다.
- 분석 결과와 주문 실행을 분리하고 기존 가드레일을 우회하지 않는다.
- 신규 탭마다 빈 상태, 지연 상태, 공급자 오류, 계산 실패를 테스트한다.
- 한 단계의 운영 데이터와 회귀 증적이 확보되기 전 다음 단계 완료를 선언하지 않는다.
