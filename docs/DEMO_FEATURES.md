# 🎯 데모 기능 가이드

## 📋 개요
이 문서는 NoahAI 클라이언트에 새로 추가된 데모 기능들에 대한 설명과 사용법을 담고 있습니다.

## 🆕 새로 추가된 기능

### 1. 💬 커뮤니티 기능
**위치**: `noahai_client/ui/community_widget.py`

#### 주요 기능
- **📝 QNA 게시판**: 사용자들이 질문과 답변을 공유하는 게시판
- **🆘 고객센터 메신저**: 1:1 고객 지원을 위한 메신저 시스템
- **👥 단체 채팅방**: 실시간 커뮤니티 소통을 위한 채팅방

#### 데모 데이터
- QNA 게시판: 3개의 샘플 게시글 (비트코인 전략, AI 트레이딩, 리스크 관리)
- 고객센터: 3개의 샘플 문의 (로그인 문제, API 키 설정, 거래 내역)
- 단체 채팅: 4개의 샘플 메시지 (시스템 알림 포함)

#### 실시간 시뮬레이션
- 5초마다 새로운 채팅 메시지가 자동으로 추가됩니다
- 데모 효과를 위해 랜덤 사용자명과 메시지가 생성됩니다

### 2. 📰 뉴스정보 & AI 애널리스트 기능
**위치**: `noahai_client/ui/news_widget.py`

#### 주요 기능
- **🤖 AI 애널리스트**: AI가 시장을 분석하고 투자 추천을 제공
- **📰 뉴스 수집**: 코인 관련 뉴스를 자동으로 수집하고 요약
- **📊 시장 동향**: 실시간 시장 분석 및 예측 정보

#### 데모 데이터
- AI 분석: 3개의 샘플 분석 결과 (비트코인 전망, 이더리움 DeFi, 알트코인 시장)
- 뉴스: 4개의 샘플 뉴스 (ETF 승인, 이더리움 2.0, DeFi 프로젝트, 규제 정책)
- 시장 지표: 공포&탐욕 지수, BTC 지배력, 총 시가총액, 거래량, 활성 주소 수

#### 실시간 시뮬레이션
- 8초마다 새로운 뉴스가 자동으로 추가됩니다
- 15초마다 새로운 AI 분석 결과가 자동으로 생성됩니다
- 진행률 바가 실시간으로 업데이트됩니다

## 🚀 데모 실행 방법

### 1. 프로그램 실행
```bash
cd noahai_client
python3 main.py
```

### 2. 로그인 후 대시보드 접속
- 프로그램 실행 후 로그인
- 메인 대시보드에서 새로 추가된 탭들을 확인

### 3. 기능 테스트
- **커뮤니티 탭**: QNA 게시판, 고객센터, 단체 채팅 기능 확인
- **뉴스정보 탭**: AI 애널리스트, 뉴스 수집, 시장 동향 기능 확인

## ⚠️ 주의사항

1. **데모 전용**: 현재 모든 기능은 더미 데이터를 사용하는 데모 버전입니다
2. **실제 기능 없음**: 버튼 클릭 시 "데모 모드" 메시지만 표시됩니다
3. **성능 영향**: 실시간 시뮬레이션 타이머가 실행되므로 리소스를 소모할 수 있습니다
4. **데이터 저장 없음**: 모든 데이터는 메모리에만 저장되며 프로그램 종료 시 사라집니다

## 🚧 개발 환경 및 기술 스택

### 백엔드
- **데이터베이스**: SQLite (개발용) → PostgreSQL (운영용)
- **API 서버**: FastAPI 또는 Django REST Framework
- **실시간 통신**: WebSocket, Redis
- **AI 서비스**: OpenAI API, Hugging Face

### 프론트엔드
- **UI 프레임워크**: PyQt5
- **차트 라이브러리**: matplotlib, plotly
- **데이터 처리**: pandas, numpy

### 배포 및 운영
- **컨테이너화**: Docker
- **모니터링**: Prometheus, Grafana
- **로깅**: ELK Stack (Elasticsearch, Logstash, Kibana)
