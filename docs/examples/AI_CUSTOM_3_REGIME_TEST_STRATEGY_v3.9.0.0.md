# NoahAI AI 커스텀 테스트 전략 — 3국면 적응형 추세·평균회귀 전략 (v3.9.0.0)

문서 버전: 1.0  
대상 클라이언트: NoahAI v3.9.0.0  
용도: PDF/Markdown 전략 추출, XAI 설명, 검토용 전략 저장 기능 테스트  
주의: 이 문서는 기능 검증용 전략 명세다. 과거 또는 미래의 수익률·승률을 보장하지 않는다.

## 1. 전략 목적

이 전략은 상승장, 하락장, 횡보장을 먼저 분류한 다음 각 국면에 맞는 한 가지 진입 방식만 선택한다. 모든 판단은 확정된 봉만 사용하며 미래 데이터, 재도색 지표 또는 미확정 봉을 사용하지 않는다.

- 대상 시장: BTC/USDT, ETH/USDT처럼 거래량과 유동성이 충분한 현물 또는 무기한 선물
- 시장 국면 판단 타임프레임: 1시간봉
- 진입·청산 타임프레임: 15분봉
- 사용 지표: EMA 20, EMA 50, EMA 200, RSI 14, ADX 14, ATR 14, Bollinger Bands 20/2, 거래량 SMA 20
- 신규 진입 판단 주기: 15분봉 마감 직후 1회
- 동시 포지션: 종목당 최대 1개, 계정 전체 최대 2개

## 2. 공통 실행 설정값

아래 값은 NoahAI 실행 엔진에 적용할 명시적 초기값이다.

```yaml
leverage: 1
position_size: 5%
signal_threshold: 0.75
stop_loss: 1.0%
take_profit: 2.0%
max_account_risk_per_trade: 0.25%
max_daily_loss: 1.5%
max_open_positions: 2
cooldown_after_loss: 3 candles
```

엔진 변환 기준:

```json
{
  "leverage": 1,
  "position_size": 0.05,
  "signal_threshold": 0.75,
  "sl_percent": 1.0,
  "tp_percent": 2.0
}
```

포지션 크기는 계정 평가금액의 5%와 `계정 위험 0.25% ÷ 실제 손절 거리`로 계산한 크기 중 더 작은 값을 사용한다. 수수료와 예상 슬리피지를 반영한 기대손익비가 1.5 미만이면 진입하지 않는다.

## 3. 시장 국면 판정

국면은 매 1시간봉 마감 후 갱신하며 다음 1시간 동안 유지한다.

### 3.1 상승 국면(BULL)

다음 조건을 모두 만족하면 상승 국면이다.

1. 1시간봉 EMA 50 > EMA 200
2. 1시간봉 종가 > EMA 50
3. ADX 14 >= 22
4. EMA 50의 최근 3개 확정봉 기울기가 양수

### 3.2 하락 국면(BEAR)

다음 조건을 모두 만족하면 하락 국면이다.

1. 1시간봉 EMA 50 < EMA 200
2. 1시간봉 종가 < EMA 50
3. ADX 14 >= 22
4. EMA 50의 최근 3개 확정봉 기울기가 음수

### 3.3 횡보 국면(SIDEWAYS)

다음 조건을 모두 만족하면 횡보 국면이다.

1. ADX 14 < 18
2. 최근 20개 1시간봉의 Bollinger Band 폭 `(상단-하단)/중앙선`이 6% 이하
3. 가격이 EMA 200에서 위아래 4% 범위 안에 있음

ADX가 18 이상 22 미만이거나 어느 국면 조건도 완성되지 않으면 국면을 `NEUTRAL`로 지정하고 신규 진입하지 않는다.

## 4. 상승 국면 진입 규칙

상승장에서는 추세 추종형 눌림목 LONG만 허용한다.

### LONG 진입 조건 — 모두 AND

1. 현재 국면 = BULL
2. 15분봉 EMA 20 > EMA 50
3. 직전 확정봉 저가가 EMA 20에 닿았거나 EMA 20 아래 0.3% 이내까지 하락
4. 현재 확정봉 종가가 EMA 20 위에서 마감
5. RSI 14가 직전 봉에서 40 이하였고 현재 봉에서 45 위로 상승
6. 현재 거래량 >= 최근 20봉 평균 거래량의 1.1배
7. 신호 신뢰도 >= 0.75

진입: 위 조건이 모두 확정된 다음 봉 시작가에 지정가 우선으로 LONG 진입한다. 지정가가 1개 봉 안에 체결되지 않으면 취소한다.

청산: 진입가 대비 +2.0%에서 전량 익절하거나, 진입가 대비 -1.0%에서 전량 손절한다. 목표가 도달 전 15분봉 EMA 20이 EMA 50 아래로 확정 교차하면 조기 청산한다.

## 5. 하락 국면 진입 규칙

하락장에서는 선물·공매도 지원 시장에서만 추세 추종형 반등 SHORT를 허용한다. 현물 또는 공매도 미지원 시장에서는 하락 국면 신규 진입을 금지한다.

### SHORT 진입 조건 — 모두 AND

1. 현재 국면 = BEAR
2. 거래소와 계정이 SHORT를 지원함
3. 15분봉 EMA 20 < EMA 50
4. 직전 확정봉 고가가 EMA 20에 닿았거나 EMA 20 위 0.3% 이내까지 상승
5. 현재 확정봉 종가가 EMA 20 아래에서 마감
6. RSI 14가 직전 봉에서 60 이상이었고 현재 봉에서 55 아래로 하락
7. 현재 거래량 >= 최근 20봉 평균 거래량의 1.1배
8. 신호 신뢰도 >= 0.75

진입: 위 조건이 모두 확정된 다음 봉 시작가에 지정가 우선으로 SHORT 진입한다. 지정가가 1개 봉 안에 체결되지 않으면 취소한다.

청산: 진입가 대비 유리한 방향 +2.0%에서 전량 익절하거나, 불리한 방향 -1.0%에서 전량 손절한다. 목표가 도달 전 15분봉 EMA 20이 EMA 50 위로 확정 교차하면 조기 청산한다.

## 6. 횡보 국면 진입 규칙

횡보장에서는 Bollinger Band 평균회귀만 사용한다. 밴드 돌파가 거래량과 함께 확대되면 추세 발생 가능성이 있으므로 진입하지 않는다.

### 횡보 LONG 진입 조건 — 모두 AND

1. 현재 국면 = SIDEWAYS
2. 15분봉 종가가 Bollinger 하단 밴드 아래로 내려갔다가 다음 확정봉에서 하단 밴드 안으로 복귀
3. RSI 14 < 35
4. 현재 거래량 <= 최근 20봉 평균 거래량의 1.5배
5. 신호 신뢰도 >= 0.75

### 횡보 SHORT 진입 조건 — 모두 AND

1. 현재 국면 = SIDEWAYS
2. SHORT 지원 시장
3. 15분봉 종가가 Bollinger 상단 밴드 위로 올라갔다가 다음 확정봉에서 상단 밴드 안으로 복귀
4. RSI 14 > 65
5. 현재 거래량 <= 최근 20봉 평균 거래량의 1.5배
6. 신호 신뢰도 >= 0.75

진입: 복귀 봉이 확정된 다음 봉 시작가에 진입한다.

청산: 기본 손절은 진입가 대비 1.0%, 기본 익절은 진입가 대비 2.0%다. 가격이 Bollinger 중앙선에 도달했는데 미실현 수익이 0.8% 이상이면 전량 청산할 수 있다. 국면이 NEUTRAL, BULL 또는 BEAR로 변경되면 횡보 전략 포지션을 청산한다.

## 7. 공통 진입 금지 조건

다음 중 하나라도 만족하면 모든 국면에서 신규 진입을 금지한다(OR).

1. 일일 실현손익이 계정 평가금액 대비 -1.5% 이하
2. 연속 손실 3회 발생 후 쿨다운 3개 봉이 지나지 않음
3. 거래소 API, 시세, 주문장 또는 포지션 데이터가 오래되었거나 누락됨
4. 예상 수수료와 슬리피지 반영 후 기대손익비 < 1.5
5. 호가 스프레드 > 0.15%
6. 현재 15분 ATR이 최근 20일 동일 시간대 ATR 평균의 2.5배 초과
7. 최소 주문금액, 수량 단위 또는 잔고 검증 실패
8. 공통 가드레일이 주문을 거부함

## 8. 우선 적용되는 가드레일

전략 신호가 발생해도 NoahAI 공통 가드레일이 항상 우선한다.

- 출금·자산 이동 API는 사용하지 않는다.
- 데이터가 없거나 오래되었으면 추정값으로 주문하지 않는다.
- 최초 사용자 또는 거래 이력이 부족한 계정은 레버리지 1, 동시 포지션 1개, 기본 주문 크기의 10%부터 제한 학습한다.
- 손절 주문 생성 또는 검증에 실패하면 신규 진입하지 않는다.
- 포지션 집중도, 최대 일일 손실, 유동성, 시장 급변 제한을 초과하면 신규 진입하지 않는다.
- 사용자 승인 전에는 전략을 실거래에 적용하지 않는다.

## 9. XAI가 사용자에게 설명해야 하는 내용

각 신호마다 다음을 표시한다.

1. 선택된 시장 국면과 국면 판정에 사용한 확정봉 시각
2. 만족한 조건과 만족하지 않은 조건
3. 진입 방향, 진입가, 손절가, 익절가, 예상 수수료와 슬리피지
4. 포지션 크기가 5%보다 작아졌다면 위험 한도 때문에 축소된 계산 근거
5. 신호를 거부했다면 가드레일 또는 데이터 부족 사유
6. 전략 원문 중 해당 판단의 근거가 된 문장

XAI 예시:

> 현재 국면은 BULL입니다. 1시간 EMA50이 EMA200 위에 있고 ADX는 26입니다. 15분봉 눌림목 조건 7개 중 7개가 충족되었습니다. 계정 위험 한도로 인해 포지션은 요청값 5%가 아닌 3.8%로 축소되었습니다. 손절 -1.0%, 익절 +2.0%, 비용 반영 기대손익비는 1.72입니다.

## 10. 적용 전 검증 기준

이 전략은 문서 추출 성공만으로 수익성이 입증되지 않는다. 다음 순서로 검증한다.

1. AI 추출 결과에서 여섯 필수 항목(진입, 청산, 손절, 익절, 포지션 크기, 시장 조건)이 누락되지 않았는지 확인
2. XAI의 AND/OR 변환이 원문과 같은지 사용자 확인
3. 과거 데이터 검증에서는 미래 데이터 참조 방지, 수수료, 펀딩비, 슬리피지를 포함
4. 서로 겹치지 않는 구간으로 학습 구간과 검증 구간을 분리
5. 실시간 관찰 또는 제한 학습에서 주문 거절, 체결 편차, 비용을 기록
6. 사용자 승인 후에도 최초 적용은 최소 위험 한도로 시작

판매·적용 판단의 최소 관찰 기준 예시:

- 검증 거래 100회 이상
- 비용 차감 후 Profit Factor 1.20 이상
- 최대 낙폭이 사전 위험 한도 이내
- 단일 국면이 아닌 BULL, BEAR, SIDEWAYS 각각에서 거래 기록 존재
- 승률 단독이 아니라 순손익, 평균 이익/손실, 비용, 최대 낙폭을 함께 평가

위 기준은 목표·통과 조건이며 이 문서 전략이 이미 달성했다는 의미가 아니다.

## 11. NoahAI 추출 기대값

PDF 분석 후 최소한 다음 값이 표시되어야 한다.

```json
{
  "name": "3국면 적응형 추세·평균회귀 전략",
  "rules": {
    "entry": "BULL 눌림목 LONG, BEAR 반등 SHORT, SIDEWAYS 밴드 복귀 평균회귀",
    "exit": "TP/SL 또는 EMA 교차·중앙선·국면 변경 시 청산",
    "stop_loss": "1.0%",
    "take_profit": "2.0%",
    "position_size": "계정 평가금액 최대 5%, 거래당 계정 위험 최대 0.25%",
    "market_conditions": "1시간봉 기준 BULL/BEAR/SIDEWAYS 분류, 불명확하면 NEUTRAL"
  },
  "engine_settings": {
    "leverage": 1,
    "position_size": 0.05,
    "signal_threshold": 0.75,
    "sl_percent": 1.0,
    "tp_percent": 2.0
  },
  "ready_for_review": true
}
```

AI가 문서에 없는 지표값 또는 적용값을 추가하면 안 된다. 여러 국면의 분기 조건을 단일 AND 조건으로 잘못 합치지 않고, 국면별 조건 묶음으로 설명해야 한다.
