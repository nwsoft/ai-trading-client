# 3.9.1.49 원격 상태·지원 경로 점검

2026-09-29. Client 소스 보완, daltrading 웹·서버 운영 반영 완료(기능 커밋 `134c26f6100c5be99091c9ff0cbdb02570890778`). Windows 설치본·실제 PC 명령 검증과 구분한다. 운영 상세 증거는 daltrading `docs/V39149_REMOTE_PRODUCTION_VERIFICATION.md`를 따른다.

## 제품 원칙과 실제 지원

전략·거래소 API 키·주문 실행·위험 검사는 PC에 남고 웹은 인증된 상태 조회와 제한된 명령 중계를 제공한다. 일반 원격 데스크톱이나 클라우드 거래 엔진이 아니다. PC 구조만으로 법적 적합성이 확정되는 것은 아니며 금융 서비스 범위·동의·개인정보·운영 방식 검토는 별도다.

| 모바일·외부 웹 기능 | 조건 / 한계 |
|---|---|
| PC별 기관·실행 상태·PAPER/LIVE/학습 확인 | 같은 계정, PC 공유 동의, 서버 베타 허용 필요 |
| 관리 포지션 수·위험·손익 요약 | PC에서 별도 동의, 마지막 위험 평가 값, 전체 계좌 손익 아님 |
| 새 진입 일시정지 | PC의 별도 허용. 기존 보호·청산을 중지하거나 기제출 주문을 취소하지 않음 |
| 자율운행 시작·재개 | PC 승인 설정 digest/모드와 일치, 웹 비밀번호 재확인, PC 회원·위험·세션 재검사 |
| 연결 해제 | 기기 권한 폐기. 거래 종료·진입 재개와 다름 |
| 거부 사유·지원용 진단 복사 | 이번 PC/서버/웹 보완. 구버전 사유는 미기록 유지 |

전략 교체·모드/예산 변경·PnL 초기화·원격 강제 청산·OS 화면 조작·전원 켜기는 제공하지 않는다. 추가하면 권한/명령/재검증 설계를 별도로 승인해야 하며 단순 버튼 추가로 처리하지 않는다.

## 발견과 수정

1. **연결 상태 혼동:** 기존 공유 ON 표시는 전송 성공이 아니었다. PC UI에서 첫 전송 대기/최근 성공/180초 미확인/실패를 분리하고 권한 저장 후 이전 성공 표시를 초기화했다.
2. **실패 원인 소실:** PC `RemoteControl`이 예외를 모두 rejected로 바꾸고 서버도 상태만 보관했다. 허용된 사유 코드만 기존 영수증·ack·result·웹으로 연결했다. 원본 예외·계좌 금액·키는 전송하지 않는다. 같은 ID 재처리는 실행하지 않고 기존 결과/사유를 유지한다.
3. **응답 묶음 상한:** 클라이언트 ack 합산에는 서버 20건/8,192자 한도가 적용되지 않았다. 상한 안에서 전송하고 미전송/실패분은 다음 주기까지 유지한다. 추가 폴링·대형 테이블·명령 권한은 만들지 않는다.
4. **지원 동선:** 웹에 사유별 다음 조치, 명령 ID/시각/상태·기관/모드·클라이언트 버전의 읽기 전용 진단 복사를 추가했다. 금액·기기 이름·전략 내용·비밀값은 복사 대상이 아니다. 복사 실패 시 표시 내용을 직접 선택할 수 있다.
5. **문서 모순:** v41 안내의 ‘시작·재개 미제공 / PnL 미공유’는 v42 기능과 충돌했다. 현행 매뉴얼을 정정하고 v41 기록은 과거 이력으로 분리했다.

PC 전송 약 60초 + 웹 새로고침 약 30초다. 명령 처리 결과도 다음 PC 전송에서 확인되므로 즉각 완료처럼 표시하지 않는다. 미전달 명령 TTL 120초, 마지막 수신 180초 이상은 오프라인이다. 긴급 청산 도구가 아니다. 오프라인/만료/불확실 상태의 실행 결과는 추정하지 않는다.

## 사이트 추가 판단

이번에는 명령 결과·자가 조치·최소 진단 기능을 우선한다. 49의 로컬 운용 요약 전체를 서버로 복제하지 않는다. 시장국면·전략 판단 원격 공유는 별도 데이터 동의·최소 필드·보관 정책이 필요하며 기존 ‘손익 요약 공유’ 동의를 임의 확대하지 않는다. 운영 확인 결과 베타 허용 계정은 1개이며 이번 배포에서 확대하지 않았다.

## 인계

- 서버의 추가 reason_code 필드는 구버전 클라이언트가 없어도 동작한다. 기존 result JSON 사용으로 DB 스키마 변경이 없다. 서버/웹 먼저, 클라이언트 다음 순서 권장. 구서버는 추가 ack 필드를 무시하므로 원인 표시는 서버 업데이트 후 제공된다.
- 기존 사이트 worktree 변경은 보존하고 원격 8개 파일만 분리해 commit/push/EC2 배포했다. 회원 allowlist 확대·실제 원격 시작/재개/정지는 실행하지 않았다.
- 공개 경로 비로그인 GET `/remote` 302, `/remote/devices` 401 확인. 운영 커밋과 공개 JS 해시 동일성·서비스 active·DB 무결성 확인. 로그인 사용자 화면·실계정 명령 처리는 별도 확인이 남았다.
- 회귀·브라우저 결과 및 Windows/실기기 남은 확인은 `TEST_STATUS.md`의 원격 후속 절을 따른다.
