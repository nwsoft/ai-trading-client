# 제휴 계약 체크리스트 (2026-04-28)

## 1. 계약 기본

- 계약 목적/범위(기술 제공 vs 실행 대행) 명확화
- 역할 분담(판단/집행/운영/고객응대) 명시
- 용어 정의(서비스 장애, 데이터 사고, 중대사고) 표준화

## 2. 책임/면책

- 투자 성과 비보장 조항
- 외부 API 장애 시 책임 분리 조항
- 손해배상 한도(cap) 및 간접손해 배제 조항

## 3. 데이터/보안

- 개인정보 처리자/수탁자 역할 정의
- 로그/KPI 데이터의 보관·파기·접근통제 규정
- 침해사고 통지 기한 및 대응 절차

## 4. 운영/품질

- SLA/SLO 목표치 및 측정 기준
- 장애 대응 우선순위와 복구 목표(RTO/RPO)
- 변경관리(배포, DB 마이그레이션) 승인 체계

## 5. 규제/컴플라이언스

- 관련 법령 준수 의무 및 위반 시 조치
- 감독기관 요청 자료 제출 협력 조항
- 샌드박스/실증 특례 신청 시 협력 의무

## 6. 상업 조건

- 과금 구조(정액/사용량/하이브리드)
- 정산 주기, 세금, 환불 정책
- 계약 기간, 갱신, 해지 사유

## 7. 분쟁 대응

- 준거법/관할
- 분쟁 해결 절차(협의 → 중재/소송)
- 긴급조치(서비스 중단, 키 폐기) 트리거

## 8. 서명 전 최종 확인

- 책임경계 문서와 계약 조항의 일치 여부
- 개인정보/로그 정책과 부속서의 일치 여부
- 기술 아키텍처 문서와 운영 범위의 일치 여부
