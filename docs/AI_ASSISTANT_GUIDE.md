## 이전 문서 기록 (아래 현재·후보 표기는 당시 기준)

기준 버전: NoahAI Client v3.9.1.27 공개판 (2026-09-11)

v3.9.1.27 Windows 설치 파일·blockmap·`latest.yml`은 공개됐습니다. 공개 사실과 실제 Provider 계정, 거래소·증권사, DPI, 업데이트/재시작·장시간 운용의 환경별 검증은 구분합니다.

v3.9.1.27에서 `429 · 심층분석 한도` 질문은 거래소 상태가 아니라 AI 호출 예산으로 설명합니다. 기본 일 30회·월 500회는 API 비용·반복 호출 보호용 사용자 설정이며 `설정 → AI 엔진/API → AI 비용 관리`에서 현재 사용량을 확인하고 일 1~1,000회·월 1~30,000회로 조정할 수 있습니다. 일일 집계는 UTC 00:00(한국시간 09:00)에 갱신됩니다. 한도 도달 시 텍스트·Pine 전략의 로컬 규칙 컴파일과 일반 안내는 계속되고 외부 AI 보조 설명만 생략됩니다. 이미지·영상 해석처럼 외부 호출이 필수인 작업은 예외입니다.

오류 코드가 `interactive_ai_budget_exceeded`이면 외부 요청을 보내기 전 NoahAI가 막은 로컬 비용 보호 429입니다. Provider가 직접 반환하는 429는 Provider 측 속도·동시 요청·쿼터·결제 제한이므로 NoahAI 한도 증액만으로 해결되지 않습니다. 앱은 이 두 원인을 같은 거래 오류나 회원 제한으로 설명하지 않습니다.

비용 카드는 사용자가 직접 실행한 어시스턴트·전략 보조·차트·전사 호출만 로컬 집계합니다. 성공 응답의 실제 토큰과 공개 단가가 있을 때만 예상 비용을 표시하고, 알 수 없는 값은 0원으로 채우지 않습니다. 자동매매 백그라운드 AI와 Provider 전체 청구서는 별도 범위입니다.

역할별 모델은 `나만의 AI 구성 · 작업별 모델`에서 현재 배치를 확인하고 아래 설정에서 변경합니다. DeepSeek의 최신 Flash 공식 별칭은 `deepseek-v4-flash`이며 Pro와 비전 실험 모델은 별도입니다. YouTube는 자막을 우선하고 자막이 없을 때만 OpenAI 전사를 호출합니다. 저장된 키의 실제 모델 목록을 확인하기 전에는 홍보 이름을 API ID로 추측하지 않습니다.

어시스턴트 답변의 `전략 스튜디오 검토 영역으로 보내기`는 복사·붙여넣기를 줄이는 전달 기능입니다. 답변은 편집 가능한 초안으로 돌아오며 사용자가 확정해야 원본과 별도 보완 근거로 결합·재분석됩니다. AI 답변만으로 전략 저장·승인·PAPER·LIVE를 자동 실행하지 않습니다.

Strategy Studio에서 위험예산이나 실행 조건이 누락되면 AI 어시스턴트는 부족한 이유와 질문·입력 예시를 설명할 수 있지만 전략 원문이나 설정을 대신 변경하지 않습니다. 사용자는 Strategy Studio의 `질문으로 함께 완성` 카드에 자신의 답을 입력하고 `답변 확정 후 다시 분석`해야 합니다. AI 예시는 자동 적용되지 않으며, 사용자 답변은 원본과 별도 해시 근거로 저장됩니다. 기존 원문과 충돌하는 답변은 차단되고, 진입·청산·방향·지표 임계값을 AI가 추측해 채우지 않습니다. NoahAI 재량 운용을 원하면 기본 NoahAI 또는 confirm 경로로 명확히 전환합니다.

Strategy Studio의 `AI에게 묻기`는 `ai_custom` 문맥을 사용합니다. 현재 차단 코드와 쉬운 제목을 함께 보내며 일반 거래소 포지션 상태로 질문을 바꾸지 않습니다. 외부 Provider가 공백·오류를 반환하면 그 응답을 캐시하지 않고 로컬 정본 안내를 표시합니다. 왕복 중 Strategy Studio는 서비스별 keep-alive 상태를 유지해 원문·파일·분석·가이드 단계를 보존합니다.

## 1. 일반 안내와 심층분석의 차이

| 구분 | 일반 안내 | 심층분석 |
|---|---|---|
| 외부 AI 호출 | 없음 | 사용자가 선택한 질문 1건만 호출 |
| API 키 | 불필요 | 설정한 Provider 키·모델 필요 |
| 비용 | 외부 AI 비용 없음 | Provider 토큰 비용과 일/월 상한 사용 |
| 근거 | 설정 정본, 런타임 상태, NoahAI 관리 포지션, 최근 구조화 신호·실행 메트릭 | 일반 안내와 같은 구조화 근거를 Provider에 전달 |
| 설정·주문 변경 | 하지 않음 | 하지 않음 |

설명 수준의 `초보자 / 일반 / 고급`은 답변의 용어와 상세도를 바꾸고 각 수준의 시스템 지시문·캐시를 분리하지만 거래 설정은 변경하지 않습니다. Strategy Studio에서 열면 초보자가 기본입니다.

## 2. 현재 답할 수 있는 내용

- High vol, PAPER/LIVE, 다중 거래소, AI 커스텀 절차와 현재 저장 설정
- 질문에 명시한 거래소·증권사의 실행 모드와 시작·정지 상태
- NoahAI 관리 포지션의 종목, 방향, 진입가, 현재가, TP, SL, 적용 전략·버전
- 최근 구조화 신호의 방향, 추세, 판단 근거
- 최근 실행 사이클의 후보·신호·주문·차단 수
- 거래가 없는 경우 확인할 실행·HOLD·국면·쿨다운·포지션 상한·API/주문 가드레일 순서
- LIVE 통계의 오늘·7일·30일·전체·사용자 지정 범위, 현재 적용된 표시 기준시각, 원본 기록 보존 여부
- PAPER 통계의 같은 기간 범위, 현재 가상 포지션, Strategy Studio 검증의 일시정지·재개·이전 attempt 보존 여부

질문에 `바이비트`, `업비트`, `키움`처럼 대상을 적으면 현재 화면에서 선택한 대상보다 질문의 대상을 우선합니다. 포지션을 묻지 않은 추세 질문은 포지션 유무와 관계없이 해당 대상의 최근 구조화 시장 신호를 확인합니다.

## 3. 근거가 없을 때의 동작

어시스턴트는 화면에 보이는 숫자만으로 보유 이유나 시장 방향을 만들지 않습니다.

- NoahAI 진입 원장이 없는 수동·외부 보유자산은 NoahAI 관리 포지션으로 단정하지 않습니다.
- 최근 신호가 없으면 추세를 추정하지 않고 필요한 학습·분석 기록을 안내합니다.
- PAPER 질문은 과거 LIVE 저장소가 아니라 현재 PAPER 런타임 포지션과 최근 PAPER 실행 근거를 사용합니다.
- `HOLD`는 신규 진입 보류일 수 있으므로 기존 포지션 청산 명령과 같은 뜻으로 해석하지 않습니다.
- TP·SL 또는 현재가가 없으면 유지 사유를 확정하지 않습니다.

## 4. 사용 순서

1. 대시보드에서 `AI 어시스턴트`를 엽니다.
2. 서비스와 설명 수준을 선택합니다.
3. 사용법·설정·현재 상태 질문은 비용 없는 `일반 안내`로 시작합니다.
4. 외부 AI의 더 긴 해석이 필요할 때만 `심층분석`을 선택합니다.
5. 심층분석 전 `설정 → AI 엔진/API`에서 Provider·키·모델 연결과 예산을 확인합니다.
6. 답변의 거래소·운용 모드·근거 시각·포지션·신호를 확인합니다.
7. 변경이 필요하면 설정 화면에서 직접 바꾸고 `현재 설정 저장`을 누릅니다.

## 6. 비용과 대화 문맥

- 일반 안내는 외부 Provider를 호출하지 않습니다.
- 심층분석은 `절약형 / 표준형 / 정밀형` 문답 정책에 따라 최근 대화 최대 4 / 8 / 12개와 출력 상한을 사용합니다.
- 같은 심층분석 질문은 설정된 캐시 시간 동안 재사용될 수 있습니다.
- 화면에는 심층분석의 Provider 사용 여부, 일일 사용량과 오류를 구분해 표시합니다.
- 거래 엔진 자동분석 예산과 사용자가 직접 누른 심층분석 예산은 별도 원장으로 관리합니다.

## 7. 설정과 실행의 안전 경계

어시스턴트는 읽기 전용 설명 도구입니다. 다음 작업을 수행했다고 주장해서는 안 됩니다.

- 설정 자동 저장 또는 기본값 복구
- 거래 시작·중지
- 주문·취소·청산
- API 키 입력·변경·표시
- 출금·송금
- AI 커스텀 전략 저장·승인·최종 적용

현재값과 설정 위치는 설명할 수 있지만 실제 변경은 해당 설정 화면에서 사용자가 저장해야 합니다.

## 8. 차트 이미지 분석

- PNG/JPG/WEBP, 최대 8MB의 사용자가 선택한 이미지에 한해 분석합니다.
- 사용자가 외부 비전 분석을 명시 실행할 때만 Analyst Provider와 별도 AI 예산을 사용합니다.
- 결과는 화면 근거, 불확실성, 참고 플랜을 분리하며 주문을 실행하지 않습니다.
- 선택 이미지와 결과를 초기화할 수 있고 임시 파일은 분석 후 정리합니다.

## 9. 정상·오류 판별

| 증상 | 판정과 확인 |
|---|---|
| 서로 다른 빠른 질문에 같은 소개 문장 반복 | 정상 아님. 현재 버전과 Gateway 응답 로그 확인 |
| 일반 안내가 Provider 키를 요구 | 정상 아님. 모드가 `guide`인지 확인 |
| 심층분석 연결 실패 | Provider 키·모델·잔액·네트워크·일/월 상한 확인 |
| 포지션이 있는데 없다고 답함 | NoahAI 관리 포지션인지, 질문 대상 거래소가 맞는지, 엔진 런타임 연결 확인 |
| 화면 숫자만 보고 보유 이유를 단정 | 정상 아님. 구조화 포지션·신호 근거 전달 여부 확인 |
| 설정을 바꿨다고 답하지만 실제 값 불변 | 현재 계약상 어시스턴트는 설정을 변경하지 않음. 설정 화면에서 직접 저장 |

## 10. 검증 범위

현재 소스 회귀는 다음을 확인합니다.

- 일반 안내가 외부 Provider를 호출하지 않음
- 설정 질문과 시장·성과·거래 부재·리스크 질문이 서로 다른 근거로 답함
- 거래소·증권사 이름을 질문에서 선택 가능
- 포지션 답변에 진입가·현재가·TP·SL·전략 버전·최근 신호를 대조
- 심층분석에 동일한 구조화 운영 근거를 전달
- 설명 수준·비용 정책·최근 대화 상한 적용

소스 테스트 통과는 Windows 설치본·실제 AI Provider·6개 거래소·4개 증권사·24~72시간 운용 완료를 뜻하지 않습니다.
