# v3.9.1.0 Web UI 1:1 전환 실행 원장

기준일: 2026-08-19  
기준 제품: v3.9.0.10 `AITrading.exe` 및 저장소 루트의 레거시 `main.py`  
대상 제품: v3.9.1.0 React/Electron Web UI  
당시 판정: **v3.9.1.0 전환 진행 중 · 전체 1:1 미완료 · 당시 테스터/공개 배포 불가**  
현행 제품: **v3.9.1.27 Windows 공개판**. 이 문서는 v3.9.1.0 전환 범위의 이력·미해결 항목 원장이며 현재 릴리스 신원을 판정하지 않는다.

이 문서는 로그인부터 대시보드, 5개 서비스, 모든 하위 탭, 거래소·증권사 화면, 설정, 매뉴얼, 종료·업데이트까지의 **유일한 1:1 완료 원장**이다. 소스가 연결됐거나 빌드가 성공했다는 이유로 행을 완료 처리하지 않는다.

사용자·운영·외부 사이트의 기능 설명은 [v3.9.1.0 기능·안내·배포 정합성 정본](archive/release/V3910_CAPABILITIES_AND_RELEASE_GATES.md)을 따른다. 그 문서는 완료 판정을 대신하지 않으며 본 원장의 필수 행이 모두 `[x] VERIFIED`가 되어야만 1:1 완료로 전환한다.

## 1. 1:1의 정의

각 행은 아래 여섯 조건을 모두 만족해야 완료다.

1. **정보 구조**: 탭 이름·순서·조건부 노출·기본 선택이 레거시와 같다.
2. **시각 구조**: 창 크기, 패널 배치, 간격, 색, 글자, 버튼, 스크롤, 빈 공간이 같다. 사용자가 승인한 개선만 별도 기록한다.
3. **동작**: 모든 버튼·입력·검색·저장·새로고침·팝업·딥링크가 같은 결과로 이어진다.
4. **데이터 범위**: 서비스·거래소·증권사·사용자별 데이터가 섞이지 않고, 같은 원본과 계산식을 사용한다.
5. **상태 표현**: 미설정·연결 중·연결됨·비활성·실행 중·실패·표본 부족을 구분한다. 빈 값을 성공이나 연결로 포장하지 않는다.
6. **증거**: 자동 회귀, macOS 실제 렌더, 레거시 나란히 비교, Windows 설치본 E2E를 각각 통과한다.

### 상태 기호

- `[ ] OPEN`: 구현 또는 증거가 부족하다.
- `[~] SOURCE`: 소스와 자동 회귀만 확인했다. 화면 1:1 완료가 아니다.
- `[~] MAC`: macOS 실제 화면까지 확인했다. 레거시 나란히 비교와 Windows가 남았다.
- `[x] VERIFIED`: 여섯 조건과 Windows E2E까지 모두 확인했다.
- `N/A`: 레거시에 없고 이번 전환 범위에도 넣지 않기로 승인된 항목이다.

### 누가 언제 `1:1`이라고 말할 수 있는가

`1:1`은 사용자가 먼저 결함을 찾아 주면 붙이는 표현이 아니다. 개발자가 아래 내부 검증을 먼저 끝내고 증거를 이 원장에 남긴 뒤에만 테스터 후보를 전달한다.

1. **개발자 소스 완료**: 모든 행의 기능·데이터·상태 계약과 자동 회귀가 PASS다. 이 단계는 `1:1`이 아니다.
2. **개발자 로컬 1:1 후보**: 동일 계정·설정·데이터·창 크기에서 레거시와 Web UI를 나란히 실행하고, 로그인·도움말·5개 서비스·모든 하위/source 탭·모든 버튼·설정·매뉴얼을 직접 조작해 승인되지 않은 차이 0건을 확인한다. 각 행의 `MAC`과 `레거시 비교`가 PASS여야 한다.
3. **Windows 테스터 후보**: Windows 설치본에서 아이콘·설치·업그레이드·자동/수동 업데이트·재시작·롤백·DPI·반복 탭 전환·PAPER 안전 종료를 개발자가 먼저 스모크 검사한다. 이 단계가 끝난 뒤에만 테스터에게 전달한다.
4. **최종 1:1 VERIFIED**: 테스터가 실제 Windows 환경과 허용된 외부 계정/PAPER를 검증하고 모든 행이 `[x] VERIFIED`가 된 상태다. 이때만 사용자와 외부에 `1:1 전환 완료`라고 말한다.

사용자의 역할은 2~3단계를 대신하는 것이 아니라, 개발자 검증을 통과한 후보의 실제 환경 최종 확인과 체감 피드백이다. `OPEN`, `SOURCE`, `RECHECK`가 하나라도 있으면 사용자에게 완성품처럼 확인을 요청하지 않는다.

## 2. 실행 기준과 증거 보관

### 2026-08-15 정본 통합 및 실시간 로그 교정

- `config/product_ui_contract.py`를 레거시와 Web UI가 함께 읽는 데이터 전용 정본으로 추가했다.
- 블록체인·주식/증권·자산 통합·생활금융·AI애널리스트의 기능명과 순서, 블록체인 6개 거래소, 증권 4개 증권사, 설정 8개 영역, 메뉴얼 11개 영역을 한 계약으로 고정했다.
- `ui/service_tab_policy.py`와 `web_platform/feature_inventory.py`가 모든 서비스의 정본 순서를 시작 시 검증한다. 하나라도 다르면 화면을 임의 순서로 열지 않고 실패한다.
- 실시간 로그 API는 현재 로컬 날짜의 로그만 반환한다. 과거 보존 로그는 삭제하지 않지만 실시간 화면에 현재 세션처럼 표시하지 않는다.
- 주식/증권 종목 정보 입력을 코인 심볼 문구와 분리하고 `종목코드 직접 분석` 및 주식 예시로 교정했다.
- Web 사용자 화면과 설정 설명의 `자동매매` 표현을 `자율주행`으로 교정했으며, 하단 상태는 레거시 정본인 `NoahAI-AI 금융 동반자 | MODE ... | EXCHANGE ... | TIME ...` 계약을 유지한다.
- 자동 증거: 집중 회귀 `148 passed`, 전체 회귀 `1,621 passed, 8 skipped`, Web production build PASS.

이 항목은 정보 구조·데이터 격리·표현의 **소스 완료 증거**다. 아래 OPEN인 화면 시각 비교, 실제 버튼 조작, Windows 설치본 E2E가 끝나기 전에는 전체 1:1 완료로 판정하지 않는다.

### 2026-08-16 비교 캡처 후 설정·매뉴얼·음성 흐름 보강

- Desktop의 2026-08-16 비교 캡처 28개를 시간순으로 확인했다. 이 중 2개는 데스크톱/동영상이 섞인 비정본 캡처이며, 나머지는 Web UI 개선안과 이전 Web 후보의 블록체인·주식·자산 통합·생활금융·AI애널리스트·설정·매뉴얼 비교 자료다. v3.9.0.10 CTk/EXE를 같은 계정·창 크기로 실행한 캡처는 아니므로 `LEGACY COMPARE` 증거로 승격하지 않는다.
- 설정에 비밀값을 반환하지 않는 `/api/v1/settings/diagnostics`와 사용자 명시 클릭에만 외부 모델 API를 조회하는 `/api/v1/settings/ai-provider-check`를 추가했다. 의도 헤더가 없으면 428로 차단하고, 키 미설정은 연결 실패와 조치를 표시한다.
- AI 엔진/API에 사용 가능 모델 새로고침·기능 검증, 절약형/균형형/정밀형 설명 프리셋, 5문항 초기 설정 진입, 저장된 음성 입력/TTS 상태 요약을 연결했다. 프리셋은 저장 전 변경 대기이며 자동으로 설정이나 주문을 확정하지 않는다.
- 거래소 API에 공식 개발자/발급 안내 링크, 주문을 만들지 않는 실제 계정 snapshot 연결 점검, 비밀값 없는 지원 요약 복사·TXT 저장을 추가했다. 키움 REST API와 한국투자 Open API는 각 공식 개발자 포털을 사용한다.
- AI 시스템 상태는 로컬 설정과 런타임을 네트워크 호출 없이 표시한다. PAPER가 꺼져 있어도 주문 대상 자격증명이 준비되지 않으면 `LIVE 차단`으로 표시한다.
- AI 어시스턴트 음성 입력은 저장 설정이 켜진 경우 Chromium/Electron `SpeechRecognition`을 사용하고, 답변 읽기는 `speechSynthesis`를 사용한다. 음성 결과는 입력칸에서 사용자가 확인한 뒤에만 전송된다.
- 매뉴얼 검색은 다음 결과 탭으로 순환하고 현재 본문의 모든 일치어를 `<mark>`로 강조한다. 실거래 준비·설정·업데이트는 설정으로, AI 커스텀과 거래소·증권은 각 실제 기능 화면으로 이동하며 팝업 닫기 복귀를 유지한다.
- macOS 개발 브라우저 실제 렌더에서 설정 기본 수 `2/14/4/5/9/1/2`, AI 키 미설정 Provider 점검 실패 폐쇄, 시스템 `LIVE 차단/detached`, 매뉴얼 `API 키` 검색 10개 탭·본문 강조·설정 딥링크를 확인했다. 이는 `MAC` 증거이며 Electron/레거시 나란히 비교와 Windows를 대신하지 않는다.
- 자동 증거: 집중 회귀 `148 passed, 1 warning`, 전체 회귀 `1,621 passed, 8 skipped, 1 warning`, production build `46 modules`·CSS `66.57 kB`(gzip `13.54 kB`)·JS `392.79 kB`(gzip `116.99 kB`), 전체 범위 소스 계약 감사 PASS.

## 13. 릴리즈 차단 조건

다음 중 하나라도 남으면 배포하지 않는다.

- 이 원장의 `[ ] OPEN` 또는 `[~]` 항목이 하나라도 존재
- Web 화면에 특정 서비스/source가 아닌 데이터가 한 건이라도 표시
- API 키 미설정인데 연결됨·조회 실패·실행 가능으로 표시
- 기존 설정·로그·전략·감사 원장이 업그레이드 뒤 달라짐
- 하단 상태바 잘림, 전체 창 무한 스크롤, 탭 중복 활성, source 순서 이동
- 레거시와 Web 캡처를 같은 크기로 비교하지 않음
- Windows Setup 신규 설치·업그레이드·자동업데이트·실패 롤백 미검증
- 실제 계정 읽기와 24~72시간 PAPER 미검증

## 14. 현재 이번 작업에서 확인된 사실

- 선택 source 통계·종료 거래를 엄격히 분리하는 소스 계약과 회귀를 추가했다.
- 일반 거래 통계는 기본 `전체` 범위로 시작하고, 사용자가 거래소·증권사 필터를 선택한 뒤에만 해당 source로 제한한다.
- 출처가 없는 과거 코인 종료 거래는 `BINANCE (LEGACY)` 그룹으로 분리하며 UPBIT·BITHUMB 등 다른 거래소에 복제하지 않는다.
