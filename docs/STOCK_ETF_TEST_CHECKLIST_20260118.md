## 🎯 설계 결정 (2026-04-23)

**주식과 ETF는 단일 "stock" 서비스로 통합 관리**
- **구조**: 주식과 ETF를 구분하지 않음 (증권사별로만 구분)
- **AI 컨텍스트**: "주식/ETF" 통합
- **데이터**: 단일 테이블 (is_etf 플래그로만 구분)
- **상세**: `docs/STOCK_ETF_ARCHITECTURE_DECISION_20260423.md` 참고

- 그러나 사용자 화면에서 `주식만 운용` / `ETF만 운용`을 별도 선택하는 모드는 아직 없습니다.

## 📋 테스트 목적

주식/증권 서비스의 현재 구현 범위를 기준으로 다음을 검증합니다.

1. 설정 UI와 서비스 전환이 정상 동작하는지
2. 증권사 하위 탭 UI 골격이 현재 구현 상태와 일치하는지
3. AI 어시스턴트와 사용자 메뉴얼이 주식/ETF 컨텍스트로 반응하는지
4. 블록체인 서비스에 회귀가 없는지

중요:

- 이 문서는 “실제 증권사 주문/잔고/포지션 연동 완료 여부”를 검증하는 문서가 아닙니다.
- 현재 주식 서비스는 UI 골격과 메뉴얼/AI 컨텍스트 중심으로 구현되어 있으며, 다중 증권사 실어댑터와 ETF 전용 지표 입력은 아직 완료되지 않았습니다.
