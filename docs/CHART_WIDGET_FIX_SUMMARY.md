# ExchangeLearningManager 구조 문제 및 해결 내역 (2025-11-01)

## 문제 정의
- 거래소별 학습 데이터 저장/로깅/인사이트 기능에서 다음과 같은 구조적 문제가 발견됨:
    - logger.XXX만 사용하여 trading_{exchange}.log에 로그가 남지 않음
    - 함수(def ...) 밖에 고아 코드(본문만 남은 코드)가 존재하여 문법 오류 및 실행 오류 발생
    - 일부 학습 데이터 저장/인사이트 생성 이벤트가 로그에 남지 않아 실제 동작 검증이 어려움
    - 코드 리팩토링/충돌/복붙 과정에서 함수 시그니처가 사라지거나, 본문만 남아있는 코드가 발생

## 원인 분석
- logger.XXX와 log_event 혼용, 표준 미준수
- 함수 시그니처와 본문 분리/누락(코드 충돌, 복붙 실수 등)
- 예외처리 및 반환값 일관성 부족

## 해결 방법
- logger.XXX → log_event로 교체하여 trading_{exchange}.log에 모든 이벤트가 기록되도록 표준화
- 함수 밖 고아 코드 삭제 또는 함수로 복구(특히 get_exchange_specific_insights)
- 인사이트/저장/로깅 로직을 함수 내부로 정리, 예외처리 및 반환값 일관성 확보
- 코드 수정 내역을 마크다운에 기록하여 추후 디버깅 및 코드 리뷰에 활용

## 적용 내역
- 2025-11-01: ExchangeLearningManager 내 get_exchange_specific_insights 함수 복구 및 구조 정비
- 2025-11-01: logger.XXX → log_event로 교체, 함수 밖 고아 코드 삭제/정비
- 2025-11-01: 본문 누락/중복/구조 오류 등 코드 전반 점검 및 수정

## 추가 조치 예정
- 모든 구조적 문제/해결 내역을 지속적으로 마크다운에 기록
- 코드 리뷰 및 테스트를 통해 추가 문제 발생 시 즉시 반영
