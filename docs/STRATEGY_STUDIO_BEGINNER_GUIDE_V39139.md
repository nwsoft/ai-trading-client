# 전략 스튜디오: 자료 이해 → 대화 → 검증 차트

2026-09-19 갱신 · v3.9.1.39 최초 안내 / 현재 소스 후보 v3.9.1.41. 공개 stable/latest는 v40이며 v41 새 Windows 설치본은 별도 검증합니다.

v40에서는 본문 14px·보조 13px와 220px 입력 공간을 사용합니다. 상단 「1. 전략 입력 → 2. 이해·보완 → 3. 저장 버전·검증·차트」로 이동하며, 차트는 저장 버전에서 과거 시세 재생을 실행한 결과에 표시됩니다. 코인/주식·ETF 공통이며 검증·승인·여권 경계는 바꾸지 않습니다.

## 1. 처음이면 어떻게 시작하나요?

- 전략이 없으면 `처음 사용 · 5분 따라 만들기` 또는 `AI 멘토 인터뷰`에서 시작합니다.
- 아이디어만 있으면 `질문으로 함께 완성`에서 짧은 문장으로 적고 `분석하고 보완 질문 받기`를 누릅니다. 예: “RSI가 낮을 때 매수하고 싶다.” AI가 숫자를 대신 확정하지 않으며 빠진 조건을 질문합니다.
- 기존 자료가 있으면 파일이나 URL을 넣고 `AI 분석 및 전략 초안 만들기`를 누릅니다. 읽기 경고를 먼저 확인합니다.

Level 1에도 `이 전략 쉽게 이해하기`가 표시됩니다. 진입(시작), 청산(종료), 손절(손실 제한), 익절(이익 확정), 위험·비중(사용 자금), 시장 조건(사용 상황)을 읽으세요. **분석 당시 원문·사용자 확인 보완 규칙**이며 이후 편집한 최종 적용값이나 이미 운용 중인 전략을 보증하지 않습니다. 줄임표는 요약이므로 상세 근거와 비교하세요.

## 2. AI와 되물으며 완성하기

1. 빠진 조건에 자신의 답을 쓰고 `답변 확정 후 다시 분석`합니다.
2. 어려우면 `이 질문을 AI와 상의` 또는 `이 결과 AI에게 묻기`를 누릅니다.
3. `일반 안내`는 외부 AI 없는 정형 도움말입니다. 결과 질문에서는 현재 규칙과 자료 범위를 설명합니다. 자유로운 AI 대화는 기본 보호 경로의 `심층분석`을 직접 선택하고 전송합니다. Provider 연결·예산과 비용이 적용됩니다.
4. 결과 질문은 현재 분석의 규칙·요약·읽은 범위·경고·일부 성과 관련 발췌를 접힌 자료 영역에 붙입니다. 다음 질문에도 같은 분석 자료가 사용됩니다. `전달할 분석 자료 보기`로 확인하고 `분석 자료·대화 해제`로 제거할 수 있습니다. 원본 파일 전체나 경로를 이 첨부에 넣지는 않습니다. 외부 심층분석은 기존 전략 카탈로그 등 앱 문맥도 사용하므로 보호 경로를 유지하세요.
5. `이 답변을 전략 스튜디오 검토 영역으로 보내기`로 돌아옵니다. 설명·예시·추측을 지우고 자신이 원하는 실행 조건만 남겨 `사용자 보완 근거로 확정·재분석`합니다.
6. 새 버전 저장 → 사용자 승인 → 과거재생 또는 비대상 확인 → PAPER → 검증 후 최종 적용으로 진행합니다. LIVE는 별도 권한·실행 확인이 필요합니다.

AI 대화는 의미를 풀고 질문하는 보조입니다. 지원하지 않는 Pine 동작, 모순된 원문, 없는 진입 조건을 자동 해결했다고 보지 않습니다. 원본은 보존되고 사용자 확인 답변은 별도 근거로 남습니다. 대화만으로 저장·승인·거래하지 않습니다.

## 3. YouTube·책·Markdown·Pine 설명

본인이 사용할 권리가 있는 YouTube URL, PDF 문서, Markdown·텍스트·Pine 파일을 넣습니다. 종이책 자체나 보호된 코드 전체를 링크만으로 읽을 수는 없습니다.

`자료 분석 범위`에서 PDF 쪽수, 자막/전사 확보 여부, 대표 장면과 경고를 확인합니다. 대표 장면과 자막을 확보해도 영상 전체를 빠짐없이 이해했다는 뜻은 아닙니다. 실패하면 관련 자막·문단·Pine 원문을 직접 제공하고 다시 분석합니다. API가 없으면 로컬 규칙 추출만 가능하며 영상·이미지 해석은 제한됩니다.

`영상·문서가 말하는 성과는 검증된 수익인가요?`는 성과 키워드를 포함한 일부 원문을 보여줍니다. 저자의 주장인지 질문·예시인지도 문맥 확인이 필요합니다. **발췌 없음은 전체 자료에 성과가 없다는 판정이 아닙니다.** 긴 자료의 일부는 설명 입력 한도로 생략되므로 필요한 대목을 따로 질문하세요.

권장 질문:

> 이 영상의 전략을 진입 → 청산 → 손실 제한 순서로 설명해줘. 영상 속 수익은 어떤 기간·종목·비용 기준인가? 없는 정보는 모른다고 하고 내가 정할 조건을 하나씩 물어봐.

출처의 수익 주장 / NoahAI 과거재생 / PAPER / LIVE / 여권은 다른 근거입니다. 원문의 승률을 NoahAI 검증 성과로 복사하지 않습니다.

## 4. 차트 따라 보기

1. 자체 진입조건 전략을 저장·승인한 뒤 `과거 시세 재생` 검사를 실행합니다. 기본 AI 후보 확인처럼 과거재생 비대상인 전략에는 임의 차트를 만들지 않습니다.
2. 저장 버전 → `검증 근거 보기` → `과거재생 차트 · 타점·누적 수익률·거래 내역`을 펼칩니다.
3. 검증 기관·종목·시간봉·기록 시각을 확인합니다. 상단은 저장된 검증 캔들, 하단은 청산 기준 누적 수익률입니다.
4. 초록 ▲ BUY는 매수, 빨강 ▼ SELL은 매도입니다. LONG은 BUY 진입/SELL 청산, SHORT는 SELL 진입/BUY 청산입니다. 국내 현물 주식·ETF의 신규 공매도를 허용하는 뜻이 아닙니다.
5. 거래표의 `#번호 보기`를 누르면 해당 구간으로 확대합니다. 모든 화살표는 유지하되 선택 거래만 타점 이름을 표시합니다. 같은 봉에 여러 거래가 있으면 거래표로 구분합니다. `전체 구간`으로 복귀하고 20건을 넘으면 페이지를 넘깁니다.
6. `선택 거래 계산 원본 값 보기`로 반올림 전 가격·수익률을 확인합니다. 시간은 UTC 봉 시작 시각이며 KST와 9시간 차이가 있습니다. 실제 체결 시각이 아닙니다.

곡선은 비용 차감 거래별 수익률을 복리 연결한 모의 결과입니다. 실제 잔고·미실현손익·주문 수량·레버리지 PnL이 아닙니다. 비용은 설정 기반 추정치이고 펀딩비·시장충격은 미반영입니다. 0거래·0%는 수익성 통과가 아닙니다.

코인·주식·ETF의 조작은 같지만 실제 제공 시간봉·통화·비용은 구분합니다. 없는 증권 분봉을 일봉으로 대체하지 않습니다. 구형 결과에 원본 캔들이 없으면 새 버전 저장·승인 후 검사합니다. 차트 표시는 PAPER·LIVE 권한이나 여권 등급을 올리지 않습니다.

## 검증 경계

이 보완은 설명·자료 전달·매뉴얼 변경입니다. 모든 원문을 실행 가능한 전략으로 변환하거나 실계정 PnL 정합 문제를 해결하는 변경이 아닙니다. 실제 Provider 답변 품질, Windows 설치본, 기관별 계정은 환경별 테스트 대상입니다. 내부 검증 후 테스트 설치본으로 사용자 대조를 받고, 안정판 승격은 남은 PnL·실환경 게이트에 따라 판단합니다. 사용자 원본 제출을 테스트 배포의 일률적 선행조건으로 삼지 않습니다.
