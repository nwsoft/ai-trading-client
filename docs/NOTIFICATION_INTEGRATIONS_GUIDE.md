# NoahAI 외부 알림 연결 가이드

v3.9.1.41 후보는 같은 설정 탭에 **내 PC 원격 관리 베타**를 추가합니다. 알림 연결과 별도 동의이며 Telegram 명령 기능이 아닙니다. 알림 후 daltrading에 로그인해 상태를 확인하고, PC에서 허용했다면 신규 제출만 일시정지합니다. [단계별 가이드](REMOTE_MANAGEMENT_GUIDE_V39141.md). 원격 시작·재개·전량 청산은 제공하지 않습니다.

이 문서는 설정의 `알림·리포트`에서 Discord 또는 Telegram을 연결하는 절차와 현재 제공 범위를 설명합니다. 이 기능은 NoahAI가 사용자에게 메시지를 보내는 **출력 기능**입니다. TradingView 신호를 NoahAI로 받는 입력 webhook과는 별개이며 주문 권한을 만들거나 바꾸지 않습니다.

## 일일 손실 경고의 계산 범위 (v3.9.1.41 후보)

일일 경고는 NoahAI의 당일 확정 청산 순손익과 관리 포지션의 미실현 손익을 구분합니다. 거래소 계좌 전체의 일별 PnL과 같은 범위라는 뜻은 아닙니다. Binance는 현재 계좌 포지션 조회가 성공하고 관리 수량이 일치하는 경우만 미실현을 사용하며, 미대조·조회 실패를 정상 또는 0손실로 표시하지 않습니다.

손실률의 분모는 같은 API 연결·날짜·기관·통화의 최초 확인 시점에 조정한 위험 기준자산을 저장해 재시작 후에도 유지합니다. 실제 자정 잔고를 복원한 값은 아니며 API 연결 변경은 별도 범위입니다. 알림 전달 채널을 바꿔도 이 계산 기준은 같고, 과거 알림 메시지는 소급 수정되지 않습니다. 실제 기관/Windows 검증과 전체 계좌 일별 대조는 아직 별도 게이트입니다. [DB 기반 조사와 남은 범위](V39141_PNL_GUARDRAIL_FEEDBACK.md).

## 가장 쉬운 선택

### 시장국면 수신 모드 (2026-09-22 미배포 소스 변경)

`설정 → 알림·리포트`의 `시장국면 변화`와 기관별 알림을 켜고 `시장국면 알림 · PAPER / LIVE / 학습·관찰`에서 원하는 실행 모드를 선택한 뒤 탭을 저장합니다. 기존 설정에 새 항목이 없으면 모두 수신합니다. 메시지는 감지 당시 모드를 표시합니다. 모드별 선택은 시장국면에만 적용되며 LIVE 손실·위험 알림, 분석/거래 실행 상태, 전략 규칙을 변경하지 않습니다.

자동 이벤트는 가드레일 중단·손실 경고·위험 데이터 확인 실패·시장국면 변화·실행 오류·새 업데이트 안내 6종입니다. 리포트 전송과 연결 테스트까지 공통 발송 유형은 8종입니다. 시장국면의 초기 관찰·동일 상태·시세 미확인·재선정 대기는 변화 알림이 아닙니다. 메시지가 없다는 사실만으로 정상/장애를 판정하지 않습니다.

실행을 꺼둔 기관을 알림 때문에 조회하지 않습니다. 후보 미산출 복구 중 반복 분석을 줄이는 최적화는 유지하며, 정상 후보로 실행 중이면 체결이 없어도 관찰합니다. 승인된 전략 스튜디오 전략도 기관 실행 경로를 사용하되 `market/symbol/both/none` 선언에 따라 국면 적용 범위가 다릅니다. 기관 시장 알림은 전략별 활성화·종목 신호·과거재생 알림이 아닙니다.

현재 코인은 기관별 시세와 정해진 계산 규칙을 사용하며 증권은 어댑터가 제공하는 지수 이력/지수값을 우선하고 없으면 대표 종목 등락률을 대용합니다. 대표 종목 기반 결과를 실제 지수 판단으로 설명하면 안 됩니다. 자동시험 통과는 실제 시세에서의 판단 정확도나 수익 개선 보장이 아닙니다.

최종 감사 보강: 잘못된 형식의 등락률·중복 날짜·누락 종가는 정상 국면 근거로 쓰지 않습니다. 지수 이력이 부적합하면 유효한 당일 지수/대표 종목을 확인하고, 모두 확인되지 않으면 unknown을 유지합니다. 알림 서버의 잘못된 응답을 전송 성공으로 간주하지 않으며 한 채널 오류가 다른 채널 전송을 막지 않도록 격리합니다. 제한된 재시도가 모두 실패하면 전달을 보장하지 못하며 외부 서버 장애를 앱이 무한 재시도로 해결하지 않습니다.

- Discord는 Webhook URL 하나만 필요하므로 가장 간단합니다.
- Telegram은 Bot Token과 받을 Chat ID가 필요하지만, NoahAI의 `대화방 자동 찾기`로 Chat ID를 선택할 수 있습니다.
- 카카오톡은 개인 Webhook 방식이 아니므로 이번 간편 연결 범위에 포함하지 않습니다.

## Discord 연결

1. Discord에서 메시지를 받을 서버와 채널을 엽니다.
2. `채널 편집 → 연동 → 웹후크 → 새 웹후크`를 선택합니다.
3. `웹후크 URL 복사`를 눌러 NoahAI의 `설정 → 알림·리포트 → Discord 웹훅`에 붙여 넣습니다.
4. `연결 저장`을 누른 뒤 `테스트 보내기`를 누릅니다.
5. Discord 채널에서 NoahAI 테스트 메시지를 확인합니다.
6. 같은 설정 탭 아래에서 `외부 알림 사용`과 `Discord 알림`을 ON으로 바꾸고 받을 이벤트를 선택한 뒤 `이 탭 저장`을 누릅니다.

Webhook URL은 해당 채널에 메시지를 보낼 수 있는 비밀값입니다. AI 질문·지원 메시지·화면 캡처·로그에 붙여 넣지 말고 전용 입력칸에서만 저장하세요.

## Telegram 연결

1. Telegram에서 `@BotFather`를 열고 `/newbot`을 실행해 Bot Token을 발급받습니다.
2. NoahAI의 `설정 → 알림·리포트 → Telegram 봇`에 토큰을 넣습니다.
3. Telegram에서 방금 만든 봇을 열어 `Start` 또는 `/start`를 보냅니다.
4. NoahAI에서 `대화방 자동 찾기`를 눌러 표시된 개인 대화나 채널을 선택합니다.
5. `토큰/대화방 저장`을 누른 뒤 `테스트 보내기`를 누릅니다.
6. Telegram에서 테스트 메시지를 확인합니다.
7. 같은 설정 탭 아래에서 `외부 알림 사용`과 `Telegram 알림`을 ON으로 바꾸고 받을 이벤트를 선택한 뒤 `이 탭 저장`을 누릅니다.

자동 찾기에 아무 대화방도 나오지 않으면 봇 대화에서 `/start`를 보낸 뒤 다시 찾으세요. 그룹에 보내려면 봇을 그룹에 추가하고 메시지를 한 번 보낸 뒤 다시 찾습니다.

## 받을 수 있는 운영 알림

- 일일 손실 가드레일 거래 중단
- 중단 한도 전 손실 경고
- 상승·하락·횡보·고변동 등 시장국면 변화
- 거래 워커 시작·정지 또는 안전 종료 실패
- AI 리포트 화면에서 사용자가 `연동 채널로 보내기`를 누른 현재 기간 요약

리포트는 KRW와 USDT를 환율 정책 없이 합산하지 않습니다. 현재 버전의 리포트 발송은 사용자가 버튼을 누르는 방식이며, 앱이 알아서 매일·매주 정해진 시각에 보내는 예약 기능은 아닙니다.

## 안전 동작

- 가드레일 판단과 거래 중단은 메시지 전송보다 우선합니다.
- 외부 전송은 제한된 별도 큐에서 처리하므로 느린 메신저가 거래 루프·설정 저장·AI 커스텀을 기다리게 하지 않습니다.
- 같은 이벤트는 설정한 반복 방지 시간 동안 중복 발송하지 않습니다.
- 전송 실패는 안전한 오류 코드만 기록하고 Webhook URL·Bot Token·Chat ID는 UI 응답이나 로그에 반환하지 않습니다.
- Discord는 공식 Discord HTTPS Webhook 주소만 허용하고, Telegram은 Telegram 공식 API 주소만 호출합니다.
- 로그인 계정이나 연결 정보가 바뀌면 이전 계정에서 대기 중이던 메시지는 버려 새 계정 채널로 잘못 전달되지 않게 합니다.
- PC 또는 NoahAI 앱이 꺼져 있으면 로컬 앱은 메시지를 보낼 수 없습니다. 24시간 발송에는 별도 서버 중계가 필요합니다.

## 연결이 안 될 때

1. 먼저 `테스트 보내기` 결과를 확인합니다.
2. Discord는 Webhook을 새로 만들어 다시 저장합니다.
3. Telegram은 봇에 `/start`를 보낸 뒤 `대화방 자동 찾기`를 다시 실행합니다.
4. 테스트는 성공하지만 운영 알림이 오지 않으면 `외부 알림 사용`, 채널 ON, 해당 이벤트 ON, `이 탭 저장` 여부를 확인합니다.
5. 방화벽·보안 프로그램이 Discord 또는 Telegram HTTPS 연결을 차단하지 않는지 확인합니다.

## 배포 검증 경계

소스 테스트 통과는 Windows 설치본과 실제 외부 서비스 발송 완료를 뜻하지 않습니다. 배포 후보마다 다음을 별도로 확인합니다.

1. Windows 설치·업데이트 후 설정 저장과 재시작 뒤 연결 상태 유지
2. 실제 Discord Webhook 테스트 메시지 수신
3. 실제 Telegram 개인 대화와 그룹 Chat ID 자동 찾기·테스트 수신
4. PAPER 환경에서 시장국면 변화·손실 경고·가드레일 이벤트 발송
5. 메신저 지연·연결 실패 중에도 거래 루프와 설정·AI 커스텀 응답이 지연되지 않는지 확인
6. 로그·지원 번들·설정 API에 비밀값 원문이 노출되지 않는지 확인
