# NoahAI Client SaaS 비즈니스 플랜 (코드 검증 기반, 2026-06-09)

## 1. 목적

클라이언트 앱의 실제 구현 상태를 기준으로, 가능한 매출화 범위와 단계별 비즈니스 실행안을 정의한다.

## 2. 현재 가능한 수익화

- B2C 구독형
  - 인증/세션/등급 수신 기반 운영 가능
- B2B 운영형(초기)
  - 계정 운영 대행 + 리포트 + 월 운영료
- BYOK 분리형
  - API 호출비를 고객이 직접 부담하고 플랫폼 사용료 과금

## 3. 현재 불가능 또는 제한되는 항목

- 등급별 한도 강제 과금형 SaaS
  - 실행 게이팅 코드 미완
- 완전 자동 초과 과금
  - 사용량 집계/청구 파이프라인 미완

## 4. 90일 상용화 전략

### 0~30일

- 플랜 정책 API/게이팅 1차 적용
- Basic/Starter/Plus 중심 유료화

### 31~60일

- Plus/Pro 초과 과금 이벤트 반영
- BYOK 전환 플로우 상용 반영

### 61~90일

- B2B 운영 리포트 패키지 출시
- Team 계약형 과금(좌석 + 운영료) 고정

## 5. KPI

- Free->Paid 전환율
- 플랜별 ARPU
- 제한 도달 후 업그레이드 전환율
- BYOK 전환율
- 월 이탈률

## 6. 제품-비즈니스 정합 규칙

- 기능 공개보다 운영 안전성이 우선
- 플랜 약속은 코드 게이트가 구현된 기능만 판매
- 법인/기관 계약은 B2B 계약서 기준으로만 판매

## 7. 증권사 SaaS 온보딩 기준 (2026-06-17 추가)

- 증권사 연동 상품은 아래 4개를 모두 충족할 때만 상용 플랜에 편입한다.
  1. 개인 사용 가능
  2. 서버 동작 가능
  3. 다수 고객 계좌 연결 가능
  4. 약관/제휴 정책 허용
- "API 존재"만으로 상용 포함을 결정하지 않는다.
- 키움은 REST 포털 존재 사실과 현재 클라이언트 구현(OpenAPI+ ActiveX 중심)을 분리해 안내한다.

## 8. 2026-06-22 재검증 메모 (코드 교차 확인)

- 유지 가능한 주장
  - 인증/세션 기반 운영 가능
  - user_grade 수신/저장/표시 가능
  - 멀티 거래소 상태 관리/격리 구조 존재

  - 판매 문구는 "현재 구현 기능"과 "로드맵 기능"을 분리해 표기해야 함

## 9. AI API 원가 운영 기준 (2026-07-24 실사용 점검)

- SaaS 전환은 비용 최적화의 전제조건이 아니다. 클라이언트 공통 엔진에 로컬 후보 선판정, 시장 이벤트 호출, 동일 상태 캐시, 짧은 출력, 거래소별 예산 폴백을 먼저 적용했다.
- 클라이언트 제품선은 IP 라이선스, 유료 클라이언트, AI 커스텀 무료 라이트·레퍼럴 모델을 위해 SaaS 이후에도 유지한다.
- 로컬 키·계좌 통제와 법적 책임 경계가 필요한 고객은 클라이언트 방식을 사용하고, SaaS는 중앙 분석 공유·운영 편의가 필요한 고객을 별도 대상으로 한다.
- SaaS의 추가 가치는 동일 공개시장 분석의 사용자 간 공유, 테넌트별 쿼터·원가 귀속, 중앙 캐시·배치, 운영자 모니터링이다.
- BYOK 상품은 API 비용을 고객에게 전가하는 구조일 뿐 과호출을 정당화하지 않는다. 플랫폼은 예상비용 표시와 Hard Stop을 제공해야 한다.
- 2026-05 비용 $62.05에서 2026-06 $51.73으로 16.6% 감소했지만, 2026-07-21~23 다중 거래소 구간은 3일 $9.08로 30일 단순 환산 $90.82였다.
- 최근 사용자 설정은 선택 거래소와 별개로 6개 거래소가 활성화되어 있었다. 플랜 원가 산정은 “회원 1명”이 아니라 `활성 거래소 수 × 분석 심볼 수 × LLM 재호출 횟수 × 토큰 × 모델 단가`로 계산한다.
- 최근 7일 Fee 전 PnL은 +0.056 USDT였으나 설정 수수료율 적용 추정 순PnL은 -0.730 USDT였다. 같은 기간 OpenAI 비용 약 $9.09를 포함하면 고객 경제성이 성립했다고 볼 수 없다.
- 실체결 Fee 원장과 사용자·거래소·모델별 비용 귀속이 연결되기 전에는 “학습할수록 비용 하락”, “자동 수익 개선”, “API 비용 대비 수익 우위”를 판매 문구로 사용하지 않는다.

운영 KPI:

- 사용자·거래소별 일/월 모델 요청 수
- 입력·출력·캐시 토큰과 모델별 비용
- 분석 후보 대비 실제 주문·체결 전환율
- 거래 1건당 AI 비용과 활성 거래소 1개당 AI 비용
- Fee 차감 순PnL, MDD, Profit Factor, 비용 포함 운영손익
- 예산 초과 차단률과 중복 호출 제거율

상용 게이트:

1. 클라이언트 이벤트 기반 호출·캐시·호출예산 폴백의 장시간 실사용 검증
2. 거래소 체결 commission과 OpenAI 비용을 동일 기간·거래소 기준으로 대조
3. 사용자 데이터 지원 내보내기에서 API 키·토큰 자동 제거
4. BYOK와 중앙과금형의 원가·책임·지원 범위 분리
5. SaaS 테넌트별 쿼터·초과 차단·원가 대시보드 검증
