## 1. NoahAI란 무엇인가

### 정체성 (한 문장)

**NoahAI는 AI 자산 의사결정 인프라(AI Asset Decision Infrastructure)이다.**

- NoahAI는 **판단·분석·설명·기록·검증·환류**만 수행한다.
- 실제 **주문·체결·자금 이동·법적 행위**의 책임은 항상 **사용자** 또는 **외부 시스템**(거래소·증권사·금융기관 API)에 있다.

NoahAI는 **금융상품 판매자, 운용자, 중개자가 아니다.**  
투자 판단에 대한 **법적 책임은 사용자**에게 있으며, NoahAI는 **설명 가능한 AI(XAI) 기반 판단 보조 인프라**이다.

### 왜 “인프라”인가

NoahAI는 금융기관을 **대체**하는 시스템이 아니라,  
**판단·설명·기록·검증을 표준화하여 연결하는 중립 계층(Infrastructure Hub)**이다.

- **허브** = 사용자·외부 기관이 실행을 담당하는 가운데, 판단 환경을 구조화하고 설명·기록·검증을 제공하는 계층
- 자동매매·자산 운용 주체가 아님

---

## 2. 핵심 철학: Decision과 Execution의 분리

### Decision Pipeline ≠ Execution Engine

| 담당 | NoahAI (Decision Hub) | 외부 기관·사용자 (Execution) |
|------|------------------------|-----------------------------|
| **판단·분석** | ✅ | ❌ |
| **설명·기록** | ✅ | ❌ |
| **검증·재현** | ✅ | ❌ |
| **주문·체결** | ❌ | ✅ 거래소·증권사 API |
| **자금 이동** | ❌ | ✅ 금융기관·사용자 |
| **계약·법적** | ❌ | ✅ 금융기관·사용자 |

- NoahAI는 **판단 파이프라인**을 담당한다. **실행 엔진**이 아니다.
- 모든 주문·체결·자금 이동은 **외부 거래소·증권사·금융기관 API**가 수행한다.

---

## 3. 3계층 구조 (개념)

NoahAI는 다음 3계층으로 설계되어 있다.

1. **Decision Layer (판단 계층)**  
   시장·자산 분석, 자산 선정, AI 학습·환류, 판단 근거 산출.  
   실행은 하지 않는다.

2. **Execution Bridge Layer (집행 브리지 계층)**  
   판단 결과를 외부 API(거래소·증권사)에 전달하는 **연결 계층**만 담당.  
   실제 주문·체결은 외부 API가 수행한다.

3. **Audit & Replay Layer (감사·재현 계층)**  
   로그·DB·설명 가능 AI(XAI)를 통해 모든 판단 과정을 기록·재현·검증 가능하게 한다.

## 4. 기술적 우수성: 구조·철학·검증 방식

### 구조

- **학습·기록·검증·설명 가능 구조**: 규칙 기반/비학습형 시스템의 한계(블랙박스, 적응 불가)를 완화하도록 설계되었다.
- **자산군 독립 파이프라인**: 암호화폐, ETF, 주식, 부동산 등 **동일한 판단 계층**을 재사용할 수 있는 구조로, 자산 타입만 교체하면 확장 가능하다.
- **멀티모달 분석**: 차트 이미지, 수치 데이터, 시장 심리 데이터를 통합하여 **판단 보조**에 활용한다(실행 지시 아님).

### 철학

- **XAI(설명 가능한 AI)**: 모든 판단·결정 과정을 로그로 남기고, 사용자가 “왜 그렇게 판단했는가”를 확인할 수 있다.
- **판단과 실행의 분리**: NoahAI는 실행 주체가 아니며, 언제든 사용자가 판단을 중단하고 개입할 수 있는 구조를 지향한다.
- **기술 기원**: 의료·돌봄 영역에서 검증된 **기록·분석·환류** 구조를 금융 의사결정 문제에 맞게 재설계하여 적용한 사례이다.

### 검증 방식

- **실환경 24/7 운영**: 암호화폐 영역에서 2024년 11월부터 실환경 운영을 통해 구조가 검증되었다.
- **로그·재현**: 모든 판단 과정이 로그로 기록되며, 사후 검증·재현이 가능하다.
- **다중 거래소 연동**: 여러 거래소와의 연동을 통해 판단·기록 파이프라인과 외부 집행 브리지가 분리되어 동작함이 검증되었다.

## 5. 구현 상태 (개념 수준)

### ✅ Already Implemented (실구현·실운영·완료)

- **암호화폐 판단 인프라**: 2024년 11월부터 실환경 24/7 운영. 다중 거래소 연동(판단·기록은 NoahAI, 집행은 외부 API).
- **Alpha Arena**: LLM 기반 판단 실험/벤치마크 환경(연구·검증 모드, 일반 서비스와 분리). 집행은 외부 API.
- **Paper Trading 모드**: 실제 집행 없이 전략·판단 검증.
- **차트 이미지 분석**: OCR 기반 차트 분석 및 AI 판단 제안(실행 지시 아님).
- **로그/XAI/DB**: 모든 판단 과정 로그 기록, 재현·감사 가능.

### 🔄 In Progress (진행 중)

- **ETF/주식 판단 인프라 확장**: UI 인터페이스·분석 서비스·신호 분기·주문 가드레일 완성. 실주문은 외부 증권사 API.  주식 자동매매는 Mock 운영(실주문 기능은 Windows + 증권사 API 환경 필요).
- **생활금융 확장**: 대출/보험/예적금 비교 엔진 + 신용도/위험도 기반 AI 상담 구현 (v3.8.9.21 기준). 현재 샘플 데이터 기반이며, 실제 금융사 API 마이그레이션은 후속 스프린트.
- **오픈소스 LLM 연동 고도화**: 다양한 LLM API 연동 구조 지원, 통합 테스트 진행.

### 🔮 Extensible (현재 구조로 가능한 확장 경로)

- **해외주식·선물·부동산·일반 금융**: 동일한 판단 파이프라인에 자산 타입만 추가하는 방식으로 확장 가능.  
  조건: 외부 API 연동 및 데이터 파이프라인 구축.  
  경계: 실행·계약·자금 이동은 항상 외부·사용자 책임.
- **기관 연계(Enterprise)**: Execution Bridge 구조로 다양한 외부 시스템(거래소/증권사/은행 등)과 연결 가능.  
  조건: 기관별 API·인터페이스 연동.  
  경계: 실행·계약·법적 책임은 기관·외부 시스템.
