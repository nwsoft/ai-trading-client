## UI 동작 기준

- 거래소 `시작`: 준비 중 `시작 중…` → 워커 확인 후 아래 상태 `진행 중`, 버튼 `중지`.
- 거래소 `중지`: 실제 루프 중지 후 아래 상태 `정지`, 버튼 `시작`.
- 상단 `⏻ 종료`: 모든 거래소 정지, Recorder DB flush, 로그 정리 후 앱 종료.
- 설정 `저장`: 저장 버튼을 눌렀을 때만 확정. X 닫기는 저장 여부를 묻는다.
- 운영 KPI: 메인 대시보드 상단 카드와 거래현황을 별도 유지한다.
- 거래소 통계: 총 거래/승률/순손익/수수료 4개 카드.
- 증권사 통계: 총 거래/오늘 체결/실현손익/미체결 4개 카드.
- 잔고: 핵심값 최대 3개를 한 줄 카드로 표시하고 7초마다 갱신.
- 포지션: 3개 동시 가시, 종목/방향/수량/진입가/레버리지/미실현손익 표시, 4개 이상 내부 스크롤.
