# NoahAI Client v3.9.0.0 구현·운용 기록

기준일: 2026-07-22  
제품 버전: 3.9.0.0  
목적: AI 커스텀을 설명용 기능이 아니라 사용자가 선택해 실제 자동매매에 연결할 수 있는 전략 생성 계층으로 정식화한다.

## 한 줄 정의

NoahAI의 AI 커스텀은 사용자의 투자 지식을 실행 가능한 전략 규칙으로 변환하고 검증·승인·운용까지 연결하는 전략 생성 계층이다.

## 실제 사용자 흐름

1. 설정 → OpenAI API → 안전 기본값 OFF 확인 → 사용자가 이해한 경우 `AI 커스텀 전략을 실제 자동매매 엔진에서 사용` ON → 저장
2. AI 커스텀에서 텍스트, Markdown, Pine Script, PDF, 차트 이미지, 로컬 영상, YouTube 또는 TradingView 자료 입력
3. 적용 범위, 시장국면, 우선순위, `기본 AI와 함께 사용 (권장)` 또는 `내 전략이 진입 신호 생성 (고급)` 선택
4. AI 분석 → XAI 근거·누락 조건·위험·engine setting 확인
5. 검토 및 전략 버전 저장 → 사용자 승인 → 자동 검증 실행
6. 검증 통과 전략은 `최종 적용`으로 일반 운용
7. 검증 미통과 전략은 설정에서 허용하고 경고를 확인한 경우에만 `1% 제한운용`
8. 대상 거래소 또는 증권사 `시작`을 누르면 활성 전략 풀이 자동매매 주문 직전에 평가됨
9. 거래소 카드와 실시간 로그에서 선택 전략, 신호 방식, 일반/제한운용, 시장국면, HOLD·차단 사유 확인
10. 중단은 전략 행의 `적용 해제`, 전체 커스텀 전략 일괄 제외는 설정 스위치 OFF

전략을 최종 적용한 뒤 별도의 전략 시작 버튼을 다시 누르는 구조가 아니다. 거래소·증권사 시작 버튼이 실행 루프를 시작하고, 그 루프가 활성 AI 커스텀 전략을 자동 평가한다.

## 운용 방식

### 일반 운용

- 자동 실행검증 통과 필요
- 사용자 최종 확인 필요
- 저장된 선언형 AND/OR 조건과 engine setting 적용
- 기존 NoahAI 수익성·전략·리스크·주문 가드레일을 모두 후행 통과

### 1배·최대 1% 제한운용

- 자동 실행검증을 먼저 완료했으나 미통과한 전략을 사용자가 직접 시험할 때만 선택
- 설정의 제한운용 허용 스위치와 적용 경고 재확인 필요
- 레버리지 1배 강제
- 전략 포지션 비중 최대 1% 강제
- 기존 엔진이 계산한 주문 수량을 늘리지 않고 축소만 허용
- 기존 가드레일과 주문 최소수량·잔고·포지션 제한을 그대로 적용

제한운용은 가드레일을 약화하는 우회 기능이 아니다. 검증 결과가 부족한 전략에 더 작은 실행 상한을 추가하는 사용자 선택형 시험 단계다.

## 기존 NoahAI와 역할 분리

| 계층 | 책임 |
|---|---|
| AI 커스텀 | 소스 수집, 전략 구조화, 누락 재확인, XAI, 버전·범위·국면·우선순위 관리 |
| 기존 NoahAI | 실시간 시장 분석, 기본 신호, 전략 비교, 주문 승인·보류와 실행 |
| 공통 가드레일 | 레버리지, 최대손실, 포지션, 집중도, 시장위험, 잔고·최소수량 제한 강제 |
| 기록 계층 | 전략 선택, 조건 미충족, HOLD, 가드레일 차단, 주문·체결·비용·PnL 로그 저장 |

## 전략 선택과 충돌 처리

- 전역 활성 실행 풀은 최대 10개다.
- 전략별 버전은 최대 10개다.
- 우선순위 10이 가장 높다.
- 자산 종류 → 거래소/증권사 → 시장국면 → 진입조건 → 우선순위 순으로 한 전략을 선택한다.
- 현재 버전은 여러 전략의 TP/SL·포지션 값을 가중 평균해 섞지 않는다.
- 같은 조건에서 여러 전략이 일치하면 가장 높은 우선순위 한 개를 사용한다.
- 어떤 전략도 맞지 않거나 후행 가드레일이 차단하면 HOLD한다.

## 실제 적용되는 값

- 선언형 진입조건: signal, confidence, RSI, MACD, 볼린저 위치, MA20/MA50, 현재가, 추세강도, 변동성, 거래량 비율
- 엔진 setting: 레버리지, TP, SL, 포지션 비율, 신호 임계값
- 적용 범위: 개별 코인 거래소, 모든 블록체인, 개별 증권사, 모든 주식/ETF, 모든 자산
- 시장국면: 전체, 상승, 하락, 횡보, 고변동성, 저변동성
- 전략 역할: 기본 AI와 함께 사용 또는 내 전략의 독립 LONG/SHORT 후보

## 2026-07-22 사용성·안전 후속 패치

- 복잡한 내부 용어를 `전략 역할`과 초보자 권장값 중심으로 바꾸고, 고급 역할을 선택할 때만 진입 방향을 표시한다.
- 분석 뒤 `검토 및 전략 버전 저장`이 실패하면 원인을 표시하며, 성공 ID가 없으면 성공 메시지를 내보내지 않는다.
- 저장은 검토 이력, 승인은 사용자 확인, 자동검증은 최근 시세 500개 판정으로 명확히 분리한다.
- 조건 일치 3회 이상, 수수료 반영 순PnL 양수, MDD 10% 이하를 모두 만족해야 자동검증 통과다.
- 실거래 사용과 미통과 1배·최대 1% 제한운용은 신규·업데이트 사용자 모두 최초 1회 OFF로 마이그레이션한다.
- UI 명칭 `AI 트레이딩 모델`을 `AI 애널리스트 모델`로 변경하고 작업별 모델 배치와의 역할 경계를 설명한다.

임의 Python/Pine 코드를 주문 서버에서 직접 실행하지 않는다. Pine과 자연어는 허용된 선언형 규칙과 정규화된 setting으로 변환한다.

## 가드레일 발생 시 사용자 동작

- 진입조건 불일치: `AI 커스텀 HOLD` 로그
- 후행 전략 가드레일 차단: 전략명과 차단 사유를 WARNING 로그로 표시
- 잔고·최소수량·포지션·일일손실·RR·수익성 차단: 주문을 실행하지 않고 기존 거래소 로그에 이유 표시
- 반복 문제가 있으면 AI 커스텀에서 `적용 해제`하거나 설정 스위치를 OFF로 저장
- 프로그램 종료는 상단 `종료`를 사용해 거래 루프·DB·비동기 로그를 flush

## 입력 범위

- PDF: 앞 100쪽 추출, AI 구조화 입력 앞 60,000자
- YouTube: watch, Shorts, youtu.be, embed, live 주소, 공개/자동 자막 우선, 대표 장면 최대 9개 OCR·비전 분석
- 무자막 YouTube: 사용자 설정 모델·최대 길이·최대 용량 내 OpenAI 전사
- TradingView: 공개 페이지 근거 또는 사용자가 제공한 Pine 원문
- 차트/로컬 영상: OCR과 비전 AI, 대표 장면 최대 9개

보호 콘텐츠 접근통제는 우회하지 않으며 사용자가 이용 권한을 가진 자료만 입력한다.
