## 6. 바이낸스 외 거래소 미체결/장기 HOLD (2026-07-05)
- **문제:**
  - "바이낸스는 거래되는데 타 거래소는 거래가 안 된다"는 운영 이슈 반복.
  - 비바이낸스 경로에서 거래 이력 부족 구간이 손실률 차단으로 해석되어 장기 HOLD로 고착되는 케이스 존재.
  - Bybit/OKX/Bitget 인증 실패 시 사용자가 원인을 바로 알기 어려워 재시도만 반복.
- **근본 원인:**
  - 전략 계층: Unified pre-entry 기본값(`loss_rate=50%`, `min_trades_history>=1`)이 cold-start에 과도하게 불리하게 작동.
  - 심볼 계층: 호환 심볼 전부 탈락 시 원본 심볼을 다시 분석하는 폴백으로 비호환 루프 발생 가능.
  - 인증 계층: 거래소별 401/IP 불일치/권한 부족을 사용자 조치 단계로 변환하는 공통 진단 UX 부재.
- **해결:**
  - `trading/unified_trader.py`
    - no-trade 기본값을 `loss_rate=0.0`, `data_insufficient=True`로 정규화
    - `min_trades_history` 기본/폴백 0으로 조정
    - 차단 사유 우선순위를 `거래 이력 부족` 우선으로 조정
    - 심볼 전부 비호환 시 분석 스킵(원본 심볼 재주입 중단)
  - `trading/exchanges/adapters/*_futures_adapter.py` (Bitget/Bybit/OKX)
    - `last_error`, `last_auth_guidance` 상태 추가
    - 인증 실패를 원인별 조치 문구로 표준화
  - `ui/settings_modern.py`
    - 거래소 검증 실패 시 조치 가이드 팝업 제공
    - Bitget 공인 IP 표시/새로고침으로 화이트리스트 점검 동선 단축
  - `trading/recorder.py`
    - 청산 로그에 `exchange` 상시 저장으로 통계 정합 보강

## 5. Recorder 구조 중복 및 초기화 오류 (2025-11-01)
- **문제:**
  - Recorder 클래스에 __init__이 두 번 정의되어 있었음. (exchange 등 인자 무시, logger/DB 경로 등 미초기화)
  - 구조적 혼란으로 인해 logger, DB, exchange 등 필드가 의도대로 동작하지 않음.
- **원인:**
  - 리팩터링/자동화 과정에서 기존 생성자를 덮어쓰는 실수 발생.
  - 여러 개발자/자동화 도구가 동시에 수정하며 충돌 가능성.
- **해결:**
  - __init__을 하나로 통합, 모든 인자와 초기화 로직을 한 곳에 정리.
  - logger, DB 경로, 로그 디렉토리, DB 초기화 등 모든 초기화 로직을 한 번에 실행.
  - super() 호출은 상속 구조에 맞게 유지.
- **적용 내역:**
  - 2025-11-01: recorder.py에서 중복된 __init__ 완전 제거 및 통합, 구조 일원화.
  - 구조적 문제로 인한 logger, exchange, DB 경로 등 미초기화 문제 해결.

## 1. 거래 통계 및 거래현황 미업데이트
- **문제:**
  - 거래가 정상적으로 체결되어도 대시보드의 거래 통계, 거래현황이 실시간으로 업데이트되지 않음.
- **원인:**
  - trade_log DB의 exchange 컬럼이 None/null로 저장된 데이터가 많음.
  - 통계 집계 쿼리에서 exchange 값이 일치하지 않아 누락.
  - 통계 저장/조회 로직이 trade_log의 최신 구조와 불일치 가능성.
- **해결:**
  - trade_log에 거래소 정보가 항상 저장되도록 마이그레이션 및 저장 로직 보강.
  - 통계 집계 쿼리에서 exchange 값이 None/null인 데이터도 포함하거나, 저장 시점에 올바른 값으로 보정.
  - 통계 저장/조회 로직을 trade_log 구조와 일치하도록 점검 및 수정.

## 2. AI 학습 데이터 저장 누락
- **문제:**
  - 실거래가 발생해도 ai_learning_data_{exchange}.json 등 AI 학습 데이터 파일에 기록이 누락됨.
- **원인:**
  - 저장 경로 오류, 쓰기 권한 문제, 예외 발생 시 조용히 패스되어 사용자가 인지하지 못함.
  - 분석 루프에서 _generate_ai_learning_data가 호출되지 않는 분기 존재 가능.
- **해결:**
  - 저장 실패 시 반드시 경고/에러 로그를 남기도록 개선.
  - 저장 경로, 파일 권한, 실제 파일 생성 여부를 점검.
  - 분석 루프에서 모든 거래 신호에 대해 학습 데이터가 저장되는지 분기 조건 점검.

## 3. 거래 시그널 품질 높였음에도 불구하고 다수 진입
- **문제:**
  - 거래 시그널 임계값을 높였음에도 불구하고, 3개 이상 코인이 바로 진입함.
- **원인:**
  - 시그널 필터링/임계값 적용 로직이 실제로 반영되지 않았거나, 조건문이 잘못 적용됨.
  - 진입 조건이 여러 군데 분산되어 있어 일부만 강화되고 나머지는 그대로일 수 있음.
- **해결:**
  - 시그널 필터링/임계값 적용 로직을 한 곳에서 일관성 있게 관리하도록 구조 개선.
  - 진입 조건 전체를 점검하여, 모든 경로에서 강화된 임계값이 적용되도록 수정.

## 4. 분석 싸이클 1회 후 멈춤
- **문제:**
  - 거래 시작 후 한 번의 분석 싸이클만 실행되고, 이후 분석이 진행되지 않음.
- **원인:**
  - 분석 루프가 예외/에러로 중단되었거나, 반복 조건이 잘못되어 루프가 종료됨.
  - 스레드/비동기 처리 문제, 중지 신호 플래그가 잘못 세팅됨.
- **해결:**
  - 분석 루프의 반복 조건, 예외처리, 중지 신호 플래그 로직을 점검 및 수정.
  - 예외 발생 시 반드시 로그를 남기고, 루프가 정상적으로 재시작되도록 보장.
