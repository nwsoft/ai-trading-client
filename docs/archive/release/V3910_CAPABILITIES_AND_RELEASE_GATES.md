# NoahAI v3.9.1.0 기능·안내·배포 정합성 정본

- 기준일: 2026-08-19
- 대상: NoahAI Client, 대시보드 사용자 매뉴얼, NoahAI Labs, InfoNoahAI, DAL Trading 회원 포털
- 상태: Web UI 내부 통합 후보
- 배포 판정: `publish_ready=false`

이 문서는 v3.9.1.0을 사용자·운영자·홍보 채널에서 같은 의미로 설명하기 위한 정본이다. 소스 구현, 화면 노출, 외부 연결 검증, 공개 배포를 서로 다른 상태로 구분한다. 상세 화면 1:1 판정은 `WEB_UI_1_TO_1_PARITY_EXECUTION_PLAN_v3.9.1.0.md`가 우선한다.

## 1. 사용자에게 현재 제공한다고 안내할 수 있는 범위

### 공통 Web UI

- 기존 Python 거래·AI·설정·원장 모듈을 Web Application Service와 localhost Gateway를 통해 호출한다.
- 로그인, 5개 상위 서비스, 하위 기능 탭, 거래소·증권사, 설정, 사용자 매뉴얼, 공통 상태·종료 흐름을 React/Electron 후보 화면에 연결했다.
- 거래소·증권사 목록은 계정 설정의 활성 선택을 따른다. 미선택 소스를 임의로 노출하거나 다른 소스 데이터로 대체하지 않는다.
- 연결 실패, 권한 부족, 데이터 없음, 준비 중 상태를 0이나 성공으로 꾸미지 않고 구분한다.
- 계정 설정 revision/diff, write-only 자격증명, 회원 등급 새로고침, AI 설정, 업데이트 상태를 기존 저장소와 서비스 경계에 연결한다.

### 서비스별 화면

- 블록체인: 실시간 로그, 코인 정보, 거래 통계, 시장 트렌드, AI 학습·리포트·어시스턴트·커스텀, 금융 인텔리전스, 활성 거래소 화면
- 주식/증권: 종목 정보, 거래 통계, 시장 트렌드, AI 학습·리포트·어시스턴트·커스텀, 금융 인텔리전스, 활성 증권사 화면
- 자산 통합: 자산 인사이트, 자산배분 진단, 리스크 브리핑, 성과·위험 분석
- 생활금융: 현금흐름, 목표, 보안 경고, 세금 계산, 금융상품 비교 화면
- AI애널리스트: 통합 분석, AI 어시스턴트, AI 요약 리포트, 시나리오 점검, 금융 인텔리전스 허브
- 설정·매뉴얼: 일반, 거래소 선택/API, AI 엔진/API, 고급 매매 계층, AlphaArena, AI 시스템 상태, 업데이트와 11개 안내 탭

위 목록은 화면·소스 연결 범위다. 실제 잔고·체결·주문·뉴스·공시·상품 조회는 아래 조건부 범위를 함께 적용한다.

## 2. 계정·권한·외부 공급자에 따라 조건부로 제공되는 범위

- 잔고·포지션·실제 체결·실주문은 사용자가 저장한 자격증명, 회원 등급, 서버 허용 범위, LEARNING/PAPER/LIVE 모드와 주문 안전 게이트를 모두 통과해야 한다.
- 거래소 API와 증권사 API는 각 공급자의 계정, 권한, 시장, 운영 시간, SDK/Windows 조건에 영향을 받는다.
- 뉴스·공시·기관·이벤트·금융상품 데이터는 운영 공급자 연결 전에는 `데이터 연결 필요` 또는 `준비 중`으로 표시한다. 임의 데이터로 채우지 않는다.
- AI 공급자 호출은 사용자가 선택하고 검증한 Provider·모델·예산 범위에서만 수행한다. 로컬 제품 사용법 안내와 외부 유료 분석 호출을 구분한다.
- 회원·레퍼럴 제한은 `관리자 전역 허용 ∩ 사용자 등급·검증 상태 ∩ 로컬 설정`을 모두 만족할 때만 실행을 허용한다.

## 3. AI 커스텀 실제 수준

### 현재 앱 소스에서 제공

- 텍스트·전략 설명·Pine, TradingView/YouTube URL, PDF, 이미지, 영상 입력
- 원문 근거, 명시 조건, 누락 조건, 위험과 엔진 설정을 분리하는 제한형 IR/XAI
- Level 1/2/3 설명, 안전 선언형 규칙, 제한형 Expression Graph·사용자 지표
- 전략 버전 저장, diff, rollback, 삭제, 사용자 승인, 자동 과거 재생
- `.noahstrategy` 가져오기·내보내기와 민감정보 제외·해시 검증
- 거래소·증권사 적용 범위, 시장국면 판단, HOLD, 계좌·주문 가드레일
- 암호화폐·주식 PAPER 종료 결과를 정확한 전략 키·버전에 append-only로 귀속하고 7일·30일 성과를 분리

### 현재 기능에 포함되지 않는 것

- TradingView 차트·Pine 전체 대체 또는 모든 Pine/Python 임의 실행
- 백테스트 결과만으로 자동 승인·자동 LIVE 승격
- 수익·승률 보장
- 실제 운영 TradingView webhook 수신 endpoint와 영속 nonce E2E 완료
- 전체 LIVE 거래의 전략 버전·시장국면별 제품 집계 완성
- 사용자 간 익명 집단지능, 공개 전략 마켓, 결제·정산, 팀 공유, 인증 B2B 배포

### 다음 고도화 순서

1. 실제 TradingView 비교 코퍼스와 서명 webhook 수신·중복 방지 E2E
2. Windows 실제 계정 PAPER 장시간 검증과 전략 버전·국면 성과 무결성 확인
3. 허가된 소액 LIVE에서 주문·부분체결·취소·재시작·청산 결과 귀속 확인
4. 익명화·동의·철회·권리 경계를 포함한 집단지능 설계
5. 팀 공유·제작자·마켓·B2B는 법무·검증·모더레이션·정산 체계 이후 공개

## 4. 현재 닫히지 않은 v3.9.1.0 배포 게이트

- 같은 계정·같은 데이터·같은 창 크기로 레거시 v3.9.0.10과 Web UI의 전체 화면·탭·버튼·빈 상태·스크롤·동작 대조
- Windows 설치·업데이트·롤백·DPI·다중 모니터·종료 후 재시작
- 6개 거래소와 4개 증권사의 실제 자격증명 연결 및 허가된 읽기/주문 E2E
- 회원 등급·레퍼럴·KPI 서버 왕복과 장애 시 fail-closed 확인
- 24~72시간 PAPER 연속 운용, 재시작 복구, 데이터 보존·중복·누락 검사
- 최종 설치 자산 SHA, manifest, 공개 다운로드, 이전 버전 복구 경로 확인

자동 회귀나 Web production build 성공만으로 위 게이트를 닫지 않는다. 모든 필수 항목이 증거와 함께 `VERIFIED`가 되기 전에는 공개 설치본 또는 완전한 1:1 전환이라고 안내하지 않는다.

## 6. 배포 전 정합성 확인 순서

1. `config/app_version.py`, 앱 매뉴얼 JSON, 릴리스 노트와 본 문서의 버전·상태가 같은지 확인한다.
2. 실행 원장의 모든 필수 화면·기능·Windows·외부 계정 행을 확인한다.
3. NoahAI Labs·InfoNoahAI·DAL Trading에서 현재 기능, 조건부 기능, 미완료 문구를 같은 의미로 사용한다.
4. 각 사이트의 소스 커밋·배포 SHA·실제 URL 렌더를 별도 증거로 기록한다.
5. 공개 설치 자산과 manifest가 확정된 뒤에만 `publish_ready=true`와 다운로드 문구를 전환한다.
