# v3.9.1.12 전략 허브·메뉴얼·검증 신뢰 테스트 계획

기준일: 2026-08-27  
상태: 소스 후보, Windows 재빌드 전

> 역사적 v3.9.1.12 계획입니다. 현재 무료 허브의 공개 계약은 v3.9.1.22에서 `권리 자기선언+패키지·IR 구조 검사 → E0 공개 → 증거 별도 승격 → 신고 기반 사후 검토`로 변경되었습니다. 아래 `REVIEW-E2E`의 사전 승인 모델은 현재 정본이 아닙니다.

## 소스 자동 검증

- [x] AI 커스텀 상단에 무료 전략 허브와 제출·다운로드 안내 링크가 있다.
- [x] 프라이빗 전략 목록 상단과 각 버전에 회원 제출 링크가 있다.
- [x] 제출은 자동 업로드가 아니며 패키지 내보내기와 회원의 직접 파일·권리 확인을 요구한다.
- [x] 인앱 메뉴얼·Web 메뉴얼 JSON·사용자 가이드·AI 어시스턴트가 제출·저장·다운로드 계약을 함께 설명한다.
- [x] 전략 파일의 자기신고 성과를 랭킹 증거로 쓰지 않고 백테스트의 한계와 검증 여권 근거를 구분한다.
- [x] 다운로드 전략은 비활성 검토 버전으로 가져오며 자동 적용·자동 LIVE가 없다.
- [x] 무료 베타, 후속 제작자·팀 운영, 상업화 준비와 선택적 블록체인 해시 증명을 현재 기능과 분리한다.
- [x] daltrading 공개 안내·비회원 제출 안내·회원 제출·관리자 승인·검증 여권·다운로드 회귀가 통과한다.
- [x] 제작자 공개 중지 요청 즉시 허브 노출·다운로드를 차단하고 운영자 확정/반려 뒤 상태·감사 원장을 보존한다.

## Windows 설치본 외부 게이트

- [ ] `WIN-BUILD`: Windows x64에서 현재 소스로 Python sidecar·NSIS 설치기·blockmap·`latest.yml`을 새로 만든다.
- [ ] `WIN-UPGRADE`: 공개 v3.9.1.11 설치본에서 v3.9.1.12 자동업데이트 후 설정·자격증명·DB·전략·PAPER 원장을 보존한다.
- [ ] `KIWOOM-E2E`: 키움 별도 QAx/COM 프로세스의 연결·종료·재시작을 확인한다.
- [ ] `KIS-E2E`: 한국투자증권 조회·종료가 암호화폐 worker와 전략 허브 동선을 방해하지 않는지 확인한다.
- [ ] `BITHUMB-E2E`: Bithumb 현물 PAPER LONG 진입·청산과 미체결 조회를 확인한다.
- [ ] `RECONCILE-E2E`: 거래소 체결·NoahAI 관리 원장·PAPER 원장이 모드별로 섞이지 않는지 확인한다.
- [ ] `SPOT-FUTURES-PAPER`: Upbit·Bithumb 현물과 Binance·Bybit·OKX·Bitget 선물 PAPER 방향·포지션·TP/SL을 확인한다.
- [ ] `REPORT-E2E`: PAPER 검증 수와 AI 리포트 수치가 정확한 전략·기간·통화 원장과 일치하는지 확인한다.
- [ ] `SOAK`: 6개 거래소를 24~72시간 실행한 뒤 설정·AI 커스텀·허브 링크가 응답하고 종료 버튼 한 번으로 60초 안에 잔류 프로세스 없이 종료되는지 확인한다.
- [ ] `EXPORT-E2E`: 설치본에서 전략 버전별 `.noahstrategy` 내보내기와 민감정보 제외를 확인한다.
- [ ] `SUBMIT-E2E`: `내 전략 제출`과 `허브에 제출`이 daltrading HTTPS 로그인·제출 화면을 열고 비회원에게 원시 401을 표시하지 않는다.
- [ ] `REVIEW-E2E`: 회원 제출 원본이 서버 생성 검토 ID로 비공개 저장되고 운영자 승인 전 공개·다운로드되지 않는다.
- [ ] `PASSPORT-E2E`: 승인 전략의 공개 검증 여권이 서버 검증 스냅샷과 해시·권리·검증 시각을 표시하고 자기신고 성과를 증거로 쓰지 않는다.
- [ ] `IMPORT-E2E`: 다운로드 패키지를 가져오면 비활성 검토 버전이며 승인·자동검증·PAPER 전에는 실행 풀과 LIVE 주문에 들어가지 않는다.
- [ ] `MANUAL-E2E`: 설치본 메뉴얼의 제출 위치·저장 위치·백테스트 한계·초보자 순서가 Web 화면 버튼과 일치한다.
- [ ] `ROLLBACK`: v3.9.1.12 설치·업데이트 실패 시 v3.9.1.11 실행 파일과 사용자 데이터로 복구한다.
- [ ] 설치기·blockmap·`latest.yml`·내장 엔진의 버전, 크기, SHA-256과 source fingerprint가 manifest와 일치한다.

모든 외부 게이트가 완료되기 전에는 `publish_ready=false`를 유지하며 공개 v3.9.1.11 자산을 덮어쓰지 않습니다.
