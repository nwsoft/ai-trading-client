# v3.9.1.1 Settings Persistence Patch 검증 계획

이 문서는 이미 배포된 v3.9.1.0 사용자를 위한 v3.9.1.1 패치의 공개 전 필수 게이트다. 소스 테스트와 실제 Windows 업데이트 결과를 구분하며, 아래 항목을 실제 결과 없이 완료 처리하지 않는다.

- [ ] **WIN-BUILD** — 깨끗한 Windows x64 환경에서 새 `NoahAIEngine.exe`, `NoahAI-3.9.1.1-Setup.exe`, blockmap, `latest.yml`을 생성하고 제품 버전 `3.9.1.1`과 updater SemVer `3.9.101`을 확인한다.
- [ ] **UPGRADE-3910-3911** — GitHub v3.9.1.0 설치본이 업데이트를 감지하고, 사용자 승인 후 다운로드·안전 종료·재시작을 거쳐 대시보드에 v3.9.1.1을 표시한다.
- [ ] **SETTINGS-GENERAL** — 제공된 사용자 설정과 동등한 회귀 조건에서 일반 설정을 변경하고 `저장 후 닫기` 후 재실행해 값이 유지되는지 확인한다.
- [ ] **SETTINGS-SECRET** — 거래소 및 AI API 자격증명을 변경·저장한 뒤 화면에는 원문을 반환하지 않으면서 실제 연결에서 새 값이 사용되는지 확인한다.
- [ ] **SAVE-CLOSE** — 성공 시 저장 완료 피드백과 창 닫힘이 보이고, 저장 성공 뒤 런타임 새로고침만 실패한 경우 이를 저장 실패 503으로 오해시키지 않는지 확인한다.
- [ ] **ROLLBACK** — 업데이트 실패·중단 시 v3.9.1.0 실행 가능 상태 또는 검증된 복구 경로가 유지되며 계정 설정 파일이 손상되지 않는지 확인한다.

완료 증거에는 Windows 버전, 설치 전후 앱 버전, `latest.yml` 버전, 설치 파일 SHA-256, 설정 저장 전후 revision, 민감값을 제거한 로그를 남긴다.
