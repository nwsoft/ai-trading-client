# v3.9.1.42 한국어·영어 지원 실행 계획

2026-09-20 사용자 승인: 한국어·영어부터 진행. 후속 UI 피드백으로 미저장 시 시스템 선호 언어를 참고하도록 변경했다. Client 설치기 빌드·릴리스는 사용자가 수행한다.

## 제품 계약

- 언어는 `ko` / `en`만 제공한다. 저장된 사용자 선택을 우선하며, 없으면 시스템의 첫 번째 선호 언어가 영어일 때 영어로 시작한다. 한국어·미지원 언어·확인 실패는 한국어다. 국가나 IP로 언어를 강제로 바꾸지 않는다.
- 언어 선택은 표시·설명용이다. 거래 모드, PnL 집계 시간대, 거래소 통화, 전략 실행 규칙·승인·여권은 언어 변경의 영향을 받지 않는다.
- 번역된 정적 UI/안내는 앱에 포함한다. 화면 번역을 위한 외부 AI 비용은 발생하지 않는다. 사용자 입력·전략 원문·로그·계약 식별자는 보존한다.
- 사용자 요청 AI 설명에는 선택 언어를 전달한다. 원문·수치·근거의 언어를 바꾸어 실행 규칙을 재생성하지 않는다.
- 신규 국가/언어 통계는 원격 계좌 자료와 분리한다. 국가/국적 자동 추정이나 무동의 수집을 추가하지 않는다. 국가별 제품 출시 권한은 별도다.
- 영어는 beta로 표기하고, 번역되지 않은 원문/고급 설명의 범위를 명시한다. 번역되지 않은 내용을 지우거나 정상/확정 수치로 대체하지 않는다.

## 사용법과 실제 범위

로그인 폼 테두리 아래의 작은 언어 선택기 또는 로그인 후 `설정 → 일반 → 표시 언어`에서 변경한다. 대시보드 상단에는 언어 선택기를 두지 않는다. 선택 즉시 적용·별도 저장되며 거래 설정의 저장/취소와 독립적이다. 별도 `display_preferences.json`과 계정별 로컬 표시 캐시에 저장하므로 거래 settings.json·원장·전략·원격 승인 해시는 바뀌지 않는다.

우선순위는 저장된 계정 선택 → 저장된 로그인 선택 → 시스템 선호 언어다. Electron은 `app.getPreferredSystemLanguages()`의 첫 언어를 읽고, 브라우저 개발 화면은 `navigator.languages`를 참고한다. 영어만 영어로 시작하고 다른 언어는 한국어 fallback이다. 국가/IP 조회·추적·텔레메트리는 추가하지 않는다. 저장된 선택은 시스템 언어 변경으로 덮어쓰지 않는다.

영어 `Manual`은 시작, 대시보드, 설정, AI 도움, 전략 작성, 차트/검증, PnL, 원격, 알림, 업데이트, 제한/지원의 11개 운영 안내다. 한국어 정본 전체의 완역은 아니며 영어 베타 안내임을 표시한다. `web_platform/english_guide.py`로 엔진에 포함된다. AI `Deep analysis`는 영어 설명을 요청하되 외부 비용·개인정보 경계가 유지된다. `Local guide`는 비용 없이 영어 운영 안내와 **원래 한국어 진단**을 함께 보여주며 이를 완역으로 가장하지 않는다.
