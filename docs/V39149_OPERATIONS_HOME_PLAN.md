# 3.9.1.49 — 거래 대시보드 중심 첫 화면

2026-09-29 사용자 승인 후 구현 계획. 기존 텍스트 요약 계획을 확장한다. 이 문서는 기능 범위 정본이며 실행 결과는 TEST_STATUS에 별도로 기록한다.

## 제품 판단

첫 화면은 모든 설정을 나열하는 곳이 아니라 **지금 상태 → 확인할 문제 → 결과 → 다음 행동**을 파악하는 곳이다. 블록체인/주식·증권은 운용·통제, 자산 통합은 전체 자산/위험, 생활금융은 현금흐름/목표, 전략 스튜디오는 제작/검증, AI는 각 문맥의 설명을 맡는다. 별도의 중복 거래 엔진·자산 정본·추천 챗봇을 만들지 않는다. 자산 통합/생활금융의 기존 첫 화면을 이번 거래 현황 화면으로 대체하지 않는다.

## 구현 범위 및 수용 조건

1. 첫 탭의 사용자 이름은 `거래 대시보드`, 내부 `.logs` 식별자·기존 경로는 보존한다. 기본은 `요약 보기`이며 `상세 로그`는 같은 화면에서 전환한다. 기관 탭/목록의 상세 버튼은 기존 기관 상세로 이동한다. 전체 범위와 기관 범위를 명시한다.
2. 기존 운영 KPI·거래 현황·일괄 실행·빠른 액션·운영 알림을 제거하지 않는다. 현황을 주 영역으로, 로그를 상세 도구로 재배치한다. PAPER/LIVE 통계는 사용자가 선택할 수 있고 모드 전환 시 이전 통계를 즉시 비운다. 통화/확정·미확정/집계기간/계좌 조회 실패는 별도로 표시한다. 결측 통계는 0으로 표시하지 않는다.
3. 설정된 기관의 모드·실행·자격정보 저장 여부·최근 근거·위험 보류·미수신을 간결한 표로 제공한다. 실행 중이라는 사실을 전체 정상으로 바꾸지 않는다. 계좌 정보/시세/보호주문을 목록 렌더링에서 새로 조회하지 않는다. 단일 기관도 같은 전체/상세 관계를 사용한다. 정지·미연결·분석 기록 없음은 중립 상태, 실제 위험 보류·조회 오류만 경고로 구분한다.
4. 상단은 실행·정지·대상 기관 수를 작은 텍스트로 표시한다. UI49.4의 큰 원형 기관 수 그래프는 제거한다. 오늘 요약 4개와 기관 목록을 하나의 스크롤 안에 두며 중복 거래 현황과 별도 우측 요약 스크롤은 제거한다. 국면은 `상승 확률`로 가장하지 않는다. 기관 국면은 전 시장 종목 비율과 다르다.
5. 기관 운용 요약은 관찰/확정 국면 배지, 현재 세션 국면 변화 이력, 실제 후보 판단·검사 근거, PAPER 평가 대상/대기 막대, 위험 상태를 시각화한다. 과거 국면은 메모리 최대 24개, 동일 상태 반복을 저장하지 않는다. 재시작/세대 변경/모드·기관을 격리한다. 시계열의 시작 전 기록을 보간하지 않는다.
6. 전략 영역은 `최근 검토 전략`과 실제 판단 결과·버전을 표시하고 전략 스튜디오/시장 트렌드/AI 설명으로 연결한다. 현재 투영에 없는 자동 추천 순위·확률·승률·최적 전략을 만들어 넣지 않는다. 추천 기능의 대체인 것처럼 명명하지 않는다. 조건 확인 개수도 수익 확률이 아니다.
7. 서비스 전체 현황에서 기관 상세·통계·시장 트렌드·전략 스튜디오·AI 설명·자산 통합으로 이동할 수 있다. AI 버튼은 문맥을 가진 대화 화면만 열며 자동 전송/외부 호출/저장/거래하지 않는다.
8. 기존 일괄 제어의 PC 위험 검사/사용자 확인 유지. 혼합 모드에서는 기관별 PAPER/LIVE/관찰 모드를 확인창과 요청에 연결하고 결과를 기관별로 표시한다. 단순 Promise fulfilled를 실제 시작 성공으로 오인하지 않도록 기존 응답 계약을 확인한다. 시작/정지는 청산과 같지 않음을 표시한다.
9. 기존 workspace 조회에 메모리 근거 투영만 추가한다. 추가 거래소/LLM 조회·SQL·DB 쓰기 0회, 최대 11기관. 전체 로그를 보지 않을 때 1초 로그 조회 중단, 현황 workspace 기존 5초 유지. UI49.5에서는 홈의 7초 계좌 자동 조회를 제거하고 `집계·계좌 확인 / AI 진단 → 현재 계좌 확인` 명시 동작으로 한정한다. 초기 LIVE 조회 때문에 새 계좌 API 호출이 발생하지 않는다. 늦은 이전 모드·계정 응답 폐기, 일부 기관 계좌 조회 실패를 전체 성공으로 표시하지 않는다.
10. 다크 테마·기존 입력 크기·설정 가독성 유지. 어시스턴트 상단은 UI 49.3의 작은 보조 도구 크기를 유지한다. 1080/1440px, 짧은 창, 다기관, 장문, 0/미수신/실패/혼합 모드 시험. 기존 앱 최소 폭과 Windows 배율은 구분한다.
11. 오늘 통계 안에 `실거래 내역 LIVE` / `가상 거래 내역 PAPER` 버튼을 나란히 표시한다. 첫 조회는 LIVE, 이후 계정·서비스별 선택을 기억한다. 색상과 체크·선택 상태를 함께 사용한다. 이 선택은 통계 조회만 바꾸며 실제 실행 모드·거래 권한·기관별 시작 확인은 바꾸지 않는다. 청산 0건은 `청산 없음 / 표본 없음`, 미수신은 확인 중, 미대조는 대조 전으로 구분한다. 시각은 현지 시간으로 표시한다.

## 이번에 표시하지 않을 데이터와 이유

- 홍보 이미지의 68.7% 강세 확률: 사건/기간/모델 검증 계약이 없다. 대신 실제 상태·확인 수를 표시한다.
- 학습 완료율 92.4%: 지속 운용에 완료 작업 총량이 없다. 슬롯 사용량을 학습 진행률로 바꾸지 않는다.
- 새 수익 곡선/MDD/샤프: 확정 손익·입출금·기간·기준자산이 일치하는 시계열을 이번 요약에서 새로 만들지 않는다. 기존 거래 통계/성과·위험 화면으로 연결한다. 차트가 없음을 숨기지 않는다.
- 새 개인화 추천 엔진/자동 전략 교체·가족 자산 공유: 이번 첫 화면 개선과 다른 실행/권한 계약이며 구현 완료로 포함하지 않는다.

## 검증과 인계

- 백엔드: 11기관 투영·모드/세대 분리·최대 이력·반복 상태·복사 격리·예외 격리·추가 I/O 없음.
- UI: 새 첫 화면/기관 이동/기존 상세 로그/모드 변경 중 역순 응답/결측·부분 자료/중복 실행 방지/확인 취소/읽기 동선의 쓰기 0.
- 문서: 과거 기본 로그/텍스트 전용을 현재 규칙으로 남기지 않는다. 기존 기록은 당시 이력으로 표시한다. 앱 매뉴얼·기능명·영문·업데이트 계획·테스트 기록 연결.
- 최종 소스/실행용 dist 일치, TypeScript·회귀·실제 Chrome 확인. Windows 설치기 빌드·릴리스는 사용자 수행. Windows 125/150%·장시간·실제 원격/알림은 별도 실환경 게이트이며 소스 시험으로 완료 표시하지 않는다.

## 구현 인계 (UI 49.4 당시 이력)

위 1~10의 소스 구현을 반영했다. `OperationsOverview`/`OperationVisuals`는 새 표시 전용 컴포넌트, `Operations`는 기존 현황/로그/명령 동선, `OperationSummary`는 기관 근거를 담당한다. Web 메뉴명 변경은 공통 제품 계약의 명시적 별칭으로 관리하며 기존 CTk 탭 문자열·내부 `.logs` 경로는 바꾸지 않았다. CTk 첫 화면까지 새 현황판으로 바꿨다고 안내하지 않는다. 영어는 새 첫 탭/보기 전환 탐색 문구를 연결했으며 모든 근거 본문의 완전한 영문화는 이번 완료 주장이 아니다.

현황 투영에서는 화면에 쓰지 않는 PAPER 풀을 다시 계산하지 않는다. 로그를 보지 않을 때 로그 요청을 중지하고, 창 숨김/요청 실패 시 기존 순차 폴러의 숨김 정지·재시도 간격 증가를 적용한다. 설정/거래/전략 데이터는 요약 표시 때문에 재작성하지 않는다. 시험 기록 및 미완료 실환경 항목은 TEST_STATUS/DEPLOY_CHECKLIST를 따른다.

## UI49.5 후속 인계

위 수용 조건을 9월 29일 후속 피드백에 맞춰 갱신했다. `OperationsOverview`는 기관 목록/주요 조치, `DashboardStats`는 조회 전용 모드·단일 집계, `Operations`는 기존 조회·명령을 담당한다. 기관 상세의 근거 그래프는 유지한다. 변경은 새 거래 엔진이나 전략 승인·손익 보호 규칙 추가가 아니다. 실제 renderer 화면 시험에서 보이는 문제를 수정한 결과와 Windows에서만 가능한 시험을 TEST_STATUS에 구분한다.
