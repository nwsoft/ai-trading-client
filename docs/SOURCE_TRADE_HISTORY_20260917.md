# v3.9.1.38 기관별 LIVE/PAPER 거래내역 전환

> 공개 상태 갱신(2026-09-18 확인): 이 기능을 포함한 v3.9.1.38은 GitHub stable/latest로 게시됐습니다. 아래 “소스 후보/공개 v37” 표현은 구현 당시 기록이며, 기관별 실계정 읽기 대조가 자동으로 완료됐다는 뜻은 아닙니다.

2026-09-17 v3.9.1.38 소스 후보 작업. 공개 v3.9.1.37 설치본·태그·manifest는 교체하지 않는다.

## 동작

- 기관별 `execution_modes[source]` 우선. 기본 자율운용/전략 스튜디오 여부와 무관하게 LIVE는 LIVE 탭, PAPER는 PAPER 탭을 기본 선택한다.
- 사용자가 반대 탭에서 과거 기록을 열어 볼 수 있다. 기관·실행 모드가 바뀌면 기본 탭을 다시 선택한다. LEARNING은 신규 주문이 없음을 명시하고 과거 LIVE 기록만 표시한다.
- 거래내역은 LIVE/PAPER 모두 기본 접힘으로 표시한다. 기관·실행 모드 전환 시 다시 접히며 `펼치기`를 누르면 내역을 확인한다. 이력 탭 선택 자체는 실행 모드를 변경하지 않는다.
- LIVE는 현재 로그인 계정 DB의 해당 기관 `trade_log` 종료 기록 최근 최대 50건. 미체결 주문·진입 중 포지션·기관 전체 체결 목록과 구분한다. PAPER 원장이나 주문·실행 계약·여권 증거를 변경하지 않는다.
- SQL에서 기관 별칭과 실행 모드를 먼저 필터링한 뒤 시간대가 반영된 종료 시각으로 정렬·제한한다. 기관 불명 기록은 다른 기관으로 재분류하지 않는다.
- PAPER/LEARNING은 LIVE 조회에서 제외한다. 과거 모드 미기록·손익 미대조·수동/외부·가져오기 기록은 확정 성과로 표시하지 않는다. 확정 순손익 근거가 없으면 `미확정`이며 0이나 과거 raw pnl로 대체하지 않는다.
- 주식/ETF는 증권사 범위를 공유하되 종목 코드를 유지한다. 해외 주식 통화 불명 기록을 KRW로 단정하지 않는다. 작은 가격·손익을 0으로 반올림하지 않는다.
- 실제 원장에 전략 키·버전이 있을 때만 전략 스튜디오 귀속을 표시한다. 현재 Recorder 스키마처럼 해당 열이 없는 기록은 `전략 귀속 미기록`으로 표시하며 추측하거나 원장을 소급 수정하지 않는다.
- 조회 중·정상 빈 목록·조회 실패를 구분한다. 갱신 실패 시 이전 내용을 현재 정상 조회처럼 표시하지 않으며 복구 시 다시 나타난다. 기존 계좌/워크스페이스 폴링을 재사용하고 새 기관 API 호출은 추가하지 않는다.

## 남은 배포 게이트

테스트 원장은 가상 데이터다. 실제 거래소/증권사 계정의 체결 수집, Windows 설치본 및 키움 실제 연결 검증을 대신하지 않는다. Coinone의 LIVE 준비 상태나 어떤 기관의 거래 권한도 이 화면 변경으로 승격되지 않는다. 신규 배포 버전 승인·Windows 재빌드·실계정 읽기 대조 후 배포 판단이 필요하다.
