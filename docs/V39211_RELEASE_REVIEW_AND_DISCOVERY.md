## 검색·AI/LLM 검색 계획

여기서 ‘AILLM’은 특정 제품명 확인이 없어 AI/LLM 검색 발견·인용으로 해석했다. 앱 내부 어시스턴트 안내는 공개 웹 검색과 별개이며 출하된 버전별 로컬 정본을 먼저 쓴다. 공개 고객 FAQ와 앱 정본은 같은 근거에서 만들되 개인 운영 기록을 공개 학습 자료로 내보내지 않는다.

2. 고객 질문을 제목으로 한 본문을 만든다: “코인과 주식의 시장국면은 왜 다르게 바뀌나요?”, “며칠째 거래가 없으면 무엇을 확인하나요?”, “PAPER 기록이 미확정이면 어떻게 재개하나요?”. 직접 답변 → 실제 기준 → 화면 확인 경로 → 적용 버전/한계 순서로 작성한다. [국면 정본](V39211_MARKET_REGIME_GUIDE.md)을 재사용한다.
3. 각 질문에 정본 URL 하나를 정하고 회사 기술 문서·정보 가이드·포털에서 내부 링크로 연결한다. 실제 보이는 본문과 구조화 데이터가 일치해야 하며 날짜는 실제 검토일로 유지한다. 언어별 canonical/hreflang·200·렌더된 텍스트·noindex·sitemap 포함을 검사한다.
4. Google Search Console의 URL 검사/색인·검색 성과, Bing Webmaster의 수집/색인·AI Performance와 변경 URL의 IndexNow 제출을 운영 인수로 진행한다. 이번에 계정 소유권·제출·색인 성공을 확인하지 않았다.
5. ChatGPT 검색은 `OAI-SearchBot` 허용과 CDN/WAF 도달 가능성을 확인한다. `GPTBot`의 학습 허용은 별도 선택이며 검색 노출 목적으로 학습까지 허용할 필요는 없다. 구체적 봇 규칙을 추가하면 일반 규칙의 비공개 경로 차단을 해당 그룹에도 반복한다. 공개 문서 외 계정/API/원격 자료는 검색 자료로 쓰지 않는다.
6. 이미 있는 `llms.txt`에는 정본 링크·현재 공개판·후보 경계·자료 확인일을 정확히 적는다. 이를 검색 등록·순위 또는 AI 인용 보장으로 취급하지 않는다. Google은 AI 검색용 별도 텍스트 파일/특수 스키마를 요구하지 않는다.
7. 매주 정해진 10개 질문으로 검색·AI 답변의 정확한 인용 URL/잘못된 버전/한계 누락을 기록한다. 비브랜드 검색 노출→가이드 방문→다운로드→PAPER 시작→첫 실제 후보 평가·보류 사유 이해→7일 유지의 전환을 개인 정보 최소화와 동의 범위 내에서 측정한다. 순위·인용 횟수만을 제품 신뢰성 지표로 쓰지 않는다.

공식 근거(확인 2026-10-11): [Google AI 기능과 웹사이트](https://developers.google.com/search/docs/appearance/ai-features), [Bing Webmaster Guidelines](https://www.bing.com/webmasters/help/bing-webmaster-guidelines-30fba23a), [OpenAI Crawlers](https://developers.openai.com/api/docs/bots). Google/Bing의 기본 크롤링·색인·유용한 내용 원칙이 AI 검색에도 적용되며, 요건 충족은 노출·인용을 보장하지 않는다.

## 출시 후 무거래 피드백을 기다리지 않는 운영

현재 앱은 7개 코인 기관의 실행 중 PAPER/LIVE 세션에 대해 30분·3회 반환 주기 이상의 무주문과 15분 주기 갱신 지연을 메인/기관 요약에서 표시한다. 앱 종료·PC 절전 중 외부 푸시 감시는 구현 범위가 아니다. 최근 128개 판단과 실제 신뢰도/필요값·자금/목록/시세/주문 상태의 사유를 사용자가 확인하게 한다. 정상 HOLD와 연결 장애를 분리하고, 자료가 없으면 정상으로 표시하지 않는다.

후속 운영 항목: 증권 장기 무거래 감시의 동일 수준 보강, 사용자 동의 기반 비식별 지원 진단 묶음, 앱 밖 알림 채널·수신 확인, 기관별 오류/대기 분포 추이와 재발 검토를 별도 개발·인수한다. 이번 로컬 패치에 이미 완료됐다고 합치지 않는다. 배포받은 PAPER 테스터가 시작→보류 이유 이해→조치→재평가→자료 보존을 관찰하고 운영자가 결과에 따라 후속 패치·확대 여부를 결정한다. 거래 횟수를 늘리려고 안전 조건을 자동 완화하지 않는다.
