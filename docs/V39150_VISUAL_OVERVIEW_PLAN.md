# v3.9.1.50 — 시각적 첫 화면·시작 오류 진단 통합

2026-10-01 후속: 사용자의 50 설치본 후보 선정/키움 종료 피드백에 따른 미배포 수정이 추가됐다. OKX 원본 시세 필드 보존, 결측 시세 제외/세부 선정 코드, 키움 읽기 취소 순서와 주문 응답 보호가 대상이다. 결과와 미완료 인수/기존 시험 충돌은 TEST_STATUS·DEPLOY_CHECKLIST의 10월 1일 절을 우선한다. 아래 50 후보/49 공개 표기는 당시 계획이다. 후속 코드는 공개 50 설치본의 검증 결과로 소급하지 않는다.

2026-09-30. 사용자가 49 배포 완료를 확인했으므로 후속 변경은 50에만 반영한다.
Windows 빌드·서명·배포는 사용자가 담당한다. 소스 시험과 공개 설치본 검증은 별개다.

## 범위와 변경 계약

후속 공통 실행 수정: 같은 기관 시작은 직렬화하고, 아직 종료 중인 워커를 교체하지 않는다. 초기화 중 정지 요청은 세대 번호로 시작을 취소하며 자동 재개하지 않는다. 다른 기관의 초기화를 전역 잠금으로 막지 않는다. 수정 전 동시 시작/종료 중 재시작 7개 실패를 재현했다. 해당 고객의 49 최초 원인과 동일하다는 증거는 아직 없다. 일반 배포 승인은 고객 장애 근거/환경 해소 확인 전 보류한다.

1. 기존 기관 상세·상세 로그·거래 제어를 유지한다. 첫 화면에 시장 국면/변화 이력 → 실제 후보 검사 구성 → 최근 검토 전략을 추가한다. 기관 상태 목록은 보조 영역이다.
2. 국면 원형은 상태 표시이지 상승 확률이 아니다. 검사 막대는 충족/미충족/미확인 개수이며 추천 점수가 아니다. 기관·모드·전략 버전·평가/봉 시각을 구분한다. 미수신·정지 전·오래된 근거는 구분하며 빈 그래프를 가짜 기록으로 채우지 않는다.
3. 기존 workspace 스냅샷만 사용한다. 새 외부 API/LLM/DB 호출 0회. 기관 선택은 화면 상태만 변경한다. 최대 24개 국면 변화·20개 검사만 렌더링한다. 통계 LIVE/PAPER 선택은 주문 모드를 바꾸지 않는다.
4. 오늘 거래 결과는 확인된 기존 KPI를 유지한다. 현재 응답은 완전한 성과 시계열을 보장하지 않으므로 누적 PnL/MDD/샤프 곡선을 새로 계산하지 않는다. 거래 통계 상세로 연결한다.
5. 49 OKX PAPER 진단의 실제 오류 코드 소실과 무조건적인 기록 복구 안내를 수정한다. HTTP 오류의 안전한 코드·요청 ID·단계를 보존한다. 알 수 없는 사유는 명시하고 민감한 원문을 공유 진단에 넣지 않는다.
6. LIVE 손익/원장 불일치에만 복구 UI·조회 연결. PAPER 후보 없음·초기화 오류·이용 권한·응답 미수신은 서로 다른 다음 조치를 안내한다. 복구 조회 시각은 시작 시각과 구분한다. 타임아웃은 시작 실패 확정이 아니라 실행 여부 미확정이다.
7. 공통 비바이낸스 시작 경로에 실패 단계 추가. 실행 모드 확인은 워커 시작 전 수행하고 워커 시작 실패 시 실행 플래그를 정리한다. 기존 bool 호출 계약과 보호 검사는 유지한다.
8. 기존 전략·승인·회원 한도(일반10/프리미엄30)·손익 보호·주문 권한은 변경하지 않는다. PnL 초기화나 오류 무시로 시작을 허용하지 않는다.
