# 3.9.1.50 — 시각적 거래 현황

2026-09-29: 사용자가 49 배포 완료를 알렸으므로 이후 재설계는 50 소스 후보로 분리한다. Windows 빌드/릴리스는 사용자가 수행한다. 보존된 deploy 파일이 48이어도 실제 49 설치기·해시를 만들어 넣지 않는다.

## 목적과 범위

첫 화면에서 시장 상태 → 실제 판단 근거 → 최근 검토 전략 → 거래 결과 → 조치를 이해한다. 49.5의 표 중심 화면은 기관 관리에 유용했으나 시각적 요약이라는 목적을 충족하지 못했다. 기존 상세 로그·기관 제어·일괄 확인·전략 승인·손익 보호·원장을 그대로 유지하며 읽기 전용 표시를 보완한다.

1. 첫 탭 `거래 현황`: 오늘 결과와 시장/근거/전략 3개 시각 영역을 첫 화면에 배치한다. 기관 목록은 그 아래 보조 영역이다. 각 영역이 상세 기능으로 연결된다.
2. 분석 기관 버튼은 화면 안의 근거만 전환한다. source + actual execution mode가 일치하는 메모리 투영만 사용한다. 오늘 LIVE/PAPER 통계 버튼과 분석 기관 선택을 분리해 각 범위를 표시한다. 실행 중/선택 기관을 우선하지만 한 기관을 전체 시장으로 표시하지 않는다.
3. 시장: 관찰/확정 국면을 범주형 원형 배지와 기존 세션 상태 전환 흐름으로 시각화한다. 원형은 상태 표시이며 확률/퍼센트 게이지가 아니다. 기관·모드·봉/대상·관찰 시각, 정지·오래된 기록을 표시한다.
4. 종합 근거: 실제 candidate.checks 최대20개를 충족/미충족/미확인으로 시각화한다. 표시한 검사 수만 센다. 빈 값은 실패나 통과로 바꾸지 않으며 중첩된 검사 요약을 독립 조건 충족률/승률로 표시하지 않는다. 이유는 원문 그대로 안전하게 텍스트 렌더링한다.
5. 전략: 최근 후보에 사용된 전략·버전·대상·방향·봉·통과/보류·이유를 카드로 표시한다. 최근 검토 전략을 적용 전략 전체/AI 최적 추천이라고 부르지 않는다. Studio/기관 상세/AI 사전입력으로 연결하고 자동 전송하지 않는다.
6. 결과: 기존 오늘 손익·포지션·승률을 보존하고 LIVE 청산 대조 완료/미확정 건수를 막대로 표시한다. PAPER에는 LIVE 대조를 적용하지 않는다. 기간·수수료·통화 계약이 없는 신규 수익률 곡선은 생성하지 않고 상세 통계로 연결한다.
7. 근거 없음도 3개 시각 영역을 유지하며 중립 배지·필요한 자료와 확인 경로를 보여준다. 가짜 수치/예시 그래프가 실행 데이터처럼 나타나지 않는다. 그래프를 보기 위해 LIVE를 권유하지 않는다.
8. 기존 5초 workspace/숨김 정지/오래된 응답 폐기 재사용, 기관 선택으로 API 요청 0회, 신규 외부 API/LLM/SQL/저장 0회. 국면24개·검사20개 제한. 계좌는 명시적 조회만 유지한다.

## 수용 기준

- 실제 dist + Chrome: 1440/1080 폭과 짧은 창, 7거래소/4증권·단일/미설정, 근거 있음/없음/정지/구형/실패, 기관 전환·모드 불일치·확률 오표시 없음, 통계와 분석 범위 구분, 버튼 동선, 거래/전략 쓰기 없음.
- 첫 화면에 시장/근거/전략 시각 영역이 보여야 한다. 단순 DOM/테스트 통과 외에 실제 캡처를 직접 검토한다. 모든 기관 행이 접힘 없이 첫 화면에 들어가는 이전 기준은 폐기한다.
- 설정9탭/어시스턴트/기존 기관 요약/재생 차트 회귀, TypeScript·Node·전체 오프라인 회귀. 설치본·배율·실거래·24시간 성능은 별도 Windows 게이트다.
- 50 버전·Windows 파일 정보·Electron updater 3.9.150·매뉴얼·문서 정합. 공개49는 사용자 확인 사실이고 이번 작업에서 배포 검증한 결과가 아니다.
