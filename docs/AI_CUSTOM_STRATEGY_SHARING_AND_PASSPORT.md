# NoahAI Strategy Studio 전략 여권·공유 패키지 정본

기준 버전: NoahAI Client v3.9.1.27 공개판  
공개 배포 기준: v3.9.1.27 Windows 설치 파일·blockmap·`latest.yml`·릴리스 manifest  
기준 일자: 2026-09-11  
배포 경계: 공개 배포 완료와 사용자별 패키지·브라우저·기관 환경 E2E를 구분한다.  
개발 순서: Strategy Studio → 검증 증거 → 무료 Verified Strategy Hub → 유료 Marketplace

> 명칭·사업·개발 단계는 [Strategy Studio 마스터 플랜](NOAHAI_STRATEGY_STUDIO_MASTER_PLAN.md)을 우선한다. Level 1~4는 화면 깊이·운용 정책 범위이며 검증 증거는 E0~E5로 별도 표기한다. Level 4는 하드 가드레일 해제 권한이 아니다.

## 한 줄 계약

> `.noahstrategy`는 사용자가 선택한 전략 규칙과 전략 여권만 담고, 계정·API·거래 데이터·로컬 실행 상태를 구조적으로 제외하는 NoahAI 전용 전략 패키지다.

v3.9.1.19부터 브라우저는 서버가 직렬화한 패키지 JSON을 그대로 저장한다. 구형 브라우저 파일은 스키마상 소수형 위험값을 복원한 뒤 기존 IR 해시와 전체 content hash가 모두 일치할 때만 가져온다. 이는 오류 복구이지 해시 우회가 아니다. 전략 여권에는 `원문 구조화 전략`과 `NoahAI 기본 진입 + 사용자 위험·청산값`을 분리해 후자를 원문 전체 성과로 오인하지 않게 한다.

v3.9.1.26부터 위험예산 보완은 AI가 만든 전략 내용이 아니라 사용자가 화면에서 확인한 값을 원문에 명시하는 편집 이력이다. 이후 생성되는 버전과 여권은 이 보완된 원문·IR을 함께 해시하며, 기본 NoahAI 판단을 선택한 결과를 사용자 독립 진입 전략으로 승격하지 않는다.

v3.9.1.27부터 AI 답변은 편집 가능한 미적용 초안으로 Strategy Studio에 전달된다. 사용자가 확인하고 전체 규칙을 재분석하기 전에는 여권 근거·저장·승인·PAPER·LIVE 권한이 되지 않으며, 저장된 생성 시각이 없는 과거 버전의 시각은 추정하지 않는다.

## 제품 경계

- 개발 1~5단계는 전략 기반, AI 멘토·제작 UX, 검증 연구소, 국면 오케스트레이션, 실행 OS다.
- 개발 6단계는 전략 여권과 무료 공개 허브, 계정별 취득·다운로드 감사다.
- 현재 클라이언트에는 `.noahstrategy` 로컬 exporter/importer, SHA-256 변조 검사, 선택형 로컬 HMAC 서명과 비활성 검토 가져오기가 구현되었다. `private/team/unlisted`는 호환 메타데이터일 뿐 현재 일반 사용자 서비스 범위가 아니다. `daltrading` 소스에는 회원 수동 제출, 권리 자기선언·패키지/IR 구조 검사 후 E0 또는 제작자 로컬 집계를 표시하는 E1 공개, 증거 단계, 신고 기반 운영자 검토·격리, 10개 범용 목적 카테고리와 동적 기관 필터, 무료 취득·계정별 실행 라이선스·내 라이선스 재다운로드, 제작자 공개 중지 요청·신규 취득 차단·기존 취득자 권리 유지와 감사 보존이 있다.
- 전략 허브는 기본 30일 `free_beta`로 시작한다. 가격 0인 제공 스냅샷·취득 거래·계정별 영구 실행 라이선스와 기존 다운로드 감사 마이그레이션은 구현되었다. 포인트 충전·차감과 제작자 수익·지급 원장은 아직 미구현이다.
- 개발 7단계는 Noah Point 구매, 전략 버전 영구 실행 라이선스, 제작자 수익 지급과 선택형 코인 결제를 순차 개방한다. 성과 기반 과금은 포함하지 않는다.
- 사용자가 제공한 Pine·책·영상·자연어 원본의 소유권을 NoahAI가 취득하지 않는다.
- NoahAI 안전 DSL, 검증·국면·가드레일·패키지 서명·실행 계약은 NoahAI 전용이다.

## 파일 형식

```text
전략이름.noahstrategy
```

공식 실행 패키지는 단순 설정 백업이나 임의 JSON이 아니다. 로컬 패키지는 SHA-256을 필수로 확인하고 선택형 로컬 HMAC 서명을 지원한다. 서버 배포 패키지는 향후 NoahAI 서버 서명을 필수화한다. 다음을 검증한 뒤에만 NoahAI가 가져온다.

- `format=noahstrategy`
- 패키지 스키마 버전
- 최소·최대 호환 클라이언트 버전
- 전략 고유 ID·버전·부모 전략 ID
- 콘텐츠 SHA-256
- 로컬 무서명 경고 또는 검증 가능한 제작자/NoahAI 서버 서명
- 허용된 안전 DSL 필드만 포함하는 화이트리스트 검증
- Noah Strategy IR 스키마·capability profile·실행 프로필 호환성 검증
- 출처·사용 권한 선언
- 전략 여권과 검증 근거

## 내부 로컬 데이터와 공유 데이터의 분리

| 정보 | NoahAI 내부 저장 | `.noahstrategy` |
|---|---|---|
| 거래소 API Key·Secret | 사용자 `config/settings.json` | 절대 제외 |
| 증권 계좌·비밀번호·인증서 값 | 사용자 `config/settings.json` | 절대 제외 |
| 로그인 토큰·자동 로그인 | `token.json`, `credentials.json` | 절대 제외 |
| 잔고·포지션·주문·개인 거래 | 런타임·`trading.db` | 절대 제외 |
| 원본 로컬 절대경로 | 개인 전략의 `source_reference`에 존재 가능 | 경로 제거, 파일명·콘텐츠 해시만 허용 |
| 활성 버전·자동 적용 상태 | 개인 전략의 `active_versions` | 절대 제외, 가져올 때 비활성 강제 |
| 사용자 승인 주체·시각 | 개인 감사 기록 | 승인 상태 제외 |
| 전략 규칙·안전 DSL·Noah Strategy IR | 개인 전략 저장소 | 사용자가 선택한 단일 버전과 capability profile만 포함 |
| 검증 결과 | 개인 전략 저장소 | 개인정보를 제거한 전략 여권 요약만 포함 |

공유 내보내기는 전체 설정이나 전략 저장소 파일을 복사하지 않는다. 허용 필드로 새 패키지를 만드는 전용 exporter만 사용한다.

## 전략 여권 필수 필드

- 전략 이름·제작자 공개 ID·전략 ID·버전
- 부모 전략·포크·구독 관계
- 원본 종류, 출처, 사용 권한 선언, 콘텐츠 해시
- 지원 자산·거래소·증권사·심볼 범위·시간봉
- Noah Strategy IR 스키마 버전, 필요한 데이터·지표·상태·주문 capability와 현재 지원 판정
- 원문 span → IR node → 실행 조건 추적 요약과 미지원·사용자 확인 이력
- LONG/SHORT, 권장·금지 국면, HOLD 조건
- 진입·청산·부분청산·TP/SL·재진입·쿨다운 지원 범위
- 검증 데이터 기간·표본 수·미사용 구간
- 수수료·슬리피지·스프레드·펀딩 가정
- 통화별 PnL, MDD, Profit Factor, 연속 손실, 국면별 성과
- 워크포워드·민감도·몬테카를로·과최적화 경고
- PAPER 전진검증·실제 체결 검증 구분
- 위험등급·중단 조건·필요 클라이언트 버전
- 패키지 해시·서명·업데이트 이력

승률 하나로 전략을 홍보하거나 순위를 정하지 않는다. 통화 환산 근거가 없으면 KRW·USDT 등 금액을 합산하지 않는다. 무료 전략 탐색의 범용 카테고리는 추세장·횡보장·저위험·소액 계정·암호화폐 선물·암호화폐 현물·주식/ETF·장기 PAPER·실제 체결·초보자 설명 우수의 10개다. 자산군·상품 유형·기관·국면·증거 단계는 별도 동적 필터이며 거래소 이름을 영구 카테고리로 하드코딩하지 않는다.

공개 후보는 제작자 배포 권리 자기선언, 패키지 해시·호환성, `supported` 실행 구조를 요구한다. 1단계 서버 분석이 자산·상품·기관·시장국면·검증 대상과 제한된 제작자 로컬 집계를 추출하고, 2단계에서 사용자가 그 범위와 권리를 확인한다. 성과 집계가 없으면 `E0 구조·무결성 확인`, 정확한 버전의 기관·통화별 로컬 집계가 있으면 `E1 제작자 로컬 근거`다. E1은 서버·거래소 미확인이며 E0와 함께 랭킹·점수에서 제외한다. 서버 서명 OOS는 E2, 계정 연동 PAPER는 E3, 제한 LIVE 관찰은 E4, LIVE 준비 기관의 확인 체결은 E5로 승격하며 원시 승률·총수익률은 사용하지 않는다. 다운로드 사용자의 로컬 결과는 그 사용자의 재검증 근거이고 원 제작자 점수에 자동 합산하지 않는다.

## 가져오기 상태머신

```text
패키지 선택
→ 확장자·스키마·해시·서명·호환 버전 검사
→ IR·capability·실행 프로필 지원 여부 검사
→ 금지 필드/API·계좌·경로·활성 상태 검사
→ 새 로컬 strategy_key로 비활성 복사
→ 원문→규칙·전략 여권·버전 차이 확인
→ 수신 사용자 승인
→ NoahAI 자동검증
→ PAPER 전진검증
→ 사용자의 최종 적용
→ 해당 거래소·증권사 시작
```

불변식:

```text
공유받기 ≠ 승인
승인 ≠ 검증 통과
검증 통과 ≠ 자동 적용
업데이트 수신 ≠ 활성 버전 자동 교체
```

가져온 전략은 원본 패키지의 `active`, `approval`, `live_confirmation`, 계정별 성과를 무시하고 항상 비활성 검토 버전으로 생성한다.

## 공유 방식

### 6A. 로컬 안전 공유

- `.noahstrategy` 내보내기·가져오기
- 전략 여권 미리보기
- SHA-256·서명·호환 버전 검사
- 복사형 포크
- 내보내기 전 민감정보 검사
- 가져온 전략은 원 패키지의 상태와 무관하게 `review_only`, 비활성, 미승인으로 초기화

### 6B. 계정 보관함과 무료 취득 라이선스

무료 베타 다운로드부터 다음 권한 계약을 사용한다.

- 다운로드한 회원 계정에 `가격 0인 취득 거래`를 기록
- 전략 ID·버전·패키지 해시가 고정된 영구·비독점 NoahAI 실행 라이선스 발급
- 같은 계정의 재다운로드 허용
- 가져온 전략은 항상 비활성·미승인·재검증 상태로 시작
- 제작자 공개 중지는 라이선스 없는 신규 취득·다운로드를 차단하되 기존 합법 취득 이력과 정상 라이선스의 재다운로드 권리를 삭제하지 않음
- 새 전략 버전은 자동 적용하거나 자동 소유 처리하지 않음

회원 초대·팀 워크스페이스는 일반 Marketplace 필수 범위에서 제외한다. 향후 B2B·기관 사용 수요가 확인되면 별도 권한 서비스로 검토하며 현재 로드맵의 완료 조건으로 사용하지 않는다.

### 보호형 전략

클라이언트로 전체 규칙을 전달하면 완전한 비공개를 보장할 수 없다. 핵심 IP 전략은 향후 서버 측 신호 평가 또는 계정 라이선스 검증을 사용한다. 암호화 파일만으로 영구적인 역공학 방지를 보장하지 않는다.

## 마켓플레이스와 분리

다음은 현재 `.noahstrategy` 무료 공유 기능에 포함하지 않는다.

- Noah Point 유상 충전과 전략 구매
- 제작자 수익 적립·원화 또는 코인 지급
- 외부 카드·계좌·코인 결제 연동
- 유료 노출·광고·성과 표현 심사와 판매 순위
- 거래소 레퍼럴 결합

위 기능은 7단계 거래·라이선스 원장과 별도 결제 서비스가 준비된 뒤 개방한다. 구매자는 전략 저작권·소유권 전체가 아니라 해당 버전의 영구·비독점 NoahAI 실행 라이선스를 취득한다. 라이선스 또는 파일 발급 후 단순 변심 환불은 제공하지 않고 중복 결제·미발급·손상·비정상 결제만 관리자 예외 처리한다.

무료 전략 허브, 현재 클라이언트 라이선스, 후속 제작자 구독·마켓, B2B·기관·IP 라이선스가 서로 다른 수익 계층이라는 대외 설명은 `docs/NOAHAI_EXTERNAL_POSITIONING_AND_BUSINESS_PLAN_20260804.md`를 따른다.

무료 목적별 탐색 화면은 6단계 기반에 포함하지만 실제 전략이 없으면 빈 상태를 표시한다. 이 화면을 유료 마켓, 투자자문 또는 수익 보장 순위로 부르지 않는다.

무료 테스트에서 유료로 넘어가는 관리자 정책은 판매 기능 자체와 구분한다. 현재 결제·포인트·라이선스·제작자 지급 실행기는 없으며 서버 코드 게이트가 기본 차단 상태이므로, 관리자 설정 화면이 존재한다는 이유만으로 유료 판매가 개시된 것으로 안내하지 않는다. 기존 `refund_policy_ready` 등 관리자 필드는 실제 출시 계약이 아니라 구형 준비 체크이므로 후속 구현에서 포인트·라이선스·예외 취소 준비 상태로 마이그레이션한다.

## 6단계 완료 기준

- 금지 필드가 포함되면 내보내기·가져오기 모두 실패 폐쇄
- 패키지 변조·서명 실패·호환 버전 불일치 차단
- 가져온 전략의 승인·활성·개인 성과가 항상 초기화됨
- 원본 출처·권리·전략 버전·검증 조건을 사용자가 가져오기 전에 확인
- IR·capability 불일치와 미지원 노드를 가져오기 전에 표시하고 승인·적용을 실패 폐쇄
- 복사·구독 업데이트가 기존 활성 버전을 자동 교체하지 않음
- 인앱 매뉴얼·사용자 가이드·업데이트 내역·테스트가 같은 계약을 사용
- 유료 판매 기능 없이 로컬 공유와 무료 허브 취득·재다운로드가 독립적으로 작동
- 10개 범용 목적 카테고리와 등록부 기반 자산·상품·기관·국면·증거 필터가 실제 검증 전략만 표시하고 빈 카테고리에 가짜 샘플을 만들지 않음
