배포 경계: v3.9.1.28 공개 자산과 모든 거래소·증권사 자격정보, 특수 DPI, 장시간 운용·실계정 결과의 무결함은 서로 다른 증거다. 후자는 환경별 후속 관찰 범위로 구분한다.

> 최종 사용자 명칭은 **NoahAI Strategy Studio(노아AI 전략 스튜디오)**다. `AI 커스텀`은 기존 사용자 안내와 내부 호환 식별자에 한시적으로 남긴다. `Strategy OS`는 장기 지향점이며 현재 완성 기능명으로 사용하지 않는다. 전체 명칭·사업·개발 단계는 [Strategy Studio 마스터 플랜](NOAHAI_STRATEGY_STUDIO_MASTER_PLAN.md)을 우선한다.

> 특히 TradingView 운영 webhook, 전체 LIVE 버전·국면 성과 집계, 자동 전략 배분, 유료 마켓·포인트·제작자 지급·B2B는 현재 제공 완료 기능이 아니다.

> v3.9.1.19는 실행 엔진과 전략 소유 범위를 분리하고, 패키지 해시를 보존하며, 실제로 어떤 논리가 검증됐는지를 여권에 표시하는 단계다. 수익률이 아니라 근거 수준과 재현 가능성을 제품 신뢰의 중심에 둔다.

> v3.9.1.20은 중지 권한·재시작 복구·멱등 청산·신규 비용과 다중 PAPER 표본 배정을 보강했고 v3.9.1.21은 통합 거래소 활성 PnL·과거 Binance 비용 근거·로그 귀속·성과회복 표본을 바로잡았다. v3.9.1.22는 LIVE와 분리된 전략 버전별 가상 포지션 병행검증과 공통 계좌 위험 투자금 계약을 추가했다. v3.9.1.23은 일시정지·같은 시도 재개·새 시도를 분리하고 메인 KPI와 거래 통계에서 LIVE/PAPER 원장을 명시적으로 분리했다. v3.9.1.24는 Strategy Studio 가독성과 Strategy Hub 인증·제출 UX를, v3.9.1.25는 입력을 잃지 않는 AI 왕복과 차단 조건 안내를 전달했다. v3.9.1.26은 안내 문장과 실행 파서의 위험계약을 일치시키고 `원문 그대로 / 질문으로 완성 / 기본 NoahAI` 세 경로, 사용자 답변 별도 근거, 원문 충돌 차단과 AI 추측 금지 경계를 고정한다. v3.9.1.27은 단일 확인창, 버전 생성 시각, 외부 AI 429와 로컬 규칙 컴파일의 분리, 설명 수준별 실제 프롬프트·캐시, AI 답변의 사용자 검토 후 재분석 전달에 더해 사용자 요청형 비용 근거와 역할별 모델 구성을 가시화한다. v3.9.1.29는 전략 제작·PAPER 검증을 회원등급에서 분리하고 실제 계정의 집중 1개·무료 3개·코인 유료 5개 용량과 Coinone 실패 폐쇄 온보딩을 추가한다.

> 역할별 AI 선택은 사용자가 자신의 비용·품질 선호를 표현하는 계층이다. NoahAI가 가격만 보고 전략 의미를 바꾸거나 미확인 모델로 자동 전환하지 않는다. 비용 표시는 실제 토큰과 등록 단가가 있는 사용자 요청형 호출의 예상액이며 Provider 전체 청구서와 자동매매 백그라운드 비용은 별도 범위다.

> **누구나 자신의 투자 지식을 AI와 함께 전략으로 만들고, 시장국면에 맞춰 검증·실행·개선하는 AI 전략 운영체제**

Strategy Studio는 숨겨 둔 부가기능이 아니다. 사용자가 이미 알고 있는 전략, 책·문서·차트·Pine·영상의 지식, NoahAI의 국면 판단·가드레일·실행·감사 기록을 하나로 연결하는 NoahAI의 대표 제품 계층이다.

## 사용자가 경험해야 할 하나의 흐름

```text
배우기 → 만들기 → 검증하기 → 실행하기 → 개선하기 → 공유하기
```

- **배우기**: AI가 투자 대상, 손실 허용 범위, 경험, 확인 가능 시간과 PAPER/LIVE 준비 수준을 묻고 전략의 원리·적합 국면·실패 조건을 설명한다.
- **만들기**: 자연어·Pine·PDF·이미지·영상·YouTube·TradingView 자료에서 원문 근거와 실행 규칙을 연결한 초안을 만든다.
- **검증하기**: 누락 조건, 비용, 국면별 결과, 낙폭과 실행 가능성을 확인한다.
- **실행하기**: 사용자 승인과 실행 권한, 계좌·주문 가드레일을 모두 통과한 전략만 LEARNING/PAPER/LIVE 경로로 보낸다.
- **개선하기**: 판단·HOLD·차단·주문·체결·손익을 전략 버전과 연결하고 개선안은 새 버전으로 제안한다.
- **공유하기**: 클라이언트는 민감정보·활성 상태를 제외하고 정확한 버전의 기관·통화별 로컬 집계 여권을 담은 `.noahstrategy` 내보내기/가져오기를 제공한다. `daltrading`에는 회원 수동 제출·권리 자기선언·구조 검사 후 E0 공개, 제작자 로컬 집계가 있는 E1 공개, 서버·계정·기관 확인 E2~E5, 신고 기반 사후 검토·범용 목적과 동적 기관 필터·로그인 다운로드 기반이 있다. 무료 취득 라이선스 원장은 현재 기반이며 유료 마켓은 후속 단계다.

## 2026-08-10 고도화 결정: 전략 생성기가 아니라 근거 기반 전략 컴파일·운영체제

자연어 전략 생성, 노코드 백테스트, AI 모델 학습, AI 코드 생성은 이미 TradingView·TrendSpider·Capitalise.ai·QuantConnect 등에서 각각 강하게 제공된다. 따라서 `AI가 전략을 만들어 준다`는 설명만으로는 지속 가능한 차별점이 아니다.

NoahAI의 우선 개발 축은 다음 세 가지로 정본화한다.

1. **Noah Strategy IR** — 여러 원본을 현재 지원 능력이 명시된 제한 중간표현으로 통합한다.
2. **근거 기반 컴파일러** — 원문 조각과 실행 노드를 연결하고 `지원 / 사용자 확인 필요 / 미지원`을 실패 폐쇄로 판정한다.
3. **Progressive Strategy UI** — 같은 전략 버전을 `요약·시험 → 핵심값 편집 → 전체 그래프 편집`의 세 깊이로 제공한다.

이 축은 검증 연구소, 국면 오케스트레이터, 계좌·주문 가드레일, 전략 여권과 결합할 때 사업적 방어력이 생긴다. `Universal Trading Strategy IR`은 내부 장기 방향일 뿐 대외 지원 약속이 아니다. 오더북·차익거래·옵션·뉴스·온체인처럼 별도 데이터와 실행 계약이 필요한 전략군은 capability profile이 준비될 때 별도 확장한다.

상세 시장 검증, P0~P3 순서, KPI와 Go/No-Go 기준은 `AI_CUSTOME_UPDATE_PLAN.md`를 따른다. 명칭과 전체 서비스 순서는 `NOAHAI_STRATEGY_STUDIO_MASTER_PLAN.md`를 우선한다.

## 제품을 구성하는 8개 계층

### 1. AI 트레이딩 멘토

초보자에게 빈 편집기부터 보여 주지 않는다. 운용 자금, 최대 허용 손실, 거래 빈도, 레버리지, 경험과 PAPER/LIVE 준비 수준을 대화로 파악하고 2~3개의 후보를 제시한다. 목표는 “돈을 버는 전략”을 단정하는 것이 아니라 왜 적합한지, 어느 국면에서 실패할 수 있는지, 언제 거래하지 않아야 하는지를 가르치는 것이다.

### 2. 멀티모달 전략 제작소

책·PDF·Pine·차트 이미지·영상·YouTube·사용자 대화를 한 제작 흐름으로 묶는다. 핵심은 입력 형식의 수가 아니라 **원본의 어느 문장·화면이 어떤 실행 규칙이 되었는지** 추적하고, 불명확한 조건만 다시 질문하는 것이다.

### 3. 범용 안전 전략 언어와 컴파일러

외부 코드를 그대로 실행하지 않고 NoahAI 안전 DSL에서 `Noah Strategy IR`로 단계적으로 정본화한다. IR은 데이터·신호·연산자·행동·위험·상태·범위·근거 primitive와 필요한 capability를 명시한다. 다중 시간봉, 중첩 AND/OR, 포지션 크기, 롱·숏별 규칙, 세션, 유동성, 부분청산·추적손절·재진입과 상태 변수를 단계적으로 지원한다. 변환 결과는 `supported / needs_clarification / unsupported`로 분류하며 미지원 조건을 조용히 제거하지 않는다.

### 4. 전략 검증 연구소

백테스트를 없애지 않고 최소 통과 필터로 사용한다. 총 PnL·총 수익률·MDD·승률·Profit Factor·월별/연별 표를 보여 주되, 미래 수익 보장이 아니며 백테스트만으로 자동 승격하지 않는다. 미사용 검증 구간, 워크포워드, 국면별 성과, 비용·슬리피지·스프레드 민감도, 부분체결·미체결, 파라미터 민감도, 과최적화 위험, PAPER 전진검증과 실제 체결 품질을 함께 본다. AlphaArena는 같은 조건의 모델·전략 비교 계층으로 연결한다.

### 5. 국면 기반 전략 오케스트레이터

현재 국면과 전략의 허용·금지 국면을 비교하고 여러 전략 중 적합한 전략을 선택한다. 국면이 불명확하거나 전략이 충돌하면 HOLD한다. 최근 결과가 악화된 전략은 자동으로 몰래 변경하지 않고 PAPER·제한운용 강등 또는 새 버전 개선안을 제안하며, 변경은 사용자가 승인한다.

### 6. 다중 거래소·증권 실행 OS

거래소·증권사별 주문 상태, 개인 체결 스트림, 증분 복구, 부분체결·취소·거절·재시도, 최소 주문·정밀도·레버리지, TP/SL, 전체 계좌 킬스위치와 공통 감사 원장을 다룬다. 이 계층이 전략 신호와 실제 주문 사이의 실행 책임을 맡는다.

### 7. 전략 여권과 제작자 생태계

공유·판매 전 각 전략에 제작자·소유권·원본 출처와 사용 권한, 버전, 지원 자산·거래소·시간봉, 권장·금지 국면, PAPER/LIVE 구분, 검증 기간·표본·비용, MDD·연속 손실, 실제 체결 검증, 위험등급과 중단 조건을 기록한다. 승률 하나만으로 순위를 만들지 않는다.

전략 탐색은 하나의 전체 랭킹 대신 `추세장 / 횡보장 / 저위험 / 소액 계정 / 암호화폐 선물 / 암호화폐 현물 / 주식·ETF / 장기 PAPER / 실제 체결 / 초보자 설명 우수`의 범용 목적을 사용한다. 자산군·상품 유형·기관·국면·증거 단계는 버전 관리 기관 등록부에서 동적 필터로 생성한다. E0/E1은 검증 전 공개 영역에만 두고, E2~E5 후보만 강건성·위험 효율·실행 품질·증거 품질·운영 품질을 합산한다. 원시 승률·총수익률과 기관·통화가 다른 PnL은 순위 기준으로 합치지 않는다.

### 8. 신뢰·권리·지식재산

교육·제작 도구·일반 템플릿·개인화 추천·PAPER·사용자 승인 실행·전략 판매를 기능과 화면에서 분리한다. 책·영상·Pine은 사용 권한과 출처를 남기고 보호 콘텐츠의 접근통제를 우회하지 않는다. 구매자는 저작권·소유권 전체가 아니라 전략 버전의 NoahAI 실행 라이선스를 취득한다.

## TradingView 및 기존 자동매매와의 위치

NoahAI의 목표는 TradingView 차트와 Pine 생태계를 그대로 복제하는 것이 아니다.

> **TradingView·책·영상·트레이더의 지식을 AI로 전략화하고, 시장국면에 맞춰 검증·실행·감독하는 상위 운영 계층**

그렇다고 기존 사용 경험을 버리지 않는다. LONG/SHORT, 진입·청산, TP/SL, 시간봉, 지표, PnL·MDD·Profit Factor·월/연도 표, Pine/알림 입력처럼 사용자가 이미 익힌 개념은 호환 다리로 유지한다. NoahAI는 이 기본 경험 위에 원문 대비 변환 diff, 모호함·미지원 차단, 과최적화 경고, PAPER, 국면·계좌·주문 가드레일과 버전·체결 감사를 추가한다. 사용자가 새 도구를 배우느라 기존 전문성을 잃게 하지 않는 것이 제품 원칙이다.

고정 알고리즘 봇이 한 전략을 계속 반복하는 문제에는 국면 적합성·HOLD·계좌 위험·전략별 기록으로 대응한다. TradingView 전략은 Pine/알림/웹훅을 입력으로 받을 수 있지만, 외부 신호 하나만으로 주문 권한을 얻지 않으며 NoahAI의 사용자 승인·전략 버전·중복 방지·가드레일·실행 상태를 통과해야 한다.

초기 시장 진입은 TradingView를 당장 교체하라고 요구하지 않는다. 차트·Pine·공개 전략을 찾는 기존 행동은 유지하고, NoahAI에서 원문 의미 확인→실제 시드 없는 PAPER→시장국면·가드레일→버전별 검증 여권→공유·수령자 재검증으로 이어지게 한다. 제작과 검증 데이터가 쌓일수록 더 많은 생명주기를 NoahAI 안에서 끝내는 전환 퍼널이다.

무료·유료 모두 Strategy Studio의 핵심 제작·검토·PAPER 개념을 공유하되 실제 기관과 자산 범위는 회원 정책·어댑터 capability·사용자 권한을 따른다. 후속 상품은 `symbol_scope`와 `venue_scope`를 전략 계약에 추가해 특정 코인·주식·ETF 또는 특정 거래소·증권사 전용 전략을 지원한다. 범위 밖 실행은 자동 호환으로 추측하지 않고 차단하며, 같은 전략이라도 기관·통화별 검증 근거를 분리한다.

크리에이터 유입 메시지는 `AI로 자동 수익`이 아니라 `AI로 전략 지식을 검증 가능한 디지털 자산으로 만들기`다. 실제 시드 없이 제작·PAPER·무료 공유까지 시작할 수 있고, 유료 라이선스·제작자 지급은 결제·권리·정산 원장이 완성된 후 열린다.

## 권장 개발 순서와 완료 기준

1. **전략 기반 정본화** — Noah Strategy IR v1, capability registry, 안전 DSL 무손실 왕복, 원본→노드→실행 추적, 미지원 조건 fail-closed
2. **AI 멘토·Progressive 제작 UX** — 대화형 인터뷰, 후보 설명, 요약·핵심값·전체 그래프의 동일 버전 편집, 자연어 단일 조건 수정과 버전 diff
3. **검증 연구소** — 비용·국면·워크포워드·PAPER·AlphaArena 비교와 과최적화 경고
4. **국면 오케스트레이션** — 전략 선택·HOLD·충돌 해결·강등·새 버전 제안
5. **실행 OS 완성** — 인증 체결 스트림, 주문 상태 복구, 거래소·증권사별 실제 E2E와 포트폴리오 위험
6. **전략 여권과 공유** — 무료 공개 허브, 계정별 취득·다운로드 감사, 권리·검증·위험 표시, 제작자 프로필
7. **마켓플레이스** — 포인트 충전, 상품 스냅샷, 영구 실행 라이선스, 제작자 수익 원장, 외부 카드·계좌·코인 결제
8. **생태계 확장** — 전략 SDK, 인증 제작자, 교육 과정, B2B·기관 배포

각 단계는 코드 구현만으로 완료하지 않는다. 사용자 화면, 인앱 매뉴얼, 테스트, 실제 지원 기관 E2E, 업데이트 내역, 웹사이트와 계약·법무 문구가 같은 상태를 말할 때 완료로 본다.

6단계의 공식 공유 형식은 `전략이름.noahstrategy`이며 설정·계좌·거래 DB·로컬 경로·활성 상태를 포함하지 않는다. 상세 스키마·가져오기 상태머신·로컬 공유·무료 계정 취득 계약은 `docs/AI_CUSTOM_STRATEGY_SHARING_AND_PASSPORT.md`를 따른다.

`daltrading /strategies`는 6단계의 탐색·검증 서버 기반이다. 화면과 API가 존재한다는 사실은 클라이언트 패키지 공유·다운로드가 완료되었다는 뜻이 아니며, 결제·판매 기능도 아니다.

초기 운영은 기본 30일 무료 테스트다. 신규 무료 다운로드는 이미 향후 유료 구매와 같은 전략·버전·패키지 해시를 가진 `FREE` 취득 거래와 영구 실행 라이선스로 기록한다. 테스트 포인트는 유료 오픈일 `1P=1원 구매가치`로 1:1 전환한다. 유상/적립 포인트, 판매자 자율 가격, PG 결제, 환불·차지백, daltrading 관리자와 제작자 월 정산은 미구현이므로 유료 전환 코드 게이트는 닫혀 있다. 10,000P부터 10,000,000P 이상 개별계약형까지의 가격구간, 20% 수수료·보상 상한·원화 우선·코인 후속 정책은 `STRATEGY_MARKETPLACE_POINTS_AND_LICENSE_PLAN.md`를 따른다.

## 공개 문구 원칙

- `현재 제공`, `고도화 중`, `향후 생태계`를 한 화면에서 구분한다.
- “모든 Pine 지원”, “수익 보장”, “AI가 알아서 전략 변경”, “즉시 실거래 가능”이라고 쓰지 않는다.
- 현재 지원하지 않는 조건은 변환 과정과 사용자 화면에서 명시적으로 차단한다.
- 개선안은 새 전략 버전으로 제안하고 사용자 승인 전 활성 버전을 바꾸지 않는다.
- 전략 마켓은 검증·권리·포인트·라이선스·제작자 수익 원장을 갖추기 전 판매 기능으로 홍보하지 않는다.
- 법적 역할과 실제 주문 가능 범위는 국가, 회원등급, 계정·API 계약, 설치 버전과 사용자 설정에 따라 별도 확인한다.
- 대외 한 줄 설명, 고객별 소개, TradingView 비교와 무료 베타→현재 라이선스→향후 제작자 생태계→B2B 사업 구조는 `docs/NOAHAI_EXTERNAL_POSITIONING_AND_BUSINESS_PLAN_20260804.md`를 정본으로 사용한다.
