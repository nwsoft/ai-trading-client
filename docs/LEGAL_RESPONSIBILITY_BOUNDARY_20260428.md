# 책임 경계 문서 (2026-04-28)

## 1. 목적

NoahAI 서비스의 책임 범위를 명확히 하여 사용자, 제휴사, 투자자 간 오해를 줄이고 법적 리스크를 낮춘다.

## 2. 역할 정의

- NoahAI
  - AI 기반 판단, 설명, 기록, 리포트 생성
  - 리스크 경고 및 가드레일 제공
- 외부 금융기관/거래소/증권사
  - 주문 접수/체결, 결제, 수탁, 계좌 원장 관리
- 사용자
  - 최종 의사결정 및 주문 실행 승인

## 3. 비해당 영역

NoahAI는 다음을 직접 수행하지 않는다.

- 투자일임(자금 운용 위임 수탁)
- 사용자 계좌 직접 집행
- 수탁/결제 인프라 운영

## 4. 실행 책임 분리

- 판단 책임: NoahAI 모델/규칙 엔진
- 집행 책임: 연동된 외부 금융기관 API
- 승인 책임: 사용자 또는 사용자 정책

## 5. 장애 및 손실 관련 원칙

- 시스템 장애/통신 장애 발생 시 주문 미실행 또는 지연 가능성을 명시한다.
- 리스크 경고는 참고 정보이며, 최종 손익 책임은 사용자의 승인된 실행 결과에 귀속된다.
- 외부 API 장애(거래소/증권사)는 해당 기관의 책임 범위에 따른다.

## 6. 사용자 고지 필수 문구(요약)

- 본 서비스는 투자판단 보조 서비스다.
- 투자 손실 가능성이 있으며 원금 보장을 하지 않는다.
- 최종 거래 실행 책임은 사용자에게 있다.
