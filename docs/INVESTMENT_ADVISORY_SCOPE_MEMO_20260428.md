# 투자자문업 해당성 검토 메모 (초안, 2026-04-28)

## 1. 검토 목적

NoahAI의 서비스 구조가 투자일임/직접 집행이 아닌 판단 보조 인프라임을 정리하고, 규제 대응 포인트를 명확화한다.

## 2. 서비스 구조 요약

- NoahAI는 판단·설명·기록 계층을 담당한다.
- 주문 실행은 외부 금융기관 API를 통해 이뤄진다.
- 최종 실행 승인 주체는 사용자다.

## 3. 비즈니스 모델 핵심 포인트

- 수익모델은 소프트웨어 구독/플랫폼 사용료 중심
- 사용자 자금 직접 수탁/운용을 전제로 하지 않음
- 사용자별 자동화 정책은 사용자가 설정/승인

## 4. 규제 리스크 포인트

- UI/문구가 "확정 수익" 또는 "보장"으로 오인되지 않도록 관리 필요
- 자동매매 기능 설명 시 "실행 주체"를 외부기관/API로 명확히 고지
- 사용자 적합성/고지 문구 누락 시 민원 리스크 증가

## 5. 대응 원칙

- 약관/가이드/마케팅 문구의 책임경계 문구 일치
- 투자 판단 보조 서비스 고지 표준화
- 법무 검토 전 대외 홍보 문구 사전 승인 절차 적용

## 6. 후속 필요 조치

- 외부 법률자문을 통한 최신 규정 적합성 검토
- 제휴 계약서의 책임분담/면책/분쟁조항 정교화
- 내부 컴플라이언스 체크리스트 주기 점검

주의: 본 문서는 법률 의견서가 아닌 내부 검토 메모다.
