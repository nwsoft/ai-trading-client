# AI 커스텀 대화형 전략·초보자 프리셋 고도화 계획

기준 일자: 2026-07-28  
목표 후보: v3.9.0.3에서 구현, v3.9.0.4 후보에 포함  
상태: 소스 구현 완료, Windows 배포·실계좌 장시간 검증 전

## 0. 고급모드 구현 경계

초보자 1+4 프리셋은 입문 예시이고 AI 커스텀의 본체는 사용자 전략을 정확히 옮겨 적절한 국면에서 운용하는 기능이다.

현재 소스 구현:

- EMA·SMA·RSI·ATR·거래량 평균 기간 2~500 사용자 지정
- 조건별 1분~1일 시간봉 지정
- `all`(AND)·`any`(OR) 진입 및 전체 청산 규칙
- 허용 지표·기간·시간봉·연산자 저장 전 차단
- 거래소별 캔들로 계산한 실제 런타임 값과 요청 지표 정의 비교 메타데이터
- 기존 승인·과거검증·최종 적용·HOLD·주문 가드레일 유지

후속 단계:

- 부분익절·추적손절·재진입의 실행 상태머신과 거래소별 주문 정합
- TradingView webhook 서명·재전송 방지·NoahAI 국면 필터 결합
- 사용자 정의 지표의 CPU·메모리·시간·네트워크 제한 샌드박스
- Pine 전체 호환이 아닌 지원 부분집합 변환 일치성 확대

따라서 현재 고급모드는 임의 코드 실행기가 아니라 매개변수화된 안전 선언형 전략 편집기다.

## 1. 목표

- 사용자가 텍스트·Markdown·Pine·PDF·차트·영상·YouTube뿐 아니라 NoahAI와의 자연어 대화로 전략을 이해하고 초안을 만들 수 있게 한다.
- 처음부터 규칙을 작성하기 어려운 사용자를 위해 `AI 자동 대응 1개 + 검토용 기본 전략 4개`를 제공한다.
- 전략을 불러오는 행위와 저장·승인·자동검증·최종 적용을 분리한다.
- 승률이나 미래 수익을 보장하지 않고 국면 불일치·신호 충돌·위험 기준 미달에서는 HOLD를 최우선으로 한다.

## 2. 초보자 기본 구성

| 사용자 표시 | 역할 | 권장 국면 | 상대적 위험도 |
|---|---|---|---|
| AI가 시장에 맞춰 자동 대응 | 기존 NoahAI가 국면과 신호를 판단. 별도 커스텀 전략을 자동 저장하지 않음 | 전체, 조건 불명확 시 HOLD | 국면별 변동 |
| 추세 따라가기 | EMA 20·50·200 정렬 기반 추세 확인 | 명확한 상승·하락 추세 | 낮음~중간 |
| 눌림목 진입 | 추세 중 EMA 20·50 부근 조정 후 재진입 | 완만한 추세·정상 변동성 | 중간 |
| 횡보장 저점·고점 대응 | 박스권에서만 RSI 평균회귀 후보 생성 | 횡보·저변동 | 중간 |
| 강한 거래량 돌파 | 범위 축소 뒤 거래량 확인 돌파 | 변동성 확대 초입 | 중간~높음 |

다중 시간대 모멘텀은 독립 프리셋으로 중복 노출하지 않고 공통 확인 계층으로 둔다. 큰 시간대 방향과 진입 신호가 충돌하면 HOLD한다.

## 3. 대화형 흐름

예시:

1. 사용자: `이평선 매매를 알고 있어?`
2. NoahAI: 전략 목적·적합 국면·HOLD 조건·상대적 위험과 검토 순서를 설명
3. 사용자: `그 전략 초안을 AI 커스텀에 넣어줘`
4. NoahAI: `추세 따라가기` 초안을 AI 커스텀 입력창에 전달
5. 시스템: 아직 실행하지 않고 `AI 분석 및 전략 초안 만들기` 단계에서 대기
6. 사용자: XAI 근거·진입·청산·손절·익절·누락 조건 검토
7. 사용자: 전략 버전 저장
8. 사용자 승인 → 자동검증 → 최종 적용

NoahAI 대화는 전략을 직접 활성화하거나 거래를 시작하지 않는다. 전략 전달이 실패하면 사용자가 AI 커스텀 프리셋에서 직접 불러오는 경로를 안내한다.

## 4. 공통 HOLD·위험 계약

다음 조건에서는 선택 프리셋보다 HOLD가 우선한다.

1. 현재 시장 국면과 전략 대상 국면 불일치
2. 큰 시간대와 진입 시간대 방향 충돌
3. 유동성 부족 또는 스프레드 확대
4. 비용 반영 예상 손익비 기준 미달
5. 급격한 HIGH 변동성 또는 국면 전환
6. 최근 성과 악화·연속 손실·손실한도 접근
7. 선언형 엔진이 지원하지 않는 조건 또는 값 누락
8. 회원등급·API 권한·시장시간·주문 가드레일 미통과

## 5. 평가 우선순위

프리셋은 승률만으로 채택하지 않는다.

1. 비용 차감 기대값
2. 최대낙폭
3. Profit Factor
4. 평균 손익비
5. 연속 손실
6. 국면별 성과
7. 승률

백테스트·자동 재생 결과는 과거 시뮬레이션이며 실거래 성과가 아니다.

## 6. 구현 위치

- 프리셋 정본: `trading/custom_strategy_presets.py`

- 자연어 설명·초안 전달: `ui/widgets/ai_assistant_widget.py`
- 구조화·XAI: `trading/strategy_source_ingestor.py`
- 저장·승인·검증 상태머신: `trading/custom_strategy_pipeline.py`
- 실제 선언형 평가: `trading/declarative_strategy_engine.py`

## 7. 완료와 남은 게이트

구현 완료:

- AI 자동 대응 1개와 편집 가능한 초안 4개
- 자연어 별칭 인식과 전략 설명
- `넣어줘/초안 만들어줘` 요청의 AI 커스텀 입력창 전달
- 전달 후 분석·저장 버튼 비활성 유지
- 국면 추천과 HOLD 우선 설명
- 수익·승률 보장 표현 금지
- AI 키가 없는 규칙 기반 분석에서는 ATR·스윙 손절, 방향별 조건 묶음처럼 확정할 수 없는 값을
  누락 조건으로 남기고 승인 준비 상태로 올리지 않는 fail-closed 회귀 검증
