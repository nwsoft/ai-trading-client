# 3.9.2.1 — AI 어시스턴트 현행 안내 정합성

요청일 2026-10-01. 범위: 최신 기능/오류 질문 안내 개선 + JEV 첨부 검증/계획. Windows 빌드·공개 릴리즈는 사용자 담당이다. 3.9.2.0의 공개 여부는 별도 확인 사항이며 소스 후속 버전과 공개 설치본을 혼동하지 않는다.

## 발견한 원인

1. `ai_custom_knowledge.py`의 광범위한 업데이트 분기가 3.9.1.30 설명을 먼저 반환했다. 뒤쪽 신기능 분기를 추가해도 해당 질문은 도달하지 못할 수 있었다.
2. 웹 서비스별 키워드 분기 때문에 코드만 붙여 넣은 OKX/키움 오류가 제품 안내가 아닌 시장 질문으로 처리될 수 있었다.
3. 웹에 별도 작성된 Level 1·2·3/과거검증 강제 문구와 공통 safe-flow의 오래된 설명이 현재 Level 1~5·선택적 과거재생 정책과 맞지 않았다.
4. 429 설명 첫 문장이 모든 429를 로컬 한도라고 단정한 뒤 뒷문장에서 Provider 429를 구분해 모순됐다.
5. 최신 질문을 직접 찾을 수 있는 공통 빠른 질문이 부족했다.

## 구현 계약

- `config/assistant_support_knowledge.py`를 코드·주제·한국어/영어·정본 경로·guide revision의 공유 안내 원본으로 추가한다. 특정 오류 코드가 버전·일반 용어보다 우선한다. 알려지지 않은 질문은 억지로 아는 원인에 연결하지 않는다.
- 웹의 설정/블록체인/증권/자산통합/애널리스트/생활금융/전략 스튜디오와 레거시 어시스턴트에 연결한다. 일반 안내는 Provider/시세/주문/복구를 호출하지 않는다. 기존 안내 감사 이벤트는 유지한다.
- 깊은 분석에 제공하는 정본 지식을 같은 안내로 연결한다. 공개 일반 질문 경로에는 개인 설정·최근 대화·현재 근거를 덧붙이지 않는다. 외부 모델의 자유 응답을 100% 정확하다고 보장하지 않는다.
- 요청 ID는 원인 코드가 아니다. 고객 사례 해결 여부, 설치 버전, 소스 구현, 실제 실행 상태는 구분한다. 모든 오류에 초기화·복구·키 재발급을 권하지 않는다.
- 안내와 진단 결과를 분리한다. 안내는 다음 확인 단계와 Q&A에 보낼 비식별 항목을 제공하며, 현재 계좌를 확인했다거나 명령을 실행했다고 말하지 않는다.
- safe-flow를 웹에서 재사용한다. 실행 규칙·승인·PAPER/LIVE 정책 자체는 변경하지 않는다. 백테스트 선택과 최종 적용 자격은 다른 단계다.
- 기존 UI 배치/글자 크기를 변경하지 않고 공통 빠른 질문을 추가한다. 버튼은 질문 입력만 채우며 자동 전송·외부 AI 호출을 하지 않는다.

## 검증 게이트

1. 모든 주제·실제 오류 문자열·서비스별 KO/EN 경로 회귀. 기존 질문/계좌 근거 경로를 가로채지 않는지 확인.
2. Provider 호출·시세 조회 없이 일반 안내 반환, 비밀키 비노출, 설정·주문·복구 미실행 확인.
3. 한국어/영어 실패 fallback·공개 질문 격리·사용자 승인 기존 시험 유지.
4. TypeScript/renderer 빌드, 빠른 질문 클릭 → 입력 → 사용자 전송 → 안내 표시를 실제 UI에서 확인. 외부 모델·거래는 실행하지 않는다.
5. 문서/버전/렌더러 지문 동기화. Windows 설치본과 실제 계정 장애 재시험은 별도이며 모의시험으로 완료하지 않는다.

최신 결과는 TEST_STATUS. 질문별 회귀의 통과가 임의의 모든 질문이나 외부 모델 답변의 무오류를 뜻하지 않는다.
