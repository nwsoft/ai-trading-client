# 혁신금융서비스 사전질의 초안 (2026-04-28)

## 1. 서비스 개요

NoahAI는 다중 자산군(암호화폐/주식/ETF/생활금융)에 대해 AI 판단·설명·기록 기능을 제공하는 의사결정 인프라다.

## 2. 혁신성

- 자산군별 서로 다른 데이터/규칙을 단일 판단 계층에서 처리
- 설명가능성(XAI)과 리스크 가드레일을 결합
- 운영 KPI 기반으로 품질과 안정성을 지속 검증

## 3. 소비자 편익

- 판단 근거 가시화로 정보 비대칭 완화
- 위험 경고 및 차단 정책을 통한 과도한 실행 방지
- 사용자 맞춤형 리포트 제공

## 4. 책임 구조

- NoahAI: 판단/설명/기록
- 외부 금융기관: 주문 체결/수탁/결제
- 사용자: 최종 승인 및 실행 책임

## 5. 데이터 처리 원칙

- 원문 개인정보 최소 수집
- 집계 KPI 중심 운영 모니터링
- 접근권한 최소화 및 보관기간 정책 적용

## 6. 잠재 리스크 및 완화

- 리스크: 알고리즘 오판, 외부 API 장애, 사용자 오해
- 완화: 가드레일, 설명 문구 표준화, 책임경계 고지, 장애대응 절차

## 7. 실증 계획(초안)

- 단계 1: 제한 사용자 그룹 대상 내부 실증
- 단계 2: 제휴사 협력 실증(운영 KPI 검증)
- 단계 3: 결과 기반 제도권 확장 검토

## 8. 요청 사항(초안)

- 서비스 범주 및 적용 규정 해석에 대한 사전 확인
- 실증 특례 적용 가능 범위 자문
- 소비자 보호 장치 적정성 검토 의견

주의: 본 문서는 사전질의 작성용 내부 초안이다.
