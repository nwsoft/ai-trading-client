# v3.9.1.33 시세 확인 불가: 안전장치와 근본 원인 분리

2026-09-15 소스 수정 후보. `unknown`은 확인되지 않은 시세를 정상 국면으로 쓰지 않는 안전장치이지 외부 API 장애의 해결 증거가 아니다.

## 공개 응답 확인 및 정정

- 사용자 키 없이 Coinone `public/v2/chart/KRW/BTC?interval=15m&size=4`를 조회해 원본 시각 차이 `-900000ms`를 확인했다. 수정된 거래 어댑터 재조회는 `+900000ms`, 시간 오름차순 4개였다.
- 빗썸 CCXT 4.5.50 지원 목록에 15m가 없다는 사실만으로 실패를 추정했으나, 실제 구형 candlestick/15m 응답은 성공하고 900000ms 간격을 반환했다. 신규 분봉 API도 성공했다. 따라서 **빗썸 15m 미지원은 이번 장애의 확정 원인에서 제외**했고, 추측에 근거한 대체 시간봉 변경은 하지 않았다.
- 공식 API 문서: [빗썸 분봉](https://apidocs.bithumb.com/reference/분minute-캔들-조회), [CCXT OHLCV 계약](https://docs.ccxt.com/docs/manual). API 응답 순서·캔들 미생성·지연은 공급자 계약과 실행 코드에서 함께 검증해야 한다.

## 보호 동작의 정확한 의미

국면 시세가 없으면 새 진입은 보류하고 마지막 유효 국면은 이력으로 보존한다. 기존 포지션 관리 함수를 호출하는 경로는 유지한다. 그러나 개별 종목 가격·분석 또는 주문 API가 실패하면 청산도 보류/실패할 수 있다. **관리 경로 유지가 청산 성공 보장은 아니다.** 거래소에 이미 접수된 보호 주문과 클라이언트가 전송해야 하는 청산도 별개다.

이 변경은 단순 문구 패치가 아니다. Coinone 시간순과 30분 변화 계산을 바로잡아 국면 판단이 달라질 수 있으므로 7개 거래소 PAPER 비교가 필요하다. 손익 개선이나 모든 사용자 장애 해결은 보장하지 않는다.

## 검증과 남은 범위

전체 Python **2,419 통과·8 건너뜀**, 문서 정합 및 매뉴얼 11개 정본 재추출 통과. 공개 Coinone 조회는 사용자 키 없는 읽기 전용 검사이며 주문·체결 E2E가 아니다.

`tests/test_v39133_market_observation_causes.py`: 정상/실패 TTL 분리·동시 요청·7기관 30분 계산·4증권사 누락/0 구분·API 원인 보존·Coinone 역순/실패 응답 검증. 전체 테스트와 문서 검사를 함께 실행한다.

현재 공유 Teayu는 저녁 피드백보다 이른 자료이며 해당 오류 문구도 확인되지 않았다. 특정 사용자에게 발생한 외부 타임아웃·권한·레이트리밋 원인을 이번 조사로 확정하지 않는다. 최신 진단본과 Windows 실제 KIS/키움/다중 거래소 PAPER 검증은 [배포 게이트](V39133_EVIDENCE_BROKER_INTEGRITY_TEST_PLAN.md)에 남긴다. 사용자 원장·설정·주문·키는 변경하지 않았다.
