# AI 엔진/API 사용자 안내 (초보자용)

> 기준: v3.9.0.3 Windows 업데이트 배포 대상(2026-07-28, 배포 전)  
> 아래 기능은 모두 v3.9.0.3에 포함하며 서명된 Windows 빌드와 실제 제공사 키 검증 후 배포합니다.

## 이 문서는 누구를 위한 문서인가?
- 개발자가 아니라, 앱 사용자(Windows/macOS) 기준 안내입니다.
- 설정 화면에서 바로 따라 할 수 있도록 최소 단계만 정리했습니다.

## 먼저 알아두기
- ChatGPT 유료 구독(Plus/Team)과 OpenAI API 과금은 별개입니다.
- NoahAI 앱은 OpenAI 또는 선택한 지원 제공사의 API 키가 필요합니다.
- API 키는 앱 안에서 발급되지 않고, 제공사 웹사이트에서 발급합니다.
- 입력한 AI API 키는 운영체제 보안 저장소에 보관되며 설정 파일에는 참조값만 저장됩니다.

## 지원 범위

| 제공사 | 현재 범위 | 선택할 때 참고 |
|---|---|---|
| OpenAI | 정식 텍스트·JSON·기존 설정 호환 | 기존 사용자의 기본 연속성 |
| DeepSeek V4 Flash/Pro | 정식 텍스트·JSON | 비용 민감 분석 후보 |
| Anthropic Claude | Haiku 4.5·Sonnet 5·Opus 5·Fable 5 텍스트/JSON | 별도 Anthropic API 키 필요 |
| Google Gemini | 3.5 Flash-Lite·3.6 Flash·3.1 Pro Preview 텍스트/JSON | Google AI Studio API 키 필요 |
| Kimi K3/K2.6 | AI 어시스턴트 문답 NoahAI 시험 연동 | 애널리스트·작업별 분석·AlphaArena 실거래로 자동 전환하지 않음 |

AlphaArena 멀티 엔진 비교·실거래 연결은 다음 업데이트 범위입니다.

## 1) OpenAI API 키 발급 순서
1. https://platform.openai.com 로그인
2. Billing(결제)에서 카드 등록
3. Usage limits(사용한도) 설정
   - 권장 시작값: Hard Limit 10~20 USD / Soft Limit 5 USD
   - 처음에는 낮게 시작하고, 사용량 확인 후 상향하세요.
4. API Keys > Create new secret key
5. Key Name(이름) 입력
   - 권장 예시: NoahAI-Desktop
   - 이유: 키를 여러 개 만들 때 용도 구분이 쉬워집니다.
6. 생성된 키를 즉시 복사
   - 보안상 생성 직후 전체 키를 다시 못 보는 경우가 많습니다.
7. NoahAI 앱 설정에 붙여넣기
   - 설정 > AI 엔진/API > OpenAI API Key

참고:
- 보통 선충전 없이 사용량 기반 과금으로 시작할 수 있습니다.
- 결제 정책/국가에 따라 소액 결제 인증이 필요할 수 있습니다.

## 2) AI 엔진 선택

1. 설정 > AI 엔진/API의 `API 키를 설정할 엔진`에서 제공사를 선택하고 각 API 키를 입력합니다. 이 선택은 키 편집 대상이며 작업 배치를 자동으로 바꾸지 않습니다.
2. `AI 애널리스트`, `AI 어시스턴트`, `빈번 호출`, `표준 분석`, `정밀 진단`마다 Provider와 모델을 각각 선택합니다. Kimi는 실제 키 검증 전까지 AI 어시스턴트에서만 선택합니다.
3. `사용 가능 모델 새로고침`으로 계정에서 허용된 모델을 확인합니다.
4. 모델 옆의 `권장·계정 확인됨·미리보기·비권장·종료` 상태를 확인합니다. 종료 모델은 저장할 수 없습니다.
5. `절약형 / 균형형 / 정밀형` 모델 배치와 문답 정책을 선택합니다.
6. 화면의 가격 참고와 `공식 가격표 열기`를 확인합니다.
7. 저장 시 capability와 계정 모델 목록을 검사하고, `실제 API 기능 검증`으로 텍스트·JSON·사용량·오류 계약을 확인합니다.

공식 Base URL은 제공사 선택 시 자동 입력됩니다.

예시 Base URL:
- DeepSeek: https://api.deepseek.com
- Kimi: https://api.moonshot.ai/v1
- Anthropic: https://api.anthropic.com
- Gemini: https://generativelanguage.googleapis.com/v1beta/openai/

`Claude Code` 구독/로그인은 NoahAI API 자격증명이 아닙니다. Anthropic Console의 API 키와
별도 API 결제가 필요합니다. 화면의 가격은 기준일 참고값이므로 `공식 가격표 열기`로 실제
단가·무료 티어·캐시/장문 요금을 확인한 뒤 모델을 선택하세요.

### 가격과 모델을 고르는 기준

- 절약형: 짧은 사용법 질문, 빈번한 요약처럼 호출이 많은 작업
- 균형형: 일반 시장 설명·리포트·전략 검토의 기본 권장
- 정밀형: 긴 문서 비교·복기·위험 진단처럼 빈도가 낮고 근거가 중요한 작업
- 화면 가격은 USD/100만 토큰 기준일 스냅샷이며 수익성이나 응답 품질 순위가 아닙니다.
- 실제 청구는 입력·출력 토큰, 캐시, 장문 컨텍스트, 배치, 지역, 서비스 티어에 따라 달라질 수 있습니다.
- 모델 ID와 가격은 변경될 수 있으므로 `사용 가능 모델 새로고침`과 공식 가격표를 함께 사용합니다.
- Kimi K2.6은 공식 캐시 미적중 단가를 참고 표시하고 K3는 공식 페이지 확인으로 표시합니다.

## 3) 문답 정책

- 문답 절약형: 최근 4회·입력 6,000자·출력 500토큰. 간단한 사용법·짧은 상태 질문에 적합
- 질문답변 표준형: 최근 8회·입력 12,000자·출력 1,200토큰. 일반 사용자 기본 권장
- 분석 정밀형: 최근 12회·입력 20,000자·출력 2,200토큰. 비교·복기·위험 검토용

문답 정책은 답변 길이와 문맥 예산입니다. 거래 신호의 수익성·승률·주문 가드레일을 바꾸지 않습니다.

## 4) 모델 선택 권장
- 모델 하나만 고르는 것보다 `빈번 호출 / 표준 분석 / 정밀 진단` 역할마다 Provider와 모델을 함께 설정합니다.
- 빈번 호출은 설정 화면에서 제공하는 가장 저렴한 소형 모델을 우선 사용합니다.
- 표준·정밀 모델은 손익 복기, 리포트, 사용자가 직접 요청한 진단처럼 호출 빈도가 낮은 작업에만 사용합니다.
- 화면의 `AI 애널리스트 모델`만 보고 실제 사용 모델을 판단하지 않습니다. 실제 청구 모델은 OpenAI Usage에서 날짜별로 확인합니다.

### AI 커스텀 무자막 YouTube 전사

- 전사는 분석 Provider와 분리되어 항상 별도의 OpenAI credential과 transcription 모델을 사용합니다.
- `gpt-4o-mini-transcribe`: 비용·속도 우선 기본값
- `gpt-4o-transcribe`: 정확도 우선
- `gpt-4o-transcribe-diarize`: 인터뷰처럼 화자가 여러 명일 때
- 공개 자막이 있으면 자막을 먼저 사용하고, 자막이 없을 때만 설정된 길이·파일 크기 안에서 전사합니다.
- 분석을 Claude·Gemini·DeepSeek로 배치해도 전사는 OpenAI 키를 사용합니다.

## 5) 비용 최적화 체크리스트
- Hard/Soft Limit를 먼저 설정했는지
- `설정 → 거래소 선택 → 실제 주문 실행 거래소`에서 주문 대상과 학습 전용 대상을 구분했는지
- `설정 → AI 엔진/API → AI 모델 역할별 배치`에서 빈번 호출이 가장 저렴한 모델인지
- 활성 거래소 전체 학습과 실제 주문 거래소가 자동 분리되는지 확인했는지
- 비용 한도에 도달해도 앱이 멈추지 않고 로컬 기술 신호로 계속 운용된다는 점을 이해했는지
- 1주 사용 후 사용량(Usage) 페이지를 보고 한도를 조정하는지

### 2026-07-24 실사용 비용 점검 기준

특정 사용자 데이터에서 확인된 값이며 모든 사용자에게 동일하게 적용되는 고정 요금이 아닙니다.

| 기간 | OpenAI 비용 | 모델 요청 | 해석 |
|---|---:|---:|---|
| 2026-05 | $62.05 | 230,596회 | 반복 심볼 분석 비중이 높음 |
| 2026-06-01~07-01 | $51.73 | 190,435회 | 역할별 저가 모델 전환 뒤 비용 16.6% 감소 |
| 2026-07-21~07-23 | $9.08 | 27,879회 | 최근 다중 거래소 분석 구간, 같은 속도면 30일 약 $90.82 |

- 위 비용 CSV는 OpenAI 프로젝트 단위 집계이며 거래소별 비용을 직접 구분하지 않습니다.
- Binance API 자체 호출과 OpenAI 모델 호출은 다른 항목입니다. 이 표의 비용은 OpenAI 모델 사용료입니다.
- 비용은 `호출 수 × 입력 토큰 × 출력 토큰 × 모델 단가`로 결정됩니다.
- 점검 자료에서는 총 모델 비용의 67.5%가 출력 토큰이었고 캐시 비용 비중은 약 0.001%로, 캐시 절감 효과가 사실상 없었습니다.
- v3.9.0.1 후속 패치에는 동일 시장상태 15분 재사용, 새 캔들·가격·RSI·MACD·국면 변화 즉시 재분석, 일·월·거래소별 호출 한도가 반영됐습니다.
- 호출 한도는 거래 중지 기능이 아닙니다. AI 신규 호출 대신 로컬 기술 신호로 계속 분석·거래하며 기회를 보존합니다.
- 선택 거래소는 실제 주문, 나머지 활성 거래소는 학습 전용이 기본입니다. 다중 실제 주문을 명시적으로 선택한 경우에만 여러 거래소에 주문합니다.
- 이 기능은 클라이언트·IP 라이선스·무료 라이트 버전에 공통 적용되며 SaaS 전환을 요구하지 않습니다.

## 6) 자주 막히는 지점
- 키 이름 입력을 건너뛰어 헷갈리는 경우
  - 해결: 키 이름을 NoahAI-Desktop처럼 앱 이름으로 고정
- ChatGPT 구독만 하면 API가 자동으로 되는 것으로 오해
  - 해결: API는 별도 결제/사용한도 설정 필요
- Base URL을 OpenAI 사용인데도 입력해서 오류 발생
  - 해결: OpenAI 공식 사용이면 Base URL은 빈칸
- 모델 새로고침이 실패하는 경우
  - 해결: API 키·결제·사용 가능 지역을 확인합니다. fallback 모델이 보이더라도 연결 성공으로 오해하지 않습니다.
- `비권장·종료 예정` 모델이 표시되는 경우
  - 해결: 대체 권장 모델로 변경합니다. `종료` 모델은 저장이 차단됩니다.
- 저장은 됐지만 `테스터 검증 대기` 경고가 있는 경우
  - 해결: API 키가 없는 Provider는 설정을 잃지 않도록 보존한 상태입니다. 빌드 후 해당 키를 넣고 `실제 API 기능 검증`을 실행합니다.
- Claude Code에는 로그인했지만 Claude 연결이 안 되는 경우
  - 해결: Anthropic Console에서 별도 API 키와 API 결제를 준비합니다.
- 제공사를 바꿨는데 거래소 주문이 늘지 않는 경우
  - 정상입니다. AI 제공사와 `실제 주문 실행 거래소`는 별도 설정이며 주문 범위는 자동 확대되지 않습니다.
- 바이낸스 한 곳만 사용한다고 생각했는데 비용이 큰 경우
  - 해결: 선택된 거래소뿐 아니라 `활성 거래소` 전체와 각 거래소 로그 생성 여부를 함께 확인
- 거래 수가 적은데 OpenAI 비용이 큰 경우
  - 해결: 거래 수가 아니라 분석 대상 심볼 수와 분석 사이클 횟수를 확인

## 7) 개발자 문서가 따로 있는 이유
- 현재 문서는 사용자용입니다.
- 개발자용 구현/코드 구조 문서는 별도로 분리되어 있습니다.
  - docs/AI_API_ARCHITECTURE.md
- 앱 설정 화면에서는 사용자용 문서를 우선 열도록 구성되어 있습니다.

## 8) 지원 요청 전 API 키 보안

- 진단을 위해 사용자 데이터 폴더 전체를 전달하면 `settings.json`, `credentials.json`, `token.json`에 비밀값이 포함될 수 있습니다.
- 전달 전 API 키와 토큰을 제거하거나 마스킹하고, 이미 전달했다면 OpenAI·거래소 키를 새로 발급합니다.
- 거래소 키는 출금 권한을 주지 않고 가능하면 IP 화이트리스트를 적용합니다.
