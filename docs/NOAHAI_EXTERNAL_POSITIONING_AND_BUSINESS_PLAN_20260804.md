## 1. 공식 한 줄 설명

### NoahAI

> **NoahAI는 사용자의 금융 지식과 시장 데이터를 판단·검증·실행·기록으로 연결하는 AI 금융 의사결정 인프라입니다.**

### NoahAI Strategy Studio

> **NoahAI Strategy Studio는 책·영상·Pine·TradingView·사용자 대화의 투자 지식을 근거가 추적되는 전략 버전으로 만들고, 시장국면·검증·PAPER·위험 가드레일과 연결하는 전략 작업 공간입니다.**

### Verified Strategy Hub

> **NoahAI 전략 허브는 승률 하나가 아니라 목적·시장·위험·검증 수준별로 전략을 탐색하는 검증 기반 허브입니다.**

최종 사용자 제품명은 `NoahAI Strategy Studio`로 통일한다. 전환 기간에는 `전략 스튜디오 (기존 AI 커스텀)`으로 병행 표기한다. `Strategy OS`는 장기 비전, `Verified Strategy Hub`는 무료 검증·탐색 서비스, `Strategy Marketplace`는 향후 유료 서비스에만 사용한다. `커스텀AI`, `AI 자동매매 만들기`, `전략 마켓`을 현재 제품 전체 이름으로 사용하지 않는다. 내부 `ai_custom` 식별자와 `.noahstrategy`는 호환을 위해 유지한다.

## 2. 외부에서 이렇게 설명한다

### 10초 소개

NoahAI는 고정된 매매 신호를 반복하는 봇이 아니라, 사용자의 전략 지식을 AI와 함께 만들고 시장국면·위험·실행 가능성을 검증해 사용자가 허용한 범위에서 운영하는 금융 의사결정 인프라입니다.

### 30초 소개

NoahAI의 대표 기능 Strategy Studio는 책, 영상, Pine, TradingView 자료나 사용자의 말에서 지원 가능한 전략 조건을 정리합니다. AI와 규칙 엔진이 진입·청산·위험 조건, 누락과 미지원 범위를 설명하고 시장국면·비용·계좌 위험·주문 규격을 확인합니다. 사용자가 승인한 전략만 LEARNING, PAPER, LIVE 권한과 가드레일을 통과해 실행되며, HOLD·차단·주문·체결 결과를 전략 버전과 함께 기록합니다.

실제 투자 시드가 없어도 전략을 만들고 시장 데이터 기반 PAPER에서 시험해 공유할 수 있습니다. PAPER는 가상 체결이므로 거래소 확인 체결과 같다고 말하지 않지만, 제작자와 다운로드 사용자가 같은 전략 버전을 각자의 환경에서 다시 검증하는 출발점이 됩니다.

### 3분 소개의 순서

1. **배우기** — AI가 목표, 경험, 허용 손실과 가능한 거래 시간을 묻고 전략의 적합·실패 국면을 설명한다.
2. **만들기** — 자연어·문서·책·영상·Pine·TradingView 자료를 안전한 전략 규칙으로 구조화한다.
3. **검증하기** — 미사용 구간, 국면, 비용, 낙폭, 민감도와 PAPER 기록을 확인한다.
4. **실행하기** — 사용자 승인, 기관 권한, 계좌 위험, 최소 주문과 주문 상태를 모두 통과한 범위에서만 실행한다.
5. **개선하기** — 결과가 나빠졌다고 기존 전략을 몰래 바꾸지 않고 새 버전과 강등안을 제안한다.
6. **공유하기** — 전략 여권·검증 근거와 함께 안전하게 공유하는 생태계로 확장한다.

## 3. 기존 자동매매·TradingView와의 정확한 차이

| 항목 | 고정 알고리즘 자동매매 | TradingView·Pine | NoahAI Strategy Studio |
|---|---|---|---|
| 주된 강점 | 정해진 규칙의 반복 실행 | 차트·Pine 작성·백테스트·알림 생태계 | 지식→규칙→검증→국면 선택→실행 감독→감사 기록 |
| 전략 만들기 | 제공자가 만든 고정 설정 중심 | 사용자가 Pine과 차트 도구로 작성 | 자연어·책·문서·이미지·영상·Pine에서 AI 초안과 누락 질문 |
| 시장국면 | 고정 전략 내부 로직에 의존 | 사용자가 전략에 직접 작성 | 전략별 허용 국면 비교, 충돌·근거 부족 시 HOLD |
| 실행 | 봇별 거래소 연결 | 전략·지표가 거래소 주문을 직접 내는 구조는 아니며 알림·웹훅 등 외부 연결 사용 | 사용자·기관 권한과 공통 주문 상태·위험 가드레일을 거친 실행 계층 |
| 개선 | 설정 덮어쓰기 가능 | Pine 버전은 사용자가 관리 | 기존 버전을 보존하고 변경점·근거가 있는 새 버전으로 제안 |
| 검증·감사 | 로그 또는 수익률 중심 | 차트 데이터와 브로커 에뮬레이터 기반 전략 테스트 | 비용·국면·PAPER·실제 체결 구분과 판단-주문-결과 연결 기록 |

따라서 공개 문구는 다음으로 통일한다.

> **TradingView의 차트·Pine·백테스트·알림 생태계를 복제하는 것이 아니라, 그 자료와 책·영상·트레이더의 지식을 AI로 전략화하고 검증·실행·감독하는 상위 운영 계층입니다.**

`TradingView 완전 상위호환`, `모든 Pine 지원`, `TradingView를 대체`, `자동으로 수익을 내는 AI`라고 설명하지 않는다. 현재 지원하지 않는 Pine 함수·외부 데이터·복합 상태는 `사용자 확인 필요` 또는 `미지원`으로 표시하고 승인 전에 차단한다.

시장 진입 초기에는 TradingView·Pine을 버리게 하는 제품이 아니라 익숙한 전략 원문을 NoahAI의 검증·실행·기록 계층과 함께 쓰게 하는 제품으로 소개한다. 이후 의미 지원·제작 UX·검증 증거가 확장될수록 제작→검증→공유→운용의 더 많은 단계를 NoahAI 안에서 끝내도록 한다. 이것이 사용자를 억지로 가두는 락인이 아니라 축적된 전략 버전·검증 여권·재검증 경험이 만드는 제품 전환 이유다.

### 시장 진입 쐐기와 사용자 전환 퍼널

첫 포지션은 `TradingView 대체재`가 아니라 **TradingView 전략 검증 동반자**다. 사용자가 이미 보는 차트·Pine·공개 전략에서 출발해 NoahAI가 원문과 실행 규칙을 대조하고, 실제 시드 없이 기관별 PAPER 근거를 쌓게 한다. 이후 전략 버전·국면·가드레일·재검증 이력이 누적될수록 제작·검증·공유·운용을 NoahAI 안에서 계속할 이유가 커진다.

```text
TradingView·책·영상·사용자 아이디어 발견
→ NoahAI 원문→실행 규칙 대조
→ 미지원·리페인팅·미래 데이터·단위 누락 차단
→ 실제 투자금 없는 거래소·증권사별 PAPER
→ 시장국면·계좌 가드레일 안에서 버전별 증거 축적
→ 무료 허브 공개·다운로드·수령자 재검증
→ 현재 NoahAI 클라이언트 사용권
→ 향후 유료 전략 라이선스와 제작자 수익
```

TradingView 공식 문서상 webhook은 외부 애플리케이션으로 HTTP 요청을 보내며, 허용 포트·3초 응답 제한·2단계 인증 요구·전달 실패 가능성이 있다. 따라서 NoahAI의 사용자 PC 실행 엔진과 기관 어댑터는 외부 알림→webhook 왕복만을 유일한 실행 경로로 삼지 않는다는 장점이 있다. 그러나 네트워크·기관 API·사용자 PC 런타임 장애까지 없어지는 것은 아니므로 `웹훅보다 무조건 안정적`이 아니라 **외부 webhook 단일 의존을 줄이고 주문 상태·가드레일·복구를 함께 관리한다**고 표현한다.

TradingView 무료·유료 플랜의 알림·백테스트 제공량은 플랜별로 달라질 수 있다. `TradingView 자동매매는 전부 유료`라고 단정하지 않고, NoahAI는 지원 회원 범위 안에서 Strategy Studio 제작·PAPER·공유의 핵심 흐름을 낮은 진입장벽으로 제공한다고 설명한다. 무료 레퍼럴 회원의 실제 기관 실행 범위는 관리자 활성화와 사용자별 귀속 확인을 통과한 Binance·Bybit·OKX·Bitget이며, Upbit·Bithumb·주식·ETF 등은 해당 클라이언트 회원 권한과 지원 어댑터를 따른다. `무료면 모든 기관 기능이 동일하다`고 광고하지 않는다.

## 4. 고객별 설명

### 처음 투자 전략을 만드는 사용자

빈 편집기와 전문 용어부터 보여 주지 않는다. AI가 목표와 손실 허용 범위를 묻고 2~3개의 후보, 사용할 국면, 거래하지 않을 조건과 예상 위험을 설명하는 `AI 트레이딩 멘토`로 안내한다.

### TradingView·Pine 사용자

기존 전략을 버리라고 하지 않는다. Pine·알림·자료를 NoahAI 안전 규칙으로 옮기고, 원문과 변환 규칙·미지원 조건을 비교한 뒤 국면·계좌·주문 가드레일과 연결하는 운영 계층으로 설명한다.

### 기존 자동매매 사용자

고정 신호의 횟수보다 `왜 진입·HOLD·차단했는지`, 전략이 현재 국면에 맞는지, 비용과 계좌 위험을 통과했는지, 재시작 후 주문 상태가 복구되는지를 함께 관리하는 제품으로 설명한다.

### 전략 제작자·교육자

원본 출처, 버전, 지원 시장, 검증 기간, 비용, MDD, PAPER·실제 체결 구분을 담은 `전략 여권`을 기반으로 안전한 공유와 향후 라이선스 생태계를 준비하는 도구로 설명한다. 현재 유료 판매가 가능하다고 안내하지 않는다.

### B2B·기관·IP 검토자

NoahAI는 특정 거래소 봇 한 개가 아니라 전략 제작·검증·국면 오케스트레이션·실행 상태·감사 기록을 분리한 금융 AI 운영 아키텍처다. 라이선스·화이트라벨·기관별 API 계약·사내 전략 배포는 별도 범위와 검증 조건으로 제안한다.

## 6. 변경된 비즈니스 플랜

Strategy Studio는 자동매매 기능 하나의 옵션이 아니라 고객 유입부터 장기 운영까지 연결하는 대표 제품 축이다.

사용자에게 약속할 가장 큰 비전은 `누구나 전략을 만들 수 있고, 주장보다 실행 근거로 비교하며, 좋은 전략은 검증 수준과 함께 공유·수익화할 수 있는 시장`이다. 현재 무료 베타에서는 이 비전의 진입장벽을 낮추기 위해 권리 자기선언과 서버 구조 검사를 통과한 제출을 E0로 공개하고, 운영자는 모든 제출의 사전 심사자가 아니라 증거 승격과 신고·권리·무결성 문제의 사후 검토자로 둔다. E0를 성과 인증으로 보이게 하지 않는 것이 빠른 성장과 신뢰를 함께 지키는 핵심이다.

우선 사업 가설은 `자연어로 수익 전략을 생성`이 아니라 `보유 전략을 더 빨리 이해·검증·PAPER 운용하게 한다`이다. 첫 유효 전략까지 걸린 시간, 원문→규칙 근거 연결률, 확인 질문 완료율, PAPER 7일·30일 유지율, 주문·체결 조정률이 개선될 때 대표 고객 획득 무기로 확대한다.

SNS·크리에이터 메시지는 `AI로 자동 수익`이 아니라 **AI로 내 전략 지식을 검증 가능한 디지털 자산으로 만들기**로 잡는다. `시드 0원 전략 제작 챌린지`, `내 Pine 전략의 실제 적용값 확인`, `같은 버전을 내 거래소에서 다시 PAPER`는 강한 유입 문구로 사용할 수 있다. `누구나 돈을 번다`, `AI가 빈 전략을 수익 전략으로 완성한다`, `PAPER 고수익이면 판매가 보장된다`는 금지한다. 기대와 참여는 크게 만들되 증거 단계와 손실 가능성은 같은 화면에서 보여 준다.

```text
무료 학습·전략 탐색
→ Strategy Studio 제작·검증
→ PAPER 전진검증
→ 현재 클라이언트 라이선스와 기관 연결
→ 안전한 공유·팀 협업
→ 검증된 제작자 생태계
→ B2B·IP·화이트라벨·API
```

### 수익 계층

1. **전략 허브 무료 베타**  
   기본 30일 동안 목적별 전략 탐색과 검증 표시를 무료로 운영해 데이터 품질·안정성·사용자 이해도를 확인한다. 이는 결제 상품이 아니라 신뢰와 제품 활성화를 위한 진입 계층이다.

2. **현재 클라이언트 라이선스**  
   기존 코인, 주식·ETF, 통합 상품의 판매·회원 권한은 유지한다. 현재 판매 가격은 클라이언트 사용권이며 향후 전략 구독료와 혼동하지 않는다.

3. **프리미엄 제작·검증 기능**  
   더 많은 전략 버전, 고급 검증, B2B 배포·감사 기능을 독립 상품으로 검토한다. 실제 제공 전에는 가격·출시를 확정 표현하지 않는다.

4. **전략 공유·제작자 생태계**  
   `.noahstrategy`, 무료 검증 허브와 제작자 프로필을 먼저 제공한다. 현재 daltrading에는 가격 0 상품의 스냅샷·취득·계정별 영구 비독점 실행 라이선스·재다운로드 기반이 구현돼 있다. 유료 단계는 `1 Noah Point = 1 KRW` 구매 단위, 구매 전 가격·버전·해시 고정, **공급가 기준 플랫폼 20%·제작자 80%**, 14일 보류 후 월 마감·T+30 원화 정산을 기본안으로 한다. 일반 PG 비용은 플랫폼 몫에서 부담한다. 카드·계좌 원화 충전을 먼저 열고, 외부 사업자를 통한 코인 결제는 후속 충전 수단으로만 검토한다.

   테스트·적립 포인트와 유상 포인트는 별도 원장으로 분리한다. 테스트 기간 적립분은 유료 오픈일 `1P=1원 구매가치`로 1:1 전환하고 모든 전략에 잔액 범위에서 100% 사용할 수 있으며, 현금화 불가 조건을 적립 전에 고지한다. 로그인 1일 1회 10P, 그날 최초 유효 PAPER 60분 100P, 30일 최대 3,000P·테스트 누적 최대 30,000P를 시작값으로 하며 플랫폼 부담 사용액 때문에 제작자 정산을 줄이지 않는다. LIVE 실행, 거래 횟수·거래금액·레버리지·PnL에는 포인트를 지급하지 않고 앱을 켜 둔 시간마다 무제한 적립하지 않는다. 판매자는 검증 단계별 허용범위에서 가격을 직접 정하며, 10,000P 입문형부터 10,000,000P 이상 개별계약형 프리미엄 전략까지 허용한다. 상세 계약과 변경 권한은 `STRATEGY_MARKETPLACE_POINTS_AND_LICENSE_PLAN.md`를 따른다.

5. **B2B·기관·IP 라이선스**  
   전략 운영 계층, 기관 어댑터, 감사 원장, 화이트라벨, 사내 전략 배포를 계약별로 구성한다. 소스·IP 소유권 이전, 기간, 보증금, 지원·검수 범위는 개별 계약 문구를 따른다.

6. **향후 API·SDK 생태계**  
   전략 SDK, 검증 API, 인증 제작자·교육 과정과 기관용 전략 배포를 후속 확장한다.

## 7. 전략 허브와 랭킹 원칙

하나의 전체 수익률·승률 랭킹을 만들지 않는다.

- 추세장 전략
- 횡보장 전략
- 저위험 전략
- 소액 계정 전략
- Binance 선물 전략
- Upbit·Bithumb 현물 전략
- 장기 PAPER 검증 전략
- 실제 체결 검증 전략
- 초보자용 설명 우수 전략
- 특정 코인·종목 전용 전략(후속 `symbol_scope`가 검증된 경우)
- 특정 거래소·증권사 전용 전략(후속 `venue_scope`와 capability가 검증된 경우)

무료 베타 공개 진입은 회원의 배포 권리 자기선언과 패키지·IR 무결성·실행 구조 검사로 낮춘다. 서버가 먼저 자산·현물/선물·기관·시장국면·검증 대상을 추출하고 회원이 확인하므로 수동 태그 누락으로 다른 범위에 공개되지 않는다. 이 단계는 `E0 구조 확인`으로만 표시하고 성과 검증으로 부르지 않으며, 검증 랭킹과 분리해 점수·순위를 표시하지 않는다. 서버 서명·계정 연동·거래소 확인 출처의 OOS·워크포워드·비용·PAPER·확인 체결만 별도 증거 단계와 다축 점수로 승격한다. 복수의 독립 권리·무결성 신고 또는 운영자 판정은 즉시 공개 격리로 연결한다. KRW·USDT 등 환산 근거가 없는 PnL을 합치지 않고 PAPER와 LIVE를 같은 성과처럼 표시하지 않는다.

현재 전략 범위는 자산군·현물/선물·지원 기관·시장국면 중심이다. 특정 코인·ETF·종목 전용 판매와 특정 기관 전용 상품은 기술적으로 확장 가능하지만, `symbol_scope`, `venue_scope`, 시세·주문 capability, 성과 표본을 패키지와 여권에 고정하고 다른 범위 실행을 fail-closed로 차단한 뒤 공개한다. 단순 태그만으로 전용 전략이라고 부르지 않는다.

## 10. 공개 FAQ

### Strategy Studio는 자동매매 프로그램인가요?

전략 제작만 하는 편집기나 주문만 반복하는 봇 중 하나가 아니다. 지식을 전략 규칙으로 만들고 검증·국면 판단·사용자 승인·실행 상태·기록을 연결하는 운영 계층이다. LIVE 주문은 사용자가 해당 기관과 실제 주문 권한을 모두 켠 경우에만 가능하다.

### TradingView가 필요 없나요?

아니다. TradingView의 차트·Pine·알림은 유용한 전략 원본과 신호 도구다. NoahAI는 이를 포함한 여러 지식 소스를 검증·실행·감독하는 상위 운영 계층을 지향한다.

### AI가 알아서 좋은 전략을 골라 수익을 내나요?

수익을 보장하지 않는다. AI는 적합 국면, 비용, 위험과 누락 조건을 설명하고 HOLD·차단할 수 있다. 최종 승인과 운용 범위는 사용자에게 있으며 전략은 손실을 낼 수 있다.

### 전략을 지금 판매할 수 있나요?

아니다. daltrading 전략 허브는 무료 베타와 검증 기반 탐색 단계다. 현재 첫 무료 다운로드는 가격 0인 취득 거래와 계정별 영구·비독점 실행 라이선스로 기록되며 「내 전략 라이선스」에서 재다운로드할 수 있다. 테스트 기간에는 구매가치를 고지한 포인트를 적립하고, 준비 완료 뒤 유료 오픈일부터 `1P=1원`으로 전략 구매에 사용한다. 판매자는 E 증거 단계별 범위 안에서 가격을 정하며 1,000만원 이상 전략도 개별계약형으로 판매할 수 있다. 현재 테스트/유상 포인트 충전·차감, 유료 주문·환불, 제작자 지급 실행기는 아직 제공되지 않는다.

### PAPER 검증 전략도 향후 판매할 수 있나요?

가능하다. 실시간 PAPER 전진검증 E3는 전략 제출·랭킹·다운로드와 향후 판매에 사용할 수 있다. 제한 실행 관찰 E4와 출처가 확인된 체결 E5는 별도의 상위 실행 증거이며 판매 필수조건이 아니다. PAPER와 LIVE 표본은 합산하지 않고 거래소·증권사·통화·전략 버전별로 분리 표시한다.

### 코인으로 전략을 살 수 있나요?

현재는 불가능하다. 원화 카드·계좌 결제를 먼저 안정화한 뒤 외부 코인 결제 사업자의 결제 완료 webhook을 확인해 Noah Point를 충전하는 방식을 검토한다. NoahAI가 사용자 코인을 직접 보관·교환·송금하거나 사용자 간 코인 거래를 중개하지 않으며, 초기 제작자 정산은 원화로만 한다.
