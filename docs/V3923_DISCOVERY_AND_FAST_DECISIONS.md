# 3.9.2.3 후속 보완: 상품을 모르는 사람의 탐색과 빠른 판단

작성·공식 자료 확인: 2026-10-04. **로컬 소스 후속 변경**이며 기존 공개 Windows 설치본에 포함됐다는 뜻이 아니다.

## 문제와 원인

`GuidedProductComparison`은 설명 다음에 `ProductIntelligenceWorkspace`의 개인 견적 양식과 별도의 두 조건 계산기를 동시에 노출했다. 가입 상태 선택은 있어도 필요한 상품 유형을 발견하는 단계가 없었다. `finance_product_dialogue`는 현재 시나리오의 금액·기간 변경을 처리하므로 처음 보험을 묻는 대화를 대신하지 못했다. 계획 문서가 요구한 전체 여정과 실제 첫 화면 사이의 누락이다.

## 이번 구현

- 첫 화면: **상황 → 유형과 이유 → 유효 상품 후보 → 비교·상담 준비**. 보험 없음/모름/있음, 의료비/운전/가족 생활비/큰 질병을 구분한다. 대출은 생활/주거/대환, 저축은 목돈/월 납입/비상금부터 고른다.
- 회사명·상품명·견적·보험료 예산 없이 안내 시작. 선택 이유, 유형 차이, 비교 항목, 다음 질문 제공. 보험 종류 안내는 실제 개인 상품 순위나 인수 판정이 아니다.
- 한국어 명시적 목적·금액·기간은 로컬 규칙으로 처리. 다중 목적·부정 문장은 선택을 다시 요청한다. 모르는 가입 여부를 미가입으로 판정하지 않는다. 임의의 자유 질문을 모두 이해한다고 주장하지 않는다.
- 대화의 상태·예산·납입 방식·금액·기간을 비교 입력으로 전달한다. 내부 탭/안내 이동은 작성 중인 비교를 유지하고, 새 상황으로 덮어쓸 때 명시적으로 확인한다. 보관함 잠금은 안내와 비교의 개인 입력을 함께 비운다.
- 유효한 상품 카탈로그가 있으면 회사·상품 카드, 검색, 최대 20개 선택, 원문·버전·확인일·만료 표시. 선택 목록을 실제 비교 후보 필터에 적용한다. 만료/판매종료/다른 유형은 탐색에서 제외한다.
- 없는 자료로 가짜 보험사·금리·보험료를 만들지 않는다. 외부 비교공시 탐색 링크와 개인 견적 입력 경로를 제공한다. 외부 링크에는 개인 조건을 전달하지 않는다.
- 생활금융 어시스턴트의 초보자 질문에도 동일한 유형 안내를 연결했다. 상세 계산·암호화 저장·기존 상담 준비와 연결은 유지한다.
- 반복 선택은 외부 모델 호출 없이 처리. 선택적 AI 설명은 기존 `frequent_cheap`(빠른 설명) 또는 `assistant`(자세한 설명) 경로를 사용한다. 모델명·전송 상황·예산 가능성을 확인한 동의가 있어야 호출하며 경로 변경은 동의를 무효화한다. 기존 사용량/예산 제한과 `persist_response=False`를 유지한다.

구현: `trading/finance_discovery.py`, `webui/src/components/FinanceDiscovery.tsx`, `GuidedProductComparison.tsx`, `web_platform/finance_ai.py`. 계산·자료 갱신·AI 설명의 역할은 분리되어 있다. `discover`는 최신 저장 스냅샷을 읽으며 재분류마다 원격 자료를 다시 받지 않는다. 자료 갱신은 화면의 명시 버튼/기존 카탈로그 갱신 경로를 사용한다.

## 모델 기사 재검증과 채택 판단

[사용자 제시 기사](https://byline.network/2026/10/2-472/)는 평가 후보를 찾는 출발점이다. 서로 다른 벤치마크 점수·제작사 속도를 NoahAI의 한국어 금융 정확도나 고객 PC 지연시간으로 옮기지 않는다.

| 후보 | 직접 확인한 제작사 자료 | 이번 처리 |
|---|---|---|
| GLiNER2.5-Decide | [공식 모델 카드](https://huggingface.co/fastino/GLiNER2.5-Decide)는 340M, Apache-2.0, 영어 분류 모델과 영어 평가를 명시. 다국어에는 별도 multi 모델을 안내하며 설명·열린 질문용 범용 모델이 아니라고 설명 | 한국어 분류·정보 추출 평가 후보. 기본 설치/자동 다운로드 없음. 다국어 모델도 한국어 금융 검증 필요 |
| AutoTrust JEV-27B | [공식 모델 카드](https://huggingface.co/autotrust/JEV-27B)는 Qwen3.8-27B 기반, 원본 생성 헤드와 결정 블록, Apache-2.0를 설명. TypeSafe와 별개 모델 | 고객 PC에 27B를 기본 탑재할 근거 없음. 자체 서버/하드웨어별 후보 평가; 한국어 실측 전 미지원 |
| Liquid d1 | [공식 문서](https://docs.liquid.ai/lfm/models/decision-models)는 `d1:free`, Choice/Score/Noul, `/decisions/v1/systemone` 계약 제시 | 기존 chat endpoint와 별도 어댑터가 필요. free 이름을 영구 무료·SLA로 해석하지 않음. 이번 외부 호출/등록 없음 |
| Fastino GLiDE | [공식 발표](https://fastino.ai/blog/introducing-glide-the-first-thinking-decision-model), [공식 서비스](https://fastino.ai/)에 생각하는 결정 모델과 API 안내 | 도구 선택·불확실 질의의 평가 후보. 추가 추론이 빠른 응답을 항상 보장하지는 않으므로 총 지연·비용 측정 필요 |
| OpenAI Decisions API / Luna | 확인한 [OpenAI 공식 모델 선택 문서](https://developers.openai.com/api/docs/guides/model-selection)는 Luna를 범위가 좁은 과제·추출·반복 작업의 효율적 선택으로 안내. 이번 공식 문서 검색으로 Decisions API의 계정 사용 가능 여부·정식 호출 계약·가격은 확정하지 못함 | 일반 chat과 새 Decisions API를 동일 취급하지 않음. 가짜 endpoint/지원 모델 추가 없음. 현재 지원된 모델 경로로 설명 최적화 |

현재 코드가 제공하는 OpenAI, DeepSeek, Kimi, Anthropic, Gemini 경로와 사용자 `ai_model_roles.frequent_cheap` 설정을 우선 재사용한다. 특정 회사의 기본 모델을 임의로 교체하거나 새 모델이 실제 지원된다고 표시하지 않았다. 빠른 경로라는 역할명은 실제 응답 속도/최저가 보증이 아니다. 수신 모델은 미리보기에서 확인한다.

## 다음 채택 기준과 남은 운영 항목

1. **실제 상품 공급 연결**: 사용 권한이 있는 공급원/API·기관 범위·수집 주기·보장 항목 정규화·단종/정정/누락 대응을 인수한다. 빈 카탈로그에서 유형 안내가 되는 것과 실상품 추천 완료는 다르다. 사용자 정보만으로 개인 보험료·승인을 만들지 않는다.
2. **한국어 판단 평가**: 로컬 규칙, 현재 저비용 LLM, GLiNER 다국어 등 후보에 같은 비식별 질문·라벨을 적용. 오타/부정/다중 목적/unknown/문서 지시 삽입/긴 문맥을 포함한다. 독립 정답 검토·개발/평가 분리, macro-F1·위험 오안내·보류율·보정오차와 P50/P95/P99, timeout·429·총비용/건·CPU/RAM을 측정한다. 이번 규칙 회귀 테스트를 금융 전문성 인증이나 모델 벤치마크로 쓰지 않는다.
3. **승격 범위**: 의도 분류·입력 추출·다음 질문/도움말 후보부터. 신뢰도는 답 분류의 확신도이지 금융 적합도·수익률·보험금 지급 확률이 아니다. 거래 중지 해제·주문·가입 승인에 쓰지 않는다.
4. **불확실할 때**: 선택 질문 → 사용자 요청과 전송 동의가 있으면 기존 AI의 추가 설명. 자동 유료 재시도·조용한 고가 모델 승격·개인 자료 캐시는 추가하지 않았다.
5. **아직 지원하지 않는 범위**: 수시 입출금의 구간별 이자 계산, 전 기관 실시간 개인 견적/심사, 실제 상담 수신처 연결, 신규 결정 모델 실환경 한국어 평가. 기존 확장 계약은 유지하지만 완료로 표시하지 않는다.

외부 비교공시 링크의 운영 주체는 [금융위원회 보험다모아 안내](https://fsc.go.kr/po010104/73716), [정부 금융상품 한눈에 안내](https://www.korea.kr/news/policyNewsView.do?newsId=148937810&pWise=Letter)로 교차 확인했다. 링크 목적지의 직접 자동 조회는 각각 403/timeout이어서 그 사이트의 현재 상품 목록·조회 성공은 확인하지 못했다. 데이터 수집 API 연결이나 전송을 뜻하지 않는다.
