# v3.9.1.42 Windows 및 원격 제어 배포 검증

클라이언트 설치기 빌드와 릴리스는 사용자가 수행합니다. 소스 자동검사 통과를 아래 설치본·실기관 검증의 완료로 간주하지 않습니다. 공개 v3.9.1.41 자산은 보존합니다.

소스 결과는 [원격 제어 실행 계획](V39142_REMOTE_CONTROL_PLAN.md), 사용법은 [원격 관리 안내](REMOTE_MANAGEMENT_GUIDE_V39142.md)를 참고합니다.

- [ ] WIN-LOCALE · 한국어 기본/영어 선택/재시작/계정 전환, 100/125/150% 배율, 원문 초안·PnL·모드·권한 불변, 영어 매뉴얼/차트 표시
- [ ] KIWOOM-E2E · Windows OCX 연결과 PAPER 실행·보호·복구
- [ ] KIS-E2E · 주식·ETF 연결, 현재 모드 승인과 원격 제어
- [ ] BITHUMB-E2E · 현물 연결·PAPER 실행과 원격 제어

- [ ] REMOTE-UI · 모바일 폭 360/390/430, 키보드·확인창·오류·오프라인, Windows 배율 100/125/150%

LIVE/PAPER 전환, 전략 교체, 전량 청산, 원격 백테스트는 이번 범위 밖입니다. 중복 방지 저장에 실패하거나 결과가 불확실하면 신규 진입을 차단하고 PC 확인을 요구합니다. 일시정지는 기존 포지션 보호·청산을 중지하지 않습니다.
