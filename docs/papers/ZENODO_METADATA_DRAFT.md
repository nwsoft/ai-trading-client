## Upload Steps (Practical)

1. Create a new Zenodo record and set upload type to preprint/publication.
2. Enter title, creator, affiliation, keywords, date, and version exactly as above.
3. Upload all files in the finalized bundle.
4. Select license and publish.
5. Record the DOI in FINAL_PACKAGE_STATUS.md and SUBMISSION_GUIDE.md.
