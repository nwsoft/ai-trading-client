# NoahAI Paper Roadmap

This roadmap defines what should be completed first and what should be expanded later for the NoahAI paper package.

## Phase 1: Complete First

1. Finalize the English manuscript as the primary submission text.
2. Keep the Korean manuscript aligned with the English version.
3. Freeze the shared scientific claims, definitions, and references.
4. Prepare the Zenodo archive package with both language versions.

## Phase 2: Submission Preparation

1. Prepare Zenodo metadata and archive DOI information.
2. Prepare the arXiv-ready English manuscript package.
3. Remove any internal provenance text that is not suitable for the arXiv main text.
4. Confirm citation style, title format, and author metadata.

## Phase 3: Expand After the Core Draft Is Stable

1. Add architecture figures and workflow diagrams.
2. Add an appendix for implementation details and extended validation notes.
3. Expand the reference list with related work and comparison papers.
4. Add a short Korean/English companion note for readers and reviewers.

## Working Rule

Do not expand the manuscript before the English submission draft is stable. Expansion should improve clarity, evidence, and reproducibility, not change the core claim.
