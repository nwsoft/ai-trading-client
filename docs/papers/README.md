## 작성 원칙

1. 주장보다 재현 가능한 구조와 근거를 우선 기록합니다.
2. 제품 홍보 문구 대신 문제-방법-검증-한계의 학술 구조를 유지합니다.
3. 버전, 날짜, 문서 ID를 헤더에 명시합니다.
4. 후속 실증 결과는 본문에 덮어쓰지 말고 버전 업으로 관리합니다.
