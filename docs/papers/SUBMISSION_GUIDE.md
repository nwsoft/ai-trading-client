# Submission Guide: Zenodo and arXiv

This guide defines how the NoahAI paper package should be prepared for Zenodo and arXiv.

## Short Answer

Yes, Zenodo and arXiv should be prepared differently in packaging and metadata. The core research content should stay aligned, but the final submission package should be adapted to each venue.

- Zenodo is best used as the archival record and DOI source.
- arXiv is best used as the public preprint distribution version.

## What Should Stay The Same

- Core claims and scientific content
- Definitions, methods, diagrams, and citations
- The manuscript version referenced by both systems

## What Should Differ

### Zenodo

- Use it as the canonical archive for the manuscript version
- Upload PDF, source files, figures, and supplemental materials if needed
- Include DOI, version tag, and repository-style metadata
- You can include bilingual materials if useful for preservation
- Keep provenance notes and archive-oriented metadata

### arXiv

- Use the cleaner public-facing preprint version
- Prefer the English manuscript for submission
- Keep author metadata concise and venue-friendly
- Avoid extra internal provenance text in the main manuscript unless it is clearly acceptable
- Ensure the PDF and source package follow arXiv formatting rules

## Recommended NoahAI Workflow

1. Finalize the English submission manuscript.
2. Archive the matching manuscript package on Zenodo.
3. Record the Zenodo DOI in the arXiv submission metadata or in the paper footnote if appropriate.
4. Submit the arXiv preprint using the English version.
5. Keep the Korean version as a companion manuscript in the same archive.

## What To Finish First

1. Lock the English manuscript as the primary submission draft.
2. Keep the Korean manuscript synchronized with the same claims and section order.
3. Freeze the bibliography and document identifiers.
4. Only then expand with figures, appendix material, and extended validation notes.

## Practical Rule

If a line reads like internal provenance, product branding, or founder attribution, it is safer to keep it in the Zenodo archive package or in an acknowledgment/provenance appendix rather than in the arXiv main text.
