# 금융 AI·생활금융·교육 콘텐츠 고도화 검토

2026-09-29. **조사와 제안이며 구현/배포 완료 목록이 아니다.** 3.9.1.49 UI·원격 진단 수정과 분리한다. Windows 49 빌드·릴리즈는 사용자가 수행한다. 이 문서의 신규 기능은 별도 범위 확정 후 개발한다.

## 결론

NoahAI는 ‘무엇을 사면 돈을 버는가’만 답하는 챗봇보다 **내 돈의 상태를 이해하고 → 선택의 근거를 비교하고 → 작은 가상 실험을 하고 → 결과를 복기하는 도구**로 발전시키는 것이 적합하다. 기존 다기관 엔진·PAPER·원장·설명 기능을 사용하고 생활비·가족 목표를 거래 예산과 분리한다.

경쟁 서비스가 모두 NoahAI보다 취약하다는 근거는 확보하지 못했다. 공개 기능만으로 수익성·정확도·안정성 우열을 판단하지 않는다. 금융사들의 데이터·배포 접근성·권한 체계와 실제 질문 동선은 벤치마킹 대상이다. 이용자 증가가 자동으로 모델 학습이나 추천 정확도 향상을 뜻하지 않으며, 고객 기록 재학습은 별도 동의·목적·보관 검토가 필요하다.

## 우선순위 제안 — 메뉴 수보다 사용자 과업 중심

### 1. 질문을 찾는 부담 제거

- 기존 종목/시장/자산 카드에 `왜 움직였나`, `내 자산에 어떤 영향인가`, `반대 근거는 무엇인가`, `무엇이 바뀌면 다시 보나` 버튼을 공통으로 제공한다.
- 새 독립 챗봇을 계속 추가하지 않고 기존 어시스턴트를 연다. 사용자가 **전달할 자료·기준 시각·외부 AI 사용 여부**를 확인한다.
- 공통 답변: 결론 → 관찰 사실 → 해석/추정 → 반대 근거 → 조건/무효화 → 누락 자료 → 확인할 다음 행동. 가격 상승과 뉴스 동시 발생만으로 인과를 확정하지 않는다.
- 종목 후보는 현재 거래 가능 상태·기관·상품·분석 기간을 고정한다. 인기 순위/커뮤니티 추천과 실행 엔진 후보를 혼합하지 않는다. 관심 목록 추가와 PAPER 검토는 가능하지만 대화 클릭만으로 주문·전략 승인을 하지 않는다.

### 2. 개인 돈 관리의 주간 점검

- 이번 달 남는 돈, 다가오는 고정비/만기, 목표 달성 간격, 부채 부담, 집중 위험을 한 화면에서 설명한다.
- ‘대출 상환액을 바꾸면’, ‘매달 적립을 늘리면’, ‘수입이 줄면’ 같은 가정별 현금흐름 비교를 기존 계산기로 수행한다. AI는 계산값을 새로 만들지 않고 입력·공식·결과를 설명한다.
- 현금흐름과 순자산 증감을 구분한다. 계좌 간 이체는 수입/소비가 아니고, 카드 사용과 카드대금 납부를 두 번 비용 처리하지 않는다. 대출 원금 상환은 현금 유출이지만 이자 비용과 다르다.
- CSV 등 명시적 자료 입력부터 시작하고 중복 제거·분류 수정·되돌리기를 제공한다. 금융기관 자동 수집은 별도 적법한 연결/제휴와 동의가 준비된 경우에만 추가한다.
- 세금·금리 등 시점 민감 계산에는 적용연도·공식 출처·지원하지 않는 사례를 표시하고 검증된 계산만 제공한다.

### 3. 가족 관리 — 공유보다 권한 설계가 먼저

- 1차: 한 사용자가 권한 있는 자료로 개인/공동 예산을 계획하는 로컬 모델. 실제 다중 사용자 공유와 구분한다.
- 2차: 가족 초대→각자 동의→개인/공동 계좌 범위 지정→조회/입력/제안 권한→철회/탈퇴. 가족 대표라는 이유로 모든 구성원의 거래/부채를 자동 노출하지 않는다.
- 가족 내부 송금, 공동계좌, 공동 소유 비율의 중복 집계 방지. 각자 비공개 영역과 합의된 공동 목표를 분리한다.
- ‘제안 수락’은 예산 계획 변경이지 타인 계좌의 주문/송금 권한이 아니다. 미성년자 영역은 별도 보호·동의 검토 대상이다.
- 기존 원격 PC 상태 공유 동의를 가족 금융자료 공유 동의로 재사용하지 않는다.

### 4. 교육을 앱 사용으로 연결

권장 순서: **짧은 웹툰/영상 → 같은 주제의 3분 실습 → 결과 이해 확인 → 선택형 저장/PAPER → 복기**. 처음부터 장편 책을 만들기보다 반복 활용되는 콘텐츠를 검증한 후 묶는다.

초기 6개 주제:

1. 월급은 그대로인데 왜 남는 돈이 줄었나 — 현금흐름 실습.
2. 이체했는데 수입이 늘었다? — 중복 집계 이해.
3. 승률은 높은데 왜 손실일까 — 손익비·수수료 가상 실습.
4. 과거 성과와 PAPER는 왜 다른가 — 표본/체결 가정 비교.
5. 투자할 돈과 생활비는 왜 나눠야 하나 — 목표·예정 지출 실습.
6. 가족 자산은 합치기 전에 무엇을 합의해야 하나 — 공개 범위·공동 목표.

웹툰은 가상의 생활 사례 4~8컷, 영상은 화면 실습, 텍스트는 근거/계산/수정 이력을 맡는다. 조회수만이 아니라 실습 완료·이해도 개선·7/30일 재방문·지원 문의 감소·비용을 측정한다. 거래 횟수 증가를 교육 성공으로 보지 않는다. 무료 교육과 모의 실습, 개인화 심층분석/저장/가족 기능 등의 유료 구분은 별도 정책 결정이다.

YouTube 자료는 요약/가정/주장과 검증된 사실을 분리한다. 영상 전체를 무단 재출판하거나 타인의 캐릭터·도표·자막을 웹툰/책에 그대로 전용하지 않는다. 사용자 제공 자료도 실행 지시가 아닌 분석 대상으로 취급한다. ‘돈 버는 공식’이나 일정 수익 보장을 판매하지 않는다.

## 구현 공통 계약과 비용

- 기존 PC 엔진/원장·생활금융 저장소·어시스턴트 문맥 전달을 재사용한다. 새 금융 ‘정본’을 대화 기록 안에 만들지 않는다.
- 계정/가구/기관/상품/모드/통화/기간/관찰 시각/원본 revision/동의 범위를 가진 읽기 전용 근거 묶음을 정의한다. 사용자 구분 없이 캐시나 대화 문맥을 공유하지 않는다.
- 계산·단위·중복 제거는 테스트 가능한 일반 코드, 문장 설명은 AI가 담당한다. 외부 호출 실패는 미완료 표시이며 거래/가계부 저장을 중단시키지 않는다.
- 조회는 요청 시 수행하고 승인된 공용 시장자료 캐시만 공유한다. 개인 재무 내용 캐시는 소유자/동의/revision별로 격리한다. 거래 워커에 뉴스 수집/LLM 대기를 붙이지 않는다.
- 출력마다 출처/시각/가정/누락/비용을 보여주고 자동 재시도·토큰·동시 실행·일일 비용 상한을 둔다. 페이지 이동마다 새 AI 분석을 돌리지 않는다.
- 개인정보 없는 이용 단계/오류 유형 집계와 고객 원장 재학습을 구분한다. 가족/개인 금융자료의 외부 AI 전달은 최소화하고 전송 전 확인·삭제/철회 경로를 설계한다.

## 출시 전 검증 및 법적 경계

- 정보 설명/사용자 조건 검색, 개별 투자자문, 자동 운용, 상품 중개는 별도 기능/검토 범위다. PC 설치형·자가 API·‘교육용’ 표시만으로 법적 적합성을 확정하지 않는다. 개인별 매수·매도 권고/비중 자동 결정/가족 계좌 운용을 사업으로 제공하기 전에는 실제 기능·수익모델 기준의 전문 검토가 필요하다.
- 금융위는 개별 투자자문과 유사투자자문 범위를 구분한다. [2024년 제도 안내](https://www.fsc.go.kr/po010101/82887), [자동매매 프로그램 관련 법령해석](https://better.fsc.go.kr/fsc_new/replyCase/LawreqDetail.do?lawreqIdx=3505&muGpNo=75&muNo=85&stNo=11). 이는 특정 NoahAI 기능의 위법/적법 판정을 대신하지 않는다.
- 필수 시험: 종목 착오/오래된 뉴스/근거 없는 인과/결측값 0 처리/통화 혼합/가족 간 정보 유출/동의 철회/카드·이체 중복/부분 수집/잘못된 세법 연도/AI 비용 폭주/회복/기존 전략 승인·거래 규칙 불변.
- 시장 뉴스·시세·공시·상품 데이터의 이용권과 갱신 SLA를 먼저 확보한다. 증권사 기능을 모방한다고 그 데이터 이용권까지 생기지 않는다.

다음 개발 범위는 **질문 동선 + 생활금융 주간 점검 + 교육 실습 3개**부터 권장한다. 가족 다중 사용자 공유와 실시간 맞춤 운용은 요구사항/데이터/권한/법적 경계를 확정한 별도 단계로 둔다. 이 제안 때문에 현재 49 배포 범위를 계속 늘리지 않는다.
