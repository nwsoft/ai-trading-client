# 증권사 확장 로드맵

**문서 목적**: NoahAI의 증권 연동 현황 + 우선순위 기반 확장 계획 명시

**핵심 전제**
- 한국에서 개인 투자자도 증권사 API를 신청해 프로그래밍 매매를 할 수 있음
- 증권사마다 개인 API 지원 수준이 다름
- NoahAI는 **초기 PMF 검증 단계**이므로, 기술적 지원 수보다 **실사용자 검증**이 더 중요
- SaaS 온보딩 판단은 "API 존재"가 아니라 4대 기준(개인 사용/서버 동작/다중계좌/약관 허용) 충족 여부로 결정

## 2. 우선순위 기준

### (1) 개인 개발자 채택률 기준
**한국투자증권 > 유안타 ≈ 이베스트 > 대신 > NH**

- 키움: 국내 자동매매 시장의 사실상 표준
- 한국투자: 최신 REST API 구조로 대체 가능성 높음
- 유안타/이베스트: 자동매매/퀀트 커뮤니티 있음
- 대신: 기존 CYBOS 기반 사용자 존재
- NH: 기관 중심에서 개인 확대 단계

### (2) NoahAI SaaS 구조와의 적합성
**REST API (한국투자, 신한, 미래에셋, 유안타, NH) > CYBOS (대신) > COM/ActiveX (키움)**

- REST API: 웹, macOS, Linux 모두 지원 가능
- CYBOS Plus: Windows 제한적
- COM/ActiveX: Windows 전용

보충:
- 키움 REST API 포털은 존재한다.
- 다만 현재 Noah 클라이언트의 키움 실연결 구현은 OpenAPI+(ActiveX/QAx) 경로이며, 키움 REST 어댑터는 아직 구현되지 않았다.
- 따라서 현재 사용자 가이드는 OpenAPI 경로 기준으로 제공한다.

### (3) 법규 위험도
**기관 중심 API (NH, 대신) < 개인 개발자 중심 API (키움, 한국투자, 유안타, 이베스트)**

- 개인 개발자 사용자가 많은 증권사: 법적 선례/관행 확립됨
- 기관 제휴 중심 API: 개인 사용 규정 불명확할 수 있음

## 3. 단계별 확장 계획

### Phase 1: 초기 PMF 검증 (현재 ~ 2026년 하반기)
**목표**: 실사용자 기반 증명, 재현 가능성 검증

- **진행 중**: 키움, 신한, 미래에셋으로 초기 사용자 확보
- **측정 항목**: 
  - 월간 활성 사용자(MAU)
  - 누적 주문 수
  - 실제 손익 통계
  - 재현성(전략 동일성에 따른 성과 일관성)

### Phase 2-1: 한국투자증권 안정화/실사용 검증 (2026년 하반기)
**이유**
- 개인 개발자 가장 많음
- REST API 구조로 SaaS 확장성 최고
- 키움 대체 가능성 → 사용자 선택폭 증대

**기술 난이도**: 중간 (REST API, OAuth 표준)

### Phase 2-2: 유안타/이베스트 추가 (2026년 하반기~2027년 상반기)
**이유**
- 자동매매/퀀트 커뮤니티 활발
- PMF 검증 후 타겟 사용자층 확대

**기술 난이도**: 중간~높음 (각사 API 스펙 학습 필요)

### Phase 3: 대신/NH 추가 (2027년 이후)
**이유**
- 기관 제휴 중심에서 개인 확대 추세
- 기존 사용자층 보호/확대

**기술 난이도**: 높음 (대신 CYBOS, NH 특화 API)

## 4. 개인 사용자 입장에서 "지원"의 의미

### NoahAI 관점
```
구현됨 (코드 완성) ✅ 키움, 신한, 미래에셋, 한국투자
확장 예정 (큐 대기) 📋 유안타, 이베스트, 대신, NH
미계획 ❌ 기타
```

### 증권사 정책 관점
```
개인 API 발급 가능 ✅ 키움, 신한, 미래에셋, 한국투자, 유안타, 이베스트, 대신, NH (모두!)
개인 미지원 ❌ (국내 주요 증권사 중 없음)
```

### 사용자 실거래 관점
```
지금 바로 가능 = 구현 완료 + 본인 계정 OpenAPI 승인
곧 가능 = 구현 예정 + 본인 계정 OpenAPI 승인
```

## 5. 사용자 혼선 방지

### 자주 받는 질문

**Q: "신한은 사업자만 지원한다고 했는데?"**
- A: 신한의 "사업자 중심" 기본값은 사실이지만, 개인도 신청/승인 가능
- A: NoahAI는 이미 개인계정 기반으로 구현됨
- A: 실거래 가능 여부는 신한의 심사 결과에 따라 다름

**Q: "미래에셋은 지원 안 한다고 했는데?"**
- A: 노아는 지원함 (코드 구현 완료)
- A: 실거래 안 되는 이유는 미래에셋 측 계정/권한 문제일 가능성
- A: 미래에셋 고객센터에 "개인 OpenAPI 발급 가능 여부" 확인 필요

**Q: "한국투자증권은 왜 없어?"**
- A: 현재 Noah에는 한국투자증권(KIS) 어댑터가 구현되어 있습니다.
- A: 실연결 가능 여부는 계정 API 권한/약관/호출 제한 정책을 함께 확인해야 합니다.

## 6. 기술 검증 vs PMF 검증 단계

### NoahAI 현재 위치
```
PoC 완료 (기술 가능성 증명)
    ↓
초기 PMF 검증 단계 (사용자가 실제로 돈을 내고 쓰는가?) ← 현재
    ↓
확장 단계 (추가 자산군/증권사 등)
```

### 이 단계에서 중요한 것
1. **재현성**: "다른 환경에서도 같은 신호 = 같은 결과인가?"
2. **사용자 수**: "실제로 사용 중인 사용자가 몇 명인가?"
3. **누적 주문**: "총 몇 건의 주문이 체결되었는가?"
4. **손익 통계**: "사용자별 손익 분포와 일관성이 있는가?"
