# v3.9.2.7 사용자 피드백 수정과 Windows 인계

2026-10-07 소스 후보. 공개 기반은 v3.9.2.6이다. Windows 빌드·릴리즈·게시 담당은 사용자이며 Codex는 수정과 로컬 검증을 담당한다. 이 문서와 로컬 통과는 설치본 인수·허브 서버 배포 완료를 뜻하지 않는다.

## 업데이트 후 기존 사용자의 동작

정상 PAPER 원장은 기존 청산 순손익과 보유 증거금을 계속 반영한다. 새 거래는 저장된 진입 계약 단위로 계산한다. 증빙 없는 계약 단위를 현재 거래소 정보나 주문 예정 금액으로 추정하지 않는다. 최신 명시 계약 단위가 있는 기록은 진입 가격과 주문 예정 가격 차이 때문에 과거 단위 오류로 잘못 분류하지 않는다.

과거 미확정·단위 모순 행은 원본을 보존하고 검증된 승률/손익에서 분리한다. 보유 포지션의 계약 단위가 불명확하면 화면에 손익 미확정으로 표시하고 0원 수익처럼 표시하지 않는다. 과거 손익을 자동 수정했다거나 실패했던 모든 주문이 재실행된다고 안내하지 않는다. 브라우저 파일 선택은 보안상 자동 복원이 불가하므로 허브 수정 반영 후 같은 파일을 다시 선택하고 분석/제출하면 된다.

공유 데이터의 과거 기록에는 진입가·청산가·수량·결제 통화가 아예 없는 행도 있다. ‘원장 대조’란 같은 거래의 진입·청산 가격, 실제 단위 수량, 통화와 비용을 맞춰 순손익을 확인한다는 뜻이다. PAPER는 실제 주문을 내지 않았으므로 거래소 체결 조회로 누락된 가상 거래를 복원할 수 없다. 과거 주문 예정 금액만으로 역산하면 실제 가상 진입 가격 차이를 누락할 수 있어 정확한 복구로 취급하지 않는다.

이 때문에 막힌 암호화폐 PAPER 계정은 **거래 현황 → 해당 기관 → 운용 요약 → 과거 기록 보존하고 새 PAPER 평가 준비**를 사용할 수 있다. 보유 PAPER 포지션 청산을 확인하고 해당 기관을 정지한 뒤, 새 평가임을 확인하는 체크박스를 선택한다. 서버 측에서 현재 모드·계정·실행 상태·메모리/저장된 보유량·영속 주문 예약을 다시 검사한다. 준비 후 사용자가 시작 버튼으로 새 검사를 진행한다. 실제 주문 제출이나 자동 거래 시작은 수행하지 않는다.

이 작업은 손익 복구가 아니라 설정의 PAPER 기준자금으로 시작하는 **별도 새 평가**다. 기존 원장·전체 기간 통계·전략·설정·LIVE 기록을 지우지 않는다. `paper_funds_sessions.json`에 기관/통화별 경계·과거 원장 SHA-256·고정 초기자금을 원자적으로 저장하고 새 구간의 청산과 보유만 가용자금에 반영한다. 재시작·설정 금액 변경·반복 클릭으로 기준을 다시 초기화하지 않는다. 확인된 손실, 원장 충돌·손상, 열린 포지션/예약을 이 기능으로 우회할 수 없다. 기존 구간의 손익과 새 구간 가용액은 다른 범위이며 화면에서 안내한다. 증권 PAPER에는 이번 기능을 제공하지 않는다.

LIVE 원장 점검은 별도다. 실제 기관의 주문·체결·비용 증거가 필요하며 PAPER 새 평가로 LIVE 손실 보호나 미확정 주문을 해제하지 않는다. API 장애, 키움 로그인, 시세 제공 실패 및 정상 위험 차단은 이 패치로 항상 성공한다고 보증하지 않는다.

## 성과 피드백의 결론

공유 기록의 기간·기본/사용자 전략·KRW/USDT·비용·계약 단위를 분리해서 평가해야 한다. 첨부 패키지의 자기 신고 성과는 원래 원장 합계와 일치하더라도 단위 오류가 있는 과거 금액을 포함하므로 검증된 수익으로 취급할 수 없다. 3.9.2.6 관찰은 한 계정의 약 7시간이어서 업데이트가 승률 하락의 원인이라는 결론도 내릴 수 없다. 계산 정상화가 수익 증가를 보장하지 않는다. 원장 정상화 이후 동일 비용·구간·예산으로 기본 전략과 후보를 별도 PAPER 전진검증해야 한다.

## 검증과 Windows 인수

최신 로컬 시험·원본 보존·복사 데이터 재개 증거는 `reports/v3927-*`와 [TEST_STATUS](TEST_STATUS.md)에서 확인한다. Windows에서는 아래 경로를 반드시 설치본으로 확인한다.

1. 3.9.2.6 → 3.9.2.7 업데이트, 계정/키/설정/전략/보유 PAPER 기록 보존.
2. 계약 크기 0.01/0.1/1/10/100/1000/100000의 LONG/SHORT 비용·순손익, AI 청산 가격, 부분청산/전체청산 원장·잔여 수량.
3. 구형 미확정 기록의 보류 사유, 새 PAPER 평가의 확인·정지·열린 포지션/예약 거절·재시작·반복 클릭·기관/통화/계정 격리.
4. 허브 서버 패치 반영 후 첨부 3개 파일의 실제 브라우저 분석과 제출, 범위/진입 종류/원본 보존.
5. LIVE 위험 보호·체결 대조, 설치/업그레이드/롤백·장시간 운용은 실제 증거로 인수. 수익·승률 상승 또는 모든 외부 장애 해소를 완료 조건으로 가장하지 않는다.
