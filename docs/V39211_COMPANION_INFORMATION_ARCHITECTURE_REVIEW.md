## 발견 및 수정

- 상단 버튼에 전용 배경·테두리 스타일이 없어 브라우저 기본 회색이 적용됐다. 기존 다크 화면과 맞는 청색 `#0369a1`, 밝은 테두리, 공통 아이콘·기능 설명을 지정했다.
- 금융비서 내부의 브리핑·배분·전략 실험·진행 중 비교에는 선택 상태 표시가 없었다. 선택 업무를 기존 primary 청색으로 강조하고 `aria-pressed`를 연결했다. 근거 다시 읽기는 조회 행동으로 유지한다.
- 창·카드·입력은 기존 `--legacy-*` 색상을 사용한다. 뷰포트 여백을 포함한 크기를 적용하고 입력 안내의 대비를 명시했다.
- 모달이 열리면 제목으로 초점을 옮기고 Tab/Shift+Tab을 보이는 창 내부에 유지한다. Escape·닫기로 닫으면 상단 버튼으로 돌아간다. 비교 미저장 확인과 기존 잠금·승인 보호는 유지한다.

- 자산 통합·생활금융·AI애널리스트 상단에도 거래소 수·미선택이 표시되던 문구를 각 서비스의 자료 기준으로 수정했다. 거래소/증권사 기준 표시는 두 투자시장 화면에 유지한다.
