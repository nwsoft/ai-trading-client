# v3.9.1.42 원격 운용 제어 실행 계획

2026-09-20. 사용자 승인: Client 소스 구현·검증 및 daltrading 배포. **Client 설치기 빌드·릴리스는 사용자가 수행**한다. 공개 v41 자산은 수정하지 않는다.

## 범위

- 상태별 시작 / 새 거래 일시정지 / 재개. 일시정지는 포지션 보호·청산을 유지하며 전량 청산·프로세스 종료가 아니다.
- v41 권한은 일시정지만 유지. v42 시작/재개는 PC의 별도 동의와 승인 당시 기관·모드·설정 범위에 한정한다.
- 웹 시작/재개는 재인증, 소유권/CSRF/Origin, 최신 상태·설정 식별자, 명령 TTL·중복 방지, PC 재검증을 거친다. 위험 제한 초기화나 설정 변경 API를 만들지 않는다.
- 원격 상태 설명, 최소 위험/성과 요약은 별도 공유 동의. 미확인 수치는 0으로 꾸미지 않고 시각·범위를 표시한다.
- 연결 해제는 기기 관리로 이동. v41·오프라인·미허용 상태의 버튼을 구분한다.
- 알림에 로그인 필요한 기관별 원격 확인 링크. 링크 자체는 명령 권한이 아니다.

전략 원격 백테스트·전략 교체·모드 전환·전체 청산은 다음 단계다. 이번 실행 계획에 포함하지 않는다.
