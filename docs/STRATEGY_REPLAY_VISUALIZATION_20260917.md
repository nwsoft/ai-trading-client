# v3.9.1.38 전략 스튜디오 과거재생 시각화

> 공개 상태 갱신(2026-09-18 확인): 이 기능을 포함한 v3.9.1.38은 GitHub stable/latest로 게시됐습니다. 아래 “소스 후보/공개 v37” 표현은 구현 당시 기록이며, 실제 기관 계정·시장 성과 검증을 뜻하지 않습니다.

## 배포 경계

v3.9.1.37 stable 공개 뒤 구현된 기능이므로 **v3.9.1.38 소스 후보**로 승격했습니다. 공개 v37 태그·설치기·`latest.yml`·매니페스트는 수정하지 않습니다. v38 Windows 새 빌드·v37→v38 업데이트·실환경 검증 대기 상태입니다.

## 기능 및 사용법

전략 스튜디오의 저장된 버전 → 검증 근거 보기 → 과거재생 차트를 엽니다.

- 검증에 사용한 정규화된 OHLC 캔들을 로컬 결과에 보존합니다. 현재 시세를 다시 조회해 과거 타점을 맞추지 않습니다.
- 상단 캔들에 LONG/SHORT 진입·청산 마커, 하단에는 청산 거래의 비용 차감 복리 수익률을 표시합니다.
- 거래표에서 진입·청산 봉 시각/가격, 방향, 청산 사유, 비용 전/비용/비용 차감 수익률을 확인합니다.
- 거래 선택 시 해당 캔들 구간으로 이동하고 선택 내역을 표시합니다. 차트의 타점 봉을 선택해도 거래가 선택됩니다.
- 거래표는 20건씩 탐색합니다. 전체 타점은 화살표로 유지하고 선택 거래의 진입·청산 이름만 표시합니다.
  적은 거래도 좁은 구간에 몰리면 글자가 겹치므로 거래 수에 따른 표시 기준은 사용하지 않습니다.
- 축·커서·상세 수익률은 같은 소수 4자리 표시 함수를 사용합니다. 표시 반올림은 저장된 손익을 변경하지 않습니다.
- 가격은 일반 가격의 소수 2자리, 1 미만 저가 코인의 유효숫자 6자리로 읽기 쉽게 표시하며,
  1e-12 미만은 0 대신 지수 표기를 사용합니다. 선택 거래의 계산 원본 값은 별도 펼침 영역에서 확인합니다.
- 차트·거래표는 UTC **봉 시작 시각** 기준이며 봉 내부의 실제 체결 시각을 뜻하지 않습니다.
- 구형/손상/시각 누락/순서 불일치/5,000봉 초과 결과는 임의 복원하거나 일부만 잘라 그리지 않습니다.
  이전 버전의 요약을 보존하고 새 버전 저장·승인 후 과거재생을 실행하도록 안내합니다.

## 손익·권한·여권 계약

- 기존 엔진의 순손익·복리 수익률을 그대로 읽습니다. 차트 표시를 위해 수익률을 새로 계산하거나 원장을 수정하지 않습니다.
- 보유 중 평가손익, 실제 계좌 잔고, 수량·레버리지 성과가 아닙니다. 기존 MDD 역시 청산 거래 기준입니다.
- 같은 봉에서 익절/손절에 동시에 닿으면 기존 손절 우선 규칙을 유지합니다. 펀딩비·시장충격은 모델링하지 않습니다.
- 증권 수수료·슬리피지·주식/ETF 매도세 차이는 기존 비용 계약을 유지합니다. 증권은 지원하는 일봉을 사용하며 분봉으로 가장하지 않습니다.
- 전략 키·버전·IR 해시·검증 기록 시각에 결과를 연결하고 캔들 해시를 보존합니다. 해시는 로컬 대조용이며 외부 인증이 아닙니다.
- 과거재생 시각화는 PAPER 증거·LIVE 권한·여권 등급을 승격하지 않습니다.
- 상세 차트 스냅샷은 `.noahstrategy` 공유 여권에서 제외합니다. 로컬 기록은 보존하며 자동 외부 전송을 추가하지 않습니다.
