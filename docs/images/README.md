# Docs Images

이 디렉터리는 문서에 포함될 스크린샷 파일을 보관합니다.

권장 사항
- 포맷: `.png`
- 해상도: 1440×900 이상(가능하면 2x Retina), 가로 폭 기준 1200px 내외로 리사이즈 권장
- 테마: 다크/라이트 중 문서 문맥에 맞게 캡처(기본은 다크)
- 파일명 규칙: `snake_case` + 간결한 설명 + 테마/상태
  - 예) `modern_dashboard_main_dark.png`, `settings_general_classic_view_on.png`

캡처 팁 (macOS)
- 단일 윈도우: `Cmd + Shift + 4` → Space → 대상 윈도우 클릭
- 지정 영역: `Cmd + Shift + 4` 후 드래그
- 저장 위치: 기본 `Desktop` → 시스템 설정에서 변경 가능

폴더 구성
- 이 디렉터리에는 실제 이미지 파일과 `.gitkeep`(빈 파일, 디렉터리 보존용)이 포함됩니다.
