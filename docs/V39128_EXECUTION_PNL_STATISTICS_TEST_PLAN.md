## 불변 계약

- NoahAI 성과는 진입부터 청산까지 연결된 `trade_log`만 사용한다.
- 기관 확인 체결은 `exchange_execution_log`에 저장하며 수동 체결만으로 승률을 만들지 않는다.
- 대조 키는 기관·종목·정확한 청산 주문 ID이고 시간 범위/반대 방향만으로 연결하지 않는다.
- 공급자 실현 PnL과 비용 반영 순손익을 분리한다. 비용 통화가 다르면 환산 근거 전까지 순손익을 확정하지 않는다.
- 부분체결·부분매도는 잔여 포지션/lots를 유지한다.
- KRW·USDT와 다른 결제통화는 합산하지 않는다.
- 과거 불완전 기록은 삭제·덮어쓰기하지 않고 대조 상태로 표시한다.
