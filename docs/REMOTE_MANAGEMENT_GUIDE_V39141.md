# v3.9.1.41 내 PC 원격 관리 베타

2026-09-19 후속 확인: Client v3.9.1.41은 GitHub에 별도로 공개됐습니다. daltrading 서버의 원격 메뉴·relay는 이번 작업에서 배포해 검증 계정 1개에 활성화했고 실제 웹 로그인·페이지/API를 확인했습니다. 이 작업에서 Windows 설치기 게시 또는 실제 PC 연결·제어 검증을 한 것은 아닙니다. 서버 정본: daltrading `docs/V39141_REMOTE_PRODUCTION_VERIFICATION.md`.

## 사용자 순서

베타 미활성 계정에는 안내 화면만 보이며 API 접근은 계속 차단됩니다. 대시보드 메뉴 아래의 원격 관리 베타 카드에서 진입합니다. 모바일 긴 PC 이름은 줄바꿈하며 이번 검사는 실제 기기가 아닌 320~1280px Chrome fixture 기준입니다.

1. PC 로그인 → **설정 → 알림·리포트 → 원격 관리 · 내 PC 상태 공유**.
2. PC 이름 입력 → **상태 공유에 동의하고 연결**. 기본은 OFF입니다.
3. 필요하면 **모바일에서 신규 주문 제출 일시정지 허용**을 체크합니다. 이미 연결한 상태라면 **원격 권한 저장**을 누릅니다. 이 영역은 전체 설정 저장과 별도로 저장합니다.
4. 휴대폰에서 daltrading에 같은 계정으로 로그인 → 대시보드의 **내 NoahAI 원격 관리**. PC의 **모바일 대시보드 열기**도 같은 주소입니다.
5. 기관·실행 여부·PAPER/LIVE/LEARNING·마지막 수신 시각을 확인합니다. 기기별 이름을 다르게 지정하세요. 계정당 활성 기기는 최대 3개입니다.
6. PC에서 허용한 온라인 기기의 **신규 제출 일시정지** → 확인. 접수와 완료는 다릅니다. PC 수신 후 확인 상태가 바뀌고, 이미 처리 중인 제출이 있으면 처리 중으로 표시됩니다.
7. 재개는 PC의 같은 영역에서 **PC에서 신규 진입 재개** → 확인합니다. 공유 해제나 PC 재시작만으로는 재개되지 않습니다.

원격 화면은 마지막 수신 상태이지 거래소에서 방금 확인한 계좌 원본이 아닙니다. PnL 상세는 미제공하며, 기존 PnL 대조 미완료 사항을 해결했다고 표시하지 않습니다. 손실 대응을 60초 폴링 원격 버튼에만 의존하지 마세요.

## 연결·해제와 오류

- PC와 NoahAI가 실행 중이어야 합니다. 절전·종료·인터넷 단절 시 새 정보나 명령을 받지 못합니다.
- PC의 공유 OFF는 새 전송을 중단합니다. 서버 마지막 상태는 남아 있다가 오프라인으로 표시됩니다.
- 모바일의 **이 PC 연결 해제**는 기기 토큰을 폐기하고 서버 상태를 비웁니다. 다음 PC 접속은 거부되며 자동 재연결하지 않습니다. PC에서 다시 명시적으로 연결할 수 있습니다.
- 공유 OFF·서버 연결 해제 모두 기존 진입 일시정지를 해제하지 않습니다.
- 모바일 웹 로그인과 PC 세션은 별개입니다. 계정 차단·PC 세션 교체·인증 버전 변경은 기기 전송을 거부합니다.
- 서버 베타가 아직 활성화되지 않았으면 연결할 수 없습니다. 실제 전송 시각이 없는 ‘공유 켜짐’만으로 서버 연결 성공을 판단하지 마세요.
- Telegram/Discord 알림은 별도 설정입니다. 알림을 받은 뒤 daltrading에 로그인해 확인하며 알림 속 링크만으로 주문 권한이 생기지 않습니다.
