# 🔍 바이낸스 API 키 유효성 검증 도구

`api_check.py`는 바이낸스 API 키의 유효성을 종합적으로 검증하는 도구입니다. 설정 파일에서 자동 로드하거나 직접 입력할 수 있습니다.

## 📋 기능

- ✅ **API 키 유효성 확인** - 서버 시간 조회를 통한 기본 검증
- ✅ **현물 거래소 접근** - 현물 거래소 정보 조회 가능 여부
- ✅ **선물 거래소 접근** - 선물 거래소 정보 조회 가능 여부
- ✅ **계정 정보 조회** - 현물 계정 정보 조회 가능 여부
- ✅ **선물 계정 조회** - 선물 계정 정보 조회 가능 여부
- ⚠️ **IP 제한 감지** - IP 제한으로 인한 접근 제한 여부
- 🔑 **다양한 입력 방식** - 직접 입력, 설정 파일 로드, 자동 감지

## 🚀 사용법

### 기본 실행
```bash
python3 api_check.py
```

### 실행 위치
프로젝트 루트 디렉토리(`noahai_client/`)에서 실행해야 합니다.

## 🔑 API 키 입력 방식

실행 시 다음 3가지 방식 중 선택할 수 있습니다:

### 1. 직접 입력 (수동)
- API Key와 Secret Key를 직접 입력
- 설정 파일이 없거나 다른 키를 테스트할 때 유용

### 2. 설정 파일에서 자동 로드
- `settings.json` 파일에서 자동으로 API 키를 읽어옴
- 기존 설정을 그대로 사용할 때 편리

### 3. 자동 감지 (기본)
- 설정 파일이 있으면 자동 로드, 없으면 직접 입력
- 가장 편리한 방식

## 📁 설정 파일 경로

설정 파일 로드 시 다음 순서로 찾습니다:

1. `data/nwsoft/config/settings.json` (기본)
2. `config/settings.json`
3. `settings.json`

## 🔧 결과 해석

### ✅ 정상 상태
- **API 키 유효**: 서버 시간 조회 성공
- **현물 거래소 접근**: 3,000개 이상 심볼 조회 가능
- **선물 거래소 접근**: 500개 이상 선물 심볼 조회 가능

### ⚠️ IP 제한 상태
- **계정 정보 조회 불가**: IP 제한으로 인한 접근 거부
- **선물 계정 조회 불가**: IP 제한으로 인한 접근 거부

### ❌ 오류 상태
- **API 키 무효**: 서버 시간 조회 실패
- **거래소 접근 불가**: 네트워크 또는 권한 문제

## 🛠️ 문제 해결

### IP 제한 해제 방법

1. **바이낸스 계정 로그인**
2. **계정** → **API 관리**
3. 해당 API 키 선택
4. **"IP 제한"** 설정을 **"제한 없음"**으로 변경
5. 또는 **"허용된 IP"**에 현재 IP 추가

### API 키 재생성 방법

1. **바이낸스 계정** → **API 관리**
2. **"새 API 키 생성"** 클릭
3. **권한 설정**:
   - ✅ 현물 거래
   - ✅ 선물 거래
   - ✅ 읽기 권한
4. **IP 제한**: "제한 없음" 선택
5. 생성 후 `settings.json`에 업데이트

## 📝 주의사항

- 이 도구는 **읽기 전용** 검증만 수행합니다
- 실제 거래나 계정 수정은 하지 않습니다
- IP 제한이 있는 경우 일부 기능이 제한될 수 있습니다
- 네트워크 연결이 필요합니다
