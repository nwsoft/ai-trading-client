# NoahAI 전략 검증 플랫폼 포지셔닝 정본

기준일: 2026-09-06  
제품명: NoahAI 전략 스튜디오  
공유·발견 공간: NoahAI 전략 허브  
검증 기록: 전략 검증 여권

## 한 문장

> NoahAI는 TradingView·Pine·문서 전략의 원문 의미와 실제 실행 규칙을 연결하고, 거래소별 PAPER·실체결 근거를 버전별 검증 여권으로 만드는 플랫폼입니다.

## 범주 창출 비전

NoahAI는 **세계 최초의 전략 검증 여권 생태계**를 구축한다. 여기서 세계 최초의 대상은 백테스트 자체가 아니라 다음을 한 제품 생명주기로 연결하는 범주다.

1. TradingView·Pine·문서 원문 의미와 제한형 실행 규칙의 추적
2. 해석 실패·리페인팅·미지원 조건의 실패 폐쇄
3. 거래소·시장·통화·전략 key/version별 PAPER와 확인 체결 귀속
4. 변조 방지 패키지와 버전별 검증 여권
5. 다운로드 사용자의 자기 환경 재검증
6. 자기신고 수익률이 아닌 검증 근거 품질 중심 탐색

이는 “세상에 없는 최초 백테스트”나 수익 보장 주장이 아니다. TradingView, MetaTrader, QuantConnect, Collective2 등에도 백테스트·전진검증·전략 공유 또는 라이브 대조 기능이 있다. NoahAI의 범주 창출 기회는 위 기능을 한 버전 계약으로 연결하고 구매자가 자신의 환경에서 다시 검증하도록 만드는 조합에 있다. 대외 문구는 `전략을 주장하는 시장에서, 실행 근거를 확인하는 문화로`를 함께 사용한다.

## 차별화 계약

- 원문 문장/Pine 코드와 실행 규칙의 1:1 추적
- 미래 데이터 참조·리페인팅·미지원 조건의 실패 폐쇄
- 수수료·슬리피지·OOS·워크포워드·과최적화 검사
- 국내 KRW 현물과 해외 USDT 선물의 방향·주문·성과 분리
- 실제 PAPER 전진검증과 거래소별 성과 귀속
- 구매자 계정에서 다시 PAPER 검증한 뒤 직접 승인
- 수익률 순위가 아닌 근거 수준·표본·재현성·위험으로 랭킹

## 검증 여권의 네 가지 상태

1. `원문 보존`: 자료와 출처는 보존했지만 아직 실행 규칙이 아니다.
2. `구조화 완료`: 지원되는 진입·청산·위험 조건이 Noah Strategy IR로 추적된다.
3. `PAPER 전진검증`: 특정 거래소·시장유형·기준통화에서 새로 청산된 가상 거래 근거다.
4. `실체결 근거`: 사용자가 허용한 LIVE에서 거래소 원장과 대조된 결과다. PAPER와 합산하거나 동일하다고 표현하지 않는다.

`NoahAI 기본 진입 + 사용자 위험·청산값`은 유효한 운용 방식이지만 원문 전체 전략 실행 검증과 다르다. 여권과 랭킹에서 반드시 별도 유형으로 표시한다.

## 랭킹 원칙

수익률 하나로 정렬하지 않는다. 최소 표시 항목은 다음과 같다.

- 원문-규칙 추적률과 미지원 조건 수
- 검증 시장·거래소·현물/선물·기준통화
- 표본 수와 관찰 기간
- 비용·슬리피지 포함 여부
- OOS·워크포워드·과최적화 결과
- PAPER와 LIVE 근거의 구분
- 버전 해시와 수정 이력
- 최대낙폭·가드레일 위반·재현 상태

## 무료 공개 베타 범위

- 제작자가 NoahAI 앱에서 `.noahstrategy`를 내보내고 daltrading에서 직접 제출한다.
- 제작자가 배포 권리를 자기선언하고 서버 패키지·IR 실행 구조 검사를 통과하면 E0로 공개한다. 운영자 사전승인은 초기 공개 조건이 아니다.
- E0는 구조·무결성 공개 단계이며 성과·PAPER·실체결·권리 검토 완료를 뜻하지 않는다. 근거 없는 E0 검증 점수는 0에서 시작한다.
- 운영자는 OOS·워크포워드·PAPER·확인 체결 근거 승격과 신고·권리·무결성 분쟁을 사후 검토한다.
- 사용자는 무료 취득 기록을 받은 뒤 패키지를 다운로드하고 자신의 NoahAI에서 가져온다.
- 가져온 전략은 비활성 검토본이며 자동 승인·자동 적용되지 않는다.
- 다운로드 사용자는 과거 결과를 믿는 대신 자신의 거래소 PAPER를 다시 수행한다.
- 실제 투자 시드 없이도 전략 제작과 PAPER 검증이 가능하다. PAPER는 시장 데이터 기반 가상 체결이며 거래소 확인 체결과 같지 않다.
- 결제·포인트·판매자 환전·성과기반 과금은 현재 범위가 아니다.

## 대외 표현 금지

- 범위를 정의하지 않은 `세계 최초 백테스트`·`세계 최초 자동매매`, 유일, 무조건 안전, 검증된 수익, 미래 수익 보장
- 현재 공개 v3.9.1.21·v3.9.1.22 소스 후보·무료 허브·향후 유료 생태계를 모두 완료 기능처럼 섞는 표현
- 모든 Pine Script 완전 변환
- PAPER가 LIVE 체결과 동일하다는 표현
- 거래소가 다른 KRW와 USDT 손익의 단순 합산
- 실행 노드가 없는 원문을 원문 전략의 전진검증으로 표시

웹사이트·앱·검색/LLM 문서는 이 문서를 정본으로 삼되, 현재 공개 버전과 다음 소스 후보를 반드시 분리한다.
