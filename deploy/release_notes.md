# NoahAI v3.9.1.45

지표 근거 보존, 시장국면 알림 검증과 전략 상담 흐름을 개선한 Windows 릴리스입니다.

- AI 어시스턴트와 전략 스튜디오에서 코인·주식/ETF 전략 상담을 시작할 수 있습니다. 조건이 모호하면 한 번에 하나씩 확인하고, 확인된 초안만 기존 분석·컴파일·사용자 승인·PAPER 검증 경로로 전달합니다.
- 전략 상담은 자동 저장·승인·거래를 실행하지 않으며 실시간 웹 검색 기능이 아닙니다. 설정된 외부 AI를 호출하면 해당 Provider 비용이 발생할 수 있습니다.
- 7개 코인 거래소의 학습 기록에 분석 시점 RSI·MACD·추세 등 구조화된 지표를 보존합니다. 기존 기록에 없던 값은 현재 시세나 임의 중립값으로 복원하지 않습니다.
- 코인 후보 기술점수는 15분·1시간 RSI 근거가 모두 없으면 미산출 이유를 표시합니다. 기술점수와 종합점수를 구분하며 후보별 추가 네트워크 호출이나 매매 가중치 변경은 없습니다.
- 시장국면 알림을 PAPER·LIVE·학습/관찰 모드별로 선택할 수 있습니다. 기존 설정이 없으면 모두 수신하며 LIVE 위험 경고와 다른 알림에는 이 필터를 적용하지 않습니다.
- 코인·증권 시장국면 입력에서 누락·비정상 시세를 unknown으로 처리하고 실제 0 거래량은 보존합니다. 평탄 구간 RSI는 중립 50으로 처리합니다.
- 알림의 비정상 JSON·빈 성공 응답을 실패로 구분하고, 한 채널 오류가 다른 채널 전송을 막지 않도록 격리합니다.
- 기본 시장국면 관찰 300초, 연속 확인 2회, 최소 유지 600초와 기존 PnL 보호·주문 승인 경계를 유지합니다.

Windows 설치기에는 x64 `NoahAIEngine.exe`와 x86 `NoahAIKiwoomHost.exe`가 포함됩니다. 자동 업데이트 자산은 `NoahAI-3.9.1.45-Setup.exe`, blockmap, updater `3.9.145`의 `latest.yml`, `release-manifest.json`입니다.

자동 회귀와 패키징 검증은 수행하지만 실제 외부 AI 장기 상담, 메신저 전송, 키움 OCX·실기관, v44→v45 실제 업데이트, 다기관 장시간 PAPER는 별도 외부 검증 항목입니다. 자세한 범위는 `docs/V39145_INDICATOR_TEST_PLAN.md`를 따릅니다.
