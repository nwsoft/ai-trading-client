# NoahAI v3.9.1.39

외부 청산 손익의 근거 표시와 전략 초보자 설명을 보강한 Windows 릴리스입니다. 공개 v3.9.1.38 자산은 변경하지 않고 v39 전용 자산을 제공합니다.

## 주요 변경 사항

- PAPER와 LIVE 원장을 분리하고 주문 근거가 없는 외부 청산을 확정 손익으로 자동 연결하지 않습니다.
- NoahAI 연결 청산 순손익과 거래소에서 수집한 체결 총손익을 구분하며, 미확정 거래가 있으면 부분 합계로 표시합니다.
- 청산 방향, 중복 귀속, 비용 통화, 수수료 환급, UTC 시각 및 증권 KRW 집계 처리를 보강했습니다.
- 미대조 손익이 수익성 검증이나 Smart Exit 통계 조정에 사용되지 않도록 차단했습니다.
- Strategy Studio에 초보자용 규칙 설명, 입력 항목 안내, 차트 읽기 및 결과 질문 흐름을 추가했습니다.

## Windows 배포 자산

- `NoahAI-3.9.1.39-Setup.exe`
- `NoahAI-3.9.1.39-Setup.exe.blockmap`
- `latest.yml` (updater `3.9.139`)
- 설치기에 포함된 x64 `NoahAIEngine.exe`와 x86 `NoahAIKiwoomHost.exe`

## 검증 범위

자동 회귀, Web production build, x64 엔진, 키움 x86 호스트, PE 아키텍처, IPC 시작·종료와 설치기·blockmap·manifest 해시는 빌드 과정에서 검증합니다. 공개 v3.9.1.38에서의 실제 업데이트, 키움 및 거래소 실계정 연결, 외부 TP/SL 주문 소유권 대조와 장시간 PAPER 운용은 별도 외부 검증 항목입니다.

거래 결과와 과거 검증은 수익을 보장하지 않습니다. LIVE 거래는 계정 권한과 위험 설정을 별도로 확인한 뒤 사용해야 합니다.
