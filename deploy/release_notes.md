# NoahAI v3.9.1.42

한국어·영어 베타 추가: 로그인 폼 하단 또는 설정 → 일반 → 표시 언어에서 선택. 저장된 선택 우선, 없으면 시스템 첫 선호 언어를 참고하며 미지원 언어는 한국어로 시작합니다. 핵심 UI, 영어 운영 매뉴얼, 명시적 AI 설명 언어 및 모바일 원격 영어 화면을 제공합니다. 일부 고급 진단·알림·기존 문구는 한국어입니다. 전체 완역이나 추가 국가의 거래 허용을 뜻하지 않습니다. `docs/V39142_ENGLISH_IMPLEMENTATION_PLAN.md` 참고.

원격 자율운행 시작·재개와 안전 승인·상태 설명 개선. PC 별도 동의·웹 재인증·현재 설정/모드 일치·회원/위험 재검사 후 실행합니다. 일시정지는 신규 진입만 막고 기존 보호·청산은 유지합니다. 공유한 손익은 NoahAI 위험 평가 범위이며 계좌 전체 PnL과 다릅니다. API 키·전략 원문은 전송하지 않습니다. 원격 모드 전환·전량 청산·백테스트는 미제공입니다.

Windows 설치기에는 x64 `NoahAIEngine.exe`와 x86 `NoahAIKiwoomHost.exe`가 포함됩니다. 자동 업데이트 자산은 `NoahAI-3.9.1.42-Setup.exe`, blockmap, updater `3.9.142`의 `latest.yml`, `release-manifest.json`입니다.

소스 자동 회귀와 패키징 검증은 수행하지만 v41→v42 실제 업데이트, 키움 OCX 및 실기관, 장시간 PAPER, 원격 모바일 E2E는 별도 외부 검증 항목입니다. 검증 정본: `docs/V39142_REMOTE_CONTROL_TEST_PLAN.md`.
