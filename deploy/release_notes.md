# NoahAI v3.9.1.43

공개 v3.9.1.42에서 거래 기록 점검·복구 유지관리와 전략 스튜디오 난이도 이동·표시·저장 동선을 개선한 Windows 릴리스입니다.

설정 → 업데이트 → 유지관리에서 최근 LIVE 기록의 주문·체결·수수료 근거를 읽기 전용 기관 API로 점검합니다. Binance는 청산 주문 ID가 없는 과거 기록도 종목·기간별 원장을 수집하여 완전한 포지션 구간과 실제 체결 근거가 확인된 경우에만 복구합니다. 근거가 불완전하거나 귀속이 섞인 기록은 임의 추정하지 않고 미확정 상태로 유지합니다. 점검은 주문 제출·취소·강제 청산·자동 재개를 수행하지 않습니다.

전략 스튜디오의 사용 난이도 버튼은 설정의 실제 선택기로 이동하며 Level 1 초보자, Level 2 일반, Level 3 고급, Level 4 실험실 표기를 한국어·영어에서 일관되게 제공합니다. 저장 검증이 완료된 경우 열린 코인·주식 전략 화면에 즉시 반영하며 전략 입력을 초기화하지 않습니다.

Windows 설치기에는 x64 `NoahAIEngine.exe`와 x86 `NoahAIKiwoomHost.exe`가 포함됩니다. 자동 업데이트 자산은 `NoahAI-3.9.1.43-Setup.exe`, blockmap, updater `3.9.143`의 `latest.yml`, `release-manifest.json`입니다.

자동 회귀와 패키징 검증은 수행하지만 특정 고객의 과거 미대조 기록 복구, 전 기관 일별 계좌 대조, 키움 OCX·실기관, v42→v43 실제 업데이트 및 장시간 PAPER는 별도 외부 검증 항목입니다. 자세한 범위는 `docs/V39143_RECORD_RECOVERY_PLAN.md`를 따릅니다.
