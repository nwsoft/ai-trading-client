# NoahAI v3.9.2.1

AI 어시스턴트의 최신 기능·오류 안내를 보강하고, 자산통합과 생활금융에 사용자의 로컬 기록을 바탕으로 한 월간 재무 점검 기능을 추가한 Windows 업데이트입니다.

- AI 어시스턴트가 거래 시작 오류, 전략, 키움 종료, PAPER 한도, JEV 검토 등 최신 기능을 한국어와 영어로 더 정확하게 안내합니다.
- 자산통합과 생활금융에서 수입·지출·내 계좌 이체를 구분하고 이번 달 현금흐름을 점검할 수 있습니다.
- 월간 계획과 수입 감소 가정을 비교할 수 있으며, 자산·가계부·PAPER 거래 성과를 서로 잘못 합산하지 않습니다.
- 생활금융 질문은 사용자가 명시적으로 요청할 때만 AI 질문 초안을 열며, 자동 송금이나 은행 계좌 자동 수집을 수행하지 않습니다.
- 금융투자소득세 폐지 안내와 근로소득공제 구간 계산 오류를 수정했습니다.
- 기존 거래 전략, 승인, 원장, PAPER/LIVE 정책과 사용자 설정은 유지됩니다. 업데이트만으로 LIVE 거래가 자동 시작되지 않습니다.

Windows 자동 업데이트 자산은 `NoahAI-3.9.2.1-Setup.exe`, blockmap, updater 버전 `3.9.201`의 `latest.yml`, `release-manifest.json`입니다. 공개 v3.9.2.0을 기반으로 합니다.

실제 거래소·증권사 계정, 유료 AI 공급자 호출, 키움 OCX 로그인·실계좌 주문, 장시간 운용과 기존 설치본 업그레이드 화면 확인은 자동 빌드와 구분된 외부 검증 항목으로 기록합니다.
