# NoahAI v3.9.2.0

고객 포털 연결을 통합하고 AI 모델 선택, 전략 일괄 관리, OKX 후보 선정과 키움 종료 안정성을 보강한 Windows 릴리스입니다.

- 로그인, 세션 확인, 전략 허브, KPI, 원격 관리와 알림의 기본 고객 포털을 `https://noahai.net`으로 통합했습니다. 기존 계정·전략·원장·권한과 구 클라이언트 API 호환은 유지합니다.
- OpenAI, Claude, Kimi 모델 카탈로그와 요청 호환을 갱신했습니다. 기존 저장 모델·역할·API 키·비용 한도는 자동으로 바꾸지 않으며, 모델 추가가 투자 정확도나 수익을 보장하지 않습니다.
- 전략 스튜디오에서 여러 전략 버전을 선택해 삭제, 일시중지, PAPER 시작·재개와 정의/패키지 ZIP 내보내기를 수행할 수 있습니다. 기존 단건 승인, 삭제 보호, PAPER 평가 한도와 LIVE 권한은 유지합니다.
- OKX 일괄 시세 실패 후 개별 시세 fallback에서 거래대금과 변화율 근거가 누락되던 경로를 수정했습니다. 시세가 확인되지 않으면 0가격 후보를 만들지 않고 실패 단계를 구분합니다.
- 키움의 긴 읽기 요청이 종료를 막지 않도록 안전한 취소와 종료 순서를 보강했습니다. 이미 전송한 주문 응답은 임의로 취소하지 않습니다.
- GPT JSON 연결 점검, Claude sampling 호환, Kimi 토큰 사용량 키와 공급자별 모델 라우팅을 보강했습니다.
- 웹 로그인·회원가입·비밀번호 및 원격 설정 화면의 작은 창과 모바일 배치를 개선했습니다.
- 기존 PAPER/LIVE 승인, 전략 원문, 거래 원장과 손익 보호 정책은 유지되며 업데이트만으로 LIVE 거래가 자동 시작되지 않습니다.

Windows 자동 업데이트 자산은 `NoahAI-3.9.2.0-Setup.exe`, blockmap, updater 버전 `3.9.200`의 `latest.yml`, `release-manifest.json`입니다. 공개 v3.9.1.50을 기반으로 합니다.

실제 거래소·증권사 계정, 유료 AI 공급자 호출, 키움 OCX 로그인·실계좌 주문, 장시간 운용과 3.9.1.50에서의 실제 업그레이드 화면 확인은 자동 빌드와 구분해 외부 검증 항목으로 기록합니다.
