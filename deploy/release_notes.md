# NoahAI v3.9.2.5 — 생활금융 비교와 후속 관리

제품 버전 3.9.2.5 · 자동 업데이트 버전 3.9.205. 공개 3.9.2.4 이후 변경 내역입니다.

- 상품을 모르는 사용자도 상황 → 내부 후보 → 비교·상담 준비로 진행합니다. 처음 알아보기/받은 견적/기존 보험/저장 계획을 나누고, 견적 없는 계획도 저장할 수 있습니다.
- 대출 목적을 실제 후보 필터에 적용하고, 선택 보험의 안내·출처·버전을 로컬 설명과 동의한 AI 설명에 연결합니다. AI 모델·키는 설정 → AI 엔진/API에서 관리합니다.
- 보험 보장의 지급 방식·한도·자기부담·면책·감액, 확인한 기존 계약을 대조합니다. 대출은 월 부담·총비용·대환 초기 비용 회수 가정을, 예적금은 우대 조건·사용 날짜와 비상금 잔액 구간 금리를 비교합니다.
- 공통 재무 조건을 암호화 저장·반영·초기화하고 관심 상품의 변경·만료·철회 및 확인한 일정을 재점검합니다.
- 운영자가 검토 피드를 등록하면 앱 패치와 별도로 자료를 갱신합니다. 실패 시 마지막 자료와 기한을 보존하고 재시도·철회·롤백·재개를 지원합니다.
- 지정 상담사/기관의 담당자·응답 예정·회신 견적을 원래 비교에 가져올 수 있도록 API 계약을 확장했습니다. 반환 조건은 확인 전 우선 후보 선정을 보류하며 중복 반영을 막습니다.
- 가계부 검색·기간 조회·수정·다음 달 납부 초안과 JSON 가져오기 중복 확인을 추가했습니다. 조회 중·실패·등록 기록 없음을 확인된 0원과 구분합니다.

실제 상품 공급과 개인 견적, 상담 수신처는 운영 연결·계정 권한·인수가 필요합니다. 초기 보험 탐색은 4개 회사·7개 안내 자료이며 전체 시장 최적 추천이나 가입 승인 서비스가 아닙니다. 세금은 요청 귀속연도와 적용 연도 미검증을 구분한 참고 계산입니다. 거래 엔진·수익성 보호 기준을 완화하지 않습니다.
