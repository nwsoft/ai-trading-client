# NoahAI v3.9.1.37

키움 제한 조회 복구와 Windows 자동업데이트 채널을 수정한 안정 릴리스입니다.

## 주요 변경 사항

- 키움 OpenAPI+ 조회의 즉시 오류, 요청 간격 제한, 응답 시간 초과와 늦은 콜백을 구분해 처리합니다.
- 계좌 목록, 잔고, 보유종목, 미체결, 종목 정보, 시세, 일봉 및 거래내역 조회를 제한된 요청 계약으로 통일합니다.
- 조회 실패를 정상 분석 결과로 넘기지 않고 최초 실패 원인과 진단 단계를 보존합니다.
- 키움 호스트 연결이 끊겨도 자동 재로그인이나 주문 자동 재전송을 하지 않으며, 사용자가 상태를 확인한 뒤 수동 재연결하도록 유지합니다.
- 업데이트 확인은 GitHub의 stable/latest 릴리스를 기준으로 하며 prerelease와 다운그레이드를 자동 선택하지 않습니다.
- 저장한 확인 주기, 자동 다운로드, 안전 종료 후 설치 설정을 그대로 적용하고 공개 자산 누락이나 네트워크 오류는 명확히 표시합니다.

## Windows 배포 자산

- `NoahAI-3.9.1.37-Setup.exe`
- `NoahAI-3.9.1.37-Setup.exe.blockmap`
- `latest.yml` (updater `3.9.137`)
- 설치기에 포함된 x64 `NoahAIEngine.exe`와 x86 `NoahAIKiwoomHost.exe`

## 검증 범위

자동 회귀, Web production build, x64 엔진, 키움 x86 호스트, PE 아키텍처, IPC 시작·종료 및 배포 자산 해시는 빌드 과정에서 검증합니다. 실제 키움 계정 로그인, 증권사·거래소 실계정 연결, 3.9.1.36에서의 설치 업데이트·롤백과 장시간 PAPER 운용은 사용자 환경의 외부 검증 항목입니다.

거래 결과와 과거 검증은 수익을 보장하지 않습니다. LIVE 거래는 계정 권한과 위험 설정을 별도로 확인한 뒤 사용해야 합니다.
