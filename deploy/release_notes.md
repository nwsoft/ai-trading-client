## v3.9.2.4 — 상황부터 금융상품 탐색·선택형 AI 판단

공개 v3.9.2.3 이후 변경입니다. 제품 3.9.2.4 / 자동 업데이트 3.9.204.

- 보험 가입 여부와 필요한 보장, 대출 목적, 저축 목적부터 금융상품을 탐색하고 비교·상담 준비로 이어집니다.
- AI 엔진/API 설정에서 생활금융 빠른 판단 모델을 선택·저장하고 명시적으로 연결을 점검할 수 있습니다. 질문 미리보기·전송 동의 후 선택 모델이 목적을 분류하며, 사용자 검토 후에만 탐색에 적용합니다. 키가 없거나 응답이 불확실하면 로컬 안내를 유지합니다.
- 보험회사·종류·보장 검색, 내부 상품 상세와 최대 4개 관심 상품 비교를 제공합니다. 공개 안내 자료의 출처·확인일·재확인 기한·판매 상태를 표시하고 상담 준비에 선택 정보를 연결합니다. 실제 개인 견적·가입 승인·전 보험사 상품 공급을 의미하지 않습니다.
- Jev와 모델 선택 안내를 AI 엔진/API 설정 및 매뉴얼에 정리했습니다. Mac 소스 실행 시 오래된 화면을 검사하고 호환 Node 경로로 준비하도록 복구했습니다.
- Windows 앱과 설치 프로그램의 아이콘을 추적된 기존 NoahAI 로고로 고정했습니다. 누락·손상 사전 검사와 실제 실행 파일/설치기 PE 아이콘 리소스 대조를 추가하여 기본 Electron 아이콘 배포를 차단합니다.

실제 상품 공급사·상담사 연결, 전문가 검토, Provider 실계정 품질, 실계좌 주문·키움 OCX 로그인, 설치 업그레이드/롤백 및 장시간 운용은 별도 외부 인수 항목입니다. 실제 증거 없이 통과로 기록하지 않습니다. 소스 커밋·fingerprint·자산 해시 및 실제 아이콘 검증 증거는 release-manifest.json에 기록합니다. 기존 3.9.2.3 바이너리는 교체하지 않습니다.
