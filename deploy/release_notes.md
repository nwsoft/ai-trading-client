# NoahAI v3.9.1.44

장기 사용 시 로그·학습 기록의 저장/조회 부하를 줄이고 XAI 근거의 기관·모드 구분과 거래 기록 복구 경로를 보강한 Windows 릴리스입니다.

- 계정·기관별 새 학습 이벤트만 추가 저장하고 동일 근거의 중복 저장을 줄입니다. 기존 학습 원본과 거래/PAPER 원장은 보존합니다.
- 새 판단의 기관·모드 충돌은 원문·사유를 별도 보존하고 정상 학습에서 제외합니다. 기관 덮어쓰기를 제거하고 증권·주식·ETF 청산 XAI의 주문 결과 연결, 타임아웃 시 실제 주문 여부 미확정을 보강합니다.
- 닫힌 진단 로그는 검증된 압축 보관본으로 대체하며 공간 확보 후 기록을 재개합니다. 상세 로그는 24시간 임시 진단용으로 켜거나 끌 수 있습니다.
- 설정 → 업데이트 → 유지관리 · 저장소에서 용량·압축·기록 충돌·오류와 필요한 조치를 한국어/영어로 확인합니다. 정상 사용 중 버튼을 매번 누를 필요는 없습니다.
- 매매 판단·PnL 보호·회원 권한은 유지합니다. 저장소 최적화가 거래 기록 점검·복구를 대신하거나 LIVE 거래를 자동 시작하지 않습니다.
- Binance 분할 청산과 기존 청산 번호의 수량 불일치에서도 전체 체결 구간을 재구성합니다. 주문 소유권·수량·정산 증명이 완전한 기록만 원자적으로 수정하고 변경 전후를 보존합니다.
- 복구 조회 체크포인트, 현재 작업 진행률, 설정 창과 독립된 이어하기 및 일시 오류·정산 지연 재시도를 지원합니다. 완료 거래와 진입·청산·분할 체결 수를 구분해 표시합니다.

Windows 설치기에는 x64 `NoahAIEngine.exe`와 x86 `NoahAIKiwoomHost.exe`가 포함됩니다. 자동 업데이트 자산은 `NoahAI-3.9.1.44-Setup.exe`, blockmap, updater `3.9.144`의 `latest.yml`, `release-manifest.json`입니다.

자동 회귀와 패키징 검증은 수행하지만 실제 고객 API 정산, 전 기관 일별 계좌 대조, 키움 OCX·실기관, v43→v44 실제 업데이트, 절전·백신 파일 잠금·디스크 부족 및 장시간 PAPER는 별도 외부 검증 항목입니다. 자세한 범위는 `docs/V39144_STORAGE_TEST_PLAN.md`를 따릅니다.
