# NoahAI v3.9.1.49

거래 대시보드, PAPER 전략 평가 용량, 완료 봉 지표와 원격 진단을 보강한 Windows 릴리스입니다.

- 첫 거래 화면을 `거래 대시보드`의 요약 보기와 상세 로그로 정리했습니다. 오늘 통계, 기관 상태, 실제 판단 근거와 위험 상태를 한 화면에서 확인할 수 있습니다.
- LIVE/PAPER 통계 선택은 조회 범위만 바꾸며 실제 실행 모드나 LIVE 승인을 변경하지 않습니다. 늦은 응답과 타 기관 응답을 집계에서 격리하고 결측, 부분 실패와 청산 0건을 구분합니다.
- PAPER 전략 평가 슬롯을 일반 회원 최대 10개, 프리미엄 회원 최대 30개로 확대하고 평가 대상, 대기와 적용 상태를 분리했습니다. LIVE 적용 한도와 승인 정책은 유지됩니다.
- Level 1~5 전략에서 완료 봉 기준 지지선, 저항선, 변동성, 역사적 변동성, DI+/DI- 조건과 숫자 상태를 공통 실행 계약에 연결했습니다.
- 운용 요약은 관찰/확정 국면, 최근 평가 근거, 전략 버전과 위험 상태를 기존 메모리에서 읽기 전용으로 표시합니다. 새로운 수익 확률이나 자동 추천을 만들지 않습니다.
- 원격 관리에서 공유 대기, 성공, 장시간 미확인과 오류를 구분하고 허용된 거부 사유 및 개인정보를 제외한 지원용 진단 복사를 제공합니다.
- 실행용 UI 빌드 지문 검사를 추가해 오래된 `webui/dist`가 새 엔진과 함께 배포되는 문제를 차단합니다.
- PAPER/LIVE 승인, 원장, 기존 전략과 위험 보호 정책은 유지되며 업데이트만으로 LIVE 거래가 자동 시작되지 않습니다.

Windows 자동 업데이트 자산은 `NoahAI-3.9.1.49-Setup.exe`, blockmap, updater 버전 `3.9.149`의 `latest.yml`, `release-manifest.json`입니다. 공개 v3.9.1.48을 기반으로 합니다.

실제 거래소·증권사 계정, 키움 OCX 로그인, 실계좌 주문과 장시간 운용은 빌드와 분리된 운영 검증 기록으로 관리합니다.
