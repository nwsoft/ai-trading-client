# NoahAI v3.9.1.47

전략 등록·기존 버전 보완과 거래 기록 복구 진단을 강화한 Windows 릴리스입니다.

- 전략 원문을 임의로 바꾸지 않고 미완성 초안으로 보관하며, 정의가 필요한 조건은 질문과 답변을 거쳐 같은 전략의 새 버전으로 저장합니다. 이전 버전과 성과는 그대로 보존합니다.
- 완료 봉 기반 기간식, 제한된 latched 상태와 명시적 `STATE`/`UPDATE` 숫자 상태를 공통 IR, PAPER 실행과 재생 경로에 연결했습니다. 상태는 계정·기관·종목·전략 버전·모드별로 격리하고 재시작 후 복원합니다.
- 전략 조건 불일치 후 기본 AI 후보를 사용자 전략 성과로 기록하던 경로와 증권 명시 청산에 완료 봉·상태 문맥이 전달되지 않던 경로를 수정했습니다.
- Binance, OKX, Bybit, Bitget 선형 선물의 누락 청산 탐색과 11개 기관 공통 CSV/TSV 검토·가져오기를 제공합니다. 원본 수량·비용·시각·계정 근거가 불완전하면 적용하지 않습니다.
- 같은 진입 주문을 공유하는 원장과 추가 체결·부분 청산은 원본 배분 근거가 있을 때만 수량과 비용을 나눠 복구합니다. 근거 없는 FIFO 또는 혼합 거래 귀속은 추측하지 않습니다.
- 업비트·빗썸·코인원과 국내 증권의 날짜별 누락 청산 탐색, 체크포인트와 재개 처리를 보강했습니다. 기관이 제공하지 않는 이력이나 비용을 0으로 채우지 않습니다.
- 승인된 전략은 PAPER 실행과 선택형 과거 시세 재생을 분리했습니다. Level 5 연구 프로필, 날짜·종목·최대 보유 봉 선택과 실제 확보 기간 안내를 추가했습니다.
- 공개 Drive 폴더와 사용자 승인형 제한 자료를 전략 자료 입력에 연결했습니다. 제한 자료는 기본 브라우저 PKCE 승인을 사용하며 NoahAI 회원 로그인이나 거래 권한을 변경하지 않습니다.
- 거래 시작 거절 시 복구 대상, 필요한 근거, 다음 조치와 요청 ID를 표시하고 인앱 복구·진단 복사·선택적 AI 질문을 제공합니다. HTTP 409나 워커 장애를 성공으로 표시하지 않습니다.
- 공개 시세 PAPER와 가상 포지션을 계좌 API 필수 조건과 분리하고, 저장·DB busy 재시도와 장시간 기록 대조 경로를 보강했습니다.

Windows 설치기에는 x64 `NoahAIEngine.exe`와 x86 `NoahAIKiwoomHost.exe`가 포함됩니다. 자동 업데이트 자산은 `NoahAI-3.9.1.47-Setup.exe`, blockmap, updater `3.9.147`의 `latest.yml`, `release-manifest.json`입니다.

업데이트만으로 LIVE 거래를 시작하거나 미확정 손익을 무시하지 않습니다. 실제 기관 계좌 응답, 키움 OCX 로그인·주문, Drive 운영 앱 설정, v45/v46→v47 설치 보존과 장시간 운용은 별도 외부 검증 항목입니다. 자세한 범위는 `docs/V39147_RUNTIME_BOUNDARY_TEST_PLAN.md`를 따릅니다.
