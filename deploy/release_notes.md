## v3.9.2.19 — PAPER 청산 복구·거래 설정 정합성

제품 3.9.2.19 · updater 3.9.219 · renderer 3.9.2.19-ui.20261019.1.
공개 v3.9.2.18을 기반으로 다음 변경을 제공합니다.
기존 설정·인증정보·전략 원문/버전/승인·원장·과거 손익을 보존합니다.

- 병행 PAPER 청산은 관측한 가격·시각·비용·손익을 먼저 영속 저장하고 같은 intent로 재시도합니다. 원장 반영 후 응답 유실/포지션 저장 실패도 기존 event ID로 대조하여 중복 청산·나중 가격 재계산을 막습니다.
- 기존 병행 가상 포지션의 청산은 신규 진입과 분리합니다. 전역 PAPER/LEARNING 전환·병행 신규 진입 끄기·종목 미선정/진입 위험 보류 중에도 읽기 전용 시세 점검을 계속합니다. 신규 실주문·자동 LIVE 전환은 없습니다.
- 계정 런타임의 독립 점검은 5초 대기 간격을 사용합니다. API 응답 시간은 별도이며 실시간 체결 보장은 아닙니다. 증권은 이미 연결된 어댑터만 조회하며 백그라운드에서 새 OCX 로그인/UAC 승인을 실행하지 않습니다. 앱 종료 시 중단하고 영속 보유/대기 청산으로 복구합니다.
- 통계는 일반 PAPER/독립 병행 검증 및 기록된 자금 기준별로 나눕니다. 필터 변경 시 청산 수·승률·손익·비용도 같은 집계를 사용합니다. 전체 합계는 원본 손실을 포함하며 계좌 수익률이 아닙니다. 명목금액을 가상 기준자금으로 추정하지 않습니다.
- 과거·중단 관찰은 연속성 미확인으로 표시하며 앞으로 명시적인 관찰 공백은 전략 통과 근거와 구분합니다. 과거 -514.60 USDT 등의 원본 손익을 손절가로 절삭·삭제·재작성하지 않습니다.
- Binance 신규 진입에 교차/격리 설정을 연결하고 확인 실패 시 보류합니다. Bybit/OKX/Bitget도 설정 실패 후 그대로 진입하지 않습니다. 같은 방식이라는 거래소 확인은 정상 처리하며 기존 포지션 강제 전환·청산은 없습니다.
- Binance 새 TP/SL에 MARK_PRICE/CONTRACT_PRICE(Last)를 선택할 수 있습니다. 기본 MARK와 기존 보호주문은 유지하며 Last 주문도 보호주문 상태 감사가 인식합니다. 발동 가격과 실제 체결가격은 다릅니다.
- LIVE에도 적용 전략명을 표시합니다. LIVE 평가 상한 기본 10개를 유지하고 프리미엄 사용자는 설정에서 최대 30개로 조절할 수 있습니다. 우선순위·호환 범위·공유 자금·동일 종목·동시 포지션·위험 제한은 별도입니다.
- 거래 통계에서 현재 최적화 제안과 새 제안의 전후값·성과 근거·시각 이력을 미적용/검토 대기로 설명합니다. 이력은 계정 경로에 보존하며 기존 과거 이력을 생성하지 않습니다. 국면별 임계값 보정과 RSI/MA 계산 기간·시간봉의 자동 탐색은 구분합니다. 같은 시간봉 RSI 기간을 5m/10m로 부르던 로그를 봉 수로 정정합니다.
