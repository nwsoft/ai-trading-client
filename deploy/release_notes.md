# NoahAI v3.9.1.50

거래 현황 시각화와 거래 시작 오류 진단을 보강하고, 다중 거래소 워커 시작과 종료 과정의 경쟁 조건을 수정한 Windows 릴리스입니다.

- 거래 현황 첫 화면에 시장 국면, 세션 변화 이력, 실제 후보 검사 구성과 최근 검토 전략을 추가했습니다. 기존 런타임 스냅샷만 읽으며 새로운 외부 조회나 주문을 만들지 않습니다.
- 국면 원형과 검사 막대는 상태와 확인 결과를 표시합니다. 상승 확률이나 자동 추천 점수로 계산하지 않으며, 미수신·오래된 자료·정지 전 자료를 구분합니다.
- 거래 시작 실패 시 안전한 지원 코드, 실패 단계, 요청 ID와 원인별 다음 조치를 표시합니다. API 키, 계좌번호, 잔고, 주문 내역과 원본 로그는 공유 진단에 포함하지 않습니다.
- PAPER 시작 오류에는 관련 없는 LIVE 거래 기록 복구를 요구하지 않습니다. 응답 시간 초과나 통신 실패는 시작 성공 또는 실패로 임의 확정하지 않고 현재 실행 상태 확인을 안내합니다.
- OKX, Bybit, Bitget, Upbit, Bithumb, Coinone의 동일 기관 동시 시작을 직렬화했습니다. 종료 중인 기존 워커 교체와 초기화 중 정지 요청 이후의 지연 시작을 차단했습니다.
- 이전 워커의 종료 처리가 새 워커 핸들을 삭제하지 않도록 보강했습니다. 다른 기관의 초기화는 전역 잠금으로 막지 않습니다.
- 기존 PAPER/LIVE 승인, 전략, 원장, 손익 보호 정책을 유지하며 업데이트만으로 LIVE 거래가 자동 시작되지 않습니다.

Windows 자동 업데이트 자산은 `NoahAI-3.9.1.50-Setup.exe`, blockmap, updater 버전 `3.9.150`의 `latest.yml`, `release-manifest.json`입니다. 공개 v3.9.1.49를 기반으로 합니다.

실제 거래소·증권사 계정, 키움 OCX 로그인, 실계좌 주문, 49에서 신고된 특정 OKX 환경과 장시간 운용 검증은 자동 빌드와 구분해 외부 검증 항목으로 기록합니다.
