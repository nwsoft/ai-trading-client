# NoahAI v3.9.1.46

기관별 실행 경계, 보호주문·포지션 확인, 저장 재처리와 대용량 학습 보관을 강화한 Windows 릴리스입니다.

- Coinone을 다른 국내 현물 기관과 같은 공통 PAPER/LIVE 실행 조건으로 정렬했습니다. LIVE는 API 인증, 명시적 시작 확인, 회원·주문 범위와 위험 제한을 계속 요구하며 업데이트만으로 자동 시작하지 않습니다.
- 기관별 LEARNING/PAPER 시작에 LIVE 조건이 잘못 적용되던 경로와 국내 현물 공개시세 기반 분석·학습 시작을 수정했습니다.
- Bybit 포지션 `trading-stop`, OKX OCO, Bitget 양쪽 보호 접수, Binance 일반·Algo 보호 조회 계약을 보강했습니다. 조회 실패를 주문 없음으로 간주하거나 외부·부분 보호주문을 임의 취소하지 않습니다.
- 선물 포지션 조회 실패와 실제 빈 계좌를 구분하고, 증권 4기관도 명시적 조회 결과를 사용해 실패를 보유 0으로 표시하지 않습니다.
- 거래 기록 쓰기를 유지관리보다 우선하고, SQLite 잠금 시 확인된 주문·체결·진입·청산 근거를 로컬 재처리 큐에 보존합니다. 완료 상태는 늦은 NEW 응답으로 되돌아가지 않습니다.
- 기존 학습 보관 파일을 스트리밍 gzip과 해제 SHA-256 검증 후 전환합니다. 활성 파일·거래 원장·오늘 자료는 제외하고 실패나 변경 충돌 시 원본을 보존합니다.
- 업비트·빗썸·코인원의 잔여 자산 평가에서 가격 조회 실패, 미지원 마켓과 실제 0 값을 구분합니다. 관리 원장 불일치는 신규 진입을 보류하며 기존 손익 기준을 초기화하지 않습니다.
- 여러 로컬 파일·폴더와 CSV·TSV·XLSX·DOCX 전략 자료를 출처별로 묶어 분석합니다. 서로 다른 실행 조건은 자동 병합하지 않고 사용자 확인을 요구합니다.
- 신규 진입은 저장 공간 확인 실패 또는 가용 공간 64MiB 미만일 때 보류하지만 보호·청산 경로는 유지합니다.

Windows 설치기에는 x64 `NoahAIEngine.exe`와 x86 `NoahAIKiwoomHost.exe`가 포함됩니다. 자동 업데이트 자산은 `NoahAI-3.9.1.46-Setup.exe`, blockmap, updater `3.9.146`의 `latest.yml`, `release-manifest.json`입니다.

자동 회귀와 패키징 검증은 수행하지만 Coinone 실제 주문, 키움 OCX·실기관, 보호주문 실계좌 대조, v45→v46 실제 업데이트와 다기관 장시간 운용은 별도 외부 검증 항목입니다. 자세한 범위는 `docs/V39146_RUNTIME_BOUNDARY_TEST_PLAN.md`를 따릅니다.
