# NoahAI v3.9.1.48

현재 거래 가능 종목 검사, 기관별 백테스트 비용, 전략 자료 입력과 전략 목록 관리를 보강한 Windows 릴리스입니다.

- 7개 가상자산 거래소와 4개 증권사의 현재 거래 가능 종목을 진입 전에 확인합니다. 사용자 지정 종목, 고정 종목과 전략 후보도 같은 검사를 통과해야 하며, 기존 포지션 청산과 원장 복구는 보존됩니다.
- Binance는 현재 `exchangeInfo`, Bithumb와 Coinone은 공식 마켓 정보를 사용합니다. 공식 근거가 없거나 오래된 경우 신규 진입은 안전하게 차단합니다.
- 중첩 캐시가 원본 거래 가능 종목 정보의 유효 시간을 연장하지 않도록 만료 경계를 보강했습니다.
- 백테스트 비용을 거래소와 상품별로 구분하고 수수료, 슬리피지, 스프레드와 주식 매도세를 명시적으로 반영합니다. 계좌별 확정 요율이 아닌 값은 추정값으로 표시합니다.
- TXT/PDF 전략 자료를 초기화한 뒤 같은 파일을 다시 선택할 수 있으며, 처리 진행 상태와 실패 원인 및 재시도 안내를 표시합니다.
- 개인 전략 목록에 검색, 상태 필터와 생성일/이름 정렬을 추가했습니다. 기존 전략과 실행 상태는 유지됩니다.
- PAPER/LIVE 승인 및 위험 보호 정책은 변경하지 않았습니다. 업데이트만으로 LIVE 거래가 자동 시작되지 않습니다.

Windows 자동 업데이트 자산은 `NoahAI-3.9.1.48-Setup.exe`, blockmap, updater 버전 `3.9.148`의 `latest.yml`, `release-manifest.json`입니다.

실제 거래소와 증권사 계정, 키움 OCX 로그인 및 실계좌 주문 검증은 배포 빌드와 분리된 운영 검증 기록으로 관리합니다.
