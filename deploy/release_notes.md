# NoahAI v3.9.2.8 — PAPER 청산 복구·전략 평가 입력 보호

공개 v3.9.2.7 이후 변경입니다. 제품 3.9.2.8 / Windows updater 3.9.208 / renderer 3.9.2.8-ui.20261008.3.

- PAPER 부분·전체청산의 확정 원장과 잔여 포지션을 재시작 때 대조합니다. 저장 오류나 강제 종료 후 수량·완료 상태를 한 번만 복구하며, 같은 청산 재요청의 중복 기록과 충돌을 차단합니다. Binance 별도 PAPER 엔진에도 적용합니다.
- 해외 선물의 과거 기록에 계약 단위 근거가 없거나 잘못되면 원본을 보존하고 미확정/무효로 분리합니다. 검증 손익과 가용자금에서 제외하며, 복구 근거 부족·손상·원장 변경을 새 PAPER 평가로 우회하지 않습니다.
- 전략 개선 평가 전에 규칙·기본 봉·추가 시간봉 전체의 엄격 JSON 입력 근거를 검증합니다. NaN/무한대·직렬화 불가 입력은 재생 없이 실패를 보고하고 후보 승인·자동 적용·LIVE 승격을 허용하지 않습니다. 기존 규칙·IR·승인 및 시간 분리·비용·평가 자원 제한을 유지합니다.
- 대시보드와 업데이트 안내 카드가 현재 매뉴얼의 버전·변경 제목·요약을 사용합니다.

Windows 전체 자동 검사, x64 엔진·x86 Kiwoom 호스트, bootstrap/인증 IPC, 패키지 정본 아이콘과 소스/자산 해시는 게시 전에 검증합니다. 실제 OCX 로그인·LIVE 계정·.7→.8 설치 및 자동 업데이트·롤백·24/72시간 운용·외부 서비스 인수는 별도 미실시 항목입니다. 허브 서버 배포는 포함하지 않습니다. pending 청산 복구가 있는 .8 데이터를 .7로 넘겨 거래를 재개하지 마세요.
