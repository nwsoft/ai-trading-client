# NoahAI v3.9.2.2

생활금융에서 보험 자료를 안전하게 정리하고 근거를 직접 확인할 수 있는 로컬 보험 워크스페이스와 초보자용 금융상품 비교 화면을 추가한 Windows 업데이트입니다.

- 보험 PDF·PNG·JPEG 자료와 직접 입력한 보장 내용을 계정별 암호화 저장소에서 관리합니다.
- 보험 계약의 보장, 보험료, 납입·만기·갱신 조건을 원문 근거와 대조하고 미확인 또는 상충 항목을 구분합니다.
- 최대 두 계약의 확인된 사실을 비교하며 보험료 차이를 절감 보장이나 상품 추천으로 표시하지 않습니다.
- 근거가 삭제되거나 내용이 수정되면 기존 확인·분석 결과를 무효화하여 오래된 판단이 유지되지 않도록 했습니다.
- 검토용 질문지와 TXT 보고서를 만들고 암호화 백업을 생성·복원할 수 있습니다.
- 대출 상환 방식과 예금·적금의 세전·세후 가정을 직접 입력해 비교하는 초보자용 안내 화면을 추가했습니다.
- 금융상품 비교 화면의 AI 기능은 사용자가 명시적으로 전송할 때만 동작하며 입력한 보험 자료를 자동 전송하지 않습니다.
- 기존 전략, 승인, 원장, 가계부, PAPER/LIVE 정책과 사용자 설정은 유지됩니다. 업데이트만으로 거래나 보험 가입·해지·상담 접수가 실행되지 않습니다.

Windows 자동 업데이트 자산은 `NoahAI-3.9.2.2-Setup.exe`, blockmap, updater 버전 `3.9.202`의 `latest.yml`, `release-manifest.json`입니다. 공개 v3.9.2.1을 기반으로 합니다.

자동 OCR·약관 의미 자동 판정·전 보험사 추천·실시간 상품 견적·가입/해지·외부 상담 접수는 제공하지 않습니다. 실제 약관 전문가·법무 검토, 실제 계정·키움 OCX·거래소 주문, 장시간 운용과 기존 설치본 업그레이드 화면 확인은 자동 빌드와 구분된 외부 검증 항목으로 기록합니다.
