## v3.9.2.16 — PAPER 기간 선택 위치·버전별 변경 안내 (미게시 후보)

제품 버전 3.9.2.16 · updater 3.9.216 · renderer 3.9.2.16-ui.20261016.3

- 전략 사용하기 첫 화면에서 1·3·7일 기간 설정 위치를 안내하고 해당 버전으로 바로 이동합니다.
- 저장 전략/검색 결과가 없을 때 다음 단계를 안내합니다. 기간 저장·일시정지·재개·최종 적용 조건은 유지합니다.
- 메뉴얼과 CHANGELOG에 .14와 .15 변경을 구분하고 .15 분봉/TR 후속 내용을 보완했습니다.

공개 .15를 보존하는 소스 후보입니다. 새 Windows 설치기/배포·기관 인수는 미실시입니다.

- 앱 재실행: macOS의 닫힌 창 참조에 접근하던 오류를 수정하고 창 수명주기 회귀 검사를 Windows 자동 검사에도 추가했습니다.

- 전략 예제: 멘토·기존 화면·Web 예제 정본을 통일했습니다. LONG/SHORT·EMA·RSI·시간봉을 보존하고 ATR 수치 미정·손익비/익절 차이·미지원 필터를 정확히 안내합니다. 기존 저장 전략은 바꾸지 않습니다.

- 눌림목 예제의 교차 연산을 원문→실행 규칙에 그대로 보존합니다. 전체시장/시장전체 국면 기준 재분석 누락을 수정했습니다.
- 멘토 손실률 입력·검증·안내를 기존 저장 한도 0.05~2%로 통일해 후보 생성 후 저장 실패를 예방합니다.
- 공유 전략 70개 저장 규칙·승인·기록·권한 보존, 원문 재분석70/70, 공유 TXT10개, 관리 예제8개와 멘토 합성 조합을 검사했습니다. 고객 전략을 삭제하거나 자동 변환하지 않습니다.

## v3.9.2.15 — 어시스턴트·전략 운용·증권 분봉 개선

제품 버전 3.9.2.15 · updater 3.9.215 · renderer 3.9.2.15-ui.20261015.3

- 설치 엔진의 일반·심층 어시스턴트 안내 의존성을 수정하고 실패 사유와 지원 ID를 보완했습니다.
- 파일별 독립 전략 초안, 명시적 내용 승인, 새 버전 이동과 기관별 승률·증권 선정/학습 근거를 개선했습니다.
- HOLD와 합의 제한을 구분하고 일반 주식 SELL 방향, 명시적 cooldown 0과 주문 거절 사유를 수정했습니다.
- 키움 opt10080/32bit IPC와 한국투자 과거·당일 분봉을 실제 평가에 연결하고 완료봉·조회 예산·캐시·연속 무응답 보호를 보완했습니다.

공개 v3.9.2.14의 후속 버전입니다. 기존 승인·PAPER/LIVE·위험 검사 경계를 유지하며 설정·규칙·권한 변경, 자동 재로그인·주문 재전송을 수행하지 않습니다. 한국투자 모의 서버 표본 부족, 미래에셋/신한 분봉과 증권 분봉 기간 재생은 별도 한계입니다.

실제 설치/업데이트/롤백·기관/OCX·실마이크·24/72시간 PAPER·외부 인수는 pending입니다. 설치기는 unsigned입니다.
